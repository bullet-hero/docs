# gv 0.10.1

新的内置关卡、版本行中的构建名称，以及更小的Android正式版

- 随游戏提供的两个测试关卡被一个演示关卡`New zero demo`取代
- 设置中的版本行除了版本，还写出构建：`gv X, sv Y, mg Z, Windows, Steam, Release`，也就是平台、商店和构建类型。每份日志的第一行写的也是同样的内容，所以错误报告和附带的日志总是指向同一个构建
- 关卡浏览器打开时，所有来源筛选器都处于开启状态，即使只有一个来源，也会显示来源行。存在但被筛掉的关卡，看起来就像丢失了一样
- 正式版构建不再带调试符号。在Android上，124.9 MB的正式版因此减少了25.7 MB

提交：游戏`41316a8d`，SDK `cdcc3d4d`
