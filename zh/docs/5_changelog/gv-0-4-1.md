# gv 0.4.1

关卡编辑器从时间轴和层级成长为完整的编辑器，关卡有了后期处理、音频效果和可重复的随机性

## 编辑器

- 用于物体、关键帧和关卡事件的检视器。在这个版本之前，编辑器只有时间轴、层级，几乎没有别的
- 五个时间轴：关卡、一个选中物体的关键帧、关卡事件、音频和预制件
- 视口中的控制柄，用于位置、旋转、缩放、尺寸、锚点和轴心。每种模式都有自己的快捷键
- 预制件经过重做：模板在单独的预制件模式中编辑，每次放置都可以覆盖模板的值
- 关卡资源在编辑器中管理：音频、纹理、字体、碰撞体、特效、主题和预制件。特效、主题、碰撞体和预制件也可以从现成的库中选取。文件选择目前只在电脑上可用
- 自定义碰撞体编辑器、曲线编辑器、渐变编辑器，以及带预览的缓动预设
- 物体可以更换类型和父级，无需重新创建
- 选中项以流动的虚线轮廓绘制
- 可以直接从编辑器启动关卡。化身在编辑器中可见，后期处理可以在编辑器中关闭
- 关卡设置中新增了作者、许可证、生成器和规则检查，规则检查会找出关卡中的问题并提出修复

## 游戏

- 后期处理作为关卡事件，共12种：模拟故障、数字故障、泛光、色差、颜色曲线、胶片颗粒、镜头畸变、提升/伽马/增益、运动模糊、阴影/中间调/高光、暗角和白平衡
- 音频轨道上的音频效果，共11种：合唱、压缩器、失真、回声、镶边、高通滤波、低通滤波、标准化、参数均衡、变调和混响
- 音乐同步经过重写。游戏跟随音频时钟，用轻微改变音高来纠正小的不同步，而不是跳跃，因此每隔几帧出现的音频卡顿消失了
- 修复：在编辑器中，时间轴光标会让关卡时钟变慢约15%
- 随机性可重复：同一关卡使用同一种子，在任何设备上的游玩都相同。关卡界面有种子字段，并带有设置随机种子和重置的按钮
- 关卡界面显示关卡及其资源的作者和许可证

## 关卡与格式

- 物体的存在时间由起点和长度组成。每条边都可以用锚点固定到父级的一条边上，之后便跟随那条边
- 图层相对于父级计算，而不是一个绝对数字
