# gv 0.16.0

新しいバージョンのファイルは開かずにゲームの更新を求め、保存しない匿名モードが加わり、大きなレベルでエディターが速くなりました

## バージョンと保存

- 新しいバージョンのゲームのファイルは開かず、代わりに`更新が必要`ウィンドウが表示されます：レベル、インポートするアーカイブ、クリップボード上のエディターの内容が対象です。`ダウンロード`でサイトのダウンロードページが開きます。レベル一覧では、そのようなレベルに`新しいバージョンのゲームで作成されています`と表示されます。以前は、エディターが警告のあとで新しいレベルを開くよう提案していました
- 新しいバージョンで保存された設定や統計には手を付けません。ゲームはデフォルト値で動き、閉じるまで自分のデータを何も保存せず、どうするかを尋ねます：`保存しないまま続ける`または`データを上書き`。レベル自身の統計が新しい場合、そのカードにはベスト記録の代わりに説明が表示されます
- 新しい設定`ゲームデータを保存しない（匿名モード）`が加わりました。オンの間、ゲームは設定も統計も書き込まず、その間にプレイした内容はディスクに残りません。[[12_launch-arguments|起動引数]]`--suppress-game-saves`で、その起動の間ずっとオンにできます
- `--autosave`でその起動のエディターの自動保存が設定されている場合、`自動保存`の設定にそのことが表示されます

## ゲーム

- マウスボタンを押したまま操作しているとき、一時停止ボタンの上を通っても操作が途切れなくなりました。レベル上で始めた押下はどこへ動かしても操作のままで、ボタン上で始めた押下はボタンのものになります
- 1ユニットより近い地点へのカーソルダッシュが、無視されなくなりました。アバターがまだ立っていない目標なら、距離に応じて短くなったダッシュが行われます
- AndroidではVulkanが必要になったため、Google PlayはVulkanのない端末にゲームを表示しなくなりました。そうした端末では画面が真っ黒になっていました

## エディター

- 大きなレベルでエディターが速くなりました。画面に表示されていないタイムラインやパネルは、編集のたびに作り直されなくなり、表示されたときに追いつきます。「このコピーはどの配置に属するか」という問いには、選択した各オブジェクト、フィールド、キーフレームのトラックごとにレベル全体を走査するのではなく、編集ごとに1つのインデックスから答えます
- 編集によって、イベントとオーディオのキーフレームの選択がリセットされなくなり、Localタイムラインのキーフレームの選択も消えなくなりました
- 通常の編集で、元に戻す・やり直しの音が鳴らなくなりました。鳴るのは元に戻すとやり直しのときだけです
- 同じスパンを持つ2つのクリップをクリックすると、上に描画されている方が選択されます。以前は隠れている方が選択され、プレハブモードではネストしたテンプレートの内容をクリックするたびに、その配置が選択されていました
- ネストしたプレハブから出るとき、外側のテンプレートに復元する選択があっても、`Collection was modified`エラーが出なくなりました
