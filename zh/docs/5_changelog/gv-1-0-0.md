# gv 1.0.0

正式发布：`gv 1.0.0`保存的文件可以在之后的每个版本中打开，来自更新版本的文件会提示你更新游戏

## `gv 1.0.0`对你意味着什么

- **你的文件会一直可用**。由`gv 1.0.0`保存的关卡、你的设置和统计数据，可以在之后每个版本的游戏中打开。文件格式发生变化时，新版本会在读取时自动转换旧文件
- **更新的文件会被拒绝打开，而不是只读一半**。来自更新版本的关卡或存档会打开`需要更新`窗口，`下载`会转到下载页面。游戏不会猜测它读不懂的内容，所以不会有任何东西丢失或被悄悄改变。更多：[[5_troubleshooting]]
- 游戏和SDK的版本是`gv 1.0.0`和`sv 1.0.0`。SDK仍在与游戏一起发展，所以它的编程接口暂时不保证保持不变

## 改动内容

- **旧的二进制关卡无法使用**。`gv 1.0.0`之前的版本以`Blob`保存的关卡无法在`gv 1.0.0`中打开，因为二进制格式在正式发布时重新开始了。以`Json`保存的关卡不受影响。如果你有旧的`Blob`关卡，请先在制作它的那个版本中打开，并保存为`Json`
- `指南`分区已从编辑器设置中移除。指南现在放在网站上，`社区`分区中有一个`文档`链接，会以你的语言打开它
- 切换语言时，关卡列表会重写自己的标签。以前来源按钮、排序按钮和关卡单元格会停留在旧的语言
- 游戏的所有文本（两种语言）现在都公开在文档仓库中，所以可以在那里报告错别字或不好的翻译，也可以自己修正：[https://github.com/bullet-hero/docs](https://github.com/bullet-hero/docs)
