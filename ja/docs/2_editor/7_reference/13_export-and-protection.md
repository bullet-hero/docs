# エクスポートと保護

エクスポートは、レベルが使うすべてのファイルと一緒に、レベルをゲームの外にフォルダーかアーカイブとして保存します。パスワードはディスク上のレベルの内容を暗号化し、忘れたパスワードは復元できません

## レベルのエクスポート

レベル設定の`{{ui:settings_level-settings_publication}}`タブにあります：保存先は`{{ui:editor_share_archive}}`、モードは`{{ui:editor_share_format}}`で選び、保護されたモードには`{{ui:editor_share_passphrase}}`が必要です。詳細：[[17_publishing]]

アーカイブには、レベル、そのメタデータ、レベルが使うすべてのファイルが入ります。レベルフォルダーの外にある曲もコピーされます。その参照は、アーカイブ内のコピーを指すように書き換えられます

AIアシスタントがレベルについてのメモを保存するレベルの`ai`フォルダーも、レベルのメタデータで`{{ui:settings_level-settings_metadata-level-ai-share}}`のチェックが外されていない限り、まとめて入れられます。パスワード付きのモードでは決して入りません：暗号化されたレベルの隣に読める設計メモがあれば、パスワードの意味がなくなるからです。フォルダーが除外されたときはレポートに表示されます。詳細：[[7_ai-assistant#aiフォルダー]]

| `{{ui:editor_share_format}}` | 得られるもの | 開くのに必要なもの |
|---|---|---|
| `{{ui:settings_level-settings_export-mode_folder}}` | レベルがディスク上に持っているのと同じフォルダー。圧縮して送れます | 不要 |
| `{{ui:settings_level-settings_export-mode_folder-protected}}` | 同じフォルダーで、レベルドキュメントが暗号化されたもの。メタデータ、カバー、メディアは読めるままなので、レベルブラウザーには引き続きカードが表示されます | レベルドキュメントにはgpg |
| `{{ui:settings_level-settings_export-mode_zip}}` | ファイル1つ | Windowsのエクスプローラーでダブルクリック。インストールは不要 |
| `{{ui:settings_level-settings_export-mode_targz}}` | ファイル1つ | 任意のアーカイバー |
| `{{ui:settings_level-settings_export-mode_zip-encrypted}}` | 独自のAES-256暗号化を持つzip。アーカイブにパスワードを付けるといえば、ふつうはこれです | 7-Zipなどのアーカイバー。パスワードを尋ねてきます |
| `{{ui:settings_level-settings_export-mode_zip-protected}}`、`{{ui:settings_level-settings_export-mode_targz-protected}}` | 同じアーカイブを`.gpg`で包んだもの | gpg |

Windowsのエクスプローラーは、パスワード付きのどの形式も開けません。それがパスワードの代償です

ライブラリのコレクションや単一のリソースも、パスワード付きを含め、同じ5つのアーカイブモードでエクスポートできます。2つのフォルダーモードはレベル専用です。詳細：[[17_publishing#アーカイブ]]

> [!tip] ヒント
> 持ち運べなかったもの（URLの先にあるリソース、何からも参照されていないファイル）は、エクスポート後のレポートに一覧で表示されます

> [!warning] 警告
> パスワードは、転送中の内容と気軽なコピーから守るものです。DRMではありません：ファイルとパスワードを持っている人は、いつでも開けます

## レベルの保護

ディスク上のレベルドキュメントを暗号化します。レベルを開くとパスワードを尋ねられます

保護されるのは**内容**です：オブジェクト、キーフレーム、テーマ。メタデータ、カバー、メディアは読めるままです。だからレベルブラウザーは、パスワードなしでもレベルのカードを表示します

パスワードはセッションごとに1回だけ尋ねられ、メモリーにだけ保持されます。どこにも書き込まれないので、自動保存は動き続けます

保護を解除するには、フィールドを空のままにして`{{ui:settings_level-settings_protect-apply}}`を押します

> [!caution] 注意
> 忘れたパスワードは復元できません。鍵はどこにも保存されておらず、パスワードなしでファイルを開く方法はありません
