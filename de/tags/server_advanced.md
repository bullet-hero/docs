# Fortgeschrittener Serverbetreiber

Ein großer Betreiber, der bereit ist, einen öffentlichen Server zu betreiben, den offiziellen zu erweitern oder einen eigenen Server zu schreiben

Einen Server gibt es noch nicht. Hier steht, was über den offiziellen Server OWS und die Community-Server NOWS entschieden ist und was das SDK schon für sie leistet
