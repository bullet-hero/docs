# gv 0.12.0

带切线的曲线、沿线段的随机值、主题槽位名称，以及一长串时间轴和预制件模式的修复

## 游戏

- 化身绘制在图层0之前，而不是之后。新物体所在图层上的内容现在位于玩家后面，要遮住玩家，需要把内容放到图层1。从*Afterbeat*导入的关卡会相应地提高一个图层

## 编辑器

- 曲线可以用切线编辑，而不只是移动点的位置。选中的关键帧两侧各有一个手柄，`断开切线`把它变成尖角，开启`加权切线`后，手柄的长度就是它的权重。预览线也会考虑权重，显示真正会播放的曲线
- `Q W E R T`从左到右切换底部面板的五个时间轴：关卡、局部、音频、事件、预制件。因此`敲击测速`失去了`T`键。速度在`节拍网格`窗口（`Shift+T`）中敲击，`敲击测速`的按键可以在`快捷键`中指定
- 预制件模式的选择方式与编辑器其他部分相同：Ctrl+单击添加片段，预制件标签页有`框选`工具，多个物体在一个检视器中编辑，并以一个撤销步骤删除或复制。以前它一次只能选中一个物体
- 在时间轴上拖动物体时会带着它的子物体一起移动，所以层级保持自己的时间安排。一次撤销即可恢复整棵子树
- 每个时间轴标签页都记住自己的工具。`编辑器` > `时间轴`中的`切换标签页时重置工具`决定标签页是否回到`选择`，默认开启
- 音频设置中的`编辑器播放`是编辑器内播放的单独音量，游戏本身的音量保持不变
- 自动保存会保存关卡本身，而不只是`backups/`中的副本。以前它只做副本，于是一晚上的编辑都在`backups/`里，而不在浏览器显示的那个关卡中
- 测试运行结束后，编辑器回到之前的状态：相机框、选中项和控制柄都能正常工作，如果原来有预览玩家，它也会回到原位，播放头和速度显示的与按下播放之前相同
- 点击局部时间轴的最后一格，会在长度为60帧的物体的第60帧放置关键帧，而不是第59帧

## 关卡与格式

- 主题槽位可以有名称。引用槽位12的颜色字段显示`12 - background`，而不是`12`
- 随机向量或颜色可以落在一条线段上，而不是一个矩形内：`A到B随机`只随机一个数，数值沿直线从`起点`移动到`终点`。这样随机色调读起来是一种色调，随机漂移是一个方向。给某个轴的两端设置同一个数，它就会保持不动
- 图像资源有自己的平铺和偏移（`导入`区块中的`平铺X`、`平铺Y`、`偏移X`和`偏移Y`）。所有使用这张图像、且没有自己UV关键帧的物体都会采用它们，所以精灵表只需描述一次
