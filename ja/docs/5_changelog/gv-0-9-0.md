# gv 0.9.0

体力と本当の当たり判定がアバター上に直接表示され、新しいバージョンのレベルは警告のあとで開きます

- アバターの体は四角形のグリッドで、体力が減ると外側から中心に向かって四角形が欠けていきます。調子の悪いプレイはバーではなくプレイヤー自身に表れます。グラフィック設定の`破片エフェクト`でこれをオフにできます：その場合、体は1つの四角形になり、代わりに暗くなります
- アバターの点の輪は当たり判定のちょうど上にあります：幅1ユニットの体に対して半径0.4です。シルエットが当たり判定だったことは一度もなく、本当の位置が見えるようになりました。同じ輪がライフも数えます：明るい点は残っているライフ、暗い点は使い切ったライフです
- インターフェース設定の`当たり判定リングの不透明度`で輪の見え方を設定します。デフォルトは0.6です。0でオフになりますが、レベルは輪が見えるプレイヤーを前提に作られています
- チェックポイントに`体力回復`の設定が追加されました：レベルがチェックポイントを通過した瞬間に、ライフが全回復します
- 新しいバージョンで作られたレベルは、レベルブラウザーで`新しいバージョン`と表示され、警告のあとで開きます。読み込み中に何かを置き換える必要があった場合、ゲームは先にバックアップを書き出し、置き換えた数を報告します
- `ループ`をオフにしたエフェクトはオンのときよりずっと少ないパーティクルしか放出せず、色のグラデーションが効かなくなったように見えていました。1回だけのエフェクトも、ループするエフェクトが維持するのと同じ数のパーティクルを放出するようになりました
