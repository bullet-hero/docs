# Экспорт видео

Редактор рендерит открытый уровень в видеофайл через ffmpeg, установленный на вашем компьютере. Рендер идёт офлайн, кадр за кадром, поэтому видео точное, как бы медленно ни работал компьютер

Экспорт работает на Windows, macOS и Linux. На телефонах его нет

## Где найти

- `{{ui:editor_video-export_open}}` в боковой колонке настроек уровня
- команда `{{ui:cmd_editor_export-video}}` в палитре команд

Окно открывается поверх редактора. Пока видео рендерится, окно нельзя закрыть: рендер прерывает `{{ui:editor_video-export_stop}}`

## Установка ffmpeg

ffmpeg не входит в игру. Установите его один раз, и окно найдёт его само. Нужна версия `{{v:ffmpeg.min-version}}` или новее. Более старая отклоняется, и окно пишет, какую версию нашло

| Система | Команда установки |
|---|---|
| Windows | `winget install ffmpeg` |
| macOS | `brew install ffmpeg` |
| Linux | пакет вашего дистрибутива, например `sudo apt install ffmpeg` |

> [!warning] Предупреждение
> Некоторые дистрибутивы Linux поставляют ffmpeg старше `{{v:ffmpeg.min-version}}` (в Ubuntu 24.04 это 6.1). Тогда установите свежую сборку с сайта ffmpeg и укажите её окну вручную

Окно ищет ffmpeg в таком порядке:
1. файл, выбранный через `{{ui:editor_video-export_ffmpeg_choose}}`. Тогда больше нигде не ищется
2. путь в переменной окружения `BH_FFMPEG`
3. `tools/ffmpeg` в папке данных игры
4. каждая папка из `PATH`
5. папки, куда пишут обычные установщики

`{{ui:editor_video-export_ffmpeg_auto}}` забывает выбранный файл и ищет заново. `{{ui:editor_video-export_ffmpeg_check}}` повторяет проверку, например сразу после установки

В вашем ffmpeg могут быть аппаратные энкодеры (NVIDIA, AMD, Intel, Apple). Окно пробует каждый на десятой доле секунды чёрного кадра и использует только те, что реально работают на этом компьютере

## Параметры окна

| Параметр | Что делает |
|---|---|
| `{{ui:editor_video-export_container}}`, `{{ui:editor_video-export_codec}}` | вид файла и способ сжатия, см. форматы ниже |
| `{{ui:editor_video-export_resolution}}` | размер видео. Ширина и высота - чётные числа от `{{v:video-export.min-size}}` до `{{v:video-export.max-size}}` |
| `{{ui:editor_video-export_fps}}` | кадров в секунду в видео, до `{{v:video-export.max-fps}}`. Не зависит от частоты кадров самого уровня. Ниже `{{v:video-export.min-simulation-rate}}` каждый кадр симулируется в несколько шагов, чтобы бот играл как в игре |
| `{{ui:editor_video-export_range}}` | весь уровень, диапазон цикла таймлайна или свои начальный и конечный кадры |
| `{{ui:editor_video-export_quality}}` | сколько места займёт видео. Скрыто для форматов, которые и так без потерь |
| `{{ui:editor_video-export_full-chroma}}` | цвет для каждого пикселя, а не для каждого второго. Тонкие цветные линии чётче, файл больше |
| `{{ui:editor_video-export_seed}}` | сид случайности уровня. `0` оставляет тот, что сейчас в редакторе |
| `{{ui:editor_video-export_preroll}}` | сколько секунд до начала проигрывается, но не записывается, чтобы у эффектов уже была история. По умолчанию `{{v:video-export.default-preroll}}`, максимум `{{v:video-export.max-preroll}}` |
| `{{ui:editor_video-export_bot}}` | по умолчанию `{{ui:enum_bot-kind_reflex}}`, ещё `{{ui:enum_bot-kind_warm}}` или `{{ui:enum_bot-kind_none}}` для видео без аватара. Попадания во время экспорта ничего не делают |
| `{{ui:editor_video-export_post-processing}}`, `{{ui:editor_video-export_effects}}` | те же переключатели, что в редакторе, только для видео |
| `{{ui:editor_video-export_audio}}` | дорожки уровня в видео |

У каждого параметра в окне есть свой `?`.

Интерфейс редактора, сетка, гизмо, выделение и границы камеры в видео никогда не попадают. Кадр строит камера уровня, а то, что не покрывает её соотношение сторон, заполняют чёрные полосы

## Скорость рендера

Видео не зависит от скорости компьютера. Время уровня и бот продвигаются ровно на один кадр видео за каждый отрендеренный кадр, поэтому медленный компьютер рендерит то же самое видео, только дольше

`{{ui:enum_bot-kind_warm}}` рассчитывает весь путь до первого кадра, и окно показывает, сколько уже готово. Если путь не найден, экспорт останавливается и просит выбрать другого бота

## Форматы

Формат - это два выбора: `{{ui:editor_video-export_container}}` и `{{ui:editor_video-export_codec}}`. В списке только пары, которые умеет ваш ffmpeg. Строка под ними говорит, какой звук идёт в паре и какой файл получится

| `{{ui:editor_video-export_container}}` | `{{ui:editor_video-export_codec}}` | Звук | Для чего подходит |
|---|---|---|---|
| `{{ui:editor_video-export_container_mp4}}` | H.264, HEVC, AV1 | `{{ui:editor_video-export_audio-codec_aac}}` | отправить и загрузить куда угодно |
| `{{ui:editor_video-export_container_mkv}}` | H.264, HEVC, AV1, VP9, FFV1 | `{{ui:editor_video-export_audio-codec_flac}}` | архив, FFV1 вообще без потерь |
| `{{ui:editor_video-export_container_mov}}` | H.264, HEVC, ProRes | `{{ui:editor_video-export_audio-codec_pcm}}` | монтаж в Premiere, DaVinci Resolve, Final Cut |
| `{{ui:editor_video-export_container_webm}}` | VP9, AV1 | `{{ui:editor_video-export_audio-codec_opus}}` | веб |
| `{{ui:editor_video-export_container_gif}}`, `{{ui:editor_video-export_container_webp}}`, `{{ui:editor_video-export_container_apng}}` | - | без звука | короткие зацикленные клипы для чатов и страниц |
| `{{ui:editor_video-export_container_sequence}}` | PNG, JPEG, WebP, TIFF | `audio.wav` рядом с кадрами | импортирует любой монтажный редактор |
| `{{ui:editor_video-export_container_audio}}` | WAV, FLAC, MP3, Opus | сам формат | только звук уровня, ничего не рендерится |

GIF берёт одну палитру из 256 цветов на весь клип. Делайте его коротким и небольшим: GIF всего уровня весит намного больше, чем MP4 того же уровня

## Куда попадает видео

По умолчанию видео сохраняется в `recordings/<id уровня>/` в папке данных игры, с именем уровня и временем экспорта. `{{ui:editor_video-export_output_folder}}` открывает эту папку. `{{ui:editor_video-export_output_choose}}` сохраняет следующее видео в любое другое место

Записи остаются, когда вы удаляете уровень. В перенос профиля они попадают, только если отметить `{{ui:settings_profile-transfer_category-recordings}}`

## Звук

Звук видео не записывается с динамиков, и во время экспорта вы ничего не слышите.

Если включён `{{ui:editor_video-export_engine-audio}}` (по умолчанию) и у дорожек есть эффекты, после кадров уровень проигрывается ещё раз в реальном времени и записывается звук самой игры вместе с эффектами. Экспорт длится дольше на длину диапазона. Если выключен, дорожки сводятся отдельно, с ключами громкости и панорамы, но без эффектов. `{{ui:editor_video-export_container_audio}}` всегда сводится отдельно

> [!warning] Предупреждение
> Не закрывайте игру, пока рендерится видео. Окно напоминает об этом всё время записи

## Чего нет в видео

- эффектов на аудиодорожках, но только при выключенном `{{ui:editor_video-export_engine-audio}}` или в `{{ui:editor_video-export_container_audio}}`. Окно предупреждает, если они есть в уровне
- прозрачного фона
- записи того, как играли вы: в видео может играть только бот
