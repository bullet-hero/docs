# gv 0.6.2

プレハブのフラット化、設定用の起動引数、全画面表示とウィンドウサイズの修正

- `プレハブをフラット化`は、プレハブの配置を通常のオブジェクトに変えます：テンプレートとのつながりはなくなり、オブジェクトは元の位置にそのまま残ります。プレハブのインスペクターのボタンとエディターのコマンドとして使え、`プレハブのフラット化`モディファイアーは範囲内のすべての配置に同じことを行います。各配置のオーバーライドはすでにオブジェクトに書き込まれているため、フラット化のあともレベルの見た目は変わりません
- `--settings`はメニューを開いてその上に設定を表示し、`--settings graphics`（またはほかのタブ名）は特定のタブを開きます
- 修正：全画面表示で、ぼやけた640x480の画面に帯が付いて表示されることがあり、全画面を抜けて入り直しても直りませんでした。全画面表示は常に画面のネイティブ解像度を使うようになり、描画解像度を下げたいときは`レンダースケール`を使います
- 修正：全画面表示を一度抜けると、ゲームがウィンドウのサイズを画面全体のサイズとして記憶していました
- 修正：タイムラインのキーフレームをクリックしても、インスペクターでそのタブが開かないことがありました

コミット：ゲーム`5a750402`、SDK `6d399f6c`
