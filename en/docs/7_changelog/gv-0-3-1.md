# Version 0.3.1

The editor learns to create objects, undo them and list them in the hierarchy

Five days after 0.3.0 the editor became more than a level player with a save button

- Objects can be created, and undo and redo work for it
- The object hierarchy shows the level's objects, and an object can be hidden from there
- A level can be deleted, after a confirmation
- Notifications and a console panel tell you what the editor just did
- Playing a level inside the editor behaves like playing it in the game

The Android build was also tuned for phones with weak GPUs
