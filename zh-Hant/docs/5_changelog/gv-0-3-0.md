# gv 0.3.0

第一個能作為遊戲執行的版本：選單、由你操控的化身、從頭玩到尾的關卡，以及第一個編輯器畫面

在此之前，引擎只能在測試場景中播放關卡。這個版本圍繞它搭起了整個遊戲，基於*UI Toolkit*構建

- **選單與設定**。主選單、在多次啟動之間儲存的設定介面、播放列表和關卡列表
- **遊玩關卡**。選擇關卡、載入並玩到結束
- **化身**。玩家在關卡中自己的形狀，由你操控
- **兩種語言**。介面提供英文和俄文
- **關卡校驗**。SDK可以按一組規則檢查關卡，並報告損壞的資料

內建編輯器以最初的形態出現。它可以建立新關卡、儲存到資料夾、以選定的速度播放並顯示當前時間。物體層級和檢視器目前只是草稿

沒有`gv 0.2`：版本號從`gv 0.1.0`直接跳到了`gv 0.3.0`
