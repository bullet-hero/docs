# gv 0.0.1

Le premier test de rendu : de nombreux objets via Unity Entities, et cela tourne déjà sur Android

Trois jours après le début, le projet a reçu sa base technique. Les objets sont dessinés via *Unity Entities* (ECS), et le jeu repose toujours sur cette approche. La scène de test remplit l'écran d'objets et change leurs couleurs, et l'ordre de dessin est tiré de la profondeur de chaque objet

- La version de test tourne déjà sur Android
- Le modèle de données des niveaux est passé dans un plugin séparé, le futur SDK
- Les premiers sprites (formes, icônes d'interface, skins) ont été repris d'un projet plus ancien

À la même époque, un pipeline de rendu maison a été envisagé puis abandonné : l'*URP* standard suffisait
