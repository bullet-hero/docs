# 链接与社区

交流和提问在Discord，视频在YouTube，游戏错误提交到bullet-hero/releases仓库的issues。源代码在GitHub上的bullet-hero组织中

可以下载的一切，包括游戏、SDK和商店：[[download]]

## 社交媒体

| 来源 | 说明 |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | 交流、提问、反馈、bug、你的关卡 |
| [YouTube](https://www.youtube.com/@bulletherogame) | 预告片和关于游戏的视频 |

## 反馈

| 来源 | 说明 |
|---|---|
| [Game Issues](https://github.com/bullet-hero/releases/issues) | 游戏中的错误和bug（仅限技术问题） |
| [SDK Issues](https://github.com/bullet-hero/sdk/issues) | SDK中的错误 |
| [Docs Issues](https://github.com/bullet-hero/docs/issues) | 文本和翻译中的错误 |
| [Discord](https://discord.gg/gkHQrp9NgS) | 提问和讨论，对游戏的反馈 |

什么内容发到哪里，详见：[[11_help]]

## 源代码

所有仓库都在[bullet-hero](https://github.com/bullet-hero)组织中

| 仓库 | 访问 | 内容 |
|---|---|---|
| [bullet-hero/game](https://github.com/bullet-hero/game) | 闭源 | 游戏和编辑器 |
| [bullet-hero/sdk](https://github.com/bullet-hero/sdk) | 开源 | SDK，关于SDK及其代码的issues |
| [bullet-hero/releases](https://github.com/bullet-hero/releases) | 开源 | 游戏构建版本，玩家提交的issues |
| [bullet-hero/docs](https://github.com/bullet-hero/docs) | 开源 | 这份文档 |
| [bullet-hero/backend](https://github.com/bullet-hero/backend) | 开源 | 服务器，目前为空 |
| [bullet-hero/frontend](https://github.com/bullet-hero/frontend) | 闭源 | 网站 |

如何帮助项目：[[community]]
