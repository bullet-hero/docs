# Версия 0.3.3

Быстрый шейдер и камера редактора, которую можно двигать мышью или двумя пальцами

- **Новый шейдер для объектов уровня.** В нём один проход и только то, что нужно для отрисовки, и работает он примерно вдвое быстрее старого
- **Камера редактора.** На ПК её двигают мышью, на телефоне - двумя пальцами. Отдельная кнопка возвращает её к фокусу
- **Текстуры.** Любую текстуру игры или уровня теперь можно наложить на объект по её собственным UV-координатам
- **Просмотр журнала.** Первая версия панели, которая показывает сообщения редактора

Коммиты: игра `b9d32ac7`, SDK `88c3224d`
