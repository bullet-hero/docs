# gv 1.0.0

リリース：`gv 1.0.0`で保存したファイルは以降のすべてのバージョンで開け、新しいバージョンのファイルはゲームの更新を求めます

## `gv 1.0.0`が意味すること

- **ファイルは使い続けられます**。`gv 1.0.0`で保存したレベル、設定、統計は、以降のすべてのバージョンのゲームで開けます。ファイルのフォーマットが変わると、新しいバージョンが読み込み時に古いファイルを自動で変換します
- **新しいファイルは中途半端に読まれず、拒否されます**。新しいバージョンのレベルやセーブデータは`更新が必要`ウィンドウを開き、`ダウンロード`でダウンロードページに移動します。ゲームは読めないものを推測しないので、何かが失われたり、知らないうちに変わったりすることはありません。詳細：[[5_troubleshooting]]
- ゲームとSDKのバージョンは`gv 1.0.0`と`sv 1.0.0`です。SDKは引き続きゲームと一緒に開発されているため、プログラミングインターフェースが変わらないことはまだ約束されていません

## 変更点

- **古いバイナリ形式のレベルが開けなくなります**。`gv 1.0.0`より前のバージョンで`Blob`として保存したレベルは、`gv 1.0.0`では開けません。リリースに合わせてバイナリ形式を一から作り直したためです。`Json`で保存したレベルには影響しません。古い`Blob`のレベルがある場合は、まずそれを作ったバージョンで開き、`Json`で保存してください
- エディターの設定から`ガイドライン`セクションが削除されました。ガイドはサイトに移り、`コミュニティ`セクションの`ドキュメント`リンクから、使用中の言語で開けます
- レベル一覧は、言語を変更するとラベルを書き換えます。以前はソースボタン、並べ替えボタン、レベルのセルが元の言語のままでした
- ゲームのすべてのテキストが両方の言語でドキュメントのリポジトリに公開されたので、誤字や不自然な翻訳をそこで報告したり、自分で修正したりできます：[https://github.com/bullet-hero/docs](https://github.com/bullet-hero/docs)
