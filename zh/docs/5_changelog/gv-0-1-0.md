# gv 0.1.0

第一个关卡格式，以及第一个能播放它的引擎：物体、主题、特效、文本、音频和碰撞

六周时间里，实验变成了游戏中两个真正的部分。屏幕上还没有菜单和编辑器，但关卡已经可以写在文件里并播放出来

**关卡格式**。关卡是一个由SDK描述的`JSON`文件。它已经包含物体、父级、主题（调色板，和*Project Arrhythmia*中一样）、特效、音频和预制件

**播放关卡的引擎**。每一帧先由并行任务构建，再进行绘制：

- 位置、旋转、缩放和父级
- 取自关卡主题的颜色，以及纹理
- 关卡的相机
- 通过一个共用的*VFX Graph*特效实现的粒子特效
- 关卡的音乐
- 通过*UniText*实现的文本，它取代了*TextMeshPro*
- 碰撞检测，这是日后让物体击中玩家的基础
- 放置到关卡中的预制件

项目也在这个版本迁移到了Unity 6.4
