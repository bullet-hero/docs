# gv 0.5.5

Android의 폴더 접근, 모든 설정 탭의 초기화 버튼, 해상도 설정 수정

- Android: 게임은 시스템 폴더 선택기로 폴더를 열고 선택한 폴더만 보므로 저장소 권한이 필요 없습니다. 설정의 `폴더 접근`에는 허용된 모든 폴더가 표시되며, `해제` 버튼은 안의 내용을 아무것도 지우지 않고 접근 권한만 거둡니다
- 모든 설정 탭에 자체 초기화 버튼이 있으며, 그 탭만 기본값으로 되돌립니다
- 수정: 그전에 창 크기를 손으로 또는 Alt+Enter 키로 바꿨다면 해상도 설정이 아무 효과가 없었습니다
- 레벨 목록에 `다시 스캔` 버튼이 생겼습니다
- 레벨 설정에 `게시` 탭이 있습니다. 지금은 `개발 중` 문구만 표시됩니다

커밋: 게임 `7d40c382`, SDK `284ff03a`
