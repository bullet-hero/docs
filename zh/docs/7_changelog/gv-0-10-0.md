# 版本0.10.0

预制件围绕真正的根物体重建，没有尺寸关键帧的物体没有自己的尺寸

- 预制件模板现在有一个真正的根物体，其中的所有内容都挂在它下面。以前把一组物体变成预制件，会留下两个连续的分组物体，而且无法合并。现在选中项只会被包裹一次
- 没有尺寸关键帧的物体尺寸为0乘0，而不是1乘1。空物体、特效和预制件放置都是不绘制任何内容的分组，因此没有尺寸。新建的形状或文本会在创建时获得一个尺寸关键帧，数值在`编辑器` > `创建`中设置（`新形状宽度`、`新文本宽度`和对应的两个高度）
- 由此带来两个结果：在视口中无法点击分组，而特效要点击其粒子所占的区域
- 把层级中的一行拖到另一行上即可更改它的父级，拖到空白处则移除父级。多个选中行的移动是一步撤销。鼠标和手写笔都可以这样操作。在手机上，父级在检视器中更改
- 按住反引号键（`` ` ``）可隐藏整个编辑器界面，只显示关卡。松开即可恢复一切。这个按键可以重新绑定
- 关卡浏览器打开时按`最近`排序，因此你最后保存的关卡位于最上方
- 结果界面显示`通过`或`失败`，而不是“Win”或“Lose”
- 展平预制件放置前会先要求确认，因为放置将不再跟随它的模板
- 命令面板和添加菜单已翻译。以前无论选择什么语言，它们都显示英文
