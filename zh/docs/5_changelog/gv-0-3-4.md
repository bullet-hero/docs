# gv 0.3.4

第一个时间轴、第一个检视器，以及直接在视口中选择物体

编辑器有了如今关卡制作所围绕的三个部分。在这个版本中，三者都是早期原型

- **时间轴**。在帧轴上显示帧编号和关卡中的物体
- **检视器**。显示物体属性的面板的第一个版本
- **选择**。可以在视口中选择物体，选中项与物体层级共享

颜色也有变化。带纹理的物体现在带有四种颜色，每个角一种，并以渐变混合。为此，物体着色器基于URP的标准*Unlit*着色器重写
