# 为朋友搭建服务器

小型社区服务器需要什么，以及关于它已经知道了什么

> [!warning] 警告
> 服务器工具尚未发布，协议也尚未设计。本页只包含已经确定的内容

## 你需要什么

- **服务器工具**。它们将以MIT许可证开源。官方服务器运行的也是同一套代码。你可以基于这些工具或任何衍生自它们的东西搭建服务器
- **每个连接者都使用完整版游戏**。来自Google Play和App Store的版本无法连接社区服务器。完整版可以在[GitHub](https://github.com/bullet-hero/releases)和项目网站上获取
- **一个发布配置**。`PublishProfile`文件决定你的服务器接受哪些关卡。更多：[[7_publish-profiles]]
- **一台运行服务器的机器**。系统需求、运行环境、端口和启动方式目前都还不知道

## 发布配置

配置决定接受哪些许可证、关卡可以从哪里获取文件，以及关卡最大可以多大。这些都不需要改代码

官方服务器使用`standard`预设，在其服务器配置中设定。从它开始，按你的需要放宽或收紧

## 你要承担什么

- **审核**。官方不审核社区服务器。完整版的EULA会告知每位玩家这一点
- **不得用于商业用途**。关卡默认以*CC BY-NC*授权，作者可以选择其他许可证。请遵守每个关卡自己的许可证。*CC BY-NC*的关卡可以免费托管和分享，但你不能为它收费，也不能以其他任何方式从中获利
- **资源的权利**。关卡中可能带有他人的音乐和图片。检查得多严格由你的配置决定。但针对他人作品的投诉会找到你。官方服务器的规则：[[ugc-licensing-policy]]

非商业分享的许可来自每个关卡的作者，而不是游戏。因此只有该作者能给予例外

## 还不知道的事

- 游戏如何找到服务器并连接它
- 社区服务器是否有账号
- 关卡如何上传和列出
- 几个人用的服务器与公共服务器的设置方式是否不同

面向更大服务器已经存在的内容：[[3_advanced-hosting]]
