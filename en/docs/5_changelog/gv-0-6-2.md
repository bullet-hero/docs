# gv 0.6.2

Flattening prefabs, a launch argument for the settings and fixes for full screen and the window size

- `Flatten Prefab` turns a prefab placement into ordinary objects: the link to the template is gone, and the objects stay exactly where they were. It is a button in the prefab inspector and an editor command, and the `Prefab Flatten` modifier does the same for every placement in its area. The level looks the same afterwards, because the overrides of each placement are already written into the objects
- `--settings` opens the menu with the settings on top of it, and `--settings graphics` (or another tab name) opens a specific tab
- Fixed: full screen could show a blurry 640x480 picture with bars, and leaving and entering it again did not fix it. Full screen now always uses the screen's native resolution, and `Render Scale` is there for a lower rendering resolution
- Fixed: leaving full screen once made the game remember the window size as the size of the whole screen
- Fixed: a click on a keyframe in the timeline did not always open its tab in the inspector
