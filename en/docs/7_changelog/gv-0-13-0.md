# Version 0.13.0

The prefab root becomes selectable, an autosave freezes the editor half as long, and a level card credits the music

- The root of a prefab template can be selected. Click its row in the Prefab timeline and its keyframes are edited like any other object's. Opening a placement lands on the root, and selecting it loops playback over the template's own length
- An autosave freezes the editor for half as long: 133 ms instead of 265 ms on a 12.3 MB level. It used to copy the whole level twice, once for the backup and once for the save
- The cleanup after a save no longer runs on the main thread. Deleting the stale file of the other format and rotating the backups used to run in the middle of a frame, four times per autosave
- A level card names who wrote the music, on its own line under the level's authors. Which resource is named is set by the `Show on the level card` tick box on that resource. A level with exactly one audio resource gets the line without ticking anything
- A timeline stops drawing a clip hidden completely behind another one on the same lane. A wider clip lies under a narrower one, and a selected or dragged clip is on top of its lane. A clip that is not drawn can still be clicked
- A timeline releases its elements as soon as it is hidden. A folded level and an unselected tab used to cost as much every frame as when they were open
