# Версия 0.0.2

Текстуры, родители, частицы, текст и эффекты постобработки, опробованные по одному в тестовых сценах

Эта версия - набор экспериментов. Каждая возможность, которая понадобится уровню, получила свой тест, и большинство из них осталось

- У объектов появились текстуры
- У объекта может быть родитель, и объект движется вместе с ним
- Появились эффекты частиц и текст (тогда ещё через *TextMeshPro*)
- Эффекты постобработки экрана: те, что есть в *Project Arrhythmia*, и несколько собственных от разработчиков

Всё замерялось на телефоне с Android. По заметкам того времени он держал около 1500 объектов при 30 fps. 2D-тени попробовали и отказались от них

Коммиты: игра `c1569325`, SDK `191dc76f`
