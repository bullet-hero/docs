# gv 0.0.2

纹理、父级、粒子、文本和后期效果，在测试场景中逐一试验

这个版本是一组实验。关卡将来需要的每项功能都有了自己的测试，其中大部分保留了下来

- 物体有了纹理
- 物体可以有父级，并随父级一起移动
- 出现了粒子特效和文本（当时还通过*TextMeshPro*实现）
- 屏幕后期效果：*Project Arrhythmia*中有的那些，以及几种自己的

一切都在一部Android手机上测量。根据当时的记录，它能在30 FPS下承载约1500个物体。2D阴影试过之后放弃了
