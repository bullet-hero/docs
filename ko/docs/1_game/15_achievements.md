# 업적

업적은 통계에 따라 저절로 달성됩니다. 다른 사람이 만든 레벨과 공정하게 플레이한 판만 인정됩니다. 목록은 메인 메뉴의 `{{ui:menu_main_achievements-btn}}`에 있습니다

## 목록

메인 메뉴의 `{{ui:menu_main_achievements-btn}}`을 누르면 빌드의 모든 업적이 그룹별로 열립니다. 미달성 업적에는 진행도가, 달성한 업적에는 달성한 날이 표시됩니다. 비밀 업적은 달성하기 전까지 `{{ui:menu_achievements_hidden_name}}`(으)로 표시됩니다

## 인정되는 것

**공정한 판**은 다음과 같은 판입니다:

- 봇이 플레이하지 않음
- 충돌이 켜져 있음
- 속도가 `{{v:achievements.fair-min-speed}}` 이상
- 목숨이 있음: `{{ui:menu_levelview_options-lifes_option-zen}}` 판은 그것을 요구하는 업적에서만 인정됩니다

체크포인트는 허용됩니다. 에디터에서 시작한 판은 절대 인정되지 않으며 기록도 남지 않습니다 - [[10_statistics]]

**직접 만든 레벨이 아닐 것.** 이 기기의 에디터에서 연 적이 있는 레벨은 직접 만든 레벨입니다. 그 클리어는 직접 만든 레벨을 테스트하는 업적에서만 인정됩니다. 기본 제공 레벨, 창작마당 레벨, 친구의 레벨은 인정됩니다

## 저장 위치

통계 옆의 `stats/achievements.json`입니다. 이 파일은 각 업적을 언제 달성했는지만 기억합니다. 달성 여부는 매번 통계로 판단하므로 파일을 잃어버릴 일은 없습니다. 지워도 다음 실행 때 얻은 업적이 모두 그날 날짜로 돌아옵니다

설정에서 통계를 지워도 업적은 남습니다. 프로필 이전과 Steam Cloud는 이 파일을 옮깁니다. 두 기기 모두 어느 한쪽에서 달성한 업적을 전부 갖게 됩니다 - [[14_profile-transfer]]

## Steam

Steam 빌드에서는 모든 업적이 Steam에서도 달성되고, Steam이 자체 알림을 표시합니다. Steam의 기록이 우선합니다. Steam에 있는 업적은 Steam의 날짜로 게임에서도 달성됩니다. 게임에는 있고 Steam에는 없는 업적은 통계가 여전히 조건을 만족하면 다시 달성됩니다

다른 빌드에서는 화면 위쪽에 게임 자체 알림이 표시됩니다
