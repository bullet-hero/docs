# 連結與社群

交流和提問在Discord，影片在YouTube，遊戲錯誤提交到bullet-hero/releases倉庫的issues。原始碼在GitHub上的bullet-hero組織中

可以下載的一切，包括遊戲、SDK和商店：[[download]]

## 社交媒體

| 來源 | 說明 |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | 交流、提問、反饋、bug、你的關卡 |
| [YouTube](https://www.youtube.com/@bulletherogame) | 預告片和關於遊戲的影片 |

## 反饋

| 來源 | 說明 |
|---|---|
| [Game Issues](https://github.com/bullet-hero/releases/issues) | 遊戲中的錯誤和bug（僅限技術問題） |
| [SDK Issues](https://github.com/bullet-hero/sdk/issues) | SDK中的錯誤 |
| [Docs Issues](https://github.com/bullet-hero/docs/issues) | 文本和翻譯中的錯誤 |
| [Discord](https://discord.gg/gkHQrp9NgS) | 提問和討論，對遊戲的反饋 |

什麼內容發到哪裡，詳見：[[11_help]]

## 原始碼

所有倉庫都在[bullet-hero](https://github.com/bullet-hero)組織中

| 倉庫 | 訪問 | 內容 |
|---|---|---|
| [bullet-hero/game](https://github.com/bullet-hero/game) | 閉源 | 遊戲和編輯器 |
| [bullet-hero/sdk](https://github.com/bullet-hero/sdk) | 開源 | SDK，關於SDK及其程式碼的issues |
| [bullet-hero/releases](https://github.com/bullet-hero/releases) | 開源 | 遊戲構建版本，玩家提交的issues |
| [bullet-hero/docs](https://github.com/bullet-hero/docs) | 開源 | 這份文件 |
| [bullet-hero/backend](https://github.com/bullet-hero/backend) | 開源 | 伺服器，目前為空 |
| [bullet-hero/frontend](https://github.com/bullet-hero/frontend) | 閉源 | 網站 |
