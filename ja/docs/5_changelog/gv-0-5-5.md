# gv 0.5.5

Androidでのフォルダーへのアクセス、設定の各タブのリセットボタン、解像度設定の修正

- Android：ゲームはシステムのフォルダー選択画面でフォルダーを開き、選んだフォルダーだけを参照するため、ストレージの権限を必要としません。設定の`フォルダーアクセス`には許可したフォルダーがすべて表示され、`解除`を押すと中身を何も削除せずにアクセスが取り消されます
- 設定の各タブに専用のリセットボタンがあり、そのタブだけをデフォルト値に戻します
- 修正：それ以前にウィンドウのサイズを手で、またはAlt+Enterで変えていると、解像度の設定が何もしませんでした
- レベル一覧に`再スキャン`ボタンが付きました
- レベル設定に`公開`タブがあります。今のところ`開発中`と表示されます

コミット：ゲーム`7d40c382`、SDK `284ff03a`
