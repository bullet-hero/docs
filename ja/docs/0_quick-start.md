# クイックスタート

ゲームをダウンロードし、レベル一覧を開いて好きなレベルをプレイします。自分で作るには、エディターでレベルを作成し、そのフォルダーに1〜2分のトラックを入れます

各ステップは最短ルートです。詳しくはリンク先を参照してください。よくある質問への短い回答：[[6_faq]]

## 1. ゲームを入手する

すべてのビルドとストア：[[download]]

## 2. 起動する

メインメニューで必要なボタンは`{{ui:menu_main_levels-btn}}`、`{{ui:menu_main_editor-btn}}`、`{{ui:settings_common_title}}`の3つです。`{{ui:menu_main_story-btn}}`と`{{ui:menu_main_multiplayer-btn}}`はまだ動作しません

## 3. 最初のレベルをプレイする

`{{ui:menu_main_levels-btn}}`を押してレベルを選び、`プレイ`を押します。操作するのは小さな四角形です。目標はトラックの最後まで生き残ることです

> [!tip] ヒント
> 初めてのプレイでは、`{{ui:menu_levelview_options-lifes_title}}`を`{{ui:menu_levelview_options-lifes_option-zen}}`に設定してください。プレイが終わらなくなり、落ち着いて操作に慣れることができます。`{{ui:menu_levelview_options-no-collision_title}}`はさらに徹底しています：オンにすると、何にも当たらなくなります

レベルを送ってもらいましたか？それはフォルダーです。`levels`フォルダーにコピーして`{{ui:root_level-browser_refresh}}`を押してください。詳細：[[2_playing-levels]]

## 4. 操作

| デバイス | 移動 | ダッシュ |
|---|---|---|
| マウス | 左ボタンを押し続ける | `Space`、`Shift`または右ボタン |
| タッチスクリーン | 指でドラッグする | 2本目の指 |
| ゲームパッド | どちらかのスティック | `Start`と`Select`以外の任意のボタン |

ゲームパッドのボタン以外は、すべて`{{ui:settings_common_title}}`→`{{ui:settings_controls_title}}`で割り当てを変更できます。詳細：[[3_controls]]

## 5. うまく動かないときは

よくある問題と解決方法：[[5_troubleshooting]]

問題の報告先：[[11_help]]

## 6. 最初のレベルを作る

`{{ui:menu_main_editor-btn}}`を押してレベルを作成し、そのフォルダーにトラック（`ogg`、`mp3`または`wav`）を入れます。始めるには1〜2分のトラックで十分です

エディターは編集の1分後にレベルを自動で保存します。`Ctrl+S`ですぐに保存できます

全体の手順を順に追うには：[[2_first-level]]
