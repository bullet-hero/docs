# 版本0.7.0

界面音效，编辑器之外可完全用手柄和键盘操作，关卡图片的新设置

- 界面现在有音效了。菜单会对按下做出反应，而关卡编辑器只为编辑的结果发声：保存、拒绝、撤销或重做、删除。鼠标悬停在按钮上时处处都没有声音，因为这是最频繁的事件，也最先让人厌烦
- 音频设置中新增`编辑器界面`滑块，与`用户界面`分开控制编辑器的音效。两者初始都是50%
- 编辑器之外的所有内容都可以只用手柄或键盘操作。使用手柄时鼠标光标会隐藏，左下角会出现一条简短提示，显示接管操作的设备。编辑器本身不能用手柄导航，但手柄的`Start`键可以退出编辑器
- 返回只关闭最上层的窗口。以前按一次可能会同时关闭一个窗口和它下面的界面
- 关卡图片有两个新设置：`采样`（`平滑`或`锐利`）和`压缩`（`允许`或`禁止`）。`禁止`会保留每个像素，内存占用最多为原来的4倍
- 关卡图片的环绕方式现在按轴设置，分为`X轴环绕`和`Y轴环绕`。在此版本之前保存的关卡两者都读取为`钳制`，因此之前设置的重复需要重新设置
- 冲刺冷却时间为0.30秒，此前为0.35秒。冲刺后的无敌时间仍为0.20秒
- 在冲刺途中暂停，化身不再在停止的关卡上继续滑行
- 深陷在形状内部的化身现在会被推离形状中心。以前它完全不会被推开
- 编辑后，层级会保留你展开的行，两个新按钮可以一次展开或折叠所有行
- 统计叠加层可以再显示三个区块：`显示帧物体`、`显示关卡物体`和`显示内存`
