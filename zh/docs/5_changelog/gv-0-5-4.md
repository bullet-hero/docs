# gv 0.5.4

处处使用矢量图形、HUD显示生命值、完整的颜色曲线、垂直同步，以及关卡列表中的Steam创意工坊关卡

- 所有图标和界面图像现在都是矢量图（SVG），而不是纹理
- HUD在进度条上方用一排圆点显示生命。失去的生命会让对应的圆点变暗，而不是移除它，所以这一排的长度不变。无敌时这一排为空
- 颜色曲线变成了URP引擎的八条曲线：`主控`、`红`、`绿`、`蓝`、`色相/色相`、`色相/饱和`、`饱和/饱和`和`亮度/饱和`。使用旧版两值颜色曲线的关卡会在加载时转换
- 修复：使用默认值的颜色曲线关键帧会让画面变灰，并把色相旋转半圈
- `垂直同步`设置，值为`关`、`开`和`半速率`，仅限电脑。开启时，帧率上限不起作用
- Steam版本：你在Steam创意工坊订阅的关卡会出现在关卡列表中。`显示所有找到的内容`还会显示磁盘上有、但未确认属于你的内容，例如没有订阅的物品或手动复制的文件夹。这类关卡在卡片上标为`未订阅`或`离线`
- 关卡的每位作者都有`分工`字段：音乐、封面、试玩等
