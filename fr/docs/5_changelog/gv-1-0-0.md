# gv 1.0.0

La sortie : un fichier enregistré par `gv 1.0.0` s'ouvre dans toutes les versions suivantes, et un fichier d'une version plus récente te demande de mettre à jour le jeu

## Ce que `gv 1.0.0` signifie pour toi

- **Tes fichiers continuent de fonctionner.** Un niveau, tes paramètres et tes statistiques enregistrés par `gv 1.0.0` s'ouvrent dans toutes les versions suivantes du jeu. Quand le format des fichiers change, la nouvelle version convertit d'elle-même l'ancien fichier en le lisant
- **Un fichier plus récent est refusé, pas lu à moitié.** Un niveau ou un enregistrement d'une version plus récente ouvre la fenêtre `Mise à jour requise`, et `Télécharger` mène à la page de téléchargement. Le jeu ne devine pas ce qu'il ne sait pas lire, donc rien n'est perdu ni modifié en silence. Plus - [[5_troubleshooting]]
- Les versions du jeu et du SDK sont `gv 1.0.0` et `sv 1.0.0`. Le SDK évolue toujours avec le jeu, donc son interface de programmation n'est pas encore promise stable

## Ce qui a changé

- **Casse les anciens niveaux binaires.** Un niveau enregistré en `Blob` par une version antérieure à `gv 1.0.0` ne s'ouvre pas dans `gv 1.0.0`, car le format binaire a été repris de zéro pour la sortie. Un niveau enregistré en `Json` n'est pas concerné. Si tu as un ancien niveau `Blob`, ouvre-le d'abord dans la version qui l'a créé et enregistre-le en `Json`
- La section `Recommandations` est retirée des paramètres de l'éditeur. Le guide vit désormais sur le site, et la section `Communauté` a un lien `Documentation` qui l'ouvre dans ta langue
- La liste des niveaux réécrit ses libellés quand la langue change. Avant, les boutons de source, le bouton de tri et les cellules des niveaux restaient dans l'ancienne langue
- Tous les textes du jeu dans les deux langues sont désormais publics dans le dépôt de la documentation, donc une coquille ou une mauvaise traduction peut y être signalée ou corrigée par toi-même - [https://github.com/bullet-hero/docs](https://github.com/bullet-hero/docs)
