# サーバー

Bullet Heroのサーバーは、レベルを保存するWebサービスです。公式サーバーOWSと、誰でも運営できるコミュニティサーバーNOWSが用意される予定です

> [!warning] 警告
> サーバーはまだ公式もコミュニティもありません。ゲームとサーバーの間のプロトコルも設計されていません

サーバーのコードは[bullet-hero/backend](https://github.com/bullet-hero/backend)で公開される予定です。現在は空です

自分と友人のためのサーバーが必要な方：[[2_hosting]]

大規模な公開サーバーが必要な方：[[3_advanced-hosting]]
