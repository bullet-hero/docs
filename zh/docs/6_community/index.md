# 社区

在哪里讨论游戏，如何帮助它，以及它是谁做的

## 在哪里交流

| 地方 | 用途 |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | 提问、反馈、bug、你的关卡 |
| [YouTube](https://www.youtube.com/@bulletherogame) | 预告片和关于游戏的视频 |
| [GitHub](https://github.com/bullet-hero) | 开放的部分：SDK、这份文档、发布版本 |

## 如何帮忙

任何人都可以帮忙：修正文档中的错误、添加翻译、报告bug或制作关卡。先选好要写到哪里

| 内容 | 去处 |
|---|---|
| 游戏版本，以及关于游戏的错误和建议 | [bullet-hero/releases](https://github.com/bullet-hero/releases) |
| SDK、它的代码和其中的错误 | [bullet-hero/sdk](https://github.com/bullet-hero/sdk) |
| 这些页面的文本和翻译 | [bullet-hero/docs](https://github.com/bullet-hero/docs) |
| 提问和讨论 | [Discord](https://discord.gg/gkHQrp9NgS) |
