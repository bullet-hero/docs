# Как поделиться уровнем вручную

Что несёт в себе архив, в каких пяти видах он бывает и какими строчками tar, zip и gpg создать и открыть каждый

Уровень - это папка файлов, а архив - та же папка, сделанная переносимой. Всё, что уровень использует, едет вместе с ним: песня, картинки, обложка - поэтому распакованный на другой машине уровень сразу играется. Куда его кладёт получатель, см. раздел [[2_metadata-and-sharing#Как поделиться сегодня]]

Не едет только ресурс, который уровень тянет по ссылке: он так и указывает туда, куда указывал. А файл, на который никто не ссылается, не пакуется. Отчёт экспорта игры перечисляет и то, и другое, см. раздел [[13_export-and-protection#Экспорт уровня]]

## Пять видов

Каждый открывается инструментами, которые на той стороне уже есть:

| Файл | Что внутри | Чем открыть |
|---|---|---|
| `level.json.gpg` | только документ уровня, под паролем, лежит в папке уровня | gpg |
| `LEVEL_FOLDER.tar.gz` | вся папка одним архивом | 7-Zip, Keka, Ark, Проводник |
| `LEVEL_FOLDER.tar.gz.gpg` | тот же архив под паролем | gpg |
| `LEVEL_FOLDER.zip` | та же папка в виде zip | Windows двойным кликом, ставить ничего не нужно |
| `LEVEL_FOLDER.zip.gpg` | тот же zip под паролем | gpg |

Пароль, который игра ставит на архив, по умолчанию - собственный AES-256 самого zip, его открывает, спросив пароль, любой архиватор, кроме Проводника. Виды с `.gpg` игра пишет по запросу

## Перед тем как запускать строчки

Заменить нужно два места. `LEVEL_FOLDER` - это имя собственной папки уровня, то есть его id: длинная строка из цифр и букв, как называется папка внутри `levels`. `YOUR_PASSWORD` - сам пароль

Пароль, вписанный в командную строку, остаётся потом в истории оболочки. Уберите из любой строки ниже `--batch --pinentry-mode loopback --passphrase YOUR_PASSWORD`, и gpg спросит его на экране сам

## Документ уровня через gpg

Шифрование кладёт рядом `level.json.gpg`, а исходник оставляет на месте - удалите его сами, когда проверите результат. Расшифровка снова кладёт документ под своим именем, а зашифрованный файл никуда не девается:

```bash
gpg -c --cipher-algo AES256 --batch --pinentry-mode loopback --passphrase YOUR_PASSWORD level.json
gpg -d --batch --pinentry-mode loopback --passphrase YOUR_PASSWORD level.json.gpg > level.json
```

## Архив tar.gz

Папка пакуется изнутри, поэтому в архиве лежат сами файлы уровня, а не папка с ними. Обеим строчкам распаковки папка назначения нужна уже существующей, потому что tar её не создаёт, а `mkdir` одинаково работает в cmd, в PowerShell и в терминале на Mac или Linux:

```bash
tar -czf LEVEL_FOLDER.tar.gz -C LEVEL_FOLDER .
mkdir LEVEL_FOLDER
tar -xzf LEVEL_FOLDER.tar.gz -C LEVEL_FOLDER
```

Упаковка с шифрованием за один проход ничего не записывает между двумя шагами, поэтому незащищённый архив вообще не попадает на диск. Вторая строчка расшифровывает и распаковывает его обратно в ту же папку:

```bash
tar -czf - -C LEVEL_FOLDER . | gpg -c --cipher-algo AES256 --batch --pinentry-mode loopback --passphrase YOUR_PASSWORD -o LEVEL_FOLDER.tar.gz.gpg
gpg -d --batch --pinentry-mode loopback --passphrase YOUR_PASSWORD LEVEL_FOLDER.tar.gz.gpg | tar -xz -C LEVEL_FOLDER
```

## Архив zip

В PowerShell, который есть на каждой машине с Windows. Звёздочка пакует то, что внутри папки, а не саму папку, а `Expand-Archive` создаёт папку сам, `mkdir` заранее не нужен:

```
Compress-Archive -Path LEVEL_FOLDER\* -DestinationPath LEVEL_FOLDER.zip
Expand-Archive -Path LEVEL_FOLDER.zip -DestinationPath LEVEL_FOLDER
```

На Mac или Linux те же два действия - это zip и unzip:

```bash
cd LEVEL_FOLDER && zip -r ../LEVEL_FOLDER.zip .
unzip LEVEL_FOLDER.zip -d LEVEL_FOLDER
```

Для zip с паролем, который спросит 7-Zip, нужен установленный 7-Zip:

```
7z a -tzip -mem=AES256 -pYOUR_PASSWORD LEVEL_FOLDER.zip .\LEVEL_FOLDER\*
```

## Игра читает их обратно

Все они работают в обе стороны - что записала игра, открывают gpg, tar и zip, а что сделали gpg, tar и zip, читает игра. Ради этого стандартные инструменты и выбраны вместо собственного формата

> [!tip] Подсказка
> Игра смотрит, чем файл является, а не как он называется, поэтому переименованный архив всё равно откроется. 7z - единственный формат, который она распознаёт и отклоняет: она называет формат вместо того, чтобы объявить файл битым, и достаточно перепаковать его в zip

> [!caution] Внимание
> **ЗАБЫТЫЙ ПАРОЛЬ ВОССТАНОВИТЬ НЕЛЬЗЯ**. Никакого ключа нигде не хранится - ни в игре, ни в файле, ни у разработчиков. Нет ни сброса, ни восстановления, ни обходного пути. Уровень, от которого потерян пароль, потерян вместе с ним, поэтому запишите пароль куда-нибудь до того, как закроете редактор
