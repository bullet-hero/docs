# gv 0.8.0

时间轴从1开始计帧，选中项一步即可变成预制件

- 帧从1开始计数。关卡的第一帧是第1帧，它从0秒开始，播放头、检视器和关卡文件显示同一个数字。物体内部关键帧的帧号也从1开始
- 已有关卡没有转换，所以有三样东西发生了偏移。所有随机值都重新随机了一次，因为随机值取决于帧号。在这个版本之前保存的检查点死亡记录和最佳成绩，读取时会偏移一帧。改动之前写入的撤销历史和自动保存无法重放
- 播放头读数以毫秒显示秒的小数部分（第60帧显示`0:00.983`）。旁边就是帧号，以前的写法看起来像是与它矛盾
- `从选中项创建预制件`（`Ctrl+G`）把选中的物体变成预制件。层级行的菜单中也有同样的操作：`由此创建预制件`
- 化身现在出现时会逐渐长大，消失时会缩成一个点，而不是瞬间出现和消失
- 关闭的窗口每帧要花掉编辑器画面4.6毫秒：界面仍然会遍历它们。现在其中十个窗口在关闭时会完全从界面中移除
- 统计叠加层新增`显示性能分析`区块：模拟的每个阶段花了多长时间
