# gv 0.0.2

Texturen, Elternobjekte, Partikel, Text und Post-Processing-Effekte, einzeln in Testszenen ausprobiert

Diese Version ist eine Reihe von Experimenten. Jede Funktion, die ein Level brauchen würde, bekam ihren eigenen Test, und die meisten davon blieben

- Objekte bekamen Texturen
- Ein Objekt kann ein Elternobjekt haben und bewegt sich mit ihm mit
- Partikeleffekte und Text kamen hinzu (damals über *TextMeshPro*)
- Post-Processing-Effekte für den Bildschirm

Alles wurde auf einem Android-Handy gemessen. Laut den damaligen Notizen schaffte es etwa 1500 Objekte bei 30 fps. 2D-Schatten wurden ausprobiert und verworfen
