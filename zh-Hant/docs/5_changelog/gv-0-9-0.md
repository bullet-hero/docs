# gv 0.9.0

生命值和真正的判定框直接顯示在化身上，來自更新版本的關卡會在警告後開啟

- 化身的身體是由方塊組成的網格，損失生命值會把方塊從邊緣向中心逐個打掉。失敗的一局直接顯示在玩家身上，而不是在一條進度條上。圖形設定中的`碎裂效果`可以關閉這一效果：身體變成一個方塊，改為逐漸變暗
- 化身上的一圈圓點正好位於它的判定框上：身體寬1個單位，半徑為0.4。輪廓從來都不是判定框，現在可以看到它真正的位置。這一圈圓點也用來計算生命：亮的圓點是你還剩下的生命，暗的是已經用掉的
- 介面設定中的`判定框圓環不透明度`決定圓環有多顯眼，預設值為0.6。0會把它關閉，但關卡是按能看到它的玩家設計的
- 檢查點新增`恢復生命值`設定：關卡經過檢查點的那一刻，檢查點會補滿你的生命
- 用更新版本製作的關卡在關卡瀏覽器中標為`版本較新`，在警告後開啟。如果讀取時有內容不得不被替換，遊戲會先寫入一份備份，並報告替換了多少處
- 關閉`迴圈`的特效發射的粒子比開啟時少得多，看起來像是顏色漸變失效了。現在一次性特效發射的粒子數量與迴圈特效保持存活的數量相同
