# gv 0.13.1

预制件放置随分组一起移动，历史标签页显示每一步改了什么，时间轴工具集中到一组按键上

- 拖动包含预制件放置的分组时，这些放置所放置的内容现在也会一起移动。以前副本留在原来的帧上，只要向左移动一帧，`Frame must be at least 1`错误就会在之后的每一帧打印，直到本次会话结束
- 被裁剪的放置在编辑其时段后，动画保持在原位。以前编辑会让放置的关键帧相对于它所放置的内容发生偏移
- `历史`标签页的每一行，以及控制台中每一条撤销或重做记录，现在都会显示这一步背后的数字：物体的id和名称、轨道，以及它在哪些帧之间移动（例如`f150 -> f160`）
- 时间轴工具移到了一组按键上，顺序与面板上相同：`Z`折叠，`X`吸附，`C`选择，`V`框选，`B`剪刀，`N`边缘。以前`V`是选择，`C`是剪刀，所以请检查你的习惯。工具较少的标签页从右侧减少工具（Local标签页有`Z` `X` `C` `V`），所以同一个字母在另一个标签页上绝不会代表另一个工具。六个按键都可以在设置中重新绑定，名称为`工具：吸附`、`工具：循环切换折叠`等
- 关卡校验不再用虚假的问题淹没带预制件的关卡。在一个有700个物体的关卡上，它曾报告38,736个损坏的重映射和19,993个悬空的根覆盖，而其中没有一个是真的
- 内置关卡`New zero demo`在这个版本中被移除
