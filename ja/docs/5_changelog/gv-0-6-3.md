# gv 0.6.3

レベルの外ではデフォルトでスマートフォンを自由に回転でき、縦向きレイアウトを持つ画面が増えました

- `画面の向き`のデフォルトが`自動回転`になりました：メニューと設定はスマートフォンに合わせて回転します。実行中のレベルは引き続き自分が宣言した軸（デフォルトは横向き）を保ち、エディターはどちらの設定にも従いません
- 操作、キー割り当て、統計、プロファイル、ヒント、値の入力ウィンドウに縦向きレイアウトが付き、スマートフォンを縦に持っても読みやすくなりました

コミット：ゲーム`9731731f`、SDK `d44635e6`
