# gv 0.14.0

Effekte spielen so, wie ihr Autor es gemeint hat, ein Effekt lässt sich von einem Objekt entfernen, und zwei neue Tastenkürzel im Editor

## Effekte

- Ein Effekt gibt Partikel in die Richtung aus, in die sein Objekt zeigt, und ein Schritt zurück auf der Zeitleiste zeichnet dasselbe, was die Wiedergabe gezeichnet hat. Vorher hing der Strom an der Welt, und auf demselben Frame war bei der Wiedergabe eine gebogene Spur zu sehen und nach einem Schritt zurück eine gerade
- Eine Emissionsform außer `Punkt` (`Kreis`, `Linie`, `Kegel`, `Torus`) dreht sich mit dem Objekt. Vorher blieb sie an der Welt ausgerichtet, und ein gedrehter Effekt erzeugte Partikel entlang von Achsen, die nichts mit ihm zu tun hatten
- Ein Effekt simuliert auch außerhalb des Bildschirms weiter, so existieren Partikel, die ins Bild fliegen sollen, schon bevor sie dort ankommen. Vorher erzeugte ein Emitter außerhalb der Kamera nichts, also konnte ein Effekt im Editor richtig aussehen und im Spiel verschwinden. Der Preis ist GPU-Zeit für Effekte außerhalb des Bildschirms
- **Macht bestehende Levels kaputt.** Die lineare Kraft eines Effekts ist jetzt eine Beschleunigung pro Sekunde, wie das Format es immer beschrieben hat. Vorher wirkte sie bei der Effektrate von 50 Hz etwa 50 Mal stärker. Ein Level, in dem sie gesetzt ist (`lfrc`), muss neu abgestimmt werden: Ein Partikel mit einer Kraft von `(1, 0)` legt jetzt in 1 s 0,51 Einheiten zurück, gegenüber 25,5 vorher

## Editor

- `Ctrl+Shift+A` (`Auswahl aufheben`) leert die ganze Auswahl auf einmal: Objekte, Keyframes, Audio und Beat. `Ctrl+Shift+E` (`Prefab-Modus beenden`) verlässt jede offene Sitzung im Prefab-Modus. Beide lassen sich wie jedes andere Kürzel neu belegen
- Die Effektauswahl hat eine Option `Nichts`, so lässt sich ein Effekt von einem Objekt entfernen. Vorher ließ sich ein einmal gewählter Effekt über die Auswahl nicht mehr leeren
- Das Öffnen eines anderen Levels aus dem Editor heraus baut die Objektliste neu auf, und der Prefab-Modus schließt sich zusammen mit dem Level, in dem er geöffnet wurde
- Ein Doppelklick auf einen Clip der Zeitleiste nahe dem Rand des Bereichs zieht das Objekt nicht mehr auf die Spur darüber. Vorher begann das Randscrollen schon beim Drücken, die Ansicht glitt unter einem ruhenden Zeiger weg, und die Bewegung wurde zu einem Ebenenwechsel
- Das [[12_launch-arguments|Startargument]] `--autosave on|off` schaltet das Autospeichern des Editors für einen Start ein oder aus, ohne die Einstellung zu ändern
