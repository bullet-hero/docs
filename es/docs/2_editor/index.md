# Editor de niveles

El editor viene integrado en el juego, no hay que instalar nada aparte. Un nivel en él es una carpeta con una canción y archivos, que llevas de vacía a lista para publicar

Las secciones se apoyan unas en otras, así que la primera vez léelas en orden
