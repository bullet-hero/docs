# gv 0.13.1

プレハブの配置がグループと一緒に動き、履歴タブに各ステップの変更内容が表示され、タイムラインのツールが1つのキーの並びにまとまりました

- プレハブの配置を含むグループをドラッグすると、それらの配置が置く内容も一緒に動くようになりました。以前はコピーが元のフレームに残り、1フレーム左に動かすだけで、セッションの終わりまで毎フレーム`Frame must be at least 1`というエラーが出力されていました
- トリミングされた配置は、スパンを編集したあともアニメーションの位置を保ちます。以前は編集によって、配置のキーフレームが、配置が置く内容に対してずれていました
- `履歴`タブの各行と、コンソールの元に戻す・やり直しの各行に、そのステップの数値が表示されるようになりました：オブジェクトのidと名前、トラック、移動前後のフレーム（例：`f150 -> f160`）
- タイムラインのツールは、パネルと同じ順で1つのキーの並びに移りました：`Z`折りたたみ、`X`スナップ、`C`選択、`V`矩形選択、`B`ハサミ、`N`エッジ。以前は`V`が選択、`C`がハサミだったので、手の癖を確認してください。ツールの少ないタブでは右側から省かれる（Localタブは`Z` `X` `C` `V`）ので、同じ文字が別のタブで別のツールを意味することはありません。6つとも設定で、`ツール：スナップ`、`ツール：折りたたみ切り替え`などとして割り当て直せます
- レベルの検証が、プレハブを含むレベルを誤った問題で埋め尽くすことはなくなりました。700オブジェクトのレベルで、壊れた再マッピング38,736件と、宙に浮いたルートのオーバーライド19,993件が見つかっていましたが、どれも本物ではありませんでした
- 内蔵レベル`New zero demo`は、このバージョンから削除されました
