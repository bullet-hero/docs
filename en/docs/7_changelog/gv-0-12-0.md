# Version 0.12.0

Curves with tangents, random values along a line, named theme slots, and a long list of timeline and Prefab Mode fixes

## Game

- The avatar is drawn in front of layer 0 instead of behind it. Content on the layer a new object is created on is now behind the player, and to cover the player you put content on layer 1. A level imported from *Afterbeat* lands one layer higher to match

## Editor

- A curve is edited by its tangents, not only by its points. The selected key gets a handle on each side, `Broken tangents` turns it into a corner, and with `Weighted tangents` the length of a handle is its weight. The preview line draws weights too, so it shows the curve that will actually play
- `Q W E R T` switch the five timelines of the bottom panel, left to right: level, local, audio, events, prefab. `Tap Tempo` lost its `T` key because of that. Tapping is done in the `Beat Grid` window (`Shift+T`), and a key for `Tap Tempo` can be set in `Keybindings`
- Prefab Mode selects like the rest of the editor: ctrl-click adds a clip, the Prefab tab has the `Marquee` tool, and many objects are edited in one inspector and deleted or copied in one undo step. Before, it selected one object at a time
- Dragging an object along a timeline takes its children with it, so a hierarchy keeps its own timing. One undo brings the whole subtree back
- Each timeline tab remembers its own tool. `Reset Tool On Tab Change` in `Game Editor` > `Timeline` decides whether a tab comes back on `Selection`, and it is on by default
- `Editor Playback` in the audio settings is a separate volume for playback in the editor, so the game's own volume stays where it was
- An autosave saves the level itself as well as its copy in `backups/`. Before, it made only the copy, so an evening of edits was in `backups/` and not in the level the browser lists
- Coming back from a test run leaves the editor as it was: the camera frame, the selection and the gizmo handles work, the preview player is back if it was there, and the playhead and speed read what they read before Play
- Clicking the last cell of the local timeline puts a keyframe on frame 60 of a 60-frame object, not on 59

## Levels and format

- A theme slot can have a name. A colour field that points at slot 12 reads `12 - background` instead of `12`
- A random vector or colour can lie on a line instead of in a box: `Rnd A to B` rolls one number, and the value moves along the straight line from `From` to `To`. A random tint then reads as one tint and a random drift as one direction. Give an axis the same number at both ends to hold it still
- An image resource has its own tiling and offset (`Tiling X`, `Tiling Y`, `Offset X` and `Offset Y` in its `Import` block). Every object using the image without UV keyframes of its own takes them, so a sprite sheet is described once
