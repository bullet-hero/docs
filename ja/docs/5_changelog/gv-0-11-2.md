# gv 0.11.2

ヒエラルキーとタイムラインの折りたたみが3段階のモードになり、エディターはスマートフォンでも完全なオーディオに対応しました

- ヒエラルキーとオブジェクトのタイムラインにある折りたたみボタンは、3つの段階を順に切り替えます：すべて展開、部分的、すべて折りたたみ。「部分的」は、選んだ種類のオブジェクトを展開したままにします。種類はボタンを長押しして選ぶか、`エディター` > `インターフェース` > `部分折りたたみ`で設定します
- レベルエディターでは、スマートフォンを含むすべてのプラットフォームでオーディオを丸ごとデコードします。圧縮されたトラックは波形を描画せず、目的のフレームではなく最も近いブロックにシークしていました。スマートフォンのゲーム本編では、オーディオは引き続き圧縮されたままです
- オーディオトラックの`レベルをフィット`は、クリップが丸ごと収まるまでトラックとレベルを一緒に延ばします。レベルは長くなるだけで、すでに収まっているクリップでは何も変わりません
- 別のフォーマットのオーディオファイルを追加すると、ゲームが対応フォーマットを伝えます：`.mp3`、`.wav`、`.ogg`
- 設定のボタン1つで、すべてのセクションを折りたたむか、すべてを展開できます
- エディターでキーボードを使ってプレビュー用アバターを動かしても、動かすたびに画面が119ms固まることはなくなりました
