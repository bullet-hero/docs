# Version 0.3.0

The first version that works as a game: a menu, an avatar you steer, levels played start to finish and the first editor screen

Until now the engine could only play a level in a test scene. Here it got the whole game around it, built on *UI Toolkit*

- **Menu and settings.** A main menu, a settings screen that saves between runs, playlists and a list of levels
- **Playing a level.** A level is chosen, loaded and played to its end
- **The avatar.** The player's own shape inside the level, steered by you
- **Two languages.** The interface is in English and Russian
- **Level checks.** The SDK can check a level against a set of rules and report broken data

The in-game editor appears in its first form. You can create a new level, save it to a folder, play it back at a chosen speed and see the current time. The object hierarchy and the inspector exist only as a first draft

There is no version 0.2: the numbers went from 0.1.0 straight to 0.3.0
