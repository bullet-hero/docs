# gv 0.7.0

インターフェースのサウンド、エディター以外でのゲームパッドとキーボードだけによる完全な操作、レベル画像の新しい設定

- インターフェースが音を出すようになりました。メニューは押すたびに応え、レベルエディターは編集の結果だけを音で知らせます：保存、拒否、元に戻す・やり直し、削除。ボタンへのホバーはどこでも無音です：最も頻繁に起こるイベントで、真っ先に耳障りになるためです
- オーディオ設定の新しいスライダー`エディターUI`で、エディターのサウンドを`UI`とは別に調整できます。どちらもデフォルトは50%です
- エディター以外はすべて、ゲームパッドだけ、またはキーボードだけで遊べます。ゲームパッドを手にしている間はマウスカーソルが隠れ、左下の隅にどのデバイスに切り替わったかが1秒間表示されます。エディター自体はゲームパッドで操作できませんが、`Start`ボタンでエディターから抜けられます
- 「戻る」はいちばん上のウィンドウだけを閉じます。以前は、1回押しただけでウィンドウとその下の画面がまとめて閉じることがありました
- レベル画像に2つの新しい設定が加わりました：`サンプリング`（`スムーズ`または`シャープ`）と`圧縮`（`許可`または`拒否`）。`拒否`はすべてのピクセルを保ちますが、最大4倍のメモリを使います
- 画像の端の外側の扱いは、軸ごとに設定するようになりました：`ラップX`と`ラップY`。このバージョンより前に保存されたレベルはどちらも`クランプ`として読み込まれるため、以前に設定した繰り返しはもう一度設定する必要があります
- ダッシュのクールダウンが0.35秒から0.30秒になりました。ダッシュ後の無敵時間は0.20秒のままです
- ダッシュの途中で一時停止しても、止まったレベルの上をアバターが引きずられなくなりました
- シェイプの奥深くに埋まったアバターは、シェイプの中心から外へ押し出されるようになりました。以前はまったく押し出されませんでした
- ヒエラルキーは、展開した行を編集のあとも保ちます。新しい2つのボタンで、すべての行をまとめて展開または折りたたみできます
- 統計オーバーレイに表示できるブロックが3つ増えました：`フレームオブジェクトを表示`、`レベルオブジェクトを表示`、`メモリを表示`
