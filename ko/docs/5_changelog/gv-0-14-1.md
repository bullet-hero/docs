# gv 0.14.1

휴대폰 수정 - 레벨 중에는 화면이 켜진 채 유지되고, 메모리 정리가 더 이상 플레이를 망치지 않음 - 그리고 라이선스 기록과 데모 레벨의 귀환

- 레벨이 재생되는 동안 화면이 켜진 채 유지되고, 일시 정지하는 즉시 다시 시스템의 화면 꺼짐 시간을 따릅니다. 이전에는 스틱을 계속 기울여 조종하는 플레이가 비활성으로 간주되어, 레벨 도중에 휴대폰이 잠겼습니다
- 레벨 중에 도착한 메모리 부족 경고는 레벨이 멈춘 뒤에 처리됩니다. Android에서 정리에 163 ms, 715 ms의 시간이 걸렸고, 33초 넘는 플레이 동안 735 ms, 523 ms짜리 프레임 두 개가 생겼는데, 각각 플레이를 잃기에 충분했습니다. 대가: 실제로 메모리가 부족하면 이제 시스템이 레벨 도중에 게임을 종료할 수 있습니다
- 게임 카메라는 정수 픽셀 단위로 움직일 때만 출력 영역을 갱신합니다. 이전에는 매 프레임 갱신되어, 레벨의 화면 비율이 바뀌지 않아도 렌더러가 중간 이미지를 초당 60번 다시 만들었습니다
- `라이선스` 창을 접을 수 있습니다: 두 단계의 헤더 모두 펼치고 접을 수 있습니다. 레벨 자체의 리소스는 처음부터 열려 있고, 게임과 함께 제공되는 것은 모두 접혀 있습니다
- 리소스를 삭제하면 그 라이선스 기록도 삭제됩니다. 이전에는 레벨에 더 이상 없는 리소스의 제작자에게 `라이선스` 창이 계속 감사를 표했습니다. 실행 취소하면 기록이 돌아옵니다
- 레벨 커버는 원본 파일 이름과 관계없이 이미지의 실제 형식에 따라 `logo.png` 또는 `logo.jpg` 파일로 저장됩니다. PNG도 JPEG도 아닌 이미지는 받지 않습니다
- 기본 레벨 `New zero demo`이(가) 돌아왔습니다. 커버가 있고, 음악 아티스트 Dunderpatrullen도 크레딧에 표기됩니다
