# gv 0.3.1

Der Editor kann Objekte erstellen, das rückgängig machen und sie in der Hierarchie zeigen

Fünf Tage nach `gv 0.3.0` wurde der Editor mehr als ein Levelplayer mit einer Speichern-Schaltfläche

- Objekte lassen sich erstellen, und Rückgängig und Wiederholen funktionieren dafür
- Die Objekthierarchie zeigt die Objekte des Levels, und von dort lässt sich ein Objekt ausblenden
- Ein Level lässt sich nach einer Bestätigung löschen
- Benachrichtigungen und ein Konsolenbereich melden, was der Editor gerade getan hat
- Ein Level im Editor zu spielen verhält sich genauso wie im Spiel

Außerdem wurde der Android-Build für Handys mit schwacher GPU abgestimmt
