# Hébergeur de serveur avancé

Un gros hébergeur, prêt à faire tourner un serveur public, à étendre le serveur officiel ou à écrire son propre serveur

Il n'y a pas encore de serveur. Voici ce qui est décidé pour le serveur officiel OWS et les serveurs communautaires NOWS, et ce que le SDK fait déjà pour eux
