## Versões

Cada produto tem a própria versão com um prefixo de letras, sempre no formato `major.minor.revision`:

| Prefixo | Significado | Produto |
|---|---|---|
| `gv` | `game version` | o jogo (o cliente) |
| `sv` | `sdk version` | o SDK |
| `bv` | `backend version` | o backend, o servidor |
| `fv` | `frontend version` | o site |
| `mg` | `model generation` | os dados |

Escreve-se assim: `gv 1.0.0`, `sv 1.0.0`, `bv 1.0.0`, `fv 1.0.0`, `mg 1`
