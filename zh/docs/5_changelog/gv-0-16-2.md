# gv 0.16.2

手机在关卡和设置中保持稳定的60帧，文本输入支持屏幕键盘

## 游戏

- 手机启动时关闭抗锯齿，电脑仍使用MSAA。使用MSAA时，Xiaomi 2209116AG的GPU负载达到98%，在关卡中只有每秒47到56帧。改用FXAA时，GPU占用51%，关卡保持稳定的60帧。FXAA也没有成为默认选项，因为即使在没有后期处理的关卡中，它也会让后期处理通道保持开启。抗锯齿仍然可以在图形设置中开启，现在从MSAA切换到其他类型确实会把它关闭
- 覆盖整个画面的界面会停止绘制它后面的关卡：设置、编辑器设置、生成器和节拍窗口。在同一部手机上，设置以60帧运行，而不是45帧。关卡在它们下面继续播放，只是不被绘制
- 图形设置显示游戏实际保持的帧率上限，例如`60 FPS`或`无限制`
- 手机上的文本输入支持屏幕键盘。每次打开字段时键盘都会打开，它的完成键保存文本，取消键恢复原来的文本，下一个字段会得到自己的键盘，所以字母不会再输入到数字字段中。灰色的未激活字段不能再通过输入窗口修改

## 编辑器

- 时间轴上选中的片段有一个4像素的醒目边框，选中的关键帧点有描边。以前选中项是一个细边框，颜色与片段自身的边框相近，在手机上会看不出来
- 在手机上的编辑器中，机器人操控化身时，视口会把触摸留给你，所以仍然可以移动视口并在其中选择。以前视口对任何触摸都没有反应
- 在`相对`操作模式下，相机移动时光标停留在屏幕上的原位。以前它会在屏幕上漂移
