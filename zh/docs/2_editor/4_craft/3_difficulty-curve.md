# 难度与曲线

用数字说明玩家在物理上能做到什么，如何构建难度曲线，以及为什么你无法评判自己的关卡

## 用数字看玩家

按这些数字设计关卡：

| 项目 | 数值 |
|---|---|
| 玩家判定框 | 半径为`0.15`世界单位的圆，而化身的绘制宽度是`0.5` |
| 普通速度 | 每秒`15`单位 |
| 冲刺 | 每秒`50`单位，持续`0.15 s`，冷却`0.3 s` |
| 冲刺时的无敌 | 整个`0.3 s` |
| 一次冲刺 | `7.5`单位，几乎瞬间完成 |
| 被击中后 | `0.2 s`内无法控制，`1 s`内忽略后续的击中 |
| 人的反应 | 0.2到0.25秒，在60 fps下是12到15帧 |
| 启动时的默认值 | 3条命，速度1.0，检查点开启 |

其他一切都由这些数字推出：
- 1个单位宽的空隙超过判定框半径的六倍，算是很宽
- 0.6宽的空隙很紧
- 7.5个单位是半秒的奔跑，或者一次冲刺

## 被击中不等于死亡

被击中后，玩家会被击退，`0.2 s`内无法控制。之后整整`1 s`内的所有击中都会被忽略。一排连续的十颗子弹只会扣掉一条命，而不是十条

> [!info] 须知
> 直觉告诉你的正好相反。密集的齐射看起来像是必死无疑。实际上它比一颗恰好在无敌结束时飞来的子弹代价更小

## 玩家的选择

生命数、播放速度和检查点由玩家在启动界面上选择。默认是3条命，速度1.0，检查点开启

你可以放置检查点，但无法强迫任何人使用它们。你也无法禁止别人用半速游玩

按默认值来设计，但不要把任何东西建立在“他们会死在这里”之上。你设计的是一种感受，而不是惩罚

## 循环

玩家重复同一个循环：游玩、死亡、再试一次。好的关卡在这个循环上叠加自己的层次，而这个循环必须是：
- 开头简单，不要一上来就是困难的机制
- 可扩展，新元素逐步加入，这样才不会乏味
- 有回报，正确的动作立刻得到反馈，玩家才会继续下去

## 曲线：教学、检验、变化

1. 以安全的形式展示模式，几乎不可能失败
2. 真正要求玩家做到
3. 改变一个变量（速度、方向、数量），再要求一次

如果一个模式第一次出现就是困难的形式，玩家会怪关卡。玩家死了，却不明白关卡想要他做什么

公平也有上限。过度手把手教学和不公平一样，都会让关卡失去乐趣

## 背板

只能靠记忆通过的关卡是一种正当的类型。但它必须是一个决定，而不是意外

界线很简单：死亡之后，玩家必须明白要记住的是什么。死了十次还不明白，那不是背板，是噪音

## 找别人测试

你无法评判自己的关卡。到发布的时候，你已经把自己的难点通过了两百次，对你来说它很简单

> [!tip] 建议
> 把关卡交给第一次看到它的人，然后安静地看着。不要给提示。一个人死了三次、还问关卡到底想要什么的地方，不是难，而是不清楚

## 从短关卡开始

第一个关卡做1到2分钟长。兴趣会比曲子先耗尽。四分钟的关卡意味着四倍的工作量和十倍的放弃理由
