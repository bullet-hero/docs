# gv 0.3.4

第一個時間軸、第一個檢視器，以及直接在視口中選擇物體

編輯器有了如今關卡製作所圍繞的三個部分。在這個版本中，三者都是早期原型

- **時間軸**。在幀軸上顯示幀編號和關卡中的物體
- **檢視器**。顯示物體屬性的面板的第一個版本
- **選擇**。可以在視口中選擇物體，選中項與物體層級共享

顏色也有變化。帶紋理的物體現在帶有四種顏色，每個角一種，並以漸變混合。為此，物體著色器基於URP的標準*Unlit*著色器重寫
