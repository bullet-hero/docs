# 给朋友的服务器

你需要开源的服务器工具、每位玩家都使用游戏完整版，以及一个PublishProfile文件。审核和遵守关卡许可证由服务器所有者负责

> [!warning] 警告
> 服务器工具尚未发布，协议尚未设计。这里只有已经确定的内容

## 需要什么

- **服务器工具**。它们将以MIT许可证开源。这与官方服务器运行的是同一份代码。你可以用这些工具或基于它们的任何东西搭建自己的服务器
- **每个连接的人都使用游戏完整版**。来自Google Play和App Store的版本无法连接社区服务器。完整版位于[GitHub](https://github.com/bullet-hero/releases)和项目网站
- **发布配置**。`PublishProfile`文件决定你的服务器接受哪些关卡。更多：[[7_publish-profiles]]
- **运行服务器的机器**。系统要求、运行环境、端口和启动方式目前都还不知道

## 发布配置

配置规定接受哪些许可证、关卡可以从哪里获取文件，以及它的大小限制。这些都不需要修改代码

官方服务器使用`standard`预设，它在服务器配置中设定。以它为起点，按自己的需要放宽或收紧

## 你要承担什么

- **审核**。Bullet Hero不审核社区服务器。完整版的EULA会把这一点告知每位玩家
- **不得用于商业**。关卡默认以*CC BY-NC*发布，作者可以选择其他许可证。请遵守每个关卡的许可证。*CC BY-NC*下的关卡可以免费托管和分享，但不能为它收费，也不能以其他方式靠它赚钱
- **资源的权利**。关卡中可能有他人的音乐和图像。检查得多严格由你的配置决定。但针对他人作品的投诉会找到你。官方服务器的规则：[[ugc-licensing-policy]]

非商业分发的许可由每个关卡的作者授予，而不是由游戏授予。所以只有作者才能给出例外

## 尚不清楚的事

- 游戏如何找到服务器并连接
- 社区服务器是否会有账号
- 关卡如何上传并进入列表
- 几个人用的服务器与公共服务器的配置方式是否不同

大型服务器已经具备的内容：[[3_advanced-hosting]]
