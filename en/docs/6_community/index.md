# Community

Where to talk about the game, how to help it and who made it

## Where to talk

| Where | What for |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | questions, feedback, bugs, your levels |
| [YouTube](https://www.youtube.com/@bulletherogame) | trailers and videos about the game |
| [GitHub](https://github.com/bullet-hero) | the open parts: the SDK, these docs, releases |

## How to help

Anyone can help: fix a mistake in the docs, add a translation, report a bug or make a level. First pick where to write

| What | Where |
|---|---|
| Game builds, bugs and requests about the game | [bullet-hero/releases](https://github.com/bullet-hero/releases) |
| The SDK, its code and bugs in it | [bullet-hero/sdk](https://github.com/bullet-hero/sdk) |
| The text of these pages and translations | [bullet-hero/docs](https://github.com/bullet-hero/docs) |
| Questions and discussion | [Discord](https://discord.gg/gkHQrp9NgS) |
