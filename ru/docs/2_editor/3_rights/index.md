# Право

В уровень, который вы публикуете, можно класть только файлы с открытой лицензией не строже CC BY-NC или с разрешением автора. Уровень для себя можно собирать из чего угодно

Проверка включается, когда уровень уходит с вашего диска на сервер или сайт
