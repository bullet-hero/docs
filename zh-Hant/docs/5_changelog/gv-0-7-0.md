# gv 0.7.0

介面音效、在編輯器之外完全支援手柄和鍵盤操作，以及關卡影像的新設定

- 介面有了音效。選單會回應按下，關卡編輯器只為編輯的結果發聲：儲存、拒絕、撤銷或重做、刪除。懸停在按鈕上在任何地方都沒有聲音：這是最頻繁的事件，也最先讓人厭煩
- 音訊設定中新增`編輯器介面`滑塊，與`使用者介面`分開控制編輯器的音效。兩者預設都是50%
- 除編輯器外，一切都可以只用手柄或只用鍵盤完成。手柄在手時滑鼠游標隱藏，左下角會顯示一秒鐘，提示哪個裝置接管了操作。編輯器本身不能用手柄操作，但`Start`按鈕可以退出編輯器
- “返回”只關閉最上層的視窗。以前按一次可能會連同下面的畫面一起關閉
- 關卡影像有兩個新設定：`取樣`（`平滑`或`銳利`）和`壓縮`（`允許`或`禁止`）。`禁止`會保留每個畫素，但佔用的記憶體最多多出4倍
- 影像超出邊緣時的行為現在按軸分別設定：`X軸環繞`和`Y軸環繞`。在這個版本之前儲存的關卡會把兩者都讀作`鉗制`，所以之前設定的重複需要重新設定
- 衝刺冷卻時間為0.30秒，而不是0.35秒。衝刺後的無敵時間仍為0.20秒
- 衝刺途中暫停，不再把化身拖過已停止的關卡
- 深深卡進形狀內部的化身現在會從形狀中心被推出去。以前它完全不會被推動
- 層級在編輯後會保留你展開的行，兩個新按鈕可以一次展開或摺疊所有行
- 統計疊加層可以再顯示三個區塊：`顯示幀物體`、`顯示關卡物體`和`顯示記憶體`
