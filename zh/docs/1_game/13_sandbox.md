# 沙盒与教程

一个可以自由操控、向自己发动攻击并一步步学习操作的竞技场

`沙盒`在主菜单中。首次启动时，游戏会提供一次教程：`开始`会打开沙盒并进入教程，`稍后`会永久关闭这个提示。无论选哪个，沙盒本身都一直留在菜单中

## 面板

沙盒左侧有一个面板。点按面板的把手可以把它收起，拖动把手可以调整面板的宽度。面板有五个标签页：

| 标签页 | 作用 |
|---|---|
| `沙盒` | 沙盒是什么，以及每个标签页的作用 |
| `教程` | 教程的步骤，以及现在要做什么 |
| `操作` | 当前操控设备的模式、体感开关，以及指向全部操作设置的链接 |
| `攻击` | 手动发动六种攻击中的任意一种，或者让波次自动到来 |
| `游戏` | 生命、攻击速度、机器人和自由相机 |

`设置`会在沙盒之上打开游戏设置。`退出`返回主菜单

## 暂停

暂停按钮在左上角，靠近面板边缘。按`Esc`也会打开暂停，而不是离开沙盒。暂停会停止一切，和关卡中一样：化身、攻击和教程。暂停窗口中有`继续`、`设置`和`返回菜单`

## 教程

六个步骤，按以下顺序：

1. `移动`：移动大约一个屏幕宽度的距离
2. `冲刺`：冲刺三次
3. `闪避`：在减速的弹幕下坚持10秒不被击中。被击中会重新开始计时
4. `穿过圆环`：圆环会扩大到超出屏幕边缘，唯一的出路是冲刺穿过它的边。冲刺期间没有东西能击中你
5. `操作模式`：在`操作`标签页上试用各种模式，然后按`保留此模式`
6. `完成`：`游玩教程关卡`会开始教程关卡

被击中或死亡只会重新开始当前步骤，而不是整个教程，这个步骤会变红，直到通过为止。已通过的步骤是绿色的

在列表中按下某个步骤就会进行那个步骤，已通过的也可以。一个步骤通过后，教程会转到下一个尚未通过的步骤。只有所有步骤都通过后，教程才算完成，这时它也会被写入统计。同一标签页上的`开始教程`可以随时重新进行教程

> [!warning] 警告
> 在`游戏`标签页上开启`无敌`时，命中完全不会被统计，所以`闪避`和`穿过圆环`这两步也看不到命中。进行教程时请保留一定的生命

这些模式改变的是当前正在操控的设备，改动会立即保存。体感没有`相对`模式。每种模式的含义：[[3_controls#操作模式]]

## 攻击与游戏

- `自动波次`会发动随机的波次，波次之间间隔`波次间隔`，和菜单背景一样
- `清除`会移除屏幕上的所有攻击
- `攻击速度`只会让攻击变慢或变快。化身始终以自己的速度移动
- 生命可以是`无敌`、1、3或5。生命用完后会恢复，沙盒永远不会结束
- `机器人`会把化身交给菜单背景所用的同一个机器人
- `自由相机`让你看到屏幕边缘以外的地方：用鼠标中键或两根手指平移，用滚轮或双指捏合缩放。蓝色边框显示关卡相机看到的范围，`恢复相机`会让视图回到它。操控、冲刺和攻击与不开启时完全一样
- 死亡的过程和关卡中一样：攻击减速并消失，化身在中央重新出现，生命被补满
