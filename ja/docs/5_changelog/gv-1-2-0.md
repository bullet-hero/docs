# gv 1.2.0

エディターからの動画エクスポート、1ファイルでのプロファイル転送、レベル一覧のフィルター、Discordへのアクティビティ表示

## 動画エクスポート

- `レベル設定`のサイドカラムにある`動画をエクスポート`で、レベルを動画にレンダリングします。同じコマンドはコマンドパレットにもあります
- コンピューターにffmpeg `7.0`以降がインストールされている必要があり、ウィンドウが自動で見つけます。Windows、macOS、Linuxに対応し、スマートフォンでは使えません
- フレームは1枚ずつレンダリングされるので、マシンがどれだけ遅くても動画は正確です
- MP4、MKV、MOV、WebM、GIF、WebP、APNG、連番画像、またはサウンドのみ。720p～2160p、または7680までの任意のサイズ、毎秒1～240フレーム
- レベルはボットがプレイし（`プレイヤー`）、グリッド、ギズモ、選択がフレームに入ることはありません

詳細：[[18_video-export]]

## プロファイル転送

- `設定` → `その他` → `プロファイル転送`で、プロファイルを1つのzipファイルにまとめます：レベル、統計、設定、ライブラリ。自動保存、エラーレポート、録画は、チェックを入れると含まれます
- `インポート`は、今あるものを置き換える（`置換`）か、追加する（`統合`）かのどちらかです。統合では、新しい方のレベルのコピーと、大きい方の統計の数値が残ります
- インポートで置き換えられたものはバックアップとして残り、`復元`で元に戻せます
- Windows、macOS、Linux、Androidに対応しています。iOSでは使えません

詳細：[[14_profile-transfer]]

## レベル一覧

- `フィルター`で、追加のフィルターのウィンドウが開きます：AIコンテンツ、長さ、進行状況、最近プレイしたもの、年齢区分、パスワード付きまたは新しいバージョンのレベル、必須または除外するタグ
- `逆順`で並び順を反転します
- 検索は、まずレベル名、次に作者、最後にタグを見ます

詳細：[[2_playing-levels]]

## Discord

- Steam版では、ゲーム内で何をしているかがDiscordのプロフィールに表示されます：メニュー、エディター、サンドボックス、またはレベル
- レベル名が表示されるのは、公開されているレベルのときだけです：Steamワークショップのアイテム、またはゲームに付属するレベル。自分のレベルや編集中のレベルの名前は決して表示されません
- 同じコンピューターでDiscordアプリが起動している間だけ動作します。Discord側で非表示にできます

詳細：[[game-privacy-policy#Discord Rich Presence]]

## 修正

- 設定でサウンドをオフにすると、レベルの音が本当に消えるようになりました。以前は他のサウンド設定が灰色になるだけでした
- ゲームを閉じる直前に変更した設定が失われなくなりました。設定が書き込まれるたびに保存アイコンが表示されます
- 設定を開いている間は、`Ctrl+S`で設定を保存します（`設定を保存`）。エディターでは引き続きレベルを保存します
- スマートフォンで設定の行が勝手に最初の選択肢に戻らなくなりました
- 一部のエフェクトが画面から消えることがありましたが、修正されました
