# gv 0.6.1

音量スライダーのミュートボタン、記憶されるウィンドウサイズ、エラーウィンドウの切り替え、ウィンドウサイズ変更後に画面が枠付きになる問題の修正

- オーディオ設定の3つの音量スライダーにミュートボタンが付きました。ゲームの実行中なら、もう一度押すと前の音量に戻ります。ミュートは単に音量0なので、ミュートのまま閉じたゲームはミュートのまま開きます
- 手でサイズを変えたウィンドウは、そのサイズを保ちます。以前は、どれか1つ設定を変えるたびに古いサイズに戻っていました
- インターフェース設定の`エラー`セクションに`例外時に通知`が加わりました。オンなら、捕捉されなかったエラーが画面に何が出ていてもその上にレポートウィンドウを開きます。オフならログに書かれるだけです。どちらの場合もレポートは収集されます
- タイムラインのキーフレームをクリックすると、インスペクターでそのタブがすぐに開きます
- 修正：ウィンドウのサイズを変えたあと、サイドバーを求めていないレベルの画面が、ウィンドウの中央に枠付きで表示されることがありました

コミット：ゲーム`810e5705`、SDK `2458b18e`
