# gv 0.13.0

預製件的根可以選中，自動儲存讓編輯器凍結的時間減半，關卡卡片寫出音樂作者

- 預製件模板的根可以選中。在預製件時間軸上點選它的那一行，它的關鍵幀就能像其他物體一樣編輯。開啟一次放置會定位到根，選中根時，播放會按模板自身的長度迴圈
- 自動儲存讓編輯器凍結的時間減半：在12.3 MB的關卡上為133毫秒，而不是265毫秒。以前它會把整個關卡複製兩次，一次用於備份，一次用於儲存
- 儲存後的清理不再在主執行緒上進行。刪除過時的另一種格式的檔案和輪換備份，以前在一幀的中途執行，每次自動儲存執行四次
- 關卡卡片在關卡作者下方單獨一行寫出音樂作者。寫哪個資源，由資源本身的`在關卡卡片上顯示`核取方塊決定。只有一個音訊資源的關卡無需任何核取方塊就會得到這一行
- 時間軸不再繪製被同一條軌道上另一個片段完全遮住的片段。較寬的片段位於較窄的片段之下，選中或正在拖動的片段位於整條軌道最上層。沒有繪製的片段仍然可以點選選中
- 時間軸一被隱藏就會釋放它的元素。以前摺疊的關卡和未選中的標籤頁每幀的開銷與開啟時一樣
