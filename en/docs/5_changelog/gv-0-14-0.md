# gv 0.14.0

Effects play the way their author meant, an effect can be removed from an object, and two new keyboard shortcuts in the editor

## Effects

- An effect emits particles in the direction its object faces, and stepping back on the timeline draws the same as playback drew. Before, the stream was attached to the world, and on the same frame you could see a curved trail during playback and a straight one after a step back
- An emitter shape other than `Point` (`Circle`, `Line`, `Cone`, `Torus`) rotates with the object. Before, it stayed aligned to the world, and a rotated effect spawned particles along axes that had nothing to do with it
- An effect keeps simulating off screen, so particles that are meant to fly into the frame exist before they get there. Before, an emitter outside the camera spawned nothing, so an effect could look right in the editor and vanish in the game. The cost is GPU time for effects off screen
- **Breaks existing levels.** An effect's linear force is now an acceleration per second, as the format always described it. Before, it acted about 50 times stronger at the 50 Hz effect rate. A level where it is set (`lfrc`) has to be retuned: one particle with a force of `(1, 0)` now travels 0.51 units in 1 s, against 25.5 before

## Editor

- `Ctrl+Shift+A` (`Deselect All`) clears the whole selection at once: objects, keyframes, audio and beat. `Ctrl+Shift+E` (`Exit Prefab Mode`) exits every open Prefab Mode session. Both can be rebound like any other shortcut
- The effect picker has a `Nothing` option, so an effect can be removed from an object. Before, once an effect was picked, it could not be cleared through the picker
- Opening another level from inside the editor rebuilds the object list, and Prefab Mode closes together with the level it was opened in
- A double click on a timeline clip near the edge of the area no longer drags the object onto the track above. Before, edge scrolling started on the press, the view slid under a still pointer, and the move turned into a change of layer
- The [[12_launch-arguments|launch argument]] `--autosave on|off` turns the editor's autosave on or off for one launch without changing the setting
