# gv 0.3.3

Un shader rápido y una cámara del editor que se mueve con el ratón o con dos dedos

- **Un shader nuevo para los objetos del nivel.** Tiene una sola pasada y solo lo que necesita el dibujo, y es unas dos veces más rápido que el anterior
- **La cámara del editor.** En PC se mueve con el ratón, en un teléfono con dos dedos. Un botón aparte la devuelve al foco
- **Texturas.** Ahora cualquier textura del juego o del nivel se puede aplicar a un objeto con sus propias coordenadas UV
- **El visor de registros.** La primera versión de un panel que muestra los mensajes del editor

Commits: juego `b9d32ac7`, SDK `88c3224d`
