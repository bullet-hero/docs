# 이미지와 폰트

도형으로 충분하다면 도형을 쓰십시오: 파일도, 메모리 비용도, 권리 문제도 없습니다. 이미지는 화면에서 차지하는 크기에 맞게 만들고, 모바일 레벨에서는 최대 {{v:texture.mobile-max-side}}, 그 밖에는 최대 {{v:texture.desktop-max-side}}까지로 하십시오

이미지 크기는 2의 거듭제곱으로 올림하십시오

## 형식과 크기

엔진이 파일의 바이트에서 디코딩할 수 있는 것은 모두 불러옵니다. 실제로는 `png`, `jpg` 형식입니다

파일 크기는 게임이 아니라 하드웨어가 제한합니다:

| 기기 | 가장 긴 변 |
|---|---|
| Android, 보장됨 | 4096 |
| Android, 일반적 | 8192-16384 |
| 데스크톱 PC | 최대 32768 |

## 메모리

**실제 한계는 메모리입니다.** 메모리에서 이미지는 파일 용량과 관계없이 원시 픽셀로 저장됩니다. `png` 이미지는 픽셀당 4바이트를 차지합니다. `jpg` 이미지는 투명도가 없어서 3바이트를 차지합니다

| 크기 | 메모리 (`png`) |
|---|---|
| 512 x 512 | 1 MB |
| 1024 x 1024 | 4 MB |
| 2048 x 2048 | 16 MB |
| 4096 x 4096 | 64 MB |
| 8192 x 8192 | 256 MB |

> [!caution] 주의
> 8192 텍스처 하나는 그림 한 장에 기가바이트의 4분의 1입니다. 휴대폰에서는 느려지는 정도가 아니라 크래시가 납니다

## 플레이어가 정하는 것

모든 플레이어의 그래픽 설정에 있는 세 항목이 이미지가 메모리를 얼마나 차지할지 정합니다:
- 불러올 때 이미지를 압축할지 여부. 압축하면 위 숫자가 4-8분의 1로 줄어듭니다
- 메모리에서 이미지의 가장 긴 변. 변이 절반이면 메모리는 4분의 1
- 밉맵, 즉 작게 그릴 때 쓰는 축소 복사본을 만들지 여부

휴대폰에서는 기본적으로 이미지를 압축하고 최대 {{v:texture.mobile-max-side}}까지로 제한합니다. 데스크톱 PC에서는 이미지를 원본 그대로 두고 최대 {{v:texture.desktop-max-side}}까지로 제한합니다

**제작자가 할 일은 이미지의 필드이며, 무엇보다 이미지가 무엇을 그린 것인지입니다.** 필드는 리소스 목록에서 이미지 옆에 있습니다. 사진은 축소와 압축을 가장 잘 견딥니다. 가장자리가 뚜렷한 그림은 덜 견딥니다

`{{ui:enum_texture-kind_pixel-art}}` 이미지는 기기가 무엇을 선호하든 밉맵을 받지 않습니다. 또한 처음에는 압축과 스무딩 없이 시작하며, `{{ui:level_resources_texture-compression}}` 및 `{{ui:level_resources_texture-sampling}}` 필드로 이를 바꿀 수 있습니다

## 밉맵

밉맵은 작은 이미지가 반짝거리는 것을 막습니다. 밉맵은 이미지가 화면에서 작을 때 원본 대신 그려지는 축소 복사본입니다. 메모리를 3분의 1 더 씁니다

밉맵이 없으면 축소된 이미지는 매끄러워지지 않고 일렁입니다. 플레이어는 밉맵을 끌 수 있고, `{{ui:enum_texture-kind_pixel-art}}` 이미지는 밉맵을 절대 받지 않습니다

화면에서 200픽셀을 차지하는 4096 이미지는 미리 256 크기로 줄인 같은 이미지보다 메모리를 256배 씁니다

## 이미지보다 도형

도형은 모든 면에서 이미지보다 저렴합니다: 파일도, 메모리도, 권리 문제도 없습니다. 내장 도형은 사각형 위의 그림이 아니라 실제 지오메트리입니다. 그려졌다가 버려지는 투명한 여백이 없습니다

이 차이는 휴대폰에서 드러납니다. 중급 모바일 칩에서 오브젝트 1000개짜리 장면은 GPU 시간의 95-97%를 픽셀 셰이딩에 씁니다. 도형은 자기 사각형의 29.4%를 덮습니다. 텍스처를 입힌 사각형의 나머지는 투명한 낭비입니다

이미지는 정확히 그림이 필요할 때 필요합니다: 로고, 사진, 손으로 그린 아트. 기하학적 형태라면 도형을 쓰십시오. 필요한 도형이 없다면 `{{ui:hint_level_shape-editor_header}}`에서 그리십시오

## 폰트

폰트는 `ttf`, `otf`, `ttc` 형식으로 불러옵니다. 자체 폰트가 없으면 텍스트는 시스템에 있는 폰트로 그려지며, 이는 기기마다 다릅니다

`{{ui:settings_level-settings_fontcache}}` 항목은 그리기 위해 미리 준비해 둔 문자 집합입니다. 생성기가 레벨에 들어 있는 텍스트로 이것을 다시 만듭니다. 텍스트가 더 이상 바뀌지 않을 때 생성기를 실행하십시오
