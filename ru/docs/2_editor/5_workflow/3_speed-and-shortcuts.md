# Скорость и горячие клавиши

Все горячие клавиши редактора, как их переназначить и четыре вещи, которые экономят больше всего времени

## Четыре главных экономии времени

- **`Выполнить команду`** (`Ctrl+Shift+P`) - всё, что умеет редактор, с поиском по названию. Быстрее, чем вспоминать, на какой панели лежит кнопка
- **`Поиск по содержимому`** (`Ctrl+F`) - переход к объекту или аудиодорожке по имени. Плейхед переходит вместе с вами
- **`Показать`** (ping) - вьюпорт вписывает выделенное, таймлайн и иерархия прокручиваются к нему, всё сразу. Повторное нажатие переходит к следующему объекту множественного выделения
- **Стрелки на таймлайне** - двигают по направлению, а не по порядку в списке. Между соседними ключами можно ходить без мыши

### Таймлайн

| Клавиша | Название в настройках | Действие |
|---|---|---|
| `Z` | `Инструмент: сворачивание` | переключить свёртку: все поддеревья, только выбранные типы, ничего |
| `X` | `Инструмент: магнит` | включить или выключить привязку |
| `C` | `Инструмент: выделение` | инструмент выделения |
| `V` | `Инструмент: рамка` | инструмент рамки |
| `B` | `Инструмент: ножницы` | инструмент ножниц |
| `N` | `Инструмент: края` | инструмент краёв |
| `Ctrl+E` | `Свернуть выделение на таймлайне` | свернуть выделенные объекты на таймлайне |
| `Q` | `Вкладка: таймлайн уровня` | открыть таймлайн уровня |
| `W` | `Вкладка: локальный таймлайн` | открыть локальный таймлайн |
| `E` | `Вкладка: таймлайн аудио` | открыть таймлайн аудио |
| `R` | `Вкладка: таймлайн событий` | открыть таймлайн событий |
| `T` | `Вкладка: таймлайн префаба` | открыть таймлайн префаба |
| `Shift+T` | `Окно сетки ритма` | окно сетки ритма, в нём отбивается темп. У самого `Отстучать темп` клавиши по умолчанию нет, назначьте её, если нужна |
| зажатый `Ctrl` с колесом | `Модификатор панорамы (колесо)` | панорамирование |
| зажатый `Shift` с колесом | `Модификатор зума (колесо)` | зум |

`Z X C V B N` идут по панели инструментов таймлайна слева направо, а `Q W E R T` - по полосе вкладок. Таймлайн, у которого инструментов меньше, теряет их справа: у локального таймлайна есть только `Z X C V`. Буква, для которой у открытого таймлайна нет инструмента, ничего не делает

| Клавиша | Название в настройках | Действие |
|---|---|---|
| `Up` | `Навигация вверх` | ход вверх по той поверхности, куда вы кликнули последней |
| `Down` | `Навигация вниз` | ход вниз по той поверхности, куда вы кликнули последней |
| `Left` | `Навигация влево` | ход влево по той поверхности, куда вы кликнули последней |

## Стрелки на таймлайне

Стрелка выбирает ближайший элемент в этом направлении на экране. Одно и то же нажатие находит один и тот же элемент при любом зуме

- При множественном выделении стрелка начинает с элемента, который дальше всех в сторону нажатия. Она никогда не шагает обратно внутрь выделенного блока
- Переход стрелкой всегда заменяет выделение. Он никогда к нему не добавляет
- Таймлайн прокручивается ровно настолько, чтобы показать новый элемент. Клик по счётчику плейхеда по-прежнему ставит вид по центру
- Пока включён пробный игрок, стрелки управляют им, а не таймлайном. Иерархия и вкладка `Сырые данные` сохраняют стрелки за собой, если в них кликнуть

## Как увидеть уровень

**Просмотр.** Зажмите `` ` ``, чтобы скрыть интерфейс редактора и смотреть только на уровень. Это удержание, а не переключатель: отпустите клавишу, и всё вернётся. Уровень, полосы леттербокса, игрок и границы камеры остаются видны.
Кнопки и настройки для этого нет. Клавиша переназначается как `Просмотр (удерживать)`

**Сетка вьюпорта** включается своей кнопкой на панели инструментов или командой `Сетка вьюпорта`. При открытии она выключена. Это меняет `Настройки` → `Редактор уровней` → `Сетка включена по умолчанию`, а то, что вы её включили, между сессиями не запоминается

**Магнит гизмо** привязывает к сетке то, что тянет гизмо. По умолчанию он включён и не зависит от режима гизмо. Его переключают кнопка на панели инструментов и команда `Магнит гизмо`

**Пауза - обычное состояние для разглядывания.** Сетка, коллайдеры, наложение бота, ручки гизмо и рамка выделения продолжают рисоваться, пока воспроизведение на паузе. Если схватить ручку гизмо, воспроизведение встаёт на паузу

## Переназначение

Любую клавишу можно переназначить: `Настройки` → `Клавиши`

Хранятся только клавиши, которые вы изменили. Остальные берутся из умолчаний.
Поэтому улучшенное умолчание дойдёт до вас, если вы эту клавишу не трогали.
`Сбросить клавиши` просто удаляет ваши изменения, и все клавиши возвращаются к умолчаниям

> [!tip] Подсказка
> Подписи клавиш не вшиты в интерфейс. После переназначения палитра команд и все контекстные меню сразу показывают новую клавишу

## Нажимаемые и удерживаемые клавиши

Нажимаемая клавиша срабатывает, только если модификаторы совпали точно.
`Ctrl+Shift+P` не сработает заодно как `Ctrl+P`, а голая `T` не сработает при зажатом `Ctrl`

Удерживаемая клавиша срабатывает, если её модификаторы есть среди зажатых. Она уточняет жест, который уже идёт

> [!info] Интересно
> Поэтому две удерживаемые клавиши могут намеренно делить одну кнопку. Множественный выбор и панорамирование таймлайна обе на `Ctrl` и друг другу не мешают
