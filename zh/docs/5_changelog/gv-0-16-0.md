# gv 0.16.0

来自更新版本的文件不会打开，游戏会提示更新，新增不保存数据的匿名模式，编辑器在大关卡上更快

## 版本与存档

- 来自更新版本游戏的文件不会打开，而是出现`需要更新`窗口：关卡、导入的归档包和剪贴板中的编辑器内容都是如此。`下载`会打开网站上的下载页面。在关卡列表中，这样的关卡标为`来自更新版本的游戏`。以前编辑器会在警告后提供打开更新版本关卡的选项
- 由更新版本保存的设置或统计数据保持不动。游戏使用默认值运行，在关闭之前不保存任何自己的数据，并询问怎么做：`继续停用存档`或`覆盖数据`。自身统计数据较新的关卡，会在卡片上显示说明，而不是最佳成绩
- 新设置`不保存游戏数据（匿名模式）`。开启时，游戏既不写入设置，也不写入统计数据，这段时间里你玩的内容不会写入磁盘。[[12_launch-arguments|启动参数]]`--suppress-game-saves`会在整次启动中开启它
- 当`--autosave`为本次启动设置了编辑器的自动保存时，`自动保存`设置会注明这一点

## 游戏

- 按住鼠标按键操控时，划过暂停按钮不再打断操控。在关卡上开始的按下，无论你把它移到哪里都仍然是操控，在按钮上开始的按下则仍然属于按钮
- 用光标冲刺到距离不足一个单位的点不再被忽略。化身尚未站在上面的任何目标，都会得到一次按距离缩短的冲刺
- 在Android上，游戏需要Vulkan，所以Google Play不再向没有Vulkan的设备提供它。这些设备上会出现黑屏

## 编辑器

- 编辑器在大关卡上更快了。不在屏幕上的时间轴或面板不再在每次编辑时重建，而是在显示时追上进度。“这个副本属于哪次放置”这一问题，每次编辑只通过一个索引来回答，而不是为每个选中的物体、字段和关键帧轨道遍历整个关卡
- 编辑不再重置事件和音频关键帧的选中项，也不再清除Local时间轴上的关键帧选中项
- 普通编辑不再播放撤销和重做的音效。只有撤销和重做才会播放它
- 点击两个时段相同的片段时，会选中绘制在上面的那个。以前选中的是被遮住的那个，在预制件模式中，点击嵌套模板的内容每次都会选中它的放置
- 当外层模板有需要恢复的选中项时，退出嵌套预制件不再报出`Collection was modified`错误
