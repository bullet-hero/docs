# gv 0.1.0

Das erste Levelformat und die erste Engine, die es abspielt: Objekte, Themes, Effekte, Text, Sound und Kollisionen

In sechs Wochen wurden aus den Experimenten zwei echte Teile des Spiels. Ein Menü oder einen Editor gibt es auf dem Bildschirm noch nicht, aber ein Level lässt sich schon in einer Datei beschreiben und abspielen

**Das Levelformat.** Ein Level ist eine `JSON`-Datei, die das SDK beschreibt. Sie enthält schon Objekte, Elternobjekte, Themes (Farbpaletten), Effekte, Sound und Prefabs

**Die Engine, die es abspielt.** Jeder Frame wird von parallelen Jobs aufgebaut und dann gezeichnet:

- Position, Drehung, Skalierung und Elternobjekte
- Farben aus dem Theme des Levels und Texturen
- die Kamera des Levels
- Partikeleffekte über einen gemeinsamen *VFX Graph*-Effekt
- die Musik des Levels
- Text über *UniText*, das *TextMeshPro* ersetzte
- Kollisionsprüfungen, die Grundlage, auf der Objekte später den Spieler treffen werden
- im Level platzierte Prefabs

In derselben Version wechselte das Projekt auf Unity 6.4
