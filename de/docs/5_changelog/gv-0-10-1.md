# gv 0.10.1

Ein neues eingebautes Level, der Build-Name in der Versionszeile und ein schlankeres Android-Release

- Die beiden Testlevels, die mit dem Spiel kamen, wurden durch ein Demo-Level ersetzt, `New zero demo`
- Die Versionszeile in den Einstellungen nennt neben der Version auch den Build: `gv X, sv Y, mg Z, Windows, Steam, Release`, also Plattform, Store und Build-Typ. Die erste Zeile jedes Logs sagt dasselbe, so nennen ein Bugreport und sein angehängtes Log immer denselben Build
- Im Levelbrowser ist beim Öffnen jeder Quellenfilter an, und die Quellenzeile wird auch bei nur einer Quelle angezeigt. Ein Level, das vorhanden, aber herausgefiltert war, sah aus wie ein fehlendes
- Release-Builds enthalten keine Debug-Symbole mehr. Auf Android sind das 25,7 MB weniger bei einem Release von 124,9 MB
