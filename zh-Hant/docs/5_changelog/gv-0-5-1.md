# gv 0.5.1

為玩家帶來檢查點、統計、新的操作方式和翻譯後的介面，為作者帶來歷史樹和節拍網格，手機畫面快4倍

## 遊戲

- 檢查點生效。死亡會把本次遊玩倒回到最後到達的檢查點：關卡時鐘在0.5秒內平滑停下，倒回，再平滑恢復。`失敗時開啟選單`則改為彈出結果視窗
- 統計資料儲存在磁碟上。關卡介面顯示所選啟動引數下的`最佳`和`嘗試次數`，設定中的`檔案`標籤頁顯示啟動次數，以及在遊戲、選單和編輯器中的時長
- 操作方式為四種裝置重寫：`鍵盤和滑鼠`、`觸屏`、`手柄`和`體感`。觸屏有了螢幕上的操控按鈕
- 任何快捷鍵都可以在`快捷鍵`標籤頁中重新繫結，改動對整個遊戲生效
- `選單背景`提供`無`、`形狀`和`機器人`。`機器人`是新的預設值：一個即時競技場，由機器人操控化身並即時躲避危險
- `螢幕方向`設定和各介面的豎屏佈局。關卡自己宣告它的方向
- 內建關卡隨遊戲提供。它們和其他關卡一樣遊玩，不能編輯，但可以複製到你自己的資料夾中編輯副本
- 介面完整提供英文和俄文，編輯器和其他介面中有提示
- 抗鋸齒：`MSAA`和`FXAA`

## 編輯器

- `歷史`標籤頁：撤銷歷史是一棵帶分支的樹，你可以跳到其中任意一點
- 時間軸工具Trim和Blade、標記，以及吸附到節拍網格
- 節拍網格：節拍段、按`T`跟著音樂敲擊，以及用`由敲擊建立`把敲擊變成一個節拍段
- 可以選中多個物體並同時編輯它們的某個欄位。複製、貼上和建立副本
- 原始資料編輯器把整個關卡當作資料來編輯，用於檢視器覆蓋不到的情況
- 所有選擇視窗合併成了同一個帶篩選和標籤的搜尋視窗
- 一個開關即可顯示整個關卡的碰撞體
- 欄位和麵板旁的`?`會開啟提示，編輯器設定中還有一份寫給關卡作者的指南
- `自動儲存`生效，備份寫入遊戲的`backups`資料夾
- 編輯器偏好設定移入設定，位於編輯器標籤頁的9個分割槽中

## 關卡與格式

- 形狀取代了預設紋理：約500種形狀，由遊戲自己生成。同樣的形狀也用作碰撞體
- 二進位制`.blob`格式。volcano測試關卡（19,341個物體）佔用5.1 MB，而JSON需要15.7 MB，讀取耗時203毫秒，而不是9,946毫秒。JSON本身的讀取也快了6倍：1,837毫秒，而不是11,249毫秒

## 效能

- 手機繪製關卡的速度約快了4倍。在Snapdragon 732G（Adreno 618）上，壓力測試場景的一幀從52.19毫秒降到12.94毫秒（每秒77幀）
- 介面之間的載入畫面取代了以前顯示的綠屏
