# gv 1.1.0

釋出到Steam創意工坊、資源合集、帶教程的沙盒、快速設定、“僅碰撞體”模式和中文

> [!warning] 警告
> 由`gv 1.1.0`儲存的檔案無法在`gv 1.0.0`中開啟：你的設定、你的統計資料和你儲存的關卡。在那裡它會開啟`需要更新`視窗。來自`gv 1.0.0`的檔案在`gv 1.1.0`中照常開啟。更多：[[5_troubleshooting]]

## 傳送關卡與創意工坊

- `分享`按鈕彙集了傳送關卡的所有方式。`分享方式`視窗提供`壓縮包`和`Steam創意工坊`，每種方式在傳送前都會自行檢查關卡
- 壓縮包可以是資料夾、tar.gz或zip，zip可以用密碼保護
- 在Steam版本中，關卡或合集可以直接從編輯器釋出到創意工坊。再次釋出同一關卡會更新已有的物品
- 關卡、它的每個資源以及它的`封面`都可以宣告是否藉助AI製作（`AI 生成`）。只要其中有AI製作的內容，選單中的關卡卡片就會標明

## 合集

- 合集是一組可用於任何關卡的資源：預製件、主題、形狀、特效、紋理、字型和音訊
- 編輯器設定中有`庫`標籤頁：你的資源、你的合集，以及你在創意工坊訂閱的合集
- `關卡設定`中有`合集`標籤頁。它可以連同所有依賴一起匯入整個合集，也可以用關卡的資源組成一個合集
- 如果關卡中已經有同一資源的另一個副本，遊戲會詢問保留哪一個

## 遊戲

- `沙盒`是主選單中的新按鈕。裡面有六步教程（移動、衝刺、躲避、衝刺穿過圓環、選擇操作模式），以及一個可以手動發動攻擊的面板。遊戲只在首次啟動時提供一次教程
- `快速設定`在一個畫面上設定效能、畫面效果、語言和音量。首次啟動時它會自動開啟，之後一直留在選單中。設定中的高階分割槽現在預設摺疊
- `“僅碰撞體”模式`位於設定的`圖形`標籤頁。關卡只繪製可能擊中你的東西，以平面填充顯示在純色背景上。音樂、碰撞和統計都保留，這一局與其他遊玩同樣計入
- 受擊後的擊退距離是7.5個單位，而不是10個，正好是一次完整衝刺的長度。緊貼游標的極短衝刺現在總會觸發
- `禪`模式重新會受擊：有擊退、護盾和受擊效果，但不消耗生命。想讓子彈穿過你，可以使用單獨的`無碰撞`選項，它的遊玩單獨統計
- 暫停和結果視窗中的`返回引數設定`會回到開始這一局的畫面，並保留相同的引數
- 遊戲支援簡體中文

## 操作

- 每個裝置只有一個`啟用`開關。你最後使用的裝置主導操作，衝刺和暫停可以在任何啟用的裝置上進行
- 傾斜操作以螢幕朝上平放的手機為靜止狀態。不需要校準，螢幕旋轉後一切依然正確
- 手柄上除Start和Select外，任意按鍵都會衝刺。Start暫停
- 鬆開滑鼠按鍵時化身停下（`鬆開時停止`），觸控則不會（`抬起手指時停止`）。兩者都可以切換
- 操控時第二根手指總是衝刺，不再按下它下面的按鈕

## Android
