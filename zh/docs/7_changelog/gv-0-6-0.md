# 版本0.6.0

启动参数，F11切换全屏，设置中显示版本，Afterbeat导入报告更清晰

- 桌面端的启动参数：`--menu`、`--editor`或`--game`选择第一个界面，`--level`按ID或文件夹指定关卡，`--speed`、`--lives`、`--seed`、`--bot`以及`--checkpoints` / `--no-checkpoints`设置本次游玩。错误的参数不会阻止游戏启动，只会在日志中留下一行。更多：[[12_launch-arguments]]
- F11在游戏的每个界面上切换全屏，按两次会让窗口回到原来的位置。它和设置中的下拉菜单改的是同一个设置。手机上没有这个功能
- 设置在一行中显示游戏版本、SDK版本和关卡格式代数。单击即可复制到剪贴板
- Afterbeat导入报告把最严重的问题列在最前面，报告很长时也不会变慢
- 含换行的关卡描述不再撑高关卡列表中的行，而是保持一行并以省略号结尾
