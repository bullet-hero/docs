# 安装

从哪里获取游戏，游戏把你的关卡存在哪里，以及更新时会发生什么

## 下载

所有版本和商店：[[download]]

游戏可以在电脑和手机上运行。关卡、编辑器和操作在所有平台上都一样

商店版本由商店负责安装和更新。Android的`.apk`需要手动安装

## 你的文件在哪里

没有账号。游戏记住的一切都保存在你的设备上

游戏有自己的数据文件夹。它不是游戏的安装文件夹

| 系统 | 文件夹 |
|---|---|
| Windows | `C:\Users\<you>\AppData\LocalLow\vertoker\Bullet Hero` |
| Android | `/storage/emulated/0/Android/data/com.vertoker.BulletHero/files` |

最快的打开方式是在游戏中：`设置`→`常规`→`打开游戏文件夹`

里面有什么：

| 文件夹 | 内容 |
|---|---|
| `levels` | 你的关卡，每个关卡一个文件夹 |
| `backups` | 编辑器的自动保存 |
| `stats` | 统计数据 |
| `settings.json` | 设置 |
| `reports` | 错误报告 |

## 更新

新版本的游戏能读取所有旧的关卡和设置，不需要搬移任何东西

旧版本不会打开新版本的关卡。如果游戏要求你更新，就更新

> [!caution] 注意
> 在Android上，卸载游戏也会删除你所有的关卡。卸载前请保存好需要的关卡

## Android与文件夹访问权限

当游戏需要自己文件夹以外的文件时，Android会亲自询问要打开哪个文件夹。游戏只能看到那个文件夹，其他都看不到

你可以收回授予的权限：`设置`→`其他`→`文件夹访问权限`
