# gv 0.8.0

The timeline counts frames from 1, and a selection turns into a prefab in one action

- Frames are counted from 1. The first frame of a level is frame 1, it starts at 0 seconds, and the playhead, the inspector and the level file show the same number. A keyframe's frame inside an object also starts at 1
- Existing levels were not converted, so three things shifted. All random values were rolled again, because a random value depends on frame numbers. Checkpoint deaths and the best result saved before this version are read one frame off. Undo history and autosaves written before the change do not replay
- The playhead readout shows fractions of a second in milliseconds (`0:00.983` on frame 60). The frame number stands next to it, and the old notation looked as if it contradicted it
- `Create Prefab From Selection` (`Ctrl+G`) turns the selected objects into a prefab. The same action is in the menu of a hierarchy row: `Create Prefab From This`
- The avatar now grows when it appears and shrinks to a point when it disappears, instead of popping in and out instantly
- Closed windows cost the editor screen 4.6 ms every frame: the interface walked through them anyway. Ten of them are now removed from the interface entirely while closed
- The statistics overlay got a `Show Profiling` block: how long each stage of the simulation took
