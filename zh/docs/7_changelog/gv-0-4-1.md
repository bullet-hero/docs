# 版本0.4.1

关卡编辑器从一条时间轴加一个层级成长为完整的编辑器，关卡有了后期处理、音频效果和可复现的随机性

## 编辑器

- 物体、关键帧和关卡事件的检视器。在这个版本之前，编辑器只有时间轴、层级，别的几乎没有
- 五条时间轴：关卡、所选物体的关键帧、关卡事件、音频和预制件
- 视口中有位置、旋转、缩放、尺寸、锚点和轴心的控制柄。每种模式都有自己的快捷键
- 预制件经过重做：模板在专门的预制件模式中编辑，每次放置都可以覆盖模板的数值
- 关卡资源在编辑器中管理：音频、纹理、字体、碰撞体、特效、主题和预制件。特效、主题、碰撞体和预制件也可以取自现成的库。文件选择器目前只在桌面端可用
- 自定义碰撞体编辑器、曲线编辑器、渐变编辑器，以及带预览的缓动预设
- 物体可以更改类型和父级，无需重新创建
- 选中项以移动的虚线轮廓显示
- 可以直接从编辑器中游玩关卡。化身在编辑器中可见，并且可以在编辑器中关闭后期处理
- 关卡设置新增作者、许可证、生成器，以及规则检查：它会找出关卡中的问题并提供修复

## 游戏

- 后期处理作为关卡事件，共12种：模拟故障、数字故障、泛光、色差、颜色曲线、胶片颗粒、镜头畸变、提升/伽马/增益、运动模糊、阴影/中间调/高光、暗角和白平衡
- 音频轨道上的音频效果，共11种：合唱、压缩器、失真、回声、镶边、高通、低通、标准化、参数均衡、变调和混响
- 音乐同步经过重写。游戏跟随音频时钟，用轻微的音高变化而不是跳跃来纠正小的偏差，因此每隔几帧出现的卡顿消失了
- 修复：在编辑器中，时间轴光标会让关卡时钟慢约15%
- 随机性可复现：同一关卡使用同一种子，在任何设备上的表现都相同。关卡界面有一个种子字段，带有随机生成和清空按钮
- 关卡界面显示关卡及其资源的作者和许可证

## 关卡与格式

- 物体的时段由起始帧和长度组成。每条边都可以锚定到父级的边上，使子物体跟随父级
- 图层相对于父级计算，而不是一个绝对数值
