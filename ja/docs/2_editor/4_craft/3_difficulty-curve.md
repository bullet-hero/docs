# 難易度とカーブ

プレイヤー自身の数値（すべて[[6_avatar]]と[[7_damage]]にあります）と、12〜15フレームという人間の反応時間を基準に設計します。新しいパターンは、まず安全な形で見せます

自分のレベルの難しさは自分では判断できません：初めて見る人にレベルを試してもらいます

## 数値で見るプレイヤー

アバターの正確な値は[[6_avatar]]と[[7_damage]]にあります。それがレベルにとって何を意味するか：

| 項目 | 設計にとっての意味 |
|---|---|
| プレイヤーの当たり判定 | 描かれた体よりずっと小さいため、体をかすめた弾は当たらないことが多い |
| ダッシュ | 画面の高さの4分の3をほぼ一瞬で横切る |
| ダッシュ中の無敵 | ダッシュそのものより長く続くため、薄い障害物をダッシュで抜けても安全 |
| 被弾後 | 操作できない短いノックバックのあと、続く被弾を無視する猶予時間がある |
| 人間の反応 | 0.2〜0.25秒、60fpsで12〜15フレーム |
| 開始時の値 | ライフ3、速度1.0、チェックポイントはオン |

ここから導かれる目安：
- 幅1ユニットの隙間は広く、0.6の隙間はぎりぎり
- 1回のダッシュで進む距離は、0.5秒走った距離と同じ

## 被弾してもすぐには倒れない

被弾するとプレイヤーはノックバックし、短い間操作できなくなります。その後しばらくは続く被弾が無視されます（[[7_damage]]）。10個の弾が連なった壁で失うライフは10ではなく1です

> [!info] 補足
> 直感とは逆です。密な一斉射撃は即死に見えます。実際には、無敵がちょうど切れたときに飛んでくる1発の弾よりも安くつきます

## プレイヤーが選ぶもの

ライフ、再生速度、チェックポイントは、プレイヤーが開始画面で選びます。デフォルトはライフ3、速度1.0、チェックポイントはオンです

チェックポイントを置くことはできますが、使わせることはできません。半分の速度でプレイすることを禁じることもできません

デフォルトの値を基準に設計しますが、「ここで倒れるはず」という計算の上には何も組み立てないようにします。設計するのは罰ではなく感覚です

## ループ

プレイヤーは1つのループを繰り返します：プレイして、倒れて、もう一度挑戦します。良いレベルはその上に層を重ねていき、ループは次のようでなければなりません：
- 最初はシンプルで、いきなり難しいメカニクスを出さない
- 拡張できる：新しい要素が少しずつ加わり、飽きさせない
- 報われる：正しい行動にすぐ報酬があることで、やる気が続く

## カーブ：教える、試す、ひねる

1. ミスがほぼ起こらない安全な形でパターンを見せる
2. 本番としてそれを要求する
3. 変数を1つ（速度、方向、数）変えて、もう一度要求する

パターンが最初からいきなり難しい形で出てくると、責められるのはレベルです。プレイヤーは倒れ、何を求められていたのかわかりません

公平さにも限度があります。過剰な「手取り足取り」は、不公平と同じように楽しさを奪います

## 暗記

覚えなければクリアできないレベルは、正当なジャンルです。ただし、それは偶然ではなく意図した結果でなければなりません

境界線はシンプルです：倒れたあと、プレイヤーは何を覚えればよいのかを理解できなければなりません。10回倒れてもまだわからないなら、それは暗記ではなくノイズです

## 他人の目で試す

自分のレベルは自分では判断できません。公開するころには、自分の難所を200回は抜けていて、自分にとっては簡単になっています

> [!tip] 推奨
> 初めて見る人にレベルを渡し、黙って見ることをおすすめします。ヒントは出しません。人が3回倒れて「何をすればよかったのか」と尋ねる場所は、難しいのではなく、わかりにくいのです

## 短いものから始める

最初のレベルは1〜2分にします。曲が終わる前に興味が尽きます。4分のレベルは4倍の作業量で、やめる理由は10倍です
