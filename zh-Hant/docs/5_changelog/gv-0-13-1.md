# gv 0.13.1

預製件放置隨分組一起移動，歷史標籤頁顯示每一步改了什麼，時間軸工具集中到一組按鍵上

- 拖動包含預製件放置的分組時，這些放置所放置的內容現在也會一起移動。以前副本留在原來的幀上，只要向左移動一幀，`Frame must be at least 1`錯誤就會在之後的每一幀列印，直到本次會話結束
- 被裁剪的放置在編輯其時段後，動畫保持在原位。以前編輯會讓放置的關鍵幀相對於它所放置的內容發生偏移
- `歷史`標籤頁的每一行，以及控制台中每一條撤銷或重做記錄，現在都會顯示這一步背後的數字：物體的id和名稱、軌道，以及它在哪些幀之間移動（例如`f150 -> f160`）
- 時間軸工具移到了一組按鍵上，順序與面板上相同：`Z`摺疊，`X`吸附，`C`選擇，`V`框選，`B`剪刀，`N`邊緣。以前`V`是選擇，`C`是剪刀，所以請檢查你的習慣。工具較少的標籤頁從右側減少工具（Local標籤頁有`Z` `X` `C` `V`），所以同一個字母在另一個標籤頁上絕不會代表另一個工具。六個按鍵都可以在設定中重新繫結，名稱為`工具：吸附`、`工具：迴圈切換摺疊`等
- 關卡校驗不再用虛假的問題淹沒帶預製件的關卡。在一個有700個物體的關卡上，它曾報告38,736個損壞的重對映和19,993個懸空的根覆蓋，而其中沒有一個是真的
- 內建關卡`New zero demo`在這個版本中被移除
