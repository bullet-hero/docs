# Juego

Bullet Hero es un híbrido de juego de ritmo y bullet hell: guías un pequeño cuadrado que tiene que sobrevivir hasta el final de la canción. El juego es gratuito y no hace falta ninguna cuenta

Las primeras páginas sirven para empezar a jugar. Más adelante está la mecánica de una partida, para quien quiera los números exactos
