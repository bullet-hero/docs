# サーバーへの接続

ゲームには、すべてのビルドで使える公式サーバーOWSと、フルビルド専用のコミュニティサーバーNOWSが用意される予定です。Bullet Heroはコミュニティサーバーをモデレーションしないため、運営者を知っているサーバーにだけ接続してください

> [!warning] 警告
> サーバーはまだなく、ゲームはサーバーに接続できません。アドレスの形式も、接続画面も、アカウントもありません

## 用意される予定のサーバー

| | OWS | NOWS |
|---|---|---|
| 正式名称 | Official Web Services | Non-official web services |
| 運営者 | Bullet Hero | 誰でも |
| モデレーション | Bullet Hero | サーバーの運営者 |
| 接続できるビルド | すべて | フルビルドのみ |

**OWSはデフォルトのサーバーです**。すべてのプラットフォームのすべてのビルドがOWSを知っているため、設定は何も要りません

**NOWSはコミュニティサーバーです**。Bullet HeroはNOWSを管理もモデレーションもしません

**Steamワークショップは、PCでレベルを入手する3つ目の経路です**。Steamビルドは、サブスクライブしたアイテムを一覧表示して起動し、エディターからレベルやコレクションをそこに公開します。詳細：[[17_publishing]]

## 接続できるビルド

| ビルド | 入手先 | OWS | NOWS |
|---|---|---|---|
| ストア版ビルド | Google Play、App Store | 可 | 不可 |
| フルビルド | [GitHub](https://github.com/bullet-hero/releases)とプロジェクトのWebサイト | 可 | 可 |

ストア版ビルドは、どうやってもコミュニティサーバーに接続できません。NOWSのサポートは設定の裏に隠されているのではなく、コンパイル時に取り除かれています

理由はストアの規約です。ストアが判断するのは、プログラムが表示するボタンではなく、プログラムにできることです。また、他の人が目にするコンテンツは、ストアの規約に従ってモデレーションされている必要があります

フルビルドには独自のアプリケーションIDを付ける予定です。そうすればAndroidでストア版と並べてインストールできます。現在、すべてのAndroidビルドは同じIDである`com.vertoker.BulletHero`を使っています

## OWSで提供される予定のもの

- アカウントと利用規約
- 公開前のすべてのレベルのチェック：エラーのあるレベルは却下され、警告のあるレベルはモデレーターに回されます
- レベルとユーザーへの通報、およびそのブロック

アカウントに何を保存するかは、まだ決まっていません。サーバーには独自のプライバシーポリシーがあり、サーバーと同時に公開されます。そこではアカウントについて説明し、その削除方法を案内します。ゲームとサイトのポリシーはサーバーを対象としていません：[[game-privacy-policy]]、[[privacy-policy]]

## 時期

Steamワークショップへの公開は、Steamビルドですでに使えます。それ以外の時期は未定です。順番は、OWS、次にGoogle Play版ビルド、次にApp Store版ビルドです

サーバーで一緒にプレイする機能はまだありません。まだ設計されていません

## 他人のサーバーのリスク

コミュニティサーバーを運営するのは、おそらく面識のない人です。Bullet Heroはそのようなサーバーを管理もモデレーションもしません。フルビルドのEULAにもそのことが明記されています

| リスク | 理由 |
|---|---|
| 権利が確認されていないレベル | 何をチェックするかは運営者が決め、何もチェックしないこともあります。作者に共有する権利のない音楽がレベルに含まれていることもあります |
| 誰もコンテンツをモデレーションしない | アップロードされたものを誰かが確認している保証はありません |
| 他のサイトのファイル | 標準ポリシーでは、レベルが直接リンクでファイルを取得できます。そのようなレベルを開くと、ゲームはレベルの作者が選んだサイトからファイルをダウンロードします。そのため、ストア版ビルドではこれが禁止されています |
| 運営者に通信内容が見える | プロトコルがまだないため、サーバーが具体的に何を受け取るかは不明です。送信したものはすべて運営者に見えると考えてください |
| サーバーが消えることがある | そのサーバーにしかないレベルは、サーバーと一緒に消えます |

デフォルトでは、レベルは*CC BY-NC*で配布され、作者はレベルのメタデータで別のライセンスを選べます。サーバーはすべてのレベルのライセンスを守らなければなりません。*CC BY-NC*のもとでは、コミュニティサーバーを含め、誰もレベルを商用でホストできません。そのようなレベルで料金を取るサーバーは、その作者全員のライセンスに違反します

> [!tip] 推奨
> 運営者を知っているサーバーにだけ接続してください。大切なレベルはすべて自分でコピーを保管してください。レベルはファイルのフォルダーであり、ディスク上のコピーはどのサーバーにも依存しません

## EULA

フルビルドにはEULAが付属しています。そこには、コミュニティサーバーはサードパーティのサービスであり、Bullet Heroはそれを管理もモデレーションもしない、と書かれています

ストア版ビルドでは、レベルを公開する前にEULAへの同意を求める予定です

これらの文書はまだどれも書かれていません
