# gv 0.10.1

A new built-in level, the build name in the version line and a lighter Android release

- The two test levels that came with the game are replaced by one demo level, `New zero demo`
- The version line in the settings names the build as well as the version: `gv X, sv Y, mg Z, Windows, Steam, Release`, that is the platform, the store and the build type. The first line of every log says the same, so a bug report and its attached log always name one build
- In the level browser every source filter is on when it opens, and the source row is shown even with one source. A level that is present but filtered out looked like a missing one
- Release builds no longer carry debugging symbols. On Android that is 25.7 MB less out of a 124.9 MB release
