# Version 0.10.0

Prefabs rebuilt around a real root object, and an object without size keyframes has no size of its own

- A prefab template has a real root object now, and everything inside hangs off it. Turning a group into a prefab used to leave two grouping objects in a row with no way to merge them. Now the selection is wrapped once
- An object without size keyframes is 0 by 0 instead of 1 by 1. A Rect, an effect and a prefab placement are groups that draw nothing, so they get no size. A new shape or text gets a size keyframe when it is created, set in `Game Editor` > `Creation` (`New Shape Width`, `New Text Width` and the two heights)
- Two consequences of that: a group cannot be clicked in the viewport, and an effect is clicked by the area its particles take up
- Drag a row of the hierarchy onto another row to change its parent, and drop it on empty space to remove the parent. Several selected rows move as one undo step. This works with a mouse and a pen. On a phone the parent is changed in the inspector
- Hold the backquote key (`` ` ``) to hide the whole editor interface and see only the level. Release it to bring everything back. The key can be rebound
- The level browser opens sorted by `Recent`, so the level you saved last is at the top
- The result screen says `Passed` or `Failed` instead of "Win" or "Lose"
- Flattening a prefab placement asks for confirmation first, because the placement stops following its template
- The command palette and the add menus are translated. Before, they showed English whatever the language
