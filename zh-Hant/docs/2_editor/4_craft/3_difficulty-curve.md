# 難度與曲線

按玩家本身的數字設計（全部數字見[[6_avatar]]和[[7_damage]]），再考慮人12到15幀的反應時間。新的模式先以安全的形式展示

你無法評判自己關卡的難度：請讓第一次看到關卡的人來測試

## 用數字看玩家

化身的精確數值見[[6_avatar]]和[[7_damage]]。它們對關卡意味著：

| 專案 | 對設計意味著什麼 |
|---|---|
| 玩家判定框 | 比繪製出的身體小得多，所以擦過身體的子彈常常打不中 |
| 衝刺 | 幾乎瞬間跨過螢幕高度的四分之三 |
| 衝刺時的無敵 | 比衝刺本身持續更久，所以衝刺穿過薄障礙是安全的 |
| 被擊中後 | 短暫的擊退且無法控制，之後有一段忽略後續擊中的時間 |
| 人的反應 | 0.2到0.25秒，在60fps下是12到15幀 |
| 啟動時的數值 | 3條命，速度1.0，檢查點開啟 |

由此得出的經驗法則：
- 1個單位寬的空隙很寬，0.6寬的空隙很緊
- 一次衝刺跨過的距離相當於半秒的奔跑

## 被擊中不會立刻死亡

被擊中後，玩家會被擊退，短時間內無法控制。之後一段時間內的所有擊中都會被忽略（[[7_damage]]）。一排連續的十顆子彈只會扣掉一條命，而不是十條

> [!info] 須知
> 直覺告訴你的正好相反。密集的齊射看起來像是必死無疑。實際上它比一顆恰好在無敵結束時飛來的子彈代價更小

## 玩家的選擇

生命數、播放速度和檢查點由玩家在啟動介面上選擇。預設是3條命，速度1.0，檢查點開啟

你可以放置檢查點，但無法強迫別人使用它們。你也無法禁止別人用半速遊玩

按預設值來設計，但不要把任何東西建立在“他會死在這裡”的算計之上。你設計的是一種感受，而不是懲罰

## 迴圈

玩家重複同一個迴圈：遊玩、死亡、再試一次。好的關卡在這個迴圈上疊加自己的層次，而這個迴圈必須是：
- 開頭簡單，不要一上來就是困難的機制
- 可擴充套件，新元素逐步加入，這樣才不會乏味
- 有回報，因為正確的動作立刻得到獎勵，才能維持動力

## 曲線：教學、檢驗、變化

1. 以安全的形式展示模式，幾乎不可能失誤
2. 真正要求玩家做到
3. 改變一個變數（速度、方向、數量），再要求一次

如果一個模式第一次出現就是困難的形式，玩家會怪關卡。玩家死了，卻不明白關卡想要他做什麼

公平也有限度。過度的“手把手帶領”和不公平一樣，都會讓人失去樂趣

## 背板

只能靠記憶通過的關卡是一種正當的型別。但它必須是一個決定，而不是意外

界線很簡單：死亡之後，玩家必須明白具體要記住什麼。死了十次還不明白，那不是背板，是噪音

## 用別人的眼睛檢驗

你無法自己評判自己的關卡。到釋出的時候，你已經把自己的難點通過了兩百次，對你來說它很簡單

> [!tip] 建議
> 把關卡交給第一次看到它的人，然後安靜地看著。不要給提示。一個人死了三次、還問關卡到底想要什麼的地方，不是難，而是不清楚

## 從短關卡開始

第一個關卡做1到2分鐘長。興趣會比曲目先耗盡。四分鐘的關卡意味著四倍的工作量和十倍的放棄理由
