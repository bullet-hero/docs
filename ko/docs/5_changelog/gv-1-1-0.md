# gv 1.1.0

Steam 창작마당 게시, 리소스 컬렉션, 튜토리얼이 있는 샌드박스, 빠른 설정, "콜라이더 전용" 모드, 중국어

> [!warning] 경고
> `gv 1.1.0`에서 저장한 파일은 `gv 1.0.0`에서 열리지 않습니다: 설정, 통계, 저장한 레벨이 해당합니다. 그곳에서는 `업데이트 필요` 창이 열립니다. `gv 1.0.0`의 파일은 이전처럼 `gv 1.1.0`에서 열립니다. 자세히 - [[5_troubleshooting]]

## 레벨 보내기와 창작마당

- `공유` 버튼에 레벨을 보내는 모든 방법이 모였습니다. `공유 방법` 창은 `아카이브`와 `Steam 창작마당`을 제공하며, 각 방법은 보내기 전에 레벨을 스스로 검사합니다
- 아카이브는 폴더, tar.gz, zip 중 하나이며, zip 파일은 비밀번호로 보호할 수 있습니다
- Steam 빌드에서는 레벨이나 컬렉션을 에디터에서 바로 창작마당에 게시합니다. 같은 레벨을 다시 게시하면 기존 아이템이 업데이트됩니다
- 레벨, 각 리소스, `커버`에 AI 생성 여부를 표시할 수 있습니다(`AI 생성`). 안의 무언가가 AI 생성물이면 메뉴의 레벨 카드에 그 사실이 표시됩니다

## 컬렉션

- 컬렉션은 어떤 레벨에서든 쓸 수 있는 리소스 모음입니다: 프리팹, 테마, 도형, 이펙트, 텍스처, 폰트, 오디오
- 에디터 설정에 `라이브러리` 탭이 생겼습니다: 직접 만든 리소스와 컬렉션, 창작마당에서 구독한 컬렉션
- `레벨 설정`에 `컬렉션` 탭이 생겼습니다. 컬렉션 전체를 그것이 의존하는 모든 것과 함께 가져오거나, 레벨의 리소스로 컬렉션을 만듭니다
- 레벨에 이미 같은 리소스의 다른 사본이 있으면, 게임이 어느 쪽을 남길지 묻습니다

## 게임

- **`샌드박스`** 버튼이 메인 메뉴에 새로 생겼습니다. 여섯 단계 튜토리얼(이동, 대시, 회피, 링 통과 대시, 조작 모드 선택)과 공격을 직접 발동하는 보드가 들어 있습니다. 게임은 첫 실행 때 한 번 튜토리얼을 권합니다
- **`빠른 설정`** 화면 하나에서 성능, 화면 효과, 언어, 음량을 설정합니다. 첫 실행 때 저절로 열리며 메뉴에 계속 남습니다. 설정의 고급 섹션은 이제 접혀 있습니다
- **`콜라이더 전용 모드`** 옵션이 설정의 `그래픽` 탭에 있습니다. 레벨은 맞을 수 있는 것만 단색 배경 위의 평면 채우기로 그립니다. 음악, 충돌, 통계는 그대로이며, 플레이는 다른 플레이처럼 집계됩니다
- 피격 후 밀려나는 거리가 10 유닛 대신 7.5 유닛이 되었습니다. 이는 완전한 대시 한 번의 길이입니다. 커서 바로 옆의 아주 짧은 대시도 이제 항상 발동합니다
- `젠` 모드도 다시 피격됩니다: 밀려남, 실드, 피격 효과는 있지만 목숨은 줄지 않습니다. 몸을 통과하는 탄을 원한다면 별도의 `충돌 없음` 옵션이 있으며, 그 플레이는 따로 집계됩니다
- 일시 정지 창과 결과 창의 `옵션으로 복귀`는 플레이를 시작한 화면으로 같은 옵션과 함께 돌아갑니다
- 게임이 중국어 간체를 지원합니다

## 조작

- 각 장치에 `활성` 스위치가 하나 있습니다. 마지막으로 사용한 장치가 우선하며, 대시와 일시 정지는 활성화된 어느 장치에서든 작동합니다
- 기울이기 조작은 화면이 위를 향해 놓인 휴대폰을 정지 상태로 봅니다. 보정이 필요 없으며, 화면이 회전해도 모든 것이 올바르게 유지됩니다
- 게임패드에서는 Start 버튼과 Select 버튼을 제외한 모든 버튼이 대시입니다. Start 버튼은 일시 정지입니다
- 마우스는 버튼을 놓으면 아바타를 멈추고(`놓으면 정지`), 터치는 그렇지 않습니다(`손 떼면 정지`). 둘 다 전환할 수 있습니다
- 조종 중 두 번째 손가락은 항상 대시하며, 더 이상 그 아래 버튼을 누르지 않습니다

## Android

- Vulkan 미지원 휴대폰에서도 다시 게임을 설치하고 플레이할 수 있습니다. 그런 기기에서는 게임이 OpenGL ES 3 렌더링을 사용합니다
