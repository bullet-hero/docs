# Rechte

Ein veröffentlichtes Level darf nur Dateien mit einer offenen Lizenz nicht strenger als CC BY-NC oder mit Erlaubnis des Autors enthalten. Ein Level für dich selbst darf alles enthalten

Die Prüfung setzt ein, wenn ein Level deine Festplatte in Richtung eines Servers oder der Website verlässt
