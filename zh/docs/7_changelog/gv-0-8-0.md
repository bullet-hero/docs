# 版本0.8.0

时间轴从1开始计帧，选中项一步就能变成预制件

- 帧从1开始计数。关卡的第一帧是第1帧，从0秒开始，播放头、检视器和关卡文件显示的是同一个数字。物体内部关键帧的帧号也从1开始
- 现有关卡没有转换，因此有三处发生了偏移。所有随机值都重新生成了，因为随机值依赖帧编号。此版本之前保存的每个检查点的死亡次数和最佳成绩，读回时会差一帧。更改之前记录的撤销历史和自动保存无法重放
- 播放头读数中秒之后的部分以毫秒显示（第60帧为`0:00.983`）。帧编号就显示在它旁边，旧的写法看起来像是和这个编号自相矛盾
- `从选中项创建预制件`（`Ctrl+G`）把选中的物体变成预制件。层级行的菜单中的`由此创建预制件`是同一个操作
- 化身出现时逐渐变大，离开时缩小成一个点，而不是突然出现和消失
- 关闭的窗口每帧都会让编辑器界面多花4.6毫秒，因为界面仍然会遍历它们。现在其中十个窗口在关闭时会完全离开界面
- 统计叠加层新增`显示性能分析`区块：每个模拟阶段耗时多少
