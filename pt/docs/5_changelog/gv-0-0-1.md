# gv 0.0.1

O primeiro teste de renderização: muitos objetos com Unity Entities, e já roda no Android

Três dias depois do início, o projeto ganhou sua base técnica. Os objetos são desenhados com *Unity Entities* (ECS), e o jogo continua apoiado nessa abordagem. A cena de teste enche a tela de objetos e muda as cores deles, e a ordem de desenho vem da profundidade de cada objeto

- A build de teste já roda no Android
- O modelo de dados do nível foi para um plugin separado, o futuro SDK
- Os primeiros sprites (formas, ícones da interface, skins) vieram de um projeto anterior

Na mesma época, um pipeline de renderização próprio foi considerado e descartado: o *URP* padrão bastava
