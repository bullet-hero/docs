# リンクとコミュニティ

雑談と質問はDiscordへ、動画はYouTubeへ、ゲームのバグはbullet-hero/releasesリポジトリのissuesへ。ソースコードはGitHubのbullet-heroオーガニゼーションにあります

ダウンロードできるものすべて（ゲーム、SDK、ストア）：[[download]]

## ソーシャルメディア

| リンク | 説明 |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | 雑談、質問、フィードバック、バグ、自作のレベル |
| [YouTube](https://www.youtube.com/@bulletherogame) | トレーラーとゲームの動画 |

## フィードバック

| リンク | 説明 |
|---|---|
| [Game Issues](https://github.com/bullet-hero/releases/issues) | ゲームのエラーとバグ（技術的なもののみ） |
| [SDK Issues](https://github.com/bullet-hero/sdk/issues) | SDKのエラー |
| [Docs Issues](https://github.com/bullet-hero/docs/issues) | テキストと翻訳の誤り |
| [Discord](https://discord.gg/gkHQrp9NgS) | 質問と議論、ゲームへのフィードバック |

何をどこに書くかの詳細：[[11_help]]

## ソースコード

すべてのリポジトリは[bullet-hero](https://github.com/bullet-hero)オーガニゼーションにあります

| リポジトリ | アクセス | 内容 |
|---|---|---|
| [bullet-hero/game](https://github.com/bullet-hero/game) | 非公開 | ゲームとエディター |
| [bullet-hero/sdk](https://github.com/bullet-hero/sdk) | 公開 | SDK、SDKとそのコードに関するissues |
| [bullet-hero/releases](https://github.com/bullet-hero/releases) | 公開 | ゲームのビルド、プレイヤーからのissues |
| [bullet-hero/docs](https://github.com/bullet-hero/docs) | 公開 | このドキュメント |
| [bullet-hero/backend](https://github.com/bullet-hero/backend) | 公開 | サーバー（現在は空） |
| [bullet-hero/frontend](https://github.com/bullet-hero/frontend) | 非公開 | サイト |

プロジェクトに協力する方法：[[community]]
