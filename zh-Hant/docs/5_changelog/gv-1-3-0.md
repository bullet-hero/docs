# gv 1.3.0

成就、自己畫的化身皮膚、七種新語言、Steam雲，以及每個關卡的難度和效能評級

## 成就

- 主選單中的`成就`列出了39個成就，其中4個是隱藏成就
- 成就根據你的統計資料計算，所以你已經玩過的內容從第一次啟動起就算數。解鎖的成就不會再被鎖上
- 只有別人的關卡算數，並且只算公平的通關：沒有機器人，碰撞開啟，速度不低於1.00，生命開啟
- 在Steam版本中，成就也會同時在Steam上解鎖。在Google Play版本中，登入Google Play遊戲後，成就也會在其中解鎖

更多：[[15_achievements]]

## 化身皮膚

- 主選單中的`角色`開啟角色中心。可以選擇現成的形狀，修改它的顏色，開關眼睛、手、影子、拖尾和其他部件
- `編輯器`可以在每邊3到8格的格子上畫出你自己的化身
- 皮膚是一個檔案。`我的皮膚`中的`匯出`和`匯入`可以移動它，轉移檔案也會帶上你的所有皮膚（`角色皮膚`）
- 皮膚只改變外觀。所有皮膚的判定框和速度都一樣

更多：[[16_skins]]

## 語言

- 遊戲現在支援日語、韓語、西班牙語、法語、德語、巴西葡萄牙語和繁體中文，一共十種語言
- 在`設定`中把語言選為`系統`時，遊戲會使用你裝置的語言

## Steam雲

- 在Steam版本中，設定、統計、成就、關卡、庫和皮膚都跟著你的Steam賬戶走。沒有按鈕：遊戲會在啟動時、遊戲中和退出時同步
- 圖形和操作設定每臺電腦各自保留
- `設定` → `其他` → `雲存檔`會顯示同步是否開啟，以及上次同步的時間

更多：[[14_profile-transfer]]

## 難度和效能

- 關卡有從`自動`到`奇點`的難度。由作者在`關卡設定`（`難度`）中設定，關卡列表和關卡頁面會顯示它
- 每個關卡上的五格條顯示它對你的裝置有多重。關卡列表中的`在此裝置上的效能`可以按它篩選
- 在這個版本之前儲存的關卡會顯示`未測量`，直到作者再次儲存
- `設定` → `圖形` → `裝置效能` → `測量此裝置`會執行最長60秒的壓力測試。在此之前，評級按一臺典型裝置計算

更多：[[2_playing-levels]]，[[17_performance-rating]]

## Android上的更新

- 在Google Play和RuStore版本中，更新會在後臺下載。準備好後，主選單會顯示`更新已就緒`，點`重新啟動`即可安裝
- 通關一個關卡後，遊戲可能會請你評分，最早在你第三次通關之後，並且60天內最多一次

更多：[[1_installation]]

## 編輯器中的AI助手

- 在電腦上，支援MCP的AI助手可以在你看著的時候編輯開啟的關卡。在你開啟`設定` → `編輯器` → `AI 代理（MCP）`中的`允許 AI 連線`之前，它一直是關閉的
- 只有這臺電腦可以連線。AI的每一批修改都是歷史中的一步，AI不能釋出、刪除或覆蓋任何東西
- AI把它的筆記儲存在關卡的`ai`資料夾中。除非取消勾選`隨關卡共享AI上下文`，這個資料夾會隨匯出和創意工坊上傳一起帶走，但永遠不會進入帶密碼的匯出

更多：[[7_ai-assistant]]

## 修復和其他

- Windows、macOS和Linux的免費版本附帶`unins000`。它會刪除遊戲自己的檔案，保留你的關卡、設定和統計
- 安裝後遊戲進入選單更快了，在一臺測試手機上快了約2秒
- 釋出時會檢查關卡的許可證與其音樂的許可證是否相容
- 編輯器中被拒絕的修改不會再在歷史中留下損壞的一步，檢查器中關鍵幀的`幀`欄位現在會移動關鍵幀
