# gv 0.0.2

Texturas, padres, partículas, texto y efectos de posprocesado, probados uno a uno en escenas de prueba

Esta versión es un conjunto de experimentos. Cada función que un nivel iba a necesitar tuvo su propia prueba, y la mayoría se quedaron

- Los objetos tienen texturas
- Un objeto puede tener un padre, y el objeto se mueve con él
- Llegaron los efectos de partículas y el texto (entonces con *TextMeshPro*)
- Efectos de posprocesado de pantalla

Todo se midió en un teléfono Android. Según las notas de entonces, aguantaba unos 1500 objetos a 30 fps. Se probaron las sombras 2D y se descartaron
