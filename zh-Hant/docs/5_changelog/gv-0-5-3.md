# gv 0.5.3

全屏節拍視窗、可以滑動和拉伸的面板、每個檢視器欄位上的重置按鈕，以及清理舊備份和統計資料

- 節拍視窗通過`開啟節拍視窗`按鈕全屏開啟。其中有一個敲擊器和並排的兩個結果：`由敲擊建立`生成一個新的節拍段，`應用到選中項`重新計算選中節拍段的速度。錄製的敲擊可以在應用前試聽，視窗開啟時關卡繼續播放
- 編輯器設定中的`時間格式`決定時間軸標尺以什麼計數：幀、時間碼、帶幀的時間碼或`小節和節拍`。關卡本身不會改變
- 編輯器面板通過滑動把手開啟和關閉，開啟的面板可以拉得更寬。手機上的按鈕變大了
- 每個檢視器欄位都有一個帶提示的`?`和一個重置按鈕，每個分組的標題中也有同樣的一對。重置分組是一個撤銷步驟
- `碰撞體跟隨形狀`：開啟時，選擇形狀也會設定相同的碰撞體，判定框跟隨輪廓
- 可以在關卡列表中刪除關卡，無需開啟它。`刪除關卡`視窗在各處都相同
- 設定中的`儲存`會刪除已不存在的關卡的備份和統計資料，或者全部刪除
- 視口網格在縮放時把格子大小精確地改變10倍，和Unity本身的場景網格一樣
- 時間軸用一個網格繪製大部分片段，而不是為每個片段使用單獨的介面元素，這在長關卡上開銷更小
- 特效和音訊效果的欄位有了說明
