# Version 0.5.5

Folder access on Android, a reset button on every settings tab, and a fix for the resolution setting

- Android: the game opens folders through the system folder picker and sees only the folder you pick, so it needs no storage permission. `Folder access` in the settings lists every folder you have granted, and `Revoke` removes the access without deleting anything inside
- Every settings tab has its own reset button that returns only that tab to its defaults
- Fixed: the resolution setting did nothing after the window had been resized by hand or with Alt+Enter
- The level browser has a `Scan again` button
- Level settings have a `Publication` tab. It says `In development` for now
