# 版本0.13.3

面向手机的内存优化：限制撤销历史、响应内存不足警告、堵上一处泄漏，另有两项预制件模式修复

- 新的编辑器设置`历史物体数`，在步数之外再限制撤销历史最多可以保存多少个物体。一次批量删除只算一步，却可能包含50,000个物体，这个设置针对的就是这种情况。默认情况下手机最多保存200,000个，桌面端不设上限。设为`0`则取消上限
- Android或iOS发出内存不足警告时，游戏现在会做出响应。编辑器会丢弃再也无法到达的历史分支，游戏会释放不再使用的内容。以前没有任何东西在监听，唯一的结局是系统把游戏关闭
- 以前每打开一次关卡，每张纹理都会有两个材质在本次会话余下的时间里一直留在内存中。现在关卡关闭时会释放它们
- 在编辑器中关闭关卡会释放关卡的数据。以前这些数据会一直留在内存中，直到打开下一个关卡
- 玩过重型关卡后，如果为它预留的内存超过普通关卡所需的四倍，而下一个关卡又用不到，游戏会归还这部分内存
- 在预制件模式中每次编辑后，预制件时间轴不再跳回最上面一行。只有在进入预制件模式时才会重置
- 预制件模板顶层未设置父级的物体，现在会适配模板的时间轴并跟随它的锚点，与它在关卡中的副本一样。以前粘贴可能会让它落在模板之外，编辑器中的显示也与实际播放不同
