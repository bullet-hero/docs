# 版本0.9.0

生命值和真实判定框直接显示在化身身上，来自更新版本的关卡会在警告后打开

- 化身的身体是由方块组成的网格，失去生命值时方块从边缘向内碎裂脱落。一局打得不顺，从玩家身上就能看出来，而不是从某个条上。图形设置中的`碎裂效果`可以关闭这一效果：身体变成一个方块，改为逐渐变淡
- 化身上的一圈圆点正好落在判定框上：半径0.4，而身体宽1个单位。轮廓从来都不是判定框，现在你能看到它真正的位置。这圈圆点也用来计算生命：亮的点是你还剩下的生命，暗的点是已经失去的生命
- 界面设置中的`判定框圆环不透明度`决定圆环有多明显，默认0.6。设为0会关闭它，但关卡是按能看到它的玩家来平衡的
- 检查点新增`恢复生命值`选项：关卡经过它时会立即补满你的生命
- 用更新版本制作的关卡会在关卡浏览器中标记为`版本较新`，并在警告后打开。如果读取时有内容必须替换，游戏会先写入备份，并说明做了多少处替换
- `循环`关闭的特效生成的粒子远少于开启时，看起来就像颜色渐变失效了。现在单次特效一次爆发的粒子数量，与循环特效持续保持的数量相同
