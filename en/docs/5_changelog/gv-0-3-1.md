# gv 0.3.1

The editor learned to create objects, undo that and show them in the hierarchy

Five days after `gv 0.3.0` the editor became more than a level player with a save button

- Objects can be created, and undo and redo work for it
- The object hierarchy shows the level's objects, and an object can be hidden from there
- A level can be deleted after a confirmation
- Notifications and a console panel report what the editor has just done
- Playing a level inside the editor behaves the same as in the game

The Android build was also tuned for phones with a weak GPU
