# gv 0.6.2

展平預製件、開啟設定的啟動引數，以及全屏模式和視窗大小的修復

- `展平預製件`把一次預製件放置變成普通物體：與模板的關聯消失，物體精確地留在原位。它是預製件檢視器中的一個按鈕，也是一條編輯器命令，`展平預製件`修改器則對範圍內的所有放置做同樣的事。之後關卡看起來完全一樣，因為每次放置的覆蓋已經寫入了物體
- `--settings`開啟選單，並在其上開啟設定，`--settings graphics`（或其他標籤頁名稱）開啟指定的標籤頁
- 修復：全屏模式可能顯示帶黑邊的模糊640x480畫面，退出後再進入也無法修復。現在全屏模式始終使用螢幕的原生解析度，想用更低的渲染解析度可以使用`渲染縮放`
- 修復：退出一次全屏模式，就會讓遊戲把視窗大小記成整個螢幕的大小
- 修復：點選時間軸上的關鍵幀並不總能在檢視器中開啟它的標籤頁
