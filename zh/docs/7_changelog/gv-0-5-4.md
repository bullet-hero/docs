# 版本0.5.4

全面使用矢量图，HUD显示生命值，完整的颜色曲线，垂直同步，关卡浏览器中出现Steam创意工坊关卡

- 所有图标和界面图片现在都是矢量图（SVG），而不是纹理
- HUD在进度条上方用一排圆点显示你的生命。失去一条生命时对应的圆点变暗而不是消失，所以这一排的长度不变。开启无敌时这一排为空
- 颜色曲线改为URP引擎的八条曲线：`主控`、`红`、`绿`、`蓝`、`色相/色相`、`色相/饱和`、`饱和/饱和`和`亮度/饱和`。使用旧版双数值颜色曲线的关卡会在加载时转换
- 修复：数值为默认值的颜色曲线关键帧会让画面变灰，并把色相旋转半圈
- `垂直同步`设置，可选`关`、`开`和`半速率`，仅限桌面端。开启时帧率上限不起作用
- Steam版：你在Steam创意工坊中订阅的关卡会出现在关卡浏览器中。`显示所有找到的内容`还会列出磁盘上存在、但未确认属于你的内容，例如已取消订阅的项目或手动复制的文件夹。这类关卡的卡片上会标记`未订阅`或`离线`
- 关卡的每位作者都有一个`分工`字段，用来填写角色：音乐、封面、试玩测试等
