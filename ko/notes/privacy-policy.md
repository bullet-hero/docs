# 개인정보 처리방침

사이트에는 계정, 분석, 광고, 추적이 없습니다. 브라우저에는 기능 쿠키 두 개와 문서 메뉴에서 펼친 폴더가 저장되고, 서버에는 기술적 요청 로그가 남습니다

이 방침은 Bullet Hero 웹사이트, 즉 문서, 노트, 다운로드 페이지에 적용됩니다. 게임 자체나 사이트에서 링크하는 서비스에는 적용되지 않습니다. 게임에는 별도의 방침이 있습니다 - [[game-privacy-policy]]

## 사이트가 수집하지 않는 것

- 계정, 로그인, 입력 양식이 없으므로 사이트는 이름, 이메일 주소, 비밀번호를 받지 않습니다
- 분석, 광고, 어떤 종류의 추적도 없습니다
- 사이트는 제3자 스크립트, 폰트, 임베드 콘텐츠를 불러오지 않습니다: 페이지의 모든 파일은 사이트가 직접 제공합니다

## 브라우저에 저장되는 것

- **기능 쿠키 두 개**, `bh_consent` 및 `bh_lang`. 쿠키 배너에 대한 응답과 선택한 언어를 기록합니다. 각 쿠키에 무엇이 담기고 얼마나 유지되는지는 [[cookie-policy]]에 설명되어 있습니다
- **문서 사이드바**는 직접 펼친 폴더를 브라우저의 세션 스토리지에 `bh-docs-open` 키로 기억합니다. 여기에는 폴더 주소만 담기며, 브라우저 밖으로 나가지 않고, 탭을 닫으면 지워집니다

## 서버 로그

다른 웹 서버와 마찬가지로 이 사이트의 서버도 요청에 대한 기술적 로그를 기록합니다: IP 주소, 요청 시각, 요청한 주소, 요청이 온 페이지의 주소, 브라우저의 `User-Agent` 문자열

로그는 사이트를 운영하고 악용으로부터 보호하는 데에만 쓰입니다. 다른 데이터와 결합하지 않으며, 방문자 프로필을 만드는 데 쓰지 않고, 제3자에게 넘기지 않습니다

## 다른 서비스로의 링크

사이트에는 GitHub, Discord, YouTube 링크가 있으며, 게임 빌드는 GitHub에서 내려받습니다. 그런 링크를 따라가면 해당 서비스가 자체 개인정보 처리방침에 따라 데이터를 처리하며, 이 방침은 그 서비스에 적용되지 않습니다

## 변경 및 문의

이 방침은 사이트와 함께 바뀝니다. 게임 서버가 생기면, 플레이어 계정에 무엇이 담기고 계정을 어떻게 삭제할 수 있는지 설명하는 서버 자체의 개인정보 처리방침도 생깁니다. 마지막 변경 날짜는 페이지 하단에 표시됩니다
