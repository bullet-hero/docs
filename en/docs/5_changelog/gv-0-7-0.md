# gv 0.7.0

Interface sounds, full gamepad and keyboard control outside the editor, and new settings for level images

- The interface makes sounds now. The menu answers a press, while the level editor sounds only the result of an edit: a save, a refusal, an undo or redo, a deletion. Hovering over a button is silent everywhere: it is the most frequent event, and the first to get tiring
- A new `Editor Interface` slider in the audio settings controls the editor's sounds separately from `User Interface`. Both default to 50%
- Everything except the editor can be played with a gamepad alone or a keyboard alone. While a gamepad is in hand, the mouse cursor is hidden, and the bottom left corner shows for a second which device took over. The editor itself cannot be navigated with a gamepad, but the `Start` button leads out of it
- "Back" closes only the topmost window. Before, one press could close a window together with the screen under it
- Level images have two new settings: `Sampling` (`Smooth` or `Sharp`) and `Compression` (`Allow` or `Refuse`). `Refuse` keeps every pixel but takes up to 4 times more memory
- What an image does beyond its edges is now set per axis: `Wrapping X` and `Wrapping Y`. A level saved before this version reads both as `Clamp`, so a repeat set earlier has to be set again
- The dash cooldown is 0.30 s instead of 0.35 s. Invulnerability after a dash stays 0.20 s
- Pausing in the middle of a dash no longer drags the avatar across the stopped level
- An avatar stuck deep inside a shape is now pushed out from its centre. Before, it got no push at all
- The hierarchy keeps the rows you unfolded after an edit, and two new buttons unfold or fold every row at once
- The statistics overlay can show three more blocks: `Show Frame Objects`, `Show Level Objects` and `Show Memory`
