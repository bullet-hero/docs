# 용어집

프로젝트의 기본 용어 목록입니다. 게임 인터페이스, 이 문서, 그 밖에 Bullet Hero 관련 글이 모두 이 단어를 쓰며, 새 용어는 먼저 여기에 추가합니다

## 레벨 내용

| 용어 | 뜻 |
|---|---|
| **레벨** | 한 번의 플레이를 이루는 모든 것: 오브젝트, 오디오, 이벤트, 자체 리소스 |
| **오브젝트** | 타임라인 위에서 제작자가 만드는 하나의 대상. 자체 구간, 트랜스폼, 부모를 가집니다 |
| **빈 오브젝트** | 아무것도 그리지 않는 오브젝트: 트랜스폼, 구간, 자식만 가집니다. 다른 모든 타입은 이 위에 자기 요소를 더합니다 |
| **도형** | 오브젝트가 그리는 실제 지오메트리이며 이미지가 아닙니다. 게임이 약 500종을 직접 생성합니다 |
| **콜라이더** | 오브젝트가 충돌하는 범위. 오브젝트가 그리는 모양과 달라도 됩니다 |
| **프리팹** | 재사용할 수 있는 오브젝트 템플릿. 레벨에 필요한 만큼 몇 번이든 배치합니다 |
| **프리팹 모드** | 주변 레벨이 아니라 템플릿 자체의 내용을 편집하는 것 |
| **이펙트** | 스포너입니다: 몇 가지 파라미터로 매 프레임 자기 오브젝트를 만듭니다 |
| **프레임 내 오브젝트** | 이펙트가 만든 오브젝트. 엔진이 관리하므로 선택도 편집도 할 수 없습니다 |
| **테마** | 레벨이 인덱스로 참조하는 팔레트: 색을 바꿀 때 백 군데가 아니라 한 군데만 고치면 됩니다 |

## 시간과 애니메이션

| 용어 | 뜻 |
|---|---|
| **프레임** | 레벨 시간의 단위. 프레임은 칸이고, 시간은 두 칸 사이의 경계입니다 |
| **키프레임** | 어떤 프레임에서 제작자가 정한 값 하나. 두 키프레임 사이의 값은 보간됩니다 |
| **트랙** | 애니메이션 가능한 속성 하나의 키프레임 행: 위치, 회전, 음량 |
| **타임라인** | 레벨을 편집하는 프레임 축: 내용 종류마다 탭이 하나씩 있습니다 |
| **구간** | 오브젝트가 존재하는 기간: 시작 프레임과 길이로 나타내며, 끝 프레임으로 나타내지 않습니다 |
| **재생 헤드** | 지금 표시하고 있는 프레임 |
| **이징** | 이전 키프레임에서 이 키프레임까지 값이 움직이는 방식 |
| **마커** | 레벨 눈금자 위의 이름 붙은 지점. 원하는 위치로 돌아가기 위한 것입니다 |
| **체크포인트** | 사망한 플레이어가 돌아가는 위치 |

## 배치와 그리기

| 용어 | 뜻 |
|---|---|
| **앵커** | 부모의 가장자리를 따라가는 가장자리: 부모를 줄이면 자식도 함께 움직입니다 |
| **레이어** | 그리기 순서이며 상대값입니다: 자식의 레이어에 부모의 레이어가 더해집니다 |
| **피벗** | 오브젝트가 회전하고 크기가 바뀌는 기준점. 오브젝트 자신의 박스 안에 있습니다 |
| **기즈모** | 뷰포트에서 선택한 오브젝트 위에 그려지는 드래그 핸들 |
| **스냅** | 드래그를 무언가에 달라붙게 하는 것: 자석이 켜져 있으면 내용에, 비트 토글이 켜져 있으면 음악에 붙습니다 |

## 음악

| 용어 | 뜻 |
|---|---|
| **비트** | 음악 자체의 그리드: 제작자가 설정하며, 플레이 중에는 아무것도 이것을 읽지 않습니다 |
| **비트 세그먼트** | 템포가 일정한 한 구역. 자체 템포, 위상, 마디 길이를 가집니다 |
| **BPM** | 분당 비트 수 - 비트 세그먼트가 얼마나 빠른지 나타냅니다 |
| **탭** | 템포를 두드려 입력할 때의 한 번의 누름. 탭이 충분히 모이면 비트 세그먼트가 정해집니다 |

## 자동화와 데이터

| 용어 | 뜻 |
|---|---|
| **생성기** | 제작 자동화: 몇 가지 파라미터로 레벨 내용을 만듭니다 |
| **모디파이어** | 추가하는 대신 이미 있는 내용을 편집하거나 제거하는 생성기 |
| **시드** | 레벨의 모든 무작위 값이 나오는 수: 몇 번을 실행해도 똑같이 재현됩니다 |
| **원시 데이터** | 저장된 모델 전체를 편집 가능한 하나의 트리로 보여 준 것. 여기서는 아무것도 검증하지 않으며, 일부러 그렇게 되어 있습니다 |
| **AI 어시스턴트** | MCP 프로토콜로 에디터에 연결된 AI 클라이언트. 보는 앞에서 열린 레벨을 편집하며, 한 번의 배치가 실행 취소 한 단계가 됩니다 |

## 리소스와 공유

| 용어 | 뜻 |
|---|---|
| **라이브러리** | 여러 레벨에서 다시 쓰기 위한 기기 안의 리소스: 내 라이브러리, 내 컬렉션, 구독한 컬렉션 |
| **컬렉션** | 최대 일곱 종류의 재사용 가능한 리소스를 담는 폴더. 가져오기는 컬렉션에서 복사해 오므로 레벨은 컬렉션에 의존하지 않습니다 |
| **난이도** | 레벨이 얼마나 어려운지: 제작자가 정하고 모더레이터가 덮어쓸 수 있는 숫자 하나. 플레이어에게는 `{{ui:enum_difficulty-tier_auto}}`부터 `{{ui:enum_difficulty-tier_singularity}}`까지의 단계로 보입니다 |
