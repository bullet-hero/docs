# 设置

快速设置、每个设置标签页的内容、如何重置，以及图形和匿名模式是如何工作的

## 标签页

| 标签页 | 内容 |
|---|---|
| `常规` | 语言（留空则跟随设备）、同时加载多少个关卡文件、网址文件的超时时间、`打开游戏文件夹` |
| `音频` | 音量：`主音量`、`游戏`、`用户界面`、`编辑器界面`、`编辑器播放` |
| `操作` | 设备和操控方式，[[3_controls]] |
| `快捷键` | 键盘快捷键，大部分属于编辑器，[[3_speed-and-shortcuts]] |
| `图形` | 显示、帧率、抗锯齿、纹理、特效、后期处理 |
| `界面` | 游戏HUD、`失败时打开菜单`、`菜单背景`、屏幕方向、统计信息叠加层 |
| `编辑器` | 编辑器自己的选项 |
| `档案` | 你的统计数据，[[10_statistics]] |
| `其他` | 存储清理、Android上的文件夹访问权限、匿名模式、`恢复默认设置` |

`菜单背景`决定主菜单按钮后面显示什么：机器人躲避攻击的实时竞技场、一片旋转的形状，或者什么都不显示

## 快速设置

`快速设置`是`常规`中位于`打开游戏文件夹`上方的按钮，它会询问几个最重要的问题，每页一个类别。首次启动时，它也会在教程邀请之前自动打开。每个答案都附有一行说明它的作用。各页可以按任意顺序访问，`下一步`只是给出建议

| 页面 | 问题 | 答案 | 改变什么 |
|---|---|---|---|
| `语言和声音` | `语言` | `系统`以及游戏自带的每种语言，各自用本语言命名 | 与`常规`中的相同 |
| | `主音量` | 滑块 | 与`音频`中的相同 |
| `图形` | `性能` | `最低`、`节能`、`推荐`、`最高` | 渲染缩放（桌面端）、抗锯齿、纹理尺寸、特效自身的帧率。从不限制帧率：每个答案都按屏幕刷新率运行。`最低`还会关闭粒子特效和后期处理，并把图片限制在512 |
| | `效果` | `全部`、`柔和`、`关` | 每一种后期效果以及化身的碎裂效果。`柔和`会关闭故障、颗粒、模糊、镜头畸变和色差 |
| `操作` | | `打开教程` | 这里不改变任何设置：教程让你试遍每种操作方式并选出自己的。教程可以从主菜单或沙盒打开 |

标有`默认`的答案是游戏在你的设备上的初始设置。每个选择都会立即生效，并反映在完整设置中。如果你的设置与所有答案都不匹配，就不会有答案被点亮，并有一行文字说明这一点：这些是你自己的设置，按下任意答案会替换它们

## 折叠的分区

较长的标签页被分成若干分区。常改的内容是展开的，细调的内容是折叠的：点分区标题即可展开。标签页重置按钮旁边的按钮可以一次折叠或展开所有分区

在`操作`中，只有你正在使用的设备是展开的

## 重置

每个标签页都有自己的重置按钮。`其他`中的`恢复默认设置`会一次重置所有标签页

重置只影响设置，你的关卡不会受影响

## 版本信息行

设置界面上有一行版本信息，点击即可复制

它的格式是`gv X, sv Y, mg Z, <Platform>, <Channel>, <Debug|Release>`。报告bug时就引用这一行，[[11_help]]

## 图形

**抗锯齿**。桌面端默认使用`MSAA`。手机初始不开抗锯齿。游戏中的每个形状都是真实的几何体，`MSAA`在所有平台上都能让它边缘干净，不会模糊

`FXAA`适用于较弱的手机。它对整个屏幕做一遍处理，开销固定。`MSAA`的开销会在大量透明形状叠加绘制时增长

故意没有提供TAA。它会在快速移动的子弹后面留下拖影，它的抖动也会与故障效果冲突

**帧率**。目标帧率是手动控制的，而不是通过垂直同步。这样关卡的时序在60Hz和144Hz的屏幕上完全相同。开启`垂直同步`时（仅限桌面端），帧率上限不起作用

> [!tip] 建议
> 在性能较弱的设备上，先把**渲染缩放**降到1以下。它只损失清晰度，界面仍保持完整尺寸。仅限桌面端

更多：[[2_mobile-devices]]

## 匿名模式

在`其他`→`不保存游戏数据（匿名模式）`中开启

开启期间，游戏不保存任何自己的数据。`settings.json`、全局统计和每个关卡的统计都原样留在硬盘上。你修改的设置在关闭游戏之前仍然有效

你在关卡上的工作照常保存：保存、导出、导入、复制和删除。编辑器的自动保存和备份也照常工作，它们有自己的开关

这个模式持续到关闭游戏为止，永远不会被记住

关闭它时会保存你当前的设置。开启期间游玩的一切都会被丢弃

> [!info] 须知
> 这个模式也会自动开启。[[12_launch-arguments|启动参数]]`--suppress-game-saves`会在整个启动期间开启它，并且无法在游戏中关闭。来自更新版本游戏的设置或统计也会开启它。此时游戏每次启动都会询问：保留这些数据，还是用默认值覆盖
