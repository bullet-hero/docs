# Серверы

Официальный сервер OWS и общественные серверы NOWS: что о них решено, какие сборки смогут подключаться и что для них уже делает SDK

> [!warning] Предупреждение
> Сервера пока нет, ни официального, ни общественного. Раздел описывает только то, что разработчики уже решили, и будет переписан, когда бэкенд появится. Протокол между игрой и сервером не спроектирован

## Два вида серверов

Сервер в Bullet Hero - это веб-сервис, который хранит уровни. Разработчики планируют два вида:

| | OWS | NOWS |
|---|---|---|
| Полное название | Official Web Services | Non-official web services |
| Кто запускает | разработчики | кто угодно |
| Код | открытый, MIT | те же открытые инструменты или что угодно на их основе |
| Политика публикации | профиль `standard`, задаётся в конфиге сервера | собственный профиль владельца |
| Модерация | разработчики | владелец сервера. Разработчики не контролируют и не модерируют общественные серверы |
| Какие сборки подключаются | все, это сервер по умолчанию | только полная сборка |

**Steam Workshop** - третий канал для уровней, запланированный для версии на ПК. Это не сервер такого рода: файлы хранит Valve, а разработчики могут только проверить их после публикации и решить, что игра загружает

## Статус

- Сервера нет, и ни одна сборка игры пока не умеет к нему подключаться
- Запланированный порядок: сначала Steam Workshop, затем OWS, затем сборка для Google Play, затем для App Store
- Дат нет. Публикация уровней в любой сервис запланирована не раньше обновления после `gv 1.0.0`, потому что данные, на которые опирается проверка, должны попасть в уровни до того, как их опубликуют
- Совместная игра на сервере только запланирована. Разработчики продумали, как аватар игрока появляется и исчезает по сетевому сообщению, но транспорт, авторитет, синхронизация уровня и лобби не спроектированы

## Какие сборки смогут подключаться

| Сборка | Откуда | OWS | NOWS |
|---|---|---|---|
| Сборка из магазина | Google Play, App Store | да | нет |
| Полная сборка | GitHub Releases и сайт проекта | да | да |

**Сборки из магазинов не смогут подключаться к общественным серверам вообще.** Поддержка NOWS вырезается из программы при компиляции, а не прячется за настройкой, потому что магазин оценивает, что программа умеет, а не какие кнопки она показывает. Общественный сервер - это сервис, который никто не модерировал для магазина, а правила магазинов требуют модерации контента, который видят другие люди

Полная сборка выходит под собственным идентификатором приложения, поэтому на Android её можно поставить рядом с версией из магазина

## EULA

Полная сборка поставляется с EULA, где прямо сказано: общественные серверы - сторонние сервисы, разработчики их не контролируют и не модерируют. Сборки из магазинов будут просить принять EULA перед публикацией уровня. Ни один из этих текстов пока не написан

## SDK и PublishProfile

Сервер опирается на тот же открытый SDK, что и игра. Он под лицензией MIT и собирается без Unity, поэтому клиент и сервер запускают одни и те же проверки над одними и теми же моделями и приходят к одному вердикту. Подробнее в [[3_sdk/index]]

Что принимает сервис, описывает файл `PublishProfile`, а не код. У каждого сервиса он свой:

| Пресет | Ключ | Для чего |
|---|---|---|
| `CreateOpen()` | `local` | уровни на вашем устройстве, ничего не требуется |
| `CreateStandard()` | `standard` | публичный сервер, политика из [[ugc-licensing-policy]] |
| `CreateStrict()` | `strict` | сборки из магазинов, без прямых ссылок, хэш у каждого ресурса |

**Уровень, который остаётся на вашем устройстве, не проверяется никак.** Профиль важен только в момент, когда уровень предлагают сервису. Как автору подготовить уровень к этому моменту, описано в [[5_publish-readiness]], поля профиля - в [[7_publish-profiles]]
