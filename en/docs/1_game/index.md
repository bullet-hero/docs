# Game

What Bullet Hero is as a game, where it runs, what the main menu offers today and which page to read next

Bullet Hero is a *rhythm* and *bullet hell* hybrid: a level is a piece of music with shapes moving to it, and you steer a small square that has to survive until the track ends. The developers build it as an engine for the genre rather than as one game, so most of what you play is made by level authors in the same editor that ships with the game

A level is a folder of files the game interprets. Zip it, send it, unzip it, play. There are no accounts and no server of the developers' own: everything the game remembers stays on your device

## Platforms and stores

The game targets PC (Windows, Linux, macOS) and mobile (Android, iOS), and every platform is a full one: the same levels, the same editor, the same controls. Builds are specified for these channels:

| Platform | Channels |
|---|---|
| Windows | free build, Steam, VK Play |
| Linux | free build, Steam |
| macOS | free build, Steam, App Store |
| Android | free build, Google Play, RuStore |
| iOS | App Store |

A specified channel is not a published one. What can be downloaded right now, and in which version, is on the [[download]] page

## The main menu

| Button | What it does now |
|---|---|
| `Levels` | the level browser, see [[2_playing-levels]] |
| `Editor` | the level editor, see [[2_editor/1_basics/index]] |
| `Settings` | every setting, see [[4_settings]] |
| `Story` | nothing yet: the button is there, the mode is not built |
| `Multiplayer` | nothing yet, same as `Story` |

Behind the buttons the menu draws a live arena where a bot dodges attacks, a field of rotating shapes, or nothing. Which one is `Settings`, `Interface`, `Menu Background`
