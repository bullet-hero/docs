# gv 0.3.0

The first version that works as a game: a menu, an avatar you control, levels from start to finish and the first editor screen

Before this the engine could play a level only in a test scene. Here the whole game appeared around it, built on *UI Toolkit*

- **Menu and settings.** The main menu, a settings screen that is saved between launches, playlists and a level list
- **Playing a level.** A level is picked, loaded and played to the end
- **The avatar.** The player's own shape inside the level, controlled by you
- **Two languages.** The interface in English and Russian
- **Level validation.** The SDK can check a level against a set of rules and report broken data

The built-in editor appeared in its first form. It can create a new level, save it to a folder, play it at a chosen speed and show the current time. The object hierarchy and the inspector are only drafts so far

There is no `gv 0.2`: the numbers went from `gv 0.1.0` straight to `gv 0.3.0`
