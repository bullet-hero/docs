# Подключение к серверу

Какие серверы будут у игры, какие сборки смогут к ним подключаться и чем рискует игрок на чужом сервере

> [!warning] Предупреждение
> Серверов пока нет, и игра не умеет к ним подключаться. Нет формата адреса, экрана подключения и аккаунтов

## Какие будут серверы

| | OWS | NOWS |
|---|---|---|
| Полное название | Official Web Services | Non-official web services |
| Кто запускает | разработчики | кто угодно |
| Кто модерирует | разработчики | владелец сервера |
| Какие сборки подключаются | все | только полная сборка |

**OWS - сервер по умолчанию.** Его знает каждая сборка игры на всех платформах, настраивать ничего не нужно

**NOWS - общественные серверы.** Разработчики их не контролируют и не модерируют

**Steam Workshop - третий канал для уровней на ПК.** Steam-сборки уже показывают и запускают предметы, на которые вы подписаны. Опубликовать туда уровень из игры пока нельзя

## Какие сборки подключаются

| Сборка | Откуда | OWS | NOWS |
|---|---|---|---|
| Сборка из магазина | Google Play, App Store | да | нет |
| Полная сборка | [GitHub](https://github.com/bullet-hero/releases) и сайт проекта | да | да |

Сборка из магазина не подключится к общественному серверу никак.
Поддержка NOWS вырезана из неё при компиляции, а не спрятана за настройкой

Причина - правила магазинов. Магазин оценивает, что программа умеет, а не какие кнопки она показывает. А контент, который видят другие люди, по их правилам должен быть модерирован

У полной сборки свой идентификатор приложения. На Android её можно поставить рядом с версией из магазина

## Что будет на OWS

- аккаунты и условия использования
- проверка каждого уровня до публикации: уровень с ошибкой отклоняется, уровень с предупреждением уходит модератору
- жалобы на уровни и пользователей и их блокировка

Что хранит аккаунт, пока не решено. Это опишет политика конфиденциальности на сайте, там же будет сказано, как удалить аккаунт

## Когда

Дат нет. Порядок такой: публикация в Steam Workshop, затем OWS, затем сборка для Google Play, затем для App Store

Публикация уровней в любой сервис появится не раньше обновления после `gv 1.0.0`

Совместной игры на сервере пока нет, она не спроектирована

## Риски чужих серверов

Общественный сервер запускает человек, которого вы, скорее всего, не знаете.
Разработчики такие серверы не контролируют и не модерируют. EULA полной сборки говорит об этом прямо

| Риск | Почему |
|---|---|
| Уровни с непроверенными правами | владелец сам решает, что проверять, и может не проверять ничего. В уровне может оказаться музыка, которой автор не имел права делиться |
| Контент никто не модерирует | нет гарантии, что кто-то смотрит на загруженное |
| Файлы с чужих сайтов | стандартная политика разрешает уровню брать файл по прямой ссылке. Открывая такой уровень, игра скачивает файл с сайта, который выбрал автор уровня. Поэтому сборки из магазинов это запрещают |
| Владелец видит ваш трафик | протокола ещё нет, поэтому неизвестно, что именно получит сервер. Считайте, что владелец видит всё отправленное |
| Сервер может исчезнуть | уровень, который есть только на этом сервере, исчезнет вместе с ним |

Уровни распространяются под *CC BY-NC*. Никто не может размещать их коммерчески, и общественный сервер тоже. Сервер, который берёт деньги за уровни, нарушает лицензию каждого автора на нём

> [!tip] Рекомендация
> Подключайтесь только к серверам, владельца которых вы знаете. Храните свою копию каждого уровня, который вам дорог: уровень - это папка файлов, и копия на вашем диске не зависит ни от какого сервера

## EULA

Полная сборка поставляется с EULA. В ней сказано: общественные серверы - сторонние сервисы, разработчики их не контролируют и не модерируют

Сборки из магазинов будут просить принять EULA перед публикацией уровня

Ни один из этих текстов пока не написан
