# gv 0.11.1

关卡也可以通过.zip传递，时间轴有了框选工具和折叠，冲刺取决于距离

没有`gv 0.11.0`：版本号从`gv 0.10.1`直接跳到了`gv 0.11.1`

- 关卡可以导出和导入为`.zip`，而不只是`.tar.gz`，也可以带密码。`.7z`文件会按名称识别并拒绝，而不是被错误读取。关卡的“包”在游戏中各处都改称归档包（`关卡归档包`）
- 冲刺到比完整距离更近的点，是按比例缩短的冲刺：路径更短，无敌时间更短，冷却也更短。目标近于冲刺距离的三分之一时完全不会冲刺
- 没有方向的冲刺不会执行。以前它会飞向一个你没有选择的任意方向
- 冲刺在每一帧都可以操控，完整冲刺后的无敌时间为0.30秒，而不是0.20秒。这等于冷却时间，所以连续不停地冲刺时，你在两次冲刺之间恰好暴露一帧
- 时间轴工具：`选择`、`边缘`、`剪刀`和新的`框选`工具，后者会把拖出的矩形碰到的所有片段加入选中项。`边缘`和`剪刀`以前叫Trim和Blade
- `剪刀`可以把一次预制件放置切成两半，两半都会从切开的位置继续播放同一个模板
- 子树可以在时间轴上折叠：用`选择`工具双击片段、标签页行中的按钮、层级行的菜单或`Ctrl+E`。折叠不会向关卡写入任何内容，也不会产生撤销步骤
- 工具提示现在会出现在发布的游戏中，而不只是在Unity内运行时出现。在触屏上，长按即可打开工具提示。带快捷键的操作的工具提示会显示该快捷键当前的绑定
- 200多条原本只有英文的文本已经翻译
