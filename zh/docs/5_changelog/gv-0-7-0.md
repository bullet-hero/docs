# gv 0.7.0

界面音效、在编辑器之外完全支持手柄和键盘操作，以及关卡图像的新设置

- 界面有了音效。菜单会回应按下，关卡编辑器只为编辑的结果发声：保存、拒绝、撤销或重做、删除。悬停在按钮上在任何地方都没有声音：这是最频繁的事件，也最先让人厌烦
- 音频设置中新增`编辑器界面`滑块，与`用户界面`分开控制编辑器的音效。两者默认都是50%
- 除编辑器外，一切都可以只用手柄或只用键盘完成。手柄在手时鼠标光标隐藏，左下角会显示一秒钟，提示哪个设备接管了操作。编辑器本身不能用手柄操作，但`Start`按钮可以退出编辑器
- “返回”只关闭最上层的窗口。以前按一次可能会连同下面的画面一起关闭
- 关卡图像有两个新设置：`采样`（`平滑`或`锐利`）和`压缩`（`允许`或`禁止`）。`禁止`会保留每个像素，但占用的内存最多多出4倍
- 图像超出边缘时的行为现在按轴分别设置：`X轴环绕`和`Y轴环绕`。在这个版本之前保存的关卡会把两者都读作`钳制`，所以之前设置的重复需要重新设置
- 冲刺冷却时间为0.30秒，而不是0.35秒。冲刺后的无敌时间仍为0.20秒
- 冲刺途中暂停，不再把化身拖过已停止的关卡
- 深深卡进形状内部的化身现在会从形状中心被推出去。以前它完全不会被推动
- 层级在编辑后会保留你展开的行，两个新按钮可以一次展开或折叠所有行
- 统计叠加层可以再显示三个区块：`显示帧物体`、`显示关卡物体`和`显示内存`
