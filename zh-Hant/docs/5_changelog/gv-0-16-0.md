# gv 0.16.0

來自更新版本的檔案不會開啟，遊戲會提示更新，新增不儲存資料的匿名模式，編輯器在大關卡上更快

## 版本與存檔

- 來自更新版本遊戲的檔案不會開啟，而是出現`需要更新`視窗：關卡、匯入的歸檔包和剪貼簿中的編輯器內容都是如此。`下載`會開啟網站上的下載頁面。在關卡列表中，這樣的關卡標為`來自更新版本的遊戲`。以前編輯器會在警告後提供開啟更新版本關卡的選項
- 由更新版本儲存的設定或統計資料保持不動。遊戲使用預設值執行，在關閉之前不儲存任何自己的資料，並詢問怎麼做：`繼續停用存檔`或`覆蓋資料`。自身統計資料較新的關卡，會在卡片上顯示說明，而不是最佳成績
- 新設定`不儲存遊戲資料（匿名模式）`。開啟時，遊戲既不寫入設定，也不寫入統計資料，這段時間裡你玩的內容不會寫入磁碟。[[12_launch-arguments|啟動引數]]`--suppress-game-saves`會在整次啟動中開啟它
- 當`--autosave`為本次啟動設定了編輯器的自動儲存時，`自動儲存`設定會註明這一點

## 遊戲

- 按住滑鼠按鍵操控時，劃過暫停按鈕不再打斷操控。在關卡上開始的按下，無論你把它移到哪裡都仍然是操控，在按鈕上開始的按下則仍然屬於按鈕
- 用游標衝刺到距離不足一個單位的點不再被忽略。化身尚未站在上面的任何目標，都會得到一次按距離縮短的衝刺
- 在Android上，遊戲需要Vulkan，所以Google Play不再向沒有Vulkan的裝置提供它。這些裝置上會出現黑屏

## 編輯器

- 編輯器在大關卡上更快了。不在螢幕上的時間軸或面板不再在每次編輯時重建，而是在顯示時追上進度。“這個副本屬於哪次放置”這一問題，每次編輯只通過一個索引來回答，而不是為每個選中的物體、欄位和關鍵幀軌道遍歷整個關卡
- 編輯不再重置事件和音訊關鍵幀的選中項，也不再清除Local時間軸上的關鍵幀選中項
- 普通編輯不再播放撤銷和重做的音效。只有撤銷和重做才會播放它
- 點選兩個時段相同的片段時，會選中繪製在上面的那個。以前選中的是被遮住的那個，在預製件模式中，點選巢狀模板的內容每次都會選中它的放置
- 當外層模板有需要恢復的選中項時，退出巢狀預製件不再報出`Collection was modified`錯誤
