# 伺服器

Bullet Hero中的伺服器是儲存關卡的網路服務。將會有官方伺服器OWS，以及任何人都能執行的社群伺服器NOWS

> [!warning] 警告
> 目前還沒有伺服器，官方的和社群的都沒有。遊戲與伺服器之間的協議尚未設計

伺服器程式碼將在[bullet-hero/backend](https://github.com/bullet-hero/backend)開源，目前那裡還是空的
