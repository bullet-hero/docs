# gv 0.3.3

Un shader rapide et une caméra d'éditeur qui se déplace à la souris ou à deux doigts

- **Un nouveau shader pour les objets du niveau.** Il n'a qu'une passe et seulement ce dont le dessin a besoin, et il tourne environ deux fois plus vite que l'ancien
- **La caméra de l'éditeur.** Sur PC, elle se déplace à la souris, sur téléphone à deux doigts. Un bouton à part la ramène sur le point de focus
- **Textures.** N'importe quelle texture du jeu ou du niveau peut désormais être posée sur un objet selon ses propres coordonnées UV
- **La visionneuse de journal.** La première version d'un panneau qui affiche les messages de l'éditeur

Commits : jeu `b9d32ac7`, SDK `88c3224d`
