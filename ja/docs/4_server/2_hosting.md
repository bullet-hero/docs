# 友人向けのサーバー

オープンなサーバーツール、接続するプレイヤー全員分のゲームのフルビルド、PublishProfileファイルが必要です。モデレーションとレベルのライセンスの遵守は、サーバーの運営者の責任です

> [!warning] 警告
> サーバーツールはリリースされておらず、プロトコルも設計されていません。このページには、すでに決まっていることだけを載せています

## 必要なもの

- **サーバーツール**。MITライセンスで公開される予定です。公式サーバーが動いているのと同じコードです。自分のサーバーは、このツールでも、これをベースにした何かでも構築できます
- **接続する全員分のゲームのフルビルド**。Google PlayとApp Storeのビルドはコミュニティサーバーに接続できません。フルビルドは[GitHub](https://github.com/bullet-hero/releases)とプロジェクトのWebサイトにあります
- **公開プロファイル**。`PublishProfile`ファイルが、サーバーが受け付けるレベルを決めます。詳細：[[7_publish-profiles]]
- **サーバー用のマシン**。システム要件、ランタイム、ポート、起動方法はまだ不明です

## 公開プロファイル

プロファイルは、受け付けるライセンス、レベルがファイルを取得できる場所、サイズの上限を設定します。そのためにコードを変更する必要はありません

公式サーバーは、サーバーの設定ファイルで指定された`standard`プリセットで動いています。これを出発点に、必要に応じて緩めたり厳しくしたりしてください

## 引き受けること

- **モデレーション**。Bullet Heroはコミュニティサーバーをモデレーションしません。フルビルドのEULAは、すべてのプレイヤーにそう伝えています
- **商用利用の禁止**。デフォルトでは、レベルは*CC BY-NC*で配布され、作者は別のライセンスを選べます。すべてのレベルのライセンスを守ってください。*CC BY-NC*のレベルは無料でホストして共有できますが、料金を取ったり、ほかの方法で収益を得たりすることはできません
- **リソースの権利**。レベルには他人の音楽やグラフィックが含まれていることがあります。どこまで厳しくチェックするかはプロファイルで決まります。ただし、他人の作品に関する苦情は運営者に届きます。公式サーバーのルール：[[ugc-licensing-policy]]

非商用での配布を許可するのは、ゲームではなく各レベルの作者です。そのため、例外を認められるのも作者だけです

## 不明なこと

- ゲームがサーバーを見つけて接続する方法
- コミュニティサーバーにアカウントがあるかどうか
- レベルをアップロードし、一覧に載せる方法
- 少人数向けのサーバーと公開サーバーで設定が異なるかどうか

大規模サーバー向けにすでにあるもの：[[3_advanced-hosting]]
