# 连接服务器

游戏将有面向所有版本的官方服务器OWS，以及仅面向完整版的社区服务器NOWS。Bullet Hero不审核社区服务器，请只连接你认识其所有者的服务器

> [!warning] 警告
> 目前还没有服务器，游戏也无法连接服务器。没有地址格式，没有连接界面，也没有账号

## 将会有哪些服务器

| | OWS | NOWS |
|---|---|---|
| 全称 | Official Web Services | Non-official web services |
| 由谁运行 | Bullet Hero | 任何人 |
| 由谁审核 | Bullet Hero | 服务器所有者 |
| 可连接的版本 | 全部 | 仅完整版 |

**OWS是默认服务器**。每个平台上的每个游戏版本都认识它，无需任何设置

**NOWS是社区服务器**。Bullet Hero既不控制也不审核它们

**Steam创意工坊是PC上的第三个关卡渠道**。Steam版可以列出并启动你订阅的物品，也可以在编辑器中把关卡和合集发布到那里：[[17_publishing]]

## 哪些版本可以连接

| 版本 | 来源 | OWS | NOWS |
|---|---|---|---|
| 商店版 | Google Play、App Store | 是 | 否 |
| 完整版 | [GitHub](https://github.com/bullet-hero/releases)和项目网站 | 是 | 是 |

商店版无论如何都无法连接社区服务器。对NOWS的支持在编译时就从中移除了，而不是藏在某个设置后面

原因在于商店规则。商店评判的是程序能做什么，而不是它显示了哪些按钮。而按照商店规则，其他人能看到的内容必须经过审核

计划为完整版分配独立的应用ID，这样在Android上它可以与商店版并存安装。目前所有Android版本共用一个ID：`com.vertoker.BulletHero`

## OWS将提供什么

- 账号和使用条款
- 每个关卡发布前都要检查：有错误的关卡会被拒绝，有警告的关卡交给审核员
- 举报关卡和用户，以及封禁它们

账号中保存什么还没有决定。服务器将有自己的隐私政策，与服务器同时出现。它会说明账号的内容，并解释如何删除账号。游戏和网站的隐私政策不涵盖服务器：[[game-privacy-policy]]、[[privacy-policy]]

## 什么时候

发布到Steam创意工坊已经可以在Steam版中使用。其余部分没有日期。顺序是：先是OWS，然后是Google Play版，最后是App Store版

在服务器上一起游玩目前还没有，也没有设计

## 他人服务器的风险

社区服务器的运行者很可能是你不认识的人。Bullet Hero既不控制也不审核这类服务器。完整版的EULA明确说明了这一点

| 风险 | 原因 |
|---|---|
| 关卡的权利未经检查 | 检查什么由所有者决定，也可能什么都不检查。关卡中可能带有作者无权分享的音乐 |
| 没有人审核内容 | 无法保证有人查看上传的内容 |
| 来自其他网站的文件 | 标准策略允许关卡通过直接链接获取文件。打开这样的关卡时，游戏会从关卡作者选定的网站下载文件。因此商店版禁止这样做 |
| 所有者能看到你的流量 | 目前还没有协议，所以不知道服务器具体会收到什么。请认为所有者能看到你发送的一切 |
| 服务器可能消失 | 只存在于该服务器上的关卡会随之消失 |

关卡默认以*CC BY-NC*发布，作者可以在关卡元数据中选择其他许可证。服务器必须遵守每个关卡的许可证。在*CC BY-NC*下，任何人都不得以商业方式托管关卡，社区服务器也不例外，对这类关卡收费的服务器违反了其中每位作者的许可证

> [!tip] 建议
> 只连接你认识其所有者的服务器。为每个你在意的关卡保留一份自己的副本：关卡就是一个装有文件的文件夹，你磁盘上的副本不依赖任何服务器

## EULA

完整版附带一份EULA。其中写明：社区服务器是第三方服务，Bullet Hero既不控制也不审核它们

商店版会在发布关卡前要求你接受EULA

这些文本都还没有写
