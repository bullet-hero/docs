# gv 0.6.3

Outside a level the phone rotates freely by default, and more screens got a vertical layout

- `Screen Orientation` now defaults to `Auto-Rotate`: the menu and the settings turn with the phone. A running level still holds the axis it declares (horizontal by default), and the editor obeys neither of these settings
- Controls, keybindings, statistics, the profile, hints and the value input window got a vertical layout and stay readable on a phone held upright
