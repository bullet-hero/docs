# 难度与曲线

按玩家本身的数字设计（全部数字见[[6_avatar]]和[[7_damage]]），再考虑人12到15帧的反应时间。新的模式先以安全的形式展示

你无法评判自己关卡的难度：请让第一次看到关卡的人来测试

## 用数字看玩家

化身的精确数值见[[6_avatar]]和[[7_damage]]。它们对关卡意味着：

| 项目 | 对设计意味着什么 |
|---|---|
| 玩家判定框 | 比绘制出的身体小得多，所以擦过身体的子弹常常打不中 |
| 冲刺 | 几乎瞬间跨过屏幕高度的四分之三 |
| 冲刺时的无敌 | 比冲刺本身持续更久，所以冲刺穿过薄障碍是安全的 |
| 被击中后 | 短暂的击退且无法控制，之后有一段忽略后续击中的时间 |
| 人的反应 | 0.2到0.25秒，在60fps下是12到15帧 |
| 启动时的数值 | 3条命，速度1.0，检查点开启 |

由此得出的经验法则：
- 1个单位宽的空隙很宽，0.6宽的空隙很紧
- 一次冲刺跨过的距离相当于半秒的奔跑

## 被击中不会立刻死亡

被击中后，玩家会被击退，短时间内无法控制。之后一段时间内的所有击中都会被忽略（[[7_damage]]）。一排连续的十颗子弹只会扣掉一条命，而不是十条

> [!info] 须知
> 直觉告诉你的正好相反。密集的齐射看起来像是必死无疑。实际上它比一颗恰好在无敌结束时飞来的子弹代价更小

## 玩家的选择

生命数、播放速度和检查点由玩家在启动界面上选择。默认是3条命，速度1.0，检查点开启

你可以放置检查点，但无法强迫别人使用它们。你也无法禁止别人用半速游玩

按默认值来设计，但不要把任何东西建立在“他会死在这里”的算计之上。你设计的是一种感受，而不是惩罚

## 循环

玩家重复同一个循环：游玩、死亡、再试一次。好的关卡在这个循环上叠加自己的层次，而这个循环必须是：
- 开头简单，不要一上来就是困难的机制
- 可扩展，新元素逐步加入，这样才不会乏味
- 有回报，因为正确的动作立刻得到奖励，才能维持动力

## 曲线：教学、检验、变化

1. 以安全的形式展示模式，几乎不可能失误
2. 真正要求玩家做到
3. 改变一个变量（速度、方向、数量），再要求一次

如果一个模式第一次出现就是困难的形式，玩家会怪关卡。玩家死了，却不明白关卡想要他做什么

公平也有限度。过度的“手把手带领”和不公平一样，都会让人失去乐趣

## 背板

只能靠记忆通过的关卡是一种正当的类型。但它必须是一个决定，而不是意外

界线很简单：死亡之后，玩家必须明白具体要记住什么。死了十次还不明白，那不是背板，是噪音

## 用别人的眼睛检验

你无法自己评判自己的关卡。到发布的时候，你已经把自己的难点通过了两百次，对你来说它很简单

> [!tip] 建议
> 把关卡交给第一次看到它的人，然后安静地看着。不要给提示。一个人死了三次、还问关卡到底想要什么的地方，不是难，而是不清楚

## 从短关卡开始

第一个关卡做1到2分钟长。兴趣会比曲目先耗尽。四分钟的关卡意味着四倍的工作量和十倍的放弃理由
