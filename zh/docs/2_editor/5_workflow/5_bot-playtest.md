# 让机器人试玩你的关卡

机器人做什么、从不保证什么、有什么开销，以及如何用它测试你正在制作的关卡

机器人用和你一样的操作来玩关卡。它观察即将到来的攻击，寻找空隙，操控的也是你会操控的那个角色。它会移动、冲刺、受到伤害，也会死亡

机器人在开始游玩前选择，就在生命和速度选项旁边

## 编辑器中的机器人

在编辑器中，机器人操控预览玩家：
1. 打开`设置` → `编辑器` → `预览玩家`
2. 勾选`由机器人操控玩家`
3. 在工具栏中开启预览玩家

预览玩家不能选择机器人，始终是`Reflex Bot v1`。只有这个机器人不需要提前做任何准备。你编辑关卡时它会继续工作，任何播放速度都可以，包括倒放

刚拖动播放头之后，机器人会短暂地玩得差一些：它在重新了解接下来会发生什么

当你拖动控制柄手柄或在文本框中输入时，预览玩家会忽略你自己的操作

同一组设置中的`显示机器人视野`会在关卡上方绘制信息。它默认关闭，而它的三个部分默认开启，所以一打开就能看到完整的画面：
- `净空场`：机器人认为屏幕每个区域有多少空间。红色是它预计会被击中的位置，空间越大颜色越淡。它认为安全的地方不绘制任何东西
- `所选目标`：它正在前往的点。目标停止移动表示机器人满意了，而不是卡住了
- `可达范围圈`：它认为自己能到达多远，内圈是走路能到的范围，外圈是冲刺能到的范围。它从不选择圈外的目标

只绘制`Reflex Bot v1`的信息。在暂停时打开它，画面是静止的

**用任意机器人完整游玩**。关卡设置的`游玩`标签页中有一个`机器人`下拉菜单，与菜单中关卡界面上的相同：`无机器人`、`Reflex Bot v1`、`Warm Bot v1`。这会启动一次真正的关卡游玩，而不是预览玩家

## 解读结果

机器人检查的是可读性，而不是难度：
- 机器人从容通过了你觉得很难的一段。说明这一段是可读的，只是你还不够熟练
- 机器人在同一个地方一次又一次被击中。去看看那个地方：通常是一个不留逃生空间的危险物。人类玩家读起来也不会更好

## 机器人保证什么、不保证什么

**机器人不保证能通关**。它是一个永远不会累的玩家，而不是一个永远不会输的玩家。如果某一段要求你提前一秒就以正确的方式进入某个弹幕模式，机器人会被击中。这并不代表有什么东西坏了

> [!info] 须知
> 机器人无法作弊，这是它的设计。它拥有的操作和玩家完全相同，没有任何额外能力：同样的速度、同样的冲刺、同样的判定框、同样的伤害。玩家过不去的地方，机器人也过不去

**机器人会消耗性能**。它每一帧都在寻找空间。在性能较弱的设备上，帧率会下降。在复杂的关卡上，最初几秒会是最卡的

## 打败了机器人的关卡

机器人只有在开发者从未见过的关卡上才会进步。机器人已经能通关的关卡对它没有任何帮助

你的关卡打败了机器人吗？把它发过来：
1. 在[bullet-hero/releases](https://github.com/bullet-hero/releases/issues)中提交一个issue
2. 说明是哪个机器人在哪里输了
3. 附上关卡文件夹
