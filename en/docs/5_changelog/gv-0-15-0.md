# gv 0.15.0

A level with animated screen limits spends 19 ms per frame on Android instead of 30-45

- A level that animates its aspect ratio with the `Screen Limit` event spends 19 ms per frame on Android instead of 30-45. The camera now always takes the whole screen, and the bars are added when the frame is put on screen. So the renderer no longer recreates its images on every frame where the bars move
- The mouse and touches read the same bars, so on a level with bars the pointer still lands where it points
