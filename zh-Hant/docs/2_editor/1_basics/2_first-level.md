# 第一個關卡：路線

到第一次試玩只需六步：建立關卡、新增曲目、標出節奏、放置物體、開始試玩、儲存

## 六個步驟

這裡只講操作順序。每個欄位的作用，由對應面板旁邊的提示說明

**1. 建立關卡**。`{{ui:settings_editor-settings_editor-settings}}` → `{{ui:settings_editor-settings_create-level}}`。選擇一個預設，設定名稱和時長。時長之後可以修改

**2. 新增曲目**。把音訊檔案複製到關卡資料夾，並在關卡中接入它。`ogg`效果最好，`flac`無法讀取。更多：[[2_preparing-the-track]]

**3. 標出節奏**。`{{ui:editor_inspector-beat_tab}}`標籤頁：BPM、偏移、每小節拍數。網格不是給遊戲用的，而是給你用的：內容會吸附到網格上

不知道速度？在`{{ui:editor_beat-window_title}}`視窗（`Shift+T`）中跟著曲目敲出速度。敲擊本身沒有預設按鍵

**4. 放置第一批物體**。建立一個物體，給它一個形狀，並在它的位置上放兩個關鍵幀。關鍵幀之間的數值由遊戲自動過渡

**5. 檢查**。直接從編輯器開始試玩。很可能所有東西不是移動得太快，就是太慢。這很正常：速度只能靠耳朵來調

**6. 儲存**。`Ctrl+S`

自動儲存預設開啟。出現未儲存的修改{{v:editor.autosave-delay}}秒後，它會儲存關卡，並把一份副本放進`backups/<level id>/`。更多：[[4_not-losing-work#自動儲存]]

## 第一個關卡要小

> [!tip] 建議
> 選一首短曲目，1到2分鐘。4分鐘的關卡工作量是四倍，半途放棄的理由是十倍

從能用的最簡單的模式開始，而不是從你想到的最難的開始。在給別人看之前，自己先從頭到尾玩一遍

生成器、預製件和修改器以後再用。它們在大型關卡上能節省時間，在第一個關卡上只會礙事
