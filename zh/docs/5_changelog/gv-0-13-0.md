# gv 0.13.0

预制件的根可以选中，自动保存让编辑器冻结的时间减半，关卡卡片写出音乐作者

- 预制件模板的根可以选中。在预制件时间轴上点击它的那一行，它的关键帧就能像其他物体一样编辑。打开一次放置会定位到根，选中根时，播放会按模板自身的长度循环
- 自动保存让编辑器冻结的时间减半：在12.3 MB的关卡上为133毫秒，而不是265毫秒。以前它会把整个关卡复制两次，一次用于备份，一次用于保存
- 保存后的清理不再在主线程上进行。删除过时的另一种格式的文件和轮换备份，以前在一帧的中途执行，每次自动保存执行四次
- 关卡卡片在关卡作者下方单独一行写出音乐作者。写哪个资源，由资源本身的`在关卡卡片上显示`复选框决定。只有一个音频资源的关卡无需任何复选框就会得到这一行
- 时间轴不再绘制被同一条轨道上另一个片段完全遮住的片段。较宽的片段位于较窄的片段之下，选中或正在拖动的片段位于整条轨道最上层。没有绘制的片段仍然可以点击选中
- 时间轴一被隐藏就会释放它的元素。以前折叠的关卡和未选中的标签页每帧的开销与打开时一样
