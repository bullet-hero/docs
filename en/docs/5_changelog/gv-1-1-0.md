# gv 1.1.0

Publishing to the Steam Workshop, resource collections, a sandbox with a tutorial, quick setup, a "Colliders Only" mode and the Chinese language

> [!warning] Warning
> A file saved by `gv 1.1.0` does not open in `gv 1.0.0`: your settings, your statistics and a level you saved. There it opens the `Update required` window. Files from `gv 1.0.0` open in `gv 1.1.0` as before. More - [[5_troubleshooting]]

## Sending levels and the Workshop

- The `Share` button gathers every way to send a level. The `How to share` window offers `Archive` and `Steam Workshop`, and each way checks the level by itself before sending
- An archive is a folder, a tar.gz or a zip, and a zip can be protected with a password
- In the Steam build, a level or a collection is published to the Workshop right from the editor. Publishing the same level again updates the existing item
- A level, each of its resources and its `Cover` can state whether they were made with AI (`AI Generation`). The level card in the menu shows this if anything inside was made by AI

## Collections

- A collection is a set of resources for any level: prefabs, themes, shapes, effects, textures, fonts and audio
- The editor settings have a `Library` tab: your resources, your collections and the collections you are subscribed to in the Workshop
- `Level Settings` has a `Collections` tab. It imports a whole collection together with everything it depends on, or builds a collection from the level's resources
- If the level already has a different copy of a resource, the game asks which one to keep

## Game

- **`Sandbox`** is a new button in the main menu. It holds a six-step tutorial (moving, dashing, dodging, dashing through a ring, choosing a control mode) and a board from which attacks are launched by hand. The game offers the tutorial once, on the first launch
- **`Quick Setup`** sets performance, screen effects, language and volume on one screen. It opens by itself on the first launch and stays in the menu. The advanced sections of the settings are now folded
- **`Colliders Only Mode`** is in the settings, on the `Graphics` tab. The level draws only what can hit you, as flat fills on a plain background. The music, the collisions and the statistics stay, and the run counts like any other
- Knockback after a hit is 7.5 units instead of 10, the length of one full dash. A very short dash next to the cursor now always fires
- `Zen` takes hits again: knockback, the shield and hit effects, but no lives are spent. For bullets that pass through you there is a separate `No Collision` option, and its runs are counted separately
- `Back to Options` in the pause and result windows returns to the screen the run started from, with the same options
- The game is available in Simplified Chinese

## Controls

- Each device has one `Active` switch. The device you used last leads, and dash and pause work from any active device
- Tilt control treats a phone lying screen up as rest. No calibration is needed, and everything stays correct when the screen rotates
- Dash on a gamepad is any button except Start and Select. Start pauses
- The mouse stops the avatar when you release the button (`Stop On Release`), touch does not (`Stop On Lift`). Both can be switched
- A second finger while steering always dashes and no longer presses the buttons under it

## Android

- Phones without Vulkan can install and play the game again. The game falls back to OpenGL ES 3
