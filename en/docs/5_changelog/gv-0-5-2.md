# gv 0.5.2

Rule validation runs about twice as fast, and saving a level now checks it in the background

- Rule validation is 1.9-2.4 times faster. On the volcano test level (19 341 objects) it takes 850 ms instead of 1 614 ms, on weathergirl (4 151 objects) 112 ms instead of 264 ms. The editor runs it when a level is opened, so large levels open faster
- Saving a level checks it against the rules in the background, once the file is already written to disk, and reports the number of problems found. Nothing is fixed automatically
- On the `Rules` tab every row is coloured by severity: error, warning or advice
