# Скорость и горячие клавиши

Все горячие клавиши редактора, как работает переназначение и четыре вещи, экономящие больше всего

## Каждая горячая клавиша это настройка

Есть каталог умолчаний и ваши переопределения поверх него, хранящиеся разреженно - только то, что вы реально сдвинули. Улучшенное умолчание поэтому доходит до всех, кто его не переназначал, а сброс это удаление, а не запись. Живут они на вкладке Keybindings в настройках

> [!tip] Подсказка
> Подписи резолвятся, а не вшиты. Переназначили - и палитра команд и каждое контекстное меню сразу показывают новую клавишу

## Умолчания

| Группа | Клавиша | Действие |
|---|---|---|
| Воспроизведение | `Space` | играть и пауза |
| Правка | `Ctrl+Z` | отменить |
| Правка | `Ctrl+Y` или `Ctrl+Shift+Z` | вернуть |
| Правка | `Ctrl+S` | сохранить |
| Правка | `Ctrl+C`, `Ctrl+V` | копировать и вставить |
| Правка | `Ctrl+D` | дублировать |
| Выделение | `Delete` | удалить выделенное |
| Выделение | зажатый `Ctrl` | множественный выбор |
| Поиск | `Ctrl+F` | поиск по содержимому |
| Поиск | `Ctrl+Shift+P` | выполнить команду |
| Таймлайн | `Shift+T` | окно сетки ритма, в котором отбивается темп. У самого набора темпа клавиши по умолчанию нет, назначьте её, если нужна |
| Таймлайн | зажатый `Ctrl` с колесом | панорамирование |
| Таймлайн | зажатый `Shift` с колесом | зум |
| Гизмо | `1-7` | выделение, позиция, поворот, масштаб, размер, якоря, пивот |
| Гизмо | `0` | скрытое: выделение остаётся, но ни ручки, ни рамка не рисуются |
| Навигация | стрелки | ходят по той поверхности, куда вы последней кликнули |

## Нажимаемые и удерживаемые клавиши

Нажимаемая клавиша сравнивает модификаторы точно, удерживаемая - как подмножество. `Ctrl+Shift+P` не может заодно сработать как `Ctrl+P`, а голая `T` не срабатывает при зажатом `Ctrl`. Удерживаемый модификатор уточняет уже происходящий жест

> [!info] Интересно
> Поэтому две удерживаемые клавиши могут намеренно делить одну кнопку - множественный выбор и панорамирование таймлайна оба на `Ctrl` и друг другу не мешают

## Четыре главных экономии времени

- **Выполнить команду** - всё, что редактор умеет, с поиском по названию. Быстрее, чем вспоминать, на какой панели лежит кнопка
- **Поиск по содержимому** - прыжок к объекту или аудиодорожке по имени, вместе с плейхедом
- **Ping** - вьюпорт кадрирует, таймлайн прокручивается, иерархия прокручивается, всё сразу. Повторное нажатие обходит множественное выделение
- **Стрелки на таймлайне** - они ходят по направлению, а не по индексу, поэтому переход между соседними ключами не требует мыши
