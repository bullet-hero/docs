# Droits

Un niveau que tu publies ne peut contenir que des fichiers sous une licence ouverte pas plus stricte que CC BY-NC ou avec l'autorisation de leur auteur. Un niveau pour toi-même peut être construit à partir de n'importe quoi

La vérification s'active quand un niveau quitte ton disque pour un serveur ou le site
