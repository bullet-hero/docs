# Links e comunidade

Conversas e perguntas vão para o Discord, vídeos para o YouTube, bugs do jogo para as issues do repositório bullet-hero/releases. O código-fonte está na organização bullet-hero no GitHub

Tudo o que você pode baixar: o jogo, o SDK, as lojas - [[download]]

## Código-fonte

Todos os repositórios estão na organização [bullet-hero](https://github.com/bullet-hero)

| Repositório | Acesso | O que tem lá |
|---|---|---|
| [bullet-hero/game](https://github.com/bullet-hero/game) | fechado | o jogo e o editor |
| [bullet-hero/sdk](https://github.com/bullet-hero/sdk) | aberto | o SDK, issues sobre o SDK e o código dele |
| [bullet-hero/releases](https://github.com/bullet-hero/releases) | aberto | builds do jogo, issues dos jogadores |
| [bullet-hero/docs](https://github.com/bullet-hero/docs) | aberto | esta documentação |
| [bullet-hero/backend](https://github.com/bullet-hero/backend) | aberto | o servidor, vazio por enquanto |
| [bullet-hero/frontend](https://github.com/bullet-hero/frontend) | fechado | o site |
