# 统计

游戏会统计你游玩和创作的哪些数据，纪录如何选出，文件在哪里，以及如何删除或冻结它们

## 两种文件

| 文件 | 内容 |
|---|---|
| `stats/statistics.json` | 关于你的一切：涵盖所有关卡和界面 |
| `stats/<LevelId>.json` | 你在某一个关卡上做过的一切 |

文件是JSON格式，时间戳是UTC。不会上传到任何地方

`stats`文件夹位于游戏文件夹中`levels`的旁边，[[1_installation]]。它从不放在关卡里面。这样你发给朋友的关卡不会带着已通关的状态，你的进度也不会因为关卡被删除后重新导入而丢失

## 档案标签页

`设置`→`档案`显示整台设备的统计文件：

| 分区 | 行 |
|---|---|
| `账户` | `首次游玩`、`最近游玩`、`启动次数`、`总时长` |
| `时间` | `菜单`、`游戏`、`编辑器`、`加载` |
| `总计` | `尝试次数`、`通关次数`、`死亡次数`、`受击次数`、`已游玩关卡`、`已通关关卡`、`模拟帧数` |
| `连胜` | `当前连续通关`、`最长连续通关` |
| `化身` | `冲刺次数`、`移动距离` |
| `教程` | `完成次数`、`首次完成`、`最近完成`。只有通过[[13_sandbox|沙盒教程]]的每一个步骤才算完成一次 |
| `创作` | `已创建关卡`、`已删除关卡`、`已创建物体`、`操作次数`、`生成器运行次数`、`已添加资源` |
| `设备` | `键盘和鼠标`、`触屏`、`手柄`、`陀螺仪` |

时间是真实的秒数，不是关卡时间。检查点的恢复过程和半速游玩的一局，都按实际花费的时间计算

设备这几行显示游玩时由哪个设备操控。仅仅是连接着的设备不计入

## 每个关卡

关卡的文件记录：

- 你第一次和最近一次游玩它的时间
- 在其中花费的真实时间和进入次数
- 尝试次数（每次重开都算一次新的尝试）、通关、死亡、受击、冲刺
- 从检查点继续的次数和中途放弃的局
- 到达的最远位置和首次通关
- 你在关卡中死亡的位置：按关卡长度的比例和按检查点统计

## 纪录

纪录按一局的条件归档：生命、速度、检查点开或关、无碰撞开或关，以及机器人。速度精确到百分位，与屏幕上显示的完全一致

禅模式（0条命）仍然统计受击：每一次碰撞都计入数据，只有生命和一局的结束不受其影响

在相同条件下，一局按以下顺序比较，胜出即打破纪录：

1. 到达得更远
2. 受击次数更少
3. 结束时剩余的生命更多
4. 使用的冲刺更少

纪录还会保存那一局的种子和当时关卡的版本。版本不属于条件。所以在关卡改版之前创下的纪录仍然可见，旁边会显示版本

**编辑器中的一局会被统计，但从不产生纪录**。它会计入尝试次数、死亡次数和受击次数。它不产生纪录、最佳进度和首次通关，因为那时关卡只存在于内存中

## 写入、删除、冻结

游戏每30秒写入一次统计。一局结束、切换界面和退出游戏时也会立即写入。崩溃最多损失30秒的数据

- **删除**：`设置`→`其他`→`存储`。其中有`已不存在的关卡的统计数据`和`全部统计数据，包括你的设备档案`
- **随关卡一起删除**：删除关卡时会提供`同时删除统计`
- **冻结**：匿名模式会在关闭游戏之前停止所有写入，[[4_settings]]

> [!warning] 警告
> 手动复制的关卡文件夹会保留关卡的ID。原关卡和副本共用同一个统计文件
