# gv 0.13.2

修復物體起點之前的幀、關卡文本的預熱、時間軸上的未啟用物體，以及編輯器視窗中的Escape鍵

- 起點被錨定的物體會早於作者設定的起點開始播放，在這些幀上它現在保持自己的第一個關鍵幀。以前幀計算在這裡會報錯，可能讓整幀都無法構建，在正式版構建中還可能導致遊戲關閉
- 關卡文本重新在關卡開始之前準備好。文本庫更新後，預熱悄無聲息地失效了，每個字母都在它第一次出現的那一幀才進入字型圖集
- Level和Prefab時間軸把關卡不繪製的物體顯示為褪色的灰色片段。這既包括關閉了啟用核取方塊的物體，也包括父級關閉了該核取方塊的物體。預製件片段保留一絲紫色，所以兩種狀態都能分辨
- `Escape`像點選背景一樣關閉22個編輯器視窗，其中包括未儲存的更改、搜尋面板、備份、生成器、關卡密碼和資源編輯器
- 關卡校驗不再報告位於關卡結尾之後的關鍵幀或物體，它的修復也不再把它們壓到最後一幀。結尾之後的內容是允許的：關卡一變長，它就會開始播放。早於第一幀的幀仍然算作問題
