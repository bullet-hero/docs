# gv 0.3.2

Una versión pequeña para teléfonos: el doble de objetos en pantalla a la vez

El límite de objetos dibujados en un fotograma subió de 512 a 1024. Unos 1000 objetos a la vez en un teléfono es el techo por ahora: no se pueden reservar más en memoria ni dibujarlos lo bastante rápido en una GPU débil

Las formas también se empaquetaron en un único atlas de texturas, y se añadió una escena de prueba de estrés para medir el límite
