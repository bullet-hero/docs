## 版本

每個產品都有自己的版本號，帶一個字母字首，格式都是`major.minor.revision`：

| 字首 | 全稱 | 產品 |
|---|---|---|
| `gv` | `game version` | 遊戲（客戶端） |
| `sv` | `sdk version` | SDK |
| `bv` | `backend version` | 後端，即伺服器 |
| `fv` | `frontend version` | 網站 |
| `mg` | `model generation` | 資料 |

寫法：`gv 1.0.0`、`sv 1.0.0`、`bv 1.0.0`、`fv 1.0.0`、`mg 1`

詳細說明見[[5_versioning]]
