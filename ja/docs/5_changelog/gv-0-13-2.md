# gv 0.13.2

オブジェクトの開始前のフレーム、レベルテキストのウォームアップ、タイムライン上の非アクティブなオブジェクト、エディターのウィンドウでのEscapeキーの修正

- 開始がアンカーされたオブジェクトは、作者が設定した開始より早く再生されます。そのフレームでは最初のキーフレームの値を保つようになりました。以前はそこでフレームの計算がエラーを出し、フレーム全体の構築が止まることがあり、リリースビルドではゲームが終了することもありました
- レベルのテキストは、再びレベル開始前に準備されるようになりました。テキストライブラリの更新後、ウォームアップが何も知らせずに動かなくなり、すべての文字が最初に現れたフレームでフォントアトラスに追加されていました
- LevelタイムラインとPrefabタイムラインでは、レベルが描画しないオブジェクトを色あせた灰色のクリップで表示します。アクティブのチェックボックスがオフのオブジェクトと、親のチェックボックスがオフのオブジェクトの両方が該当します。プレハブのクリップには紫色の名残が残るので、両方の状態を読み取れます
- `Escape`は、背景のクリックと同じように22のエディターウィンドウを閉じます。未保存の変更、検索パレット、バックアップ、ジェネレーター、レベルのパスワード、リソースエディターなどです
- レベルの検証は、レベルの終わりより後にあるキーフレームやオブジェクトを報告しなくなり、その修正で最後のフレームに寄せることもなくなりました。終わりより後の内容は許可されています：レベルが長くなればすぐに再生され始めます。最初のフレームより前のフレームは、引き続き問題として扱われます

コミット：ゲーム`1a81d1f5`、SDK `5d82f79e`
