# gv 0.3.1

에디터가 오브젝트를 만들고, 그것을 실행 취소하고, 계층 구조에 표시하게 되었습니다

`gv 0.3.0` 출시 5일 뒤, 에디터는 저장 버튼이 달린 레벨 플레이어 이상의 것이 되었습니다

- 오브젝트를 만들 수 있으며, 이 작업에 실행 취소와 다시 실행이 작동합니다
- 오브젝트 계층 구조에 레벨의 오브젝트가 표시되며, 거기서 오브젝트를 숨길 수 있습니다
- 확인을 거쳐 레벨을 삭제할 수 있습니다
- 알림과 콘솔 패널이 에디터가 방금 한 일을 알려 줍니다
- 에디터 안에서 레벨을 재생하면 게임에서와 똑같이 동작합니다

Android 빌드도 GPU 성능이 약한 스마트폰에 맞게 조정되었습니다

커밋: 게임 `393c49d2`, SDK `e2d57751`
