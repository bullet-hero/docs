# Version 0.3.4

The first timeline, the first inspector and selecting objects right in the viewport

The editor got the three pieces that level work is built around today. All three are early prototypes here

- **Timeline.** It shows frame numbers and the level's objects on the frame axis
- **Inspector.** A first version of the panel for an object's properties
- **Selection.** An object can be picked in the viewport, and the selection is shared with the object hierarchy

Colours changed too. A textured object now carries four colours, one per corner, and blends between them as a gradient. The object shader was rewritten on top of the standard URP *Unlit* shader for this
