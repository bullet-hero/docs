# gv 0.3.1

O editor aprendeu a criar objetos, a desfazer isso e a mostrá-los na hierarquia

Cinco dias depois da `gv 0.3.0`, o editor deixou de ser só um reprodutor de níveis com um botão de salvar

- Objetos podem ser criados, e desfazer e refazer funcionam para isso
- A hierarquia de objetos mostra os objetos do nível, e dali um objeto pode ser ocultado
- Um nível pode ser excluído depois de uma confirmação
- Notificações e um painel de console informam o que o editor acabou de fazer
- Jogar um nível dentro do editor funciona igual a jogar no jogo

A build de Android também foi ajustada para celulares com GPU fraca
