# gv 0.13.0

The prefab root became selectable, autosave freezes the editor half as long, and the level card names the music artist

- The root of a prefab template can be selected. Click its row on the prefab timeline, and its keyframes are edited like those of any other object. Opening a placement lands on the root, and while it is selected, playback loops over the template's own length
- Autosave freezes the editor half as long: 133 ms instead of 265 ms on a 12.3 MB level. Before, it copied the whole level twice, once for the backup and once for the save
- Cleanup after a save no longer runs on the main thread. Deleting a stale file of the other format and rotating backups used to run in the middle of a frame, four times per autosave
- The level card names the music artist on a separate line under the level's authors. Which resource to name is set by the `Show on the level card` checkbox on the resource itself. A level with exactly one audio resource gets this line without any checkbox
- The timeline no longer draws a clip that is fully covered by another clip on the same lane. A wider clip lies under a narrower one, and a selected or dragged clip is on top of the whole lane. A clip that is not drawn can still be selected with a click
- A timeline releases its elements as soon as it is hidden. A folded level and an unselected tab used to cost as much every frame as when open
