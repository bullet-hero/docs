# gv 0.0.2

Textures, parents, particules, texte et effets de post-traitement, essayés un par un dans des scènes de test

Cette version est une série d'expériences. Chaque fonctionnalité dont un niveau aurait besoin a eu son propre test, et la plupart sont restées

- Les objets ont reçu des textures
- Un objet peut avoir un parent, et l'objet se déplace avec lui
- Les effets de particules et le texte sont arrivés (à l'époque via *TextMeshPro*)
- Des effets de post-traitement de l'écran

Tout a été mesuré sur un téléphone Android. D'après les notes de l'époque, il tenait environ 1500 objets à 30 fps. Les ombres 2D ont été essayées puis abandonnées
