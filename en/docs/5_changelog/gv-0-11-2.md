# gv 0.11.2

Folding in the hierarchy and on the timelines became a three-step mode, and the editor got full audio on phones

- The fold button of the hierarchy and of the object timelines cycles through three steps: everything unfolded, partial, everything folded. "Partial" keeps the object kinds you chose unfolded. Hold the button to choose them, or set them in `Game Editor` > `Interface` > `Partial Folding`
- In the level editor audio is decoded whole on every platform, phones included. A compressed track drew no waveform and seeked to the nearest block instead of the frame you wanted. In the game on a phone audio still stays compressed
- `Fit Level` on an audio track lengthens the track and the level together until the clip fits whole. The level only gets longer, and a clip that already fits changes nothing
- When an audio file of another format is added, the game says what is supported: `.mp3`, `.wav` and `.ogg`
- One button in the settings folds every section or unfolds everything
- Moving the preview avatar with the keyboard in the editor no longer freezes the screen for 119 ms on every move
