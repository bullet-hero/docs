# gv 0.14.0

特效按作者設想的方式播放，可以從物體上移除特效，編輯器新增兩個快捷鍵

## 特效

- 特效朝其物體所指的方向發射粒子，在時間軸上後退一步時繪製的內容與播放時一致。以前噴射流固定在世界空間中，所以同一幀在播放時可能顯示一道彎曲的軌跡，後退一步後又顯示一道筆直的軌跡
- `點`以外的發射形狀（`圓形`、`線段`、`錐形`、`圓環`）會隨物體一起旋轉。以前它們始終與世界對齊，所以旋轉過的特效會沿著與它無關的軸生成粒子
- 特效在螢幕外也會繼續模擬，因此本應飛入畫面的粒子在到達之前就已存在。以前相機之外的發射器什麼都不生成，所以特效可能在編輯器中看起來正常，在遊戲中卻消失了。代價是螢幕外的特效也要佔用GPU時間
- **會破壞現有關卡**。特效的線性力現在是每秒的加速度，與格式一直以來的描述一致。以前在50 Hz的特效頻率下，它的作用大約強50倍。設定了它（`lfrc`）的關卡需要重新調整：一個受力`(1, 0)`的粒子現在1秒移動0.51個單位，而以前是25.5個

## 編輯器

- `Ctrl+Shift+A`（`取消全選`）一次清除所有選中項：物體、關鍵幀、音訊和節拍。`Ctrl+Shift+E`（`退出預製件模式`）退出所有開啟的預製件模式會話。兩者都可以像其他快捷鍵一樣重新繫結
- 特效選擇器提供`無`選項，因此可以從物體上移除特效。以前一旦選擇了特效，就無法通過選擇器把它去掉
- 在編輯器內開啟另一個關卡會重建物體列表，預製件模式會與開啟它的關卡一起關閉
- 在區域邊緣附近雙擊時間軸片段，不再把物體拖到上一條軌道。以前邊緣滾動在按下時就開始了，檢視在靜止的指標下移動，這次移動就變成了圖層的改變
- [[12_launch-arguments|啟動引數]]`--autosave on|off`在單次啟動中開啟或關閉編輯器的自動儲存，不改動設定
