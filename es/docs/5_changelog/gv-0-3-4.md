# gv 0.3.4

La primera línea de tiempo, el primer inspector y la selección de objetos directamente en la vista

El editor recibió las tres partes en torno a las que hoy se organiza el trabajo con un nivel. Aquí las tres son prototipos tempranos

- **La línea de tiempo.** Muestra los números de fotograma y los objetos del nivel sobre un eje de fotogramas
- **El inspector.** La primera versión de un panel con las propiedades de un objeto
- **La selección.** Un objeto se puede seleccionar en la vista, y la selección se comparte con la jerarquía de objetos

También cambiaron los colores. Un objeto con textura ahora lleva cuatro colores, uno por esquina, y los mezcla en un degradado. Para eso el shader de objetos se reescribió sobre el shader estándar *Unlit* de URP
