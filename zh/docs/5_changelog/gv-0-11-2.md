# gv 0.11.2

层级和时间轴中的折叠变成了三档模式，编辑器在手机上有了完整的音频

- 层级和物体时间轴上的折叠按钮在三档之间切换：全部展开、部分、全部折叠。“部分”会让你选择的物体类型保持展开。按住按钮即可选择它们，也可以在`编辑器` > `界面` > `部分折叠`中设置
- 在关卡编辑器中，音频在所有平台上（包括手机）都会被完整解码。压缩的音轨不绘制波形，定位时会跳到最近的数据块，而不是你想要的那一帧。在手机上的游戏中，音频仍然保持压缩
- 音频轨道上的`适配关卡`会同时延长轨道和关卡，直到片段完整放下。关卡只会变长，已经放得下的片段不会改变任何东西
- 添加其他格式的音频文件时，游戏会说明支持哪些格式：`.mp3`、`.wav`和`.ogg`
- 设置中的一个按钮可以折叠所有分区或全部展开
- 在编辑器中用键盘移动预览化身时，不再每次移动都让画面冻结119毫秒
