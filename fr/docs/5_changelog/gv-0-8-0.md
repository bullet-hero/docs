# gv 0.8.0

La timeline compte les images à partir de 1, et une sélection devient un prefab en une seule action

- Les images se comptent à partir de 1. La première image d'un niveau est l'image 1, elle commence à 0 seconde, et la tête de lecture, l'inspecteur et le fichier du niveau affichent le même nombre. L'image d'une image clé à l'intérieur d'un objet commence elle aussi à 1
- Les niveaux existants n'ont pas été convertis, donc trois choses se sont décalées. Toutes les valeurs aléatoires ont été retirées, car une valeur aléatoire dépend des numéros d'image. Les morts aux checkpoints et le meilleur résultat enregistrés avant cette version se lisent avec une image de décalage. L'historique d'annulation et les enregistrements automatiques écrits avant le changement ne se rejouent pas
- L'affichage de la tête de lecture montre les fractions de seconde en millisecondes (`0:00.983` à l'image 60). Le numéro d'image est juste à côté, et l'ancienne notation semblait le contredire
- `Créer un prefab à partir de la sélection` (`Ctrl+G`) transforme les objets sélectionnés en prefab. La même action se trouve dans le menu d'une ligne de la hiérarchie : `Créer un prefab à partir de celui-ci`
- L'avatar grandit désormais quand il apparaît et se réduit à un point quand il disparaît, au lieu d'apparaître et de disparaître d'un coup
- Les fenêtres fermées coûtaient 4,6 ms à chaque image à l'écran de l'éditeur : l'interface les parcourait quand même. Dix d'entre elles sont désormais entièrement retirées de l'interface tant qu'elles sont fermées
- La superposition des statistiques a reçu un bloc `Afficher le profilage` : combien de temps a pris chaque étape de la simulation
