# 版本1.0.0

正式发布：1.0.0保存的文件在之后的每个版本中都能打开，来自更新版本的文件会提示你更新

## 1.0.0对你意味着什么

- **你的文件会一直可用**。由1.0.0保存的关卡、设置和统计数据，在游戏之后的每个版本中都能打开。文件格式变化时，新版本会在读取旧文件的同时完成转换
- **更新版本的文件会被拒绝，绝不会只读一半**。来自更新版本的关卡或存档会打开`需要更新`窗口，`下载`会带你前往下载页面。游戏不会去猜测它读不懂的内容，因此不会有任何东西丢失或被悄悄改变。更多：[[5_troubleshooting]]
- 游戏和SDK的版本都是1.0.0。SDK仍然跟随游戏一起变化，所以它的代码接口暂时不保证保持不变

## 改动内容

- **旧二进制关卡的不兼容变更**。1.0.0之前的版本以`Blob`保存的关卡无法在1.0.0中打开，因为二进制格式为正式发布重新开始了。以`Json`保存的关卡不受影响。如果你有旧的`Blob`关卡，请先在创建它的那个版本中打开，并另存为`Json`
- 编辑器设置中的`Guidelines`分区已移除。指南现在放在网站上，`社区`中有一个`文档`链接，会以你的语言打开它
- 切换语言时，关卡列表会重写自己的标签。以前来源按钮、排序按钮和关卡单元格都停留在旧语言
- 游戏的所有文本（两种语言）现在都公开在文档仓库中，因此错别字或糟糕的翻译都可以在那里报告或修正：[https://github.com/bullet-hero/docs](https://github.com/bullet-hero/docs)
