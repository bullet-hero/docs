# gv 0.3.1

Редактор научился создавать объекты, отменять это и показывать их в иерархии

Через пять дней после `gv 0.3.0` редактор стал чем-то большим, чем проигрыватель уровня с кнопкой сохранения

- Объекты можно создавать, и для этого работают отмена и повтор
- Иерархия объектов показывает объекты уровня, и оттуда объект можно скрыть
- Уровень можно удалить после подтверждения
- Уведомления и панель консоли сообщают, что редактор только что сделал
- Проигрывание уровня внутри редактора ведёт себя так же, как в игре

Сборку для Android тоже подстроили под телефоны со слабым GPU

Коммиты: игра `393c49d2`, SDK `e2d57751`
