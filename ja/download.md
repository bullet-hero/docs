# ゲーム

現在のバージョン：`gv {{v:version.gv}}`

| 配布形態 | ダウンロード |
|---|---|
| Windowsインストーラー | [`.exe`をダウンロード](https://github.com/bullet-hero/releases/releases/latest/download/bullet-hero-windows-installer.exe) |
| Windowsアーカイブ | [`.zip`をダウンロード](https://github.com/bullet-hero/releases/releases/latest/download/bullet-hero-windows.zip) |
| Androidインストーラー | [`.apk`をダウンロード](https://github.com/bullet-hero/releases/releases/latest/download/bullet-hero-android.apk) |
| Steam（Windows） | [Steamで開く](https://store.steampowered.com/app/4546060/Bullet_Hero/) |
| Google Play（Android） | [[google-play-testing]] |
| itch.io（Windows/Android） | [itch.ioで開く](https://vertoker.itch.io/bullet-hero) |

## SDK

現在のバージョン：`sv {{v:version.sv}}`

コードからゲームを扱いたい場合は、[ソースコードが公開されています](https://github.com/bullet-hero/sdk)。自由に使ってください

| プラットフォーム | ダウンロード |
|---|---|
| GitHub | [`.dll`をダウンロード](https://github.com/bullet-hero/sdk/releases/latest/download/BH.SDK.dll) |
| NuGet | [NuGetで開く](https://www.nuget.org/packages/BulletHero.SDK) |
