# パフォーマンス評価

プレイする前に、レベルがあなたのデバイスでどれだけ重いかをゲームが表示します。緑は快適に動作、黄はぎりぎり、赤は重すぎてフレームレートが落ちることを表します

スコアは数値で、`{{v:performance.score-limit}}` がちょうど目標フレームレートで1フレームにかけられる時間に当たります。区分はスコアで決まります：

| 区分 | スコア |
|---|---|
| `{{ui:level_performance_holds}}` | `{{v:performance.score-warning}}` 未満 |
| `{{ui:level_performance_tight}}` | `{{v:performance.score-warning}}` から `{{v:performance.score-limit}}` まで |
| `{{ui:level_performance_does-not-hold}}` | `{{v:performance.score-limit}}` を超える |
| `{{ui:level_performance_unknown}}` | レベルかデバイスがまだ測定されていない |

スコアはレベルの平均ではなく、最も重い場面の予測です。3分間は軽く、1秒だけ止まるレベルは、その1秒のスコアになります

## どこで見られるか

- レベルブラウザー：各レベルカードの色付きの点と、フィルターの `{{ui:root_level-filters_performance}}` グループ
- メニューのレベルページ：区分とスコア
- レベルエディターのレベルのメタデータ：あなたのデバイスと基準デバイスでのスコア、そしてレベルの最も重い場面のタイムスタンプ

## スコアの2つの半分

**レベルの半分**はエディターでレベルを保存したときに測定され、そのメタデータに保存されます。レベルが何を要求するかを表します：生きているオブジェクトの数、それが画面のどれだけを覆うか、エフェクトとポストプロセスのパスがいくつ動くか。この機能より前に保存されたレベルにはこの記録がなく、もう一度保存されるまで `{{ui:level_performance_unknown}}` と表示されます。エディターはレベルを開いたときにそれを測定し、ゲームを閉じるまで結果を保持しますが、ファイルには書き込みません

**デバイスの半分**は、あなたのデバイスがそれぞれをどれだけ速く処理するかを表します。デバイスを測定するまでは、ゲームはあなたのプラットフォームの基準デバイスを使います。設定も反映されます：レンダースケール、アンチエイリアス、エフェクト、ポストプロセスは、測定し直さなくてもスコアを変えます

## デバイスを測定する

1. メインメニューから `{{ui:settings_common_title}}` → `{{ui:settings_graphics_title}}` → `{{ui:settings_graphics-performance_title}}` を開きます
2. `{{ui:settings_graphics-performance_measure}}` を押します
3. 数分待ちます。設定画面が隠れ、ゲームがテスト用のレベルを再生します。他のアプリに切り替えないでください

終わると、そのセクションにデバイスを制限しているもの（プロセッサーかグラフィックチップ）と、おすすめの `{{ui:settings_quick-setup_performance}}` プリセットが表示されます

測定が不安定だった場合（デバイスが熱くなりすぎた、他のアプリが動いていた）、ゲームはそれを使わずに基準デバイスのままにします。他のアプリを閉じて、もう一度測定してください

## 別のデバイスに移る

測定結果は、測定したデバイスのものです。プロファイルの移行（[[14_profile-transfer]]）とクラウドセーブはそれを運ばないので、新しいデバイスは測定し直すまで基準デバイスから始まります
