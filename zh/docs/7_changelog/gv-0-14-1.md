# 版本0.14.1

手机修复：关卡中屏幕保持常亮，内存清理不再卡住游玩，另有许可证记录修复，演示关卡回归

- 关卡播放时屏幕保持唤醒，暂停后重新遵循系统的息屏时间。以前用一直按住的摇杆操控时会被算作空闲，手机会在关卡中途锁屏
- 关卡进行中收到的内存不足警告，会在关卡停止后再处理。在Android上清理耗时163毫秒和715毫秒，在33秒的游玩中造成了两帧分别为735毫秒和523毫秒的卡顿，每一次都足以让这局失败。代价是：在真正的内存压力下，系统现在可能会在关卡进行中关闭游戏
- 游戏相机只有在移动满一整个像素时才更新视口。以前每帧都会更新，即使关卡的宽高比保持不变，渲染器也会每秒重建60次中间图像
- `许可证`窗口可以折叠：两级标题现在都是折叠栏。关卡自己的资源默认展开，游戏自带的所有内容默认折叠
- 删除资源会同时删除它的许可证记录。以前`许可证`窗口会继续为关卡已经没有的资源注明作者。撤销可以恢复这条记录
- 关卡封面根据图片的实际类型保存为`logo.png`或`logo.jpg`，与源文件的名称无关。既不是PNG也不是JPEG的图片会被拒绝
- 内置关卡`New zero demo`回来了，带有封面，并注明了音乐作者Dunderpatrullen
