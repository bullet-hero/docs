# 版本0.3.0

第一个能当作游戏来玩的版本：菜单、由你操控的化身、从头玩到尾的关卡，以及第一个编辑器界面

此前引擎只能在测试场景中播放关卡。这个版本基于*UI Toolkit*为它搭起了完整的游戏外壳

- **菜单和设置**。主菜单、在两次运行之间保存的设置界面、播放列表和关卡列表
- **游玩关卡**。选择一个关卡，加载，一直玩到结束
- **化身**。玩家在关卡中的形象，由你操控
- **两种语言**。界面提供英文和俄文
- **关卡检查**。SDK可以按一组规则检查关卡，并报告损坏的数据

游戏内编辑器第一次出现。你可以新建关卡，把它保存到文件夹，以选定的速度播放，并查看当前时间。物体层级和检视器还只是初稿

没有0.2版本：版本号从0.1.0直接跳到了0.3.0
