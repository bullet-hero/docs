# gv 0.3.3

빠른 셰이더, 그리고 마우스나 두 손가락으로 움직이는 에디터 카메라

- **레벨 오브젝트용 새 셰이더.** 패스가 하나이고 그리는 데 필요한 것만 담았으며, 이전 셰이더보다 약 두 배 빠르게 동작합니다
