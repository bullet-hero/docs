# Links and community

Talk and questions go to Discord, videos to YouTube, game bugs to the issues of the bullet-hero/releases repository. The source code is in the bullet-hero organization on GitHub

Everything you can download: the game, the SDK, stores - [[download]]

## Social media

| Source | Description |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | talk, questions, feedback, bugs, your levels |
| [YouTube](https://www.youtube.com/@bulletherogame) | trailers and videos about the game |

## Feedback

| Source | Description |
|---|---|
| [Game Issues](https://github.com/bullet-hero/releases/issues) | Errors and bugs in the game (technical only) |
| [SDK Issues](https://github.com/bullet-hero/sdk/issues) | Errors in the SDK |
| [Docs Issues](https://github.com/bullet-hero/docs/issues) | Errors in the text and translations |
| [Discord](https://discord.gg/gkHQrp9NgS) | Questions and discussion, feedback on the game |

More on what to write and where - [[11_help]]

## Source code

All repositories are in the [bullet-hero](https://github.com/bullet-hero) organization

| Repository | Access | What is there |
|---|---|---|
| [bullet-hero/game](https://github.com/bullet-hero/game) | closed | the game and the editor |
| [bullet-hero/sdk](https://github.com/bullet-hero/sdk) | open | the SDK, issues about the SDK and its code |
| [bullet-hero/releases](https://github.com/bullet-hero/releases) | open | game builds, issues from players |
| [bullet-hero/docs](https://github.com/bullet-hero/docs) | open | these docs |
| [bullet-hero/backend](https://github.com/bullet-hero/backend) | open | the server, empty for now |
| [bullet-hero/frontend](https://github.com/bullet-hero/frontend) | closed | the site |
