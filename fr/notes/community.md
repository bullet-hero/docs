# Communauté

Les questions, les retours et tes niveaux vont sur Discord. Tout le monde peut aider le jeu : corriger une erreur dans la documentation, ajouter une traduction, signaler un bug ou faire un niveau

## Où discuter

| Où | Pour quoi |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | questions, retours, bugs, tes niveaux |
| [YouTube](https://www.youtube.com/@bulletherogame) | bandes-annonces et vidéos sur le jeu |
| [GitHub](https://github.com/bullet-hero) | les parties ouvertes : le SDK, cette documentation, les versions publiées |
