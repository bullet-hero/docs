# gv 0.3.4

最初のタイムライン、最初のインスペクター、ビューポートでの直接のオブジェクト選択

エディターに、今のレベル作業の中心となる3つの部分がそろいました。ここではどれも初期のプロトタイプです

- **タイムライン**。フレーム番号と、フレームの軸上に並ぶレベルのオブジェクトを表示します
- **インスペクター**。オブジェクトのプロパティを表示するパネルの最初のバージョン
- **選択**。ビューポートでオブジェクトを選択でき、選択はオブジェクトのヒエラルキーと共有されます

色も変わりました。テクスチャ付きのオブジェクトは角ごとに1色、計4色を持ち、それらをグラデーションで混ぜます。そのために、オブジェクトのシェーダーはURP標準の*Unlit*シェーダーをもとに書き直されました
