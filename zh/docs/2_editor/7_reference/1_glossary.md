# 术语表

项目的主要术语列表。游戏界面、这份文档以及其他所有关于Bullet Hero的文字都使用这些词，新术语要先添加到这里

## 关卡内容

| 术语 | 含义 |
|---|---|
| **关卡** | 一次游玩的全部内容：物体、音频、事件和它自己的资源 |
| **物体** | 时间轴上由作者创建的一个东西，有自己的生命周期、变换和父级 |
| **空物体** | 不绘制任何内容的物体：只有变换、生命周期和子物体。其他类型都在它的基础上添加自己的内容 |
| **形状** | 物体绘制的真实几何体，不是图片。游戏自己生成约500种 |
| **碰撞体** | 物体用来碰撞的部分。它可能与物体绘制的内容不一致 |
| **预制件** | 可复用的物体模板，可以在关卡中放置任意多次 |
| **预制件模式** | 编辑模板自身的内容，而不是它周围的关卡 |
| **特效** | 一种生成源：每帧根据几个参数创建自己的物体 |
| **帧内物体** | 特效生成的物体。它由引擎管理：不能选中或编辑 |
| **主题** | 关卡按索引引用的调色板：重新配色只需改一处，而不是一百处 |

## 时间与动画

| 术语 | 含义 |
|---|---|
| **帧** | 关卡时间的单位。帧是一个格子，时间是两个格子之间的边界 |
| **关键帧** | 某一帧上由作者设定的一个值。两个关键帧之间的值会被插值 |
| **轨道** | 一个可动画属性的一行关键帧：位置、旋转、音量 |
| **时间轴** | 编辑关卡所用的帧轴：每类内容一个标签页 |
| **时段** | 物体存在的时间：起始帧和长度，而不是结束帧 |
| **播放头** | 当前正在显示的帧 |
| **缓动** | 数值从上一个关键帧移动到这一个的方式 |
| **标记** | 关卡标尺上的命名点，用于回到需要的位置 |
| **检查点** | 死亡后玩家被送回的位置 |

## 摆放与绘制

| 术语 | 含义 |
|---|---|
| **锚点** | 跟随父级边缘的边：缩小父级，子物体会随之移动 |
| **图层** | 绘制顺序，并且是相对的：子物体的图层会加上父级的图层 |
| **轴心** | 物体旋转和缩放所围绕的点，位于它自己的框内 |
| **控制柄** | 视口中绘制在选中物体上的拖拽手柄 |
| **吸附** | 把拖拽拉到某个东西上：开启磁铁时吸附到内容，开启节拍开关时吸附到音乐 |

## 音乐

| 术语 | 含义 |
|---|---|
| **节拍** | 音乐自己的网格：由作者设定，游玩时没有任何东西读取它 |
| **节拍段** | 一段恒定速度，有自己的速度、相位和小节长度 |
| **BPM** | 每分钟节拍数，即一个节拍段走得多快 |
| **敲击** | 你敲出速度时的一次按下。足够多次敲击就能描述一个节拍段 |

## 自动化与数据

| 术语 | 含义 |
|---|---|
| **生成器** | 创作自动化：根据几个参数生成关卡内容 |
| **修改器** | 编辑或删除已有内容而不是添加内容的生成器 |
| **种子** | 关卡中所有随机值的来源数字：每次运行都完全相同地重放 |
| **原始数据** | 整个保存模型作为一棵可编辑的树。这里不做任何校验，这是有意的 |

## 资源与分享

| 术语 | 含义 |
|---|---|
| **库** | 设备上供各关卡复用的资源：你的库、你的合集和你订阅的合集 |
| **合集** | 存放最多七类可复用资源的文件夹。导入会从中复制内容，所以关卡不依赖它 |
