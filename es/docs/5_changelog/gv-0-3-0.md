# gv 0.3.0

La primera versión que funciona como juego: un menú, un avatar que controlas, niveles de principio a fin y la primera pantalla del editor

Antes de esto el motor solo podía reproducir un nivel en una escena de prueba. Aquí apareció todo el juego a su alrededor, construido con *UI Toolkit*

- **Menú y configuración.** El menú principal, una pantalla de configuración que se guarda entre sesiones, listas de reproducción y una lista de niveles
- **Jugar un nivel.** Se elige un nivel, se carga y se juega hasta el final
- **El avatar.** La forma propia del jugador dentro del nivel, controlada por ti
- **Dos idiomas.** La interfaz en inglés y en ruso
- **Validación del nivel.** El SDK puede comprobar un nivel con un conjunto de reglas e informar de los datos rotos

El editor integrado apareció en su primera forma. Puede crear un nivel nuevo, guardarlo en una carpeta, reproducirlo a la velocidad elegida y mostrar el tiempo actual. La jerarquía de objetos y el inspector por ahora son solo borradores

No hay `gv 0.2`: la numeración pasó de `gv 0.1.0` directamente a `gv 0.3.0`
