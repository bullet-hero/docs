# gv 1.3.0

成就、自己画的化身皮肤、七种新语言、Steam云，以及每个关卡的难度和性能评级

## 成就

- 主菜单中的`成就`列出了39个成就，其中4个是隐藏成就
- 成就根据你的统计数据计算，所以你已经玩过的内容从第一次启动起就算数。解锁的成就不会再被锁上
- 只有别人的关卡算数，并且只算公平的通关：没有机器人，碰撞开启，速度不低于1.00，生命开启
- 在Steam版本中，成就也会同时在Steam上解锁。在Google Play版本中，登录Google Play游戏后，成就也会在其中解锁

更多：[[15_achievements]]

## 化身皮肤

- 主菜单中的`角色`打开角色中心。可以选择现成的形状，修改它的颜色，开关眼睛、手、影子、拖尾和其他部件
- `编辑器`可以在每边3到8格的格子上画出你自己的化身
- 皮肤是一个文件。`我的皮肤`中的`导出`和`导入`可以移动它，转移档案也会带上你的所有皮肤（`角色皮肤`）
- 皮肤只改变外观。所有皮肤的判定框和速度都一样

更多：[[16_skins]]

## 语言

- 游戏现在支持日语、韩语、西班牙语、法语、德语、巴西葡萄牙语和繁体中文，一共十种语言
- 在`设置`中把语言选为`系统`时，游戏会使用你设备的语言

## Steam云

- 在Steam版本中，设置、统计、成就、关卡、库和皮肤都跟着你的Steam账户走。没有按钮：游戏会在启动时、游戏中和退出时同步
- 图形和操作设置每台电脑各自保留
- `设置` → `其他` → `云存档`会显示同步是否开启，以及上次同步的时间

更多：[[14_profile-transfer]]

## 难度和性能

- 关卡有从`自动`到`奇点`的难度。由作者在`关卡设置`（`难度`）中设定，关卡列表和关卡页面会显示它
- 每个关卡上的五格条显示它对你的设备有多重。关卡列表中的`在此设备上的性能`可以按它筛选
- 在这个版本之前保存的关卡会显示`未测量`，直到作者再次保存
- `设置` → `图形` → `设备性能` → `测量此设备`会运行最长60秒的压力测试。在此之前，评级按一台典型设备计算

更多：[[2_playing-levels]]，[[17_performance-rating]]

## Android上的更新

- 在Google Play和RuStore版本中，更新会在后台下载。准备好后，主菜单会显示`更新已就绪`，点`重新启动`即可安装
- 通关一个关卡后，游戏可能会请你评分，最早在你第三次通关之后，并且60天内最多一次

更多：[[1_installation]]

## 编辑器中的AI助手

- 在电脑上，支持MCP的AI助手可以在你看着的时候编辑打开的关卡。在你打开`设置` → `编辑器` → `AI 代理（MCP）`中的`允许 AI 连接`之前，它一直是关闭的
- 只有这台电脑可以连接。AI的每一批修改都是历史中的一步，AI不能发布、删除或覆盖任何东西
- AI把它的笔记保存在关卡的`ai`文件夹中。除非取消勾选`随关卡共享AI上下文`，这个文件夹会随导出和创意工坊上传一起带走，但永远不会进入带密码的导出

更多：[[7_ai-assistant]]

## 修复和其他

- Windows、macOS和Linux的免费版本附带`unins000`。它会删除游戏自己的文件，保留你的关卡、设置和统计
- 安装后游戏进入菜单更快了，在一台测试手机上快了约2秒
- 发布时会检查关卡的许可证与其音乐的许可证是否兼容
- 编辑器中被拒绝的修改不会再在历史中留下损坏的一步，检查器中关键帧的`帧`字段现在会移动关键帧
