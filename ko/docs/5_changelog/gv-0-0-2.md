# gv 0.0.2

텍스처, 부모, 파티클, 텍스트, 포스트 프로세싱 효과를 테스트 씬에서 하나씩 시험했습니다

이 버전은 실험의 모음입니다. 레벨에 필요할 기능마다 전용 테스트가 만들어졌고, 대부분이 남았습니다

- 오브젝트에 텍스처가 생겼습니다
- 오브젝트가 부모를 가질 수 있으며, 부모와 함께 움직입니다
- 파티클 이펙트와 텍스트가 추가되었습니다(당시에는 *TextMeshPro* 사용)
- 화면 포스트 프로세싱 효과

모든 것을 Android 스마트폰에서 측정했습니다. 당시 메모에 따르면 30 fps에서 약 1500개의 오브젝트를 유지했습니다. 2D 그림자도 시험했지만 채택하지 않았습니다
