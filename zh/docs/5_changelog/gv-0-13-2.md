# gv 0.13.2

修复物体起点之前的帧、关卡文本的预热、时间轴上的未激活物体，以及编辑器窗口中的Escape键

- 起点被锚定的物体会早于作者设定的起点开始播放，在这些帧上它现在保持自己的第一个关键帧。以前帧计算在这里会报错，可能让整帧都无法构建，在正式版构建中还可能导致游戏关闭
- 关卡文本重新在关卡开始之前准备好。文本库更新后，预热悄无声息地失效了，每个字母都在它第一次出现的那一帧才进入字体图集
- Level和Prefab时间轴把关卡不绘制的物体显示为褪色的灰色片段。这既包括关闭了激活复选框的物体，也包括父级关闭了该复选框的物体。预制件片段保留一丝紫色，所以两种状态都能分辨
- `Escape`像点击背景一样关闭22个编辑器窗口，其中包括未保存的更改、搜索面板、备份、生成器、关卡密码和资源编辑器
- 关卡校验不再报告位于关卡结尾之后的关键帧或物体，它的修复也不再把它们压到最后一帧。结尾之后的内容是允许的：关卡一变长，它就会开始播放。早于第一帧的帧仍然算作问题
