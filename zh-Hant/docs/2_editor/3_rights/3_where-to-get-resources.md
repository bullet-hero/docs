# 去哪裡找資源

預設安全的來源：音樂來自ccMixter、Freesound和Kenney，圖片來自Poly Haven、Pexels和Unsplash，字型來自Google Fonts。不能從YouTube、SoundCloud和Spotify獲取

## 不能從哪裡獲取

> [!caution] 注意
> YouTube、SoundCloud和Spotify在名單中標為**禁止**。它們不是任何形式的許可證：它們不向任何人發放任何東西。如果作品只在那裡釋出，誠實的記錄是“條款未知”。唯一的出路是[[2_legal-resource-paths|作者的許可]]

## 音訊

**預設安全**：
- [ccMixter](https://ccmixter.org/)：CC BY、CC BY-NC
- [Freesound](https://freesound.org/)：CC0、CC BY、CC BY-NC
- [Incompetech](https://incompetech.com/)：CC BY
- [Teknoaxe](https://teknoaxe.com/)：CC BY
- [Kenney](https://kenney.nl/)：CC0

**每條記錄都值得看一眼**：
- [SoundImage](https://soundimage.org/)
- [Pixabay](https://pixabay.com)
- [GoodKid](https://goodkidofficial.com/creators/)：形式上沒有宣告任何許可，但他們的FAQ相當於不強制署名的CC BY
- NCS：僅限關卡保持標準的`CC BY-NC`時

**先讀條款**：[OpenGameArt](https://opengameart.org/)、[Free Music Archive](https://freemusicarchive.org/home)、SoundBible

**存疑**：
- Zapsplat
- [Play On Loop](https://www.playonloop.com/music-licensing/)：僅限遊戲不是商業專案時。目前它不是商業專案

## 圖片和字型

**圖片，預設安全**：[Poly Haven](https://polyhaven.com/)、[AmbientCG](https://ambientcg.com/)、[Kenney](https://kenney.nl/)、[Pexels](https://www.pexels.com/)、[Unsplash](https://unsplash.com/)

**圖片，每條記錄都值得看一眼**：[Pixabay](https://pixabay.com)

**圖片，先讀條款**：[OpenGameArt](https://opengameart.org/)、[Rawpixel](https://www.rawpixel.com/)（僅限其Personal和Public Domain）、itch.io、Wikimedia Commons

**字型**：[Google Fonts](https://fonts.google.com/)

## 不在名單中的網站

> [!warning] 警告
> 網站不在列表中並不等於允許。它的意思是對這個網站一無所知

名單本身只是一個起點。每個服務的運營方都可以替換它

## 等級

每個已知網站都有一個等級：

| 等級 | 含義 |
|---|---|
| **已批准** | 那裡的一切都可以釋出，不需要逐個資源檢查 |
| **部分批准** | 網站上的條款不止一種，值得看一眼記錄 |
| **需要檢查許可證** | 那裡可能出現任何許可證，每次上傳單獨註明 |
| **需要檢查資源** | 條款取決於作品本身，或上傳者選擇的方案 |
| **禁止** | 這裡的任何東西都不行，無論記錄中寫了什麼 |

許可證欄位說明作者聲稱了什麼。網站說明這個聲稱有多可信。兩者結合，稽核成本就很低

## 如何識別網站

網站按你填寫的連結中的主機名識別，包括子域名。沒有協議（沒有`https://`）的地址也能識別

YouTube、SoundCloud和Spotify在名單中被直接列出，而不是簡單地省略。這樣，帶有這類連結的關卡在你貼上連結的那一刻就會被拒絕。不在名單中的網站只會得到“需要有人看一下”。對於關卡無法釋出最常見的原因來說，這太寬鬆了
