# gv 0.3.1

El editor aprendió a crear objetos, a deshacerlo y a mostrarlos en la jerarquía

Cinco días después de `gv 0.3.0` el editor dejó de ser solo un reproductor de niveles con un botón de guardar

- Se pueden crear objetos, y deshacer y rehacer funcionan con ello
- La jerarquía de objetos muestra los objetos del nivel, y desde ahí se puede ocultar un objeto
- Un nivel se puede eliminar tras una confirmación
- Las notificaciones y un panel de consola informan de lo que el editor acaba de hacer
- Jugar un nivel dentro del editor se comporta igual que en el juego

La compilación de Android también se ajustó para teléfonos con una GPU débil

Commits: juego `393c49d2`, SDK `e2d57751`
