# 版本0.6.1

音量滑块旁的静音按钮，记住窗口大小，错误窗口开关，并修复了调整窗口大小后画面被框在中间的问题

- 音频设置中的三个音量滑块都有静音按钮。取消静音会恢复之前的音量，只要游戏还在运行。静音就是把音量设为0，所以静音状态下关闭游戏，下次打开时仍是静音
- 手动调整过的窗口会保持其大小。以前，下一次修改任何设置都会让窗口恢复旧的大小
- 界面设置的`错误`分区中新增`异常时提醒`。开启时，未捕获的错误会在当前画面之上打开报告窗口。关闭时，错误只写入日志，而报告无论如何都会生成
- 单击时间轴上的关键帧会直接打开它的检视器标签页
- 修复：调整窗口大小后，要求不显示侧边黑边的关卡可能会把画面框在窗口中间显示
