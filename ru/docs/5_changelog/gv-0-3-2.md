# gv 0.3.2

Небольшой выпуск для телефонов: вдвое больше объектов на экране одновременно

Предел объектов, которые рисуются за один кадр, вырос с 512 до 1024. На телефоне около 1000 объектов одновременно - пока потолок: больше не удаётся выделить в памяти или нарисовать достаточно быстро на слабом GPU

Фигуры также собрали в один атлас текстур, а для замера предела добавили сцену стресс-теста

Коммиты: игра `223d907c`, SDK `d3af9547`
