# Версия 0.6.2

Сплющивание префабов, аргумент запуска для настроек и исправления полноэкранного режима и размера окна

- `Сплющить префаб` превращает размещение префаба в обычные объекты: связь с шаблоном пропадает, а объекты остаются точно на своих местах. Это кнопка в инспекторе префаба и команда редактора, а модификатор `Сплющивание префабов` делает то же самое для всех размещений в области. Уровень после этого выглядит так же, потому что переопределения каждого размещения уже записаны в объекты
- `--settings` открывает меню с настройками поверх него, а `--settings graphics` (или другое имя вкладки) открывает конкретную вкладку
- Исправлено: полноэкранный режим мог показывать размытую картинку 640x480 с полосами, и выход с повторным входом её не исправлял. Теперь полноэкранный режим всегда использует собственное разрешение экрана, а для меньшего разрешения отрисовки есть `Масштаб рендера`
- Исправлено: один выход из полноэкранного режима заставлял игру запомнить размер окна как размер всего экрана
- Исправлено: клик по ключу на таймлайне не всегда открывал его вкладку в инспекторе
