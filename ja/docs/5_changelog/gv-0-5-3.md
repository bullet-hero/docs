# gv 0.5.3

全画面のビートウィンドウ、スワイプで開閉して広げられるパネル、インスペクターの全フィールドのリセットボタン、古いバックアップと統計の整理

- ビートウィンドウは`ビートウィンドウを開く`ボタンで全画面で開きます。タッパーが1つと、2つの結果が並んでいます：`タップから作成`は新しいビートセグメントを作り、`選択に適用`は選択中のセグメントのテンポを計算し直します。録音は適用する前に聞き直せ、ウィンドウを開いている間もレベルは再生され続けます
- エディター設定の`時間フォーマット`で、タイムラインのルーラーの単位を選べます：フレーム、タイムコード、フレーム付きタイムコード、`小節とビート`。レベル自体は変わりません
- エディターのパネルはハンドルをスワイプして開閉でき、開いたパネルは横に広げられます。スマートフォンではボタンが大きくなりました
- インスペクターのすべてのフィールドに、ヒント付きの`?`とリセットボタンがあり、すべてのグループの見出しにも同じ組があります。グループのリセットは元に戻す1ステップ分です
- `コライダーをシェイプに連動`：オンの間は、シェイプを選ぶと対応するコライダーも設定され、当たり判定がシルエットに沿います
- レベルを開かずにレベル一覧から削除できます。`レベルの削除`ウィンドウはどこでも同じです
- 設定の`ストレージ`は、もう存在しないレベルのバックアップと統計、またはそのすべてを削除します
- ビューポートのグリッドは、ズームするとセルのサイズがちょうど10倍ずつ変わります。Unity自体のシーングリッドと同じです
- タイムラインは、クリップごとに別々のインターフェース要素を使う代わりに、ほとんどのクリップを1つのメッシュで描画します。長いレベルではそのほうが軽くなります
- エフェクトとオーディオエフェクトのフィールドに説明が付きました
