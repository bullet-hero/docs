# コミュニティ

質問、フィードバック、自作のレベルはDiscordへ。ドキュメントの間違いの修正、翻訳の追加、バグの報告、レベル作りなど、誰でもゲームに協力できます

## 話す場所

| 場所 | 用途 |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | 質問、フィードバック、バグ、自作のレベル |
| [YouTube](https://www.youtube.com/@bulletherogame) | トレーラーとゲームの動画 |
| [GitHub](https://github.com/bullet-hero) | オープンな部分：SDK、このドキュメント、リリース |

プロジェクトのすべてのリンク：[[links]]

## 協力する方法

まず書き込む場所を選んでください

| 内容 | 場所 |
|---|---|
| ゲームのビルド、ゲームのバグと要望 | [bullet-hero/releases](https://github.com/bullet-hero/releases) |
| SDK、そのコードとバグ | [bullet-hero/sdk](https://github.com/bullet-hero/sdk) |
| これらのページのテキストと翻訳 | [bullet-hero/docs](https://github.com/bullet-hero/docs) |
| 質問と議論 | [Discord](https://discord.gg/gkHQrp9NgS) |
