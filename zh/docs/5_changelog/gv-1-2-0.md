# gv 1.2.0

从编辑器导出视频、用一个文件转移档案、关卡列表的筛选，以及在Discord中显示你的动态

## 导出视频

- 关卡设置侧栏中的`导出视频`会把关卡渲染成视频。命令面板中也有同样的命令
- 电脑上需要安装`7.0`或更新版本的ffmpeg，窗口会自己找到它。支持Windows、macOS和Linux，手机上不可用
- 画面逐帧渲染，所以无论电脑多慢，视频都是精确的
- 支持MP4、MKV、MOV、WebM、GIF、WebP、APNG、图片序列或只导出声音。分辨率从720p到2160p，或最大7680的任意尺寸，每秒1到240帧
- 由机器人游玩关卡（`由谁游玩`），网格、控制柄和选中框永远不会出现在画面中

更多：[[18_video-export]]

## 转移档案

- `设置` → `其他` → `转移档案`会把你的档案打包成一个zip文件：关卡、统计数据、设置和库。自动保存、错误报告和录像在勾选后也会打包进去
- `导入`可以替换现有内容（`替换`），也可以添加到现有内容中（`合并`）。合并时保留关卡较新的副本和统计数据中较大的数值
- 导入替换掉的内容会保留为一份备份，`恢复`可以把它找回来
- 支持Windows、macOS、Linux和Android。iOS上不可用

更多：[[14_profile-transfer]]

## 关卡列表

- `筛选`会打开一个包含更多筛选条件的窗口：AI内容、长度、进度、最近游玩、年龄分级、带密码或来自更新版本的关卡，以及必须包含或排除的标签
- `反向排序`会把排序反过来
- 搜索先看关卡名称，然后是作者，最后是标签

更多：[[2_playing-levels]]

## Discord

- Steam版会在你的Discord个人资料中显示你正在游戏中做什么：菜单、编辑器、沙盒或某个关卡
- 只有公开的关卡才会显示名称：Steam创意工坊物品或游戏自带的关卡。你自己的关卡和正在编辑的关卡永远不会显示名称
- 只有当Discord应用在同一台电脑上运行时才有效。可以在Discord中隐藏你的动态

更多：[[game-privacy-policy#Discord Rich Presence]]

## 修复

- 在设置中关闭声音后，关卡现在真的会静音。以前它只会让其他声音设置变灰
- 关闭游戏前刚改的设置不会再丢失。每次写入设置时都会出现保存图标
- 设置打开时，`Ctrl+S`会保存设置（`保存设置`）。在编辑器中它仍然保存关卡
- 手机上的设置行不会再自己跳回第一个选项
- 某些特效可能会从画面上消失，现在不会了
