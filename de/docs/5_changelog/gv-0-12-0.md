# gv 0.12.0

Kurven mit Tangenten, Zufallswerte entlang einer Linie, Namen für Theme-Slots und eine lange Liste von Korrekturen für die Zeitleisten und den Prefab-Modus

## Spiel

- Der Avatar wird vor Ebene 0 gezeichnet statt dahinter. Inhalt auf der Ebene, auf der ein neues Objekt erstellt wird, liegt jetzt hinter dem Spieler, und um den Spieler zu verdecken, kommt Inhalt auf Ebene 1

## Editor

- Eine Kurve wird mit Tangenten bearbeitet, nicht nur über die Position ihrer Punkte. Der ausgewählte Keyframe bekommt auf jeder Seite einen Griff, `Getrennte Tangenten` macht daraus eine Ecke, und mit `Gewichtete Tangenten` ist die Länge eines Griffs sein Gewicht. Die Vorschaulinie berücksichtigt die Gewichte ebenfalls und zeigt die Kurve, die tatsächlich abgespielt wird
- `Q W E R T` schalten die fünf Zeitleisten des unteren Bereichs von links nach rechts um: Level, lokal, Audio, Ereignisse, Prefab. Deshalb hat `Tap-Tempo` seine Taste `T` verloren. Das Tempo wird im Fenster `Beat-Raster` (`Shift+T`) eingetippt, und eine Taste für `Tap-Tempo` lässt sich unter `Tastenbelegung` zuweisen
- Der Prefab-Modus wählt genauso aus wie der Rest des Editors: Ctrl-Klick fügt einen Clip hinzu, der Prefab-Tab hat das Werkzeug `Rechteckauswahl`, und viele Objekte werden in einem Inspector bearbeitet und in einem Rückgängig-Schritt gelöscht oder kopiert. Vorher wählte er ein Objekt nach dem anderen aus
- Ein Objekt entlang einer Zeitleiste zu ziehen zieht seine Kinder mit, so behält die Hierarchie ihr Timing. Ein Rückgängig bringt den ganzen Teilbaum zurück
- Jeder Tab der Zeitleiste merkt sich sein eigenes Werkzeug. `Werkzeug bei Tabwechsel zurücksetzen` unter `Editor` > `Zeitleiste` entscheidet, ob ein Tab zu `Auswahl` zurückkehrt, und ist standardmäßig an
- `Editor-Wiedergabe` in den Audioeinstellungen ist eine eigene Lautstärke für die Wiedergabe im Editor, so bleibt die Lautstärke des Spiels selbst, wie sie war
- Das Autospeichern speichert das Level selbst, nicht nur eine Kopie in `backups/`. Vorher machte es nur die Kopie, und ein Abend voller Änderungen landete in `backups/` und nicht in dem Level, das der Browser zeigt
- Nach einem Testlauf kehrt der Editor in seinen vorherigen Zustand zurück: Der Kamerarahmen, die Auswahl und die Gizmo-Griffe funktionieren, der Vorschau-Spieler steht an seinem Platz, wenn er da war, und Abspielkopf und Geschwindigkeit zeigen dasselbe wie vor Play
- Ein Klick auf die letzte Zelle der lokalen Zeitleiste setzt bei einem Objekt von 60 Frames einen Keyframe auf Frame 60, nicht auf 59

## Levels und Format

- Ein Theme-Slot kann einen Namen haben. Ein Farbfeld, das auf Slot 12 verweist, zeigt `12 - background` statt `12`
- Ein zufälliger Vektor oder eine zufällige Farbe kann auf einer Linie liegen statt in einem Rechteck: `Zuf. A bis B` würfelt eine Zahl, und der Wert wandert auf einer Geraden von `Von` nach `Bis`. Eine zufällige Tönung wirkt dann wie eine Tönung, und eine zufällige Drift wie eine Richtung. Gib einer Achse an beiden Enden dieselbe Zahl, damit sie still bleibt
- Eine Bildressource hat ihre eigene Kachelung und ihren eigenen Versatz (`Kachelung X`, `Kachelung Y`, `Versatz X` und `Versatz Y` im Block `Importieren`). Jedes Objekt mit diesem Bild, das keine eigenen UV-Keyframes hat, übernimmt sie, so wird ein Spritesheet einmal beschrieben
