# gv 0.1.0

第一個關卡格式，以及第一個能播放它的引擎：物體、主題、特效、文本、音訊和碰撞

六週時間裡，實驗變成了遊戲中兩個真正的部分。螢幕上還沒有選單和編輯器，但關卡已經可以寫在檔案裡並播放出來

**關卡格式**。關卡是一個由SDK描述的`JSON`檔案。它已經包含物體、父級、主題（調色盤）、特效、音訊和預製件

**播放關卡的引擎**。每一幀先由並行任務構建，再進行繪製：

- 位置、旋轉、縮放和父級
- 取自關卡主題的顏色，以及紋理
- 關卡的相機
- 通過一個共用的*VFX Graph*特效實現的粒子特效
- 關卡的音樂
- 通過*UniText*實現的文本，它取代了*TextMeshPro*
- 碰撞檢測，這是日後讓物體擊中玩家的基礎
- 放置到關卡中的預製件

專案也在這個版本遷移到了Unity 6.4
