# gv 0.6.3

Fuera de un nivel el teléfono gira libremente de forma predeterminada, y más pantallas tienen diseño vertical

- `Orientación de pantalla` ahora es `Giro automático` de forma predeterminada: el menú y la configuración giran con el teléfono. Un nivel en curso sigue manteniendo el eje que declara (horizontal de forma predeterminada), y el editor no obedece a ninguna de estas opciones
- Los controles, la asignación de teclas, las estadísticas, el perfil, las ayudas y la ventana de entrada de valores recibieron un diseño vertical y se leen bien en un teléfono en vertical
