# ボットはレベルをどうプレイするか

ボットはプレイヤーと同じ操作でレベルをプレイし、難しさではなく読みやすさをチェックします。レベルをクリアできることは保証しません

ボットは飛んでくるものを見て、空いている場所を探し、プレイヤーと同じキャラクターを動かします。歩き、ダッシュし、ダメージを受け、死亡します

ボットは、レベルを始める前にライフや速度と並んで選びます

## エディターでのボット

エディターでは、ボットがプレビュープレイヤーを操作します：
1. `{{ui:settings_common_title}}` → `{{ui:hint_settings_game-editor_header}}` → `{{ui:settings_game-editor_player_title}}`を開きます
2. `{{ui:settings_game-editor-player_bot}}`にチェックを入れます
3. ツールバーでプレビュープレイヤーをオンにします

プレビュープレイヤーではボットを選べず、常に`{{ui:enum_bot-kind_reflex}}`です。事前に何も準備しなくてよいのは、このボットだけです。レベルを編集している間も、どの再生速度でも（逆再生を含む）動作し続けます

スクラブした直後は、ボットのプレイが一時的に悪くなります：この先に何があるかを学び直しているためです

ギズモのハンドルをドラッグしている間やテキストフィールドに入力している間は、プレビュープレイヤーは操作を受け付けません

同じ設定にある`{{ui:settings_game-editor-player_bot-debug}}`は、レベルの上に描画します。デフォルトではオフで、3つの要素はオンになっているので、オンにするとすぐに全体像が見えます：
- `{{ui:settings_game-editor-player_bot-debug-grid}}`：画面の各部分にどれだけ空いている場所があるとボットが考えているか。赤は被弾を予想している場所で、余裕が増えるほど色が薄くなります。安全だと考えている場所には何も描画されません
- `{{ui:settings_game-editor-player_bot-debug-target}}`：ボットが向かっている点。目標が動かないのは、ボットが満足しているということで、行き詰まっているわけではありません
- `{{ui:settings_game-editor-player_bot-debug-reach}}`：どこまで届くと予想しているか。内側の円は歩いて、外側の円はダッシュで届く範囲です。この外にある目標を選ぶことはありません

描画されるのは`{{ui:enum_bot-kind_reflex}}`だけです。画面が静止する一時停止中にオンにしてください

**任意のボットでの通しプレイ**。レベル設定の`{{ui:settings_level-settings_play}}`タブには、メニューのレベル画面と同じ`{{ui:settings_level-settings_bot}}`リストがあります：`{{ui:enum_bot-kind_none}}`、`{{ui:enum_bot-kind_reflex}}`、`{{ui:enum_bot-kind_warm}}`。これはプレビュープレイヤーではなく、レベルの実際のプレイを開始します

## 結果の読み方

ボットがチェックするのは、難しさではなく読みやすさです：
- 自分には難しいセクションを、ボットは落ち着いて通過する。その場合、セクションは読みやすく、足りないのは練習です
- ボットが同じ場所で何度も被弾する。その場所を見てください：たいていは逃げる余地のない危険物です。人間がそれをもっとうまく読めることはありません

## ボットが約束すること、しないこと

**ボットはクリアを保証しません**。疲れないプレイヤーであって、負けないプレイヤーではありません。あるセクションで、パターンの1秒前に正しく入る必要があるなら、ボットは被弾します。これはバグではありません

> [!info] 補足
> ボットは不正ができません。そのように作られています。プレイヤーと同じ操作を持ち、それ以上は何もありません：同じ速度、同じダッシュ、同じ当たり判定、同じダメージ。プレイヤーが通れない場所は、ボットも通れません

**ボットはデバイスに負荷をかけます**。毎フレーム、空いている場所を探すためです。性能の低いデバイスでは、フレーム落ちを覚悟してください。重いレベルでは、最初の数秒が最も重くなります

## ボットに勝ったレベル

ボットが上達するのは、まだ見たことのないレベルだけです。ボットがすでにクリアできるレベルからは、何も学びません
