# gv 0.9.0

生命值和真正的判定框直接显示在化身上，来自更新版本的关卡会在警告后打开

- 化身的身体是由方块组成的网格，损失生命值会把方块从边缘向中心逐个打掉。失败的一局直接显示在玩家身上，而不是在一条进度条上。图形设置中的`碎裂效果`可以关闭这一效果：身体变成一个方块，改为逐渐变暗
- 化身上的一圈圆点正好位于它的判定框上：身体宽1个单位，半径为0.4。轮廓从来都不是判定框，现在可以看到它真正的位置。这一圈圆点也用来计算生命：亮的圆点是你还剩下的生命，暗的是已经用掉的
- 界面设置中的`判定框圆环不透明度`决定圆环有多显眼，默认值为0.6。0会把它关闭，但关卡是按能看到它的玩家设计的
- 检查点新增`恢复生命值`设置：关卡经过检查点的那一刻，检查点会补满你的生命
- 用更新版本制作的关卡在关卡浏览器中标为`版本较新`，在警告后打开。如果读取时有内容不得不被替换，游戏会先写入一份备份，并报告替换了多少处
- 关闭`循环`的特效发射的粒子比开启时少得多，看起来像是颜色渐变失效了。现在一次性特效发射的粒子数量与循环特效保持存活的数量相同
