# Version 0.6.2

Prefab flattening, a launch argument for the settings, and fixes for full screen and the window size

- `Flatten Prefab` turns a prefab placement into ordinary objects: the link to the template goes, and the objects stay exactly where they are. It is a button in the prefab inspector and an editor command, and the `Prefab Flatten` modifier does the same for every placement in a scope. The level looks identical afterwards, because per-placement overrides are already written onto the objects
- `--settings` opens the menu with the settings on top, and `--settings graphics` (or another tab name) opens a specific tab
- Fixed: full screen could show a blurry letterboxed 640x480 picture that leaving and re-entering did not clear. Full screen always uses the display's own resolution now, and a lower render resolution is what `Render Scale` is for
- Fixed: leaving full screen once made the game remember the window as the size of the whole display
- Fixed: clicking a key on a timeline did not always open its inspector tab
