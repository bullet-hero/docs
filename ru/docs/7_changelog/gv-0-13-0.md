# Версия 0.13.0

Корень префаба стал выбираемым, автосохранение замораживает редактор вдвое короче, а карточка уровня называет автора музыки

- Корень шаблона префаба можно выбрать. Щёлкните его строку на таймлайне префаба, и его ключи правятся как у любого другого объекта. Открытие размещения попадает на корень, а при его выборе воспроизведение зацикливается на собственной длине шаблона
- Автосохранение замораживает редактор вдвое короче: 133 мс вместо 265 мс на уровне в 12.3 МБ. Раньше оно копировало весь уровень дважды, один раз для резервной копии и один раз для сохранения
- Уборка после сохранения больше не идёт в главном потоке. Удаление устаревшего файла другого формата и ротация резервных копий раньше выполнялись посреди кадра, четыре раза за каждое автосохранение
- Карточка уровня называет автора музыки отдельной строкой под авторами уровня. Какой ресурс назвать, задаёт флажок `Показывать на карточке уровня` у самого ресурса. Уровень ровно с одним аудиоресурсом получает эту строку без всяких флажков
- Таймлайн больше не рисует клип, полностью закрытый другим клипом на той же полосе. Более широкий клип лежит под более узким, а выделенный или перетаскиваемый клип - поверх всей полосы. Клип, который не нарисован, всё равно можно выбрать щелчком
- Таймлайн освобождает свои элементы, как только его скрывают. Свёрнутый уровень и невыбранная вкладка раньше стоили каждый кадр столько же, сколько в открытом виде
