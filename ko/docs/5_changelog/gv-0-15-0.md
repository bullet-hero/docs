# gv 0.15.0

화면 제한이 애니메이션되는 레벨이 Android에서 프레임당 30-45 ms 대신 19 ms만 씁니다

- `화면 제한` 이벤트로 화면 비율을 애니메이션하는 레벨이 Android에서 프레임당 30-45 ms 대신 19 ms만 씁니다. 이제 카메라가 항상 화면 전체를 차지하고, 프레임을 화면에 내보낼 때 바가 추가됩니다. 그래서 바가 움직이는 프레임마다 렌더러가 이미지를 다시 만들지 않습니다
- 마우스와 터치도 같은 바를 읽으므로, 바가 있는 레벨에서도 포인터가 가리키는 곳에 정확히 닿습니다

커밋: 게임 `9f5d9143`, SDK `57b5af5b`
