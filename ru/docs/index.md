## Версии

У каждого продукта своя версия с буквенным префиксом, каждая в виде major.minor.revision:

| Префикс | Расшифровка | Продукт |
|---|---|---|
| `gv` | `game version` | игра (клиент) |
| `sv` | `sdk version` | SDK |
| `fv` | `frontend version` | сайт |
| `bv` | `backend version` | бэкенд, сервер |

Номера версий не обязаны друг за другом следовать, но в большинстве случаев они совпадают.
Также бамп версии происходит одновременно и общее обновление имеет одинаковую версию

Также существует отдельная версия уровней `mg` (`model generation`). Это обычное число в каждом сохранении, что описывает версию данных.
Оно значительно важнее всех остальных, используется повсеместно для обновления и поддержки. Подробнее в [[5_versioning]]
