# Welcome

This is a placeholder note. Replace it with real writing — the site reads whatever
markdown lives under `content/`.

Notes are the catch-all section: essays, public documents, policies, loose thoughts.
Anything that is not step-by-step documentation belongs here.

## How linking works

Write an Obsidian link like [[cookie-policy]] and it resolves on the site exactly as it
does in the vault. Links are language-agnostic: the same `[[cookie-policy]]` sends an
English reader to the English page and a Russian reader to the Russian one.

A link to something that does not exist yet, like [[not-written-yet]], still renders —
it is marked as missing and reported as a build warning.

See also [[markdown-kitchen-sink]] for everything the renderer supports.
