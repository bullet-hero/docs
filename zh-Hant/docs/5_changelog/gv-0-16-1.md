# gv 0.16.1

化身的行走速度從每秒10個單位提高到15個單位，最短的衝刺等於一個化身身體的長度

- 行走速度為每秒15個單位，而不是10個。化身從螢幕頂部走到底部只需三分之二秒，而不是一秒。用游標操控時，化身以行走速度追趕指標，所以急速移動後的滯後縮短了三分之一。速度為10時，在需要精確的地方會感覺很慢
- 衝刺和擊退仍為每秒50個單位，所以兩者現在是行走速度的3.3倍，而不是5倍
- 最短的衝刺是一個化身身體，0.5個單位。比這更近的目標完全不會觸發衝刺。沒有這個門檻時，緊貼化身的游標每隔一幀就會觸發一次衝刺，每次都有自己的軌跡、音效和統計記錄

化身的所有數值都集中在一個頁面上：[[6_avatar]]
