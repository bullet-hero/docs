# 游玩关卡

如何找到关卡、添加别人的关卡、开始一局，以及如何看懂结果窗口

## 主菜单

| 按钮 | 作用 |
|---|---|
| `关卡` | 关卡列表，见下文 |
| `编辑器` | 关卡编辑器，[[2_editor/1_basics/index]] |
| `设置` | 所有设置，[[4_settings]] |
| `剧情` | 暂时还不能用 |
| `多人游戏` | 暂时还不能用 |

## 关卡列表

主菜单中的`关卡`会打开关卡列表。关卡有三个来源：

- `我的关卡`：`levels`文件夹，[[1_installation]]
- `内置`：游戏自带的关卡
- `创意工坊`：仅限Steam版本，列出你订阅的关卡。你订阅的资源合集不是关卡，它们出现在编辑器的“库”中，[[16_library-and-collections]]

顶部有搜索框、`排序`和`视图`（网格或列表）。可以按`最佳匹配`、`名称`、`时长`、`进度`和`最近`排序

把关卡复制进了文件夹？按`重新扫描`，列表就会更新

卡片上有锁，表示这个关卡受密码保护

长按或右键点击卡片会打开菜单：`打开`和`删除`

## 添加别人的关卡

关卡就是一个普通的文件夹。你可以把它压缩后发给朋友

**文件夹**。把关卡文件夹复制到`levels`，然后按`重新扫描`。要复制的是关卡文件夹本身：里面有`level.json`（或`level.blob`）和`metadata.json`的那个文件夹

**归档包**。打开编辑器，用`关卡归档包`生成器创建一个新关卡。然后用`选择关卡归档包……`选择文件

| 文件 | 结果 |
|---|---|
| `.zip`、`.tar.gz` | 可以打开 |
| 自带密码的`.zip`、`.zip.gpg`、`.tar.gz.gpg` | 出现`受保护，输入密码后再按一次`后可以打开 |
| `.7z` | 暂时不支持，请重新打包为zip |
| 其他任何文件 | 拒绝，[[5_troubleshooting]] |

改过扩展名的归档包照样能打开：游戏根据文件的字节判断格式。旧版本游戏的归档包会在导入时更新

默认情况下，导入的关卡会获得自己的新ID。所以它不会覆盖你设备上已有的关卡

更多：[[6_sharing-by-hand]]。*Afterbeat*的关卡：[[3_afterbeat-import]]

## 关卡界面

关卡界面显示封面、作者、简介和音乐署名。界面上还有`作者`和`许可证`按钮

年龄分级由关卡作者自行声明，不经过检查

当作者声明关卡本身、其封面或其中某个资源由 AI 生成时，会显示“含有 AI 生成的内容”。这同样是作者自己的声明。没有这一行并不代表“没有 AI”：作者可能只是没有说明

开始之前你可以选择条件：

| 选项 | 可选值 |
|---|---|
| `生命` | `禅`（这一局永远不会结束）、`一条命`、`三条命`、`自定义`（滑块，最多16） |
| `速度` | `0.5`、`1.0`、`2.0`、`自定义`（滑块，最多2）。关卡和音乐会一起变速 |
| `检查点` | 开或关，[[7_damage]] |
| `无碰撞` | 开或关。化身会穿过一切，[[7_damage]] |
| `机器人` | `无机器人`、`Reflex Bot v1`、`Warm Bot v1`，[[9_bots]] |
| `玩家种子` | 一个数字，`随机化`，`清除`。`0`表示每局使用新的种子，[[8_determinism]] |

按`开始`开始这一局

暂停窗口中有`继续`、`重开`、`设置`、`返回菜单`和`退出游戏`

## 结果窗口

窗口显示`通过`或`失败`，以及三个部分：`进度`、`伤害`和`条件`

- 各行：`完成度`、`已到达检查点`、`时间`、`关卡时长`、`受击次数`、`剩余生命`、`最长无伤时长`
- 本局条件：`速度`、`生命`、`机器人`、`种子`、`检查点`。开启`无碰撞`的一局会在`生命`后面标注`· 无碰撞`
- 按钮：`重开`、`从检查点重新开始`、`设置`、`返回菜单`

默认情况下，失败的一局不会打开这个窗口，而是倒回到上一个检查点。要改变这一点：`设置`→`界面`→`失败时打开菜单`

## 纪录

关卡界面上有一个纪录区：`最佳`、`尝试次数`和`通关`（或`从未游玩`）

每一组条件都有自己的纪录：生命、速度、检查点、无碰撞和机器人。纪录区显示的是当前所选条件下的纪录。尝试次数和通关次数会统计每一局

纪录是怎么选出来的：[[10_statistics]]

## 卡片标记

| 标记 | 含义 |
|---|---|
| `未订阅` | 硬盘上有一个创意工坊文件夹，但你没有订阅它。只有打开`设置`→`常规`→`显示所有找到的内容`时才会列出 |
| `离线` | 关卡来源没有响应 |
| `版本较新`、`来自更新版本的游戏` | 这个版本的游戏无法打开该关卡，[[5_troubleshooting]] |

## 删除关卡

长按或右键点击卡片→`删除`。游戏会先要求确认

你可以同时删除关卡的统计数据（`同时删除统计`）和备份（`同时删除备份`）

删除受保护的关卡不需要密码
