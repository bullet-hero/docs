# gv 0.3.3

A fast shader and an editor camera you can move with the mouse or two fingers

- **A new shader for level objects.** It has one pass and only what drawing needs, and it runs about twice as fast as the old one
- **The editor camera.** On PC it is moved with the mouse, on a phone with two fingers. A separate button brings it back to the focus
- **Textures.** Any texture of the game or the level can now be laid on an object by its own UV coordinates
- **The log viewer.** The first version of a panel that shows the editor's messages
