# gv 0.14.1

スマートフォン向けの修正（レベル中は画面が消えず、メモリの後処理でプレイが中断しなくなった）、ライセンスの記録、デモレベルの復活

- レベルの再生中は画面が消えず、一時停止するとすぐにシステムのタイムアウトに従います。以前はスティックを倒したまま操作するプレイが無操作と見なされ、レベルの途中でスマートフォンがロックされていました
- レベル中に届いたメモリ不足の警告は、レベルが止まってから処理されます。Androidでは後処理に163msと715msかかり、33秒のプレイ中に735msと523msのフレームが2回発生しました。どちらも、プレイを失うのに十分な長さです。その代わり、本当にメモリが足りない場合は、システムがレベル中にゲームを終了することがあります
- ゲームのカメラは、1ピクセル単位で動いたときだけ出力領域を更新します。以前は毎フレーム更新していて、レベルのアスペクト比が変わらなくても、レンダラーが中間画像を毎秒60回作り直していました
- `ライセンス`ウィンドウは折りたためるようになりました：2段階の見出しのどちらも、展開と折りたたみができます。レベル自身のリソースは最初から開いていて、ゲームに付属するものはすべて折りたたまれています
- リソースを削除すると、そのライセンスの記録も削除されます。以前は`ライセンス`ウィンドウが、レベルにもう存在しないリソースの作者に感謝し続けていました。元に戻すと記録も戻ります
- レベルのカバーは、元のファイル名に関係なく、画像の実際の形式に応じて`logo.png`または`logo.jpg`として保存されます。PNGでもJPEGでもない画像は受け付けません
- 内蔵レベル`New zero demo`が、カバーとクレジットされた音楽アーティストDunderpatrullenとともに戻りました
