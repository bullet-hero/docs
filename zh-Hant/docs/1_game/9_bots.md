# 機器人

機器人用你自己的操作替你遊玩關卡。它觀察飛來的東西，尋找空位，移動和你相同的角色：行走、衝刺、受到傷害、死亡

**機器人不保證通關**。它不會疲勞，但會失敗。如果某個組合需要提前一秒正確進入，機器人就會被擊中。這時什麼都沒有壞

**機器人會給裝置帶來負載**。尋找空位是每一幀都要做的真實工作。在效能較弱的裝置上會掉幀。在複雜的關卡上，最開始的幾秒最嚴重

選擇機器人：關卡介面上的`{{ui:menu_levelview_options-bot}}`條件，可選`{{ui:enum_bot-kind_none}}`、`{{ui:enum_bot-kind_reflex}}`或`{{ui:enum_bot-kind_warm}}`。和生命、速度一樣，每次遊玩單獨選擇

> [!info] 須知
> 機器人無法作弊，這是它的構造，而不是一句承諾。它的操作和你完全相同，沒有任何額外能力：相同的速度、相同的衝刺、相同的判定框、相同的傷害。你穿不過去的東西，它也穿不過去

## 關卡打敗了機器人？

機器人會在它們還沒見過的關卡上變得更好。這樣的關卡值得發過來

在[bullet-hero/releases](https://github.com/bullet-hero/releases/issues)中提交issue。寫明哪個機器人在哪裡失敗，並附上關卡資料夾

## 兩個機器人

機器人每幀只給出一個輸入，和鍵盤一樣，除此之外什麼都沒有。它無法獲取化身的位置、生命值或關卡狀態。如果機器人在某一幀沒有響應，這一幀由你的裝置操控

| | `{{ui:enum_bot-kind_reflex}}` | `{{ui:enum_bot-kind_warm}}` |
|---|---|---|
| 知道什麼 | 接下來的1.5秒，每幀重新計算 | 整個關卡，只計算一次 |
| 何時產生負載 | 執行期間的每一幀 | 一次，在遊玩開始前 |
| 能做什麼 | 躲開前方看到的東西 | 執行任何前瞻都找不到的計劃 |
| 什麼會讓它失敗 | 需要提前一秒進入的組合 | 在它之下發生了變化的關卡 |
| 如何操控 | 按方向 | 按目標 |

Warm機器人追求零傷害。為此它要多一個載入階段：`{{ui:root_loading_baking}}`。它可能持續幾十秒

`{{ui:menu_levelview_options-bot}}`旁邊的`?`會提前說明這一點，每個機器人一段。`{{ui:root_loading_cancel}}`會中止計算，把這次遊玩交給你。Warm機器人的路線取決於種子，[[8_determinism]]

## 機器人還在哪裡遊玩

- **編輯器的試玩玩家**：`{{ui:settings_common_title}}`→`{{ui:settings_game-editor_title}}`→`{{ui:settings_game-editor-player_bot}}`。那裡只有Reflex機器人：它不需要提前準備任何東西，也能承受倒帶。更多：[[5_bot-playtest]]
- **主選單背景**：按鈕後面的競技場是一個Reflex機器人，它即時遊玩，完全不做前瞻

機器人屬於紀錄的條件。因此機器人的遊玩永遠不會取代你的最佳成績，[[10_statistics]]
