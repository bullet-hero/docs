# Как помочь

Как устроен репозиторий документации, куда кладётся каждый вид страниц и как правка попадает на сайт через pull request

Документация открыта, чтобы любой мог исправить ошибку, закрыть пробел или добавить перевод. Код самого сайта закрыт, но каждая страница, которую он показывает, берётся из публичного репозитория [github.com/vertoker/bullet-hero-docs](https://github.com/vertoker/bullet-hero-docs)

## Как устроен репозиторий

- **Это только markdown и ничего больше.** У репозитория нет своей сборки и нет скриптов
- **Это хранилище [Obsidian](https://obsidian.md/).** Откройте корневую папку репозитория как хранилище, и ссылки, встраивания и превью будут работать так же, как на сайте. Любой другой markdown-редактор тоже подойдёт
- **Это подмодуль сайта.** Сайт подключает репозиторий как папку `content/`, компилирует страницы при сборке и заранее рендерит каждую из них
- **Принятая правка появляется не сразу.** Сайт подхватывает её, когда его указатель на этот репозиторий сдвигают вперёд, поэтому правка появится на [bullethero.space](https://bullethero.space/) со следующим деплоем сайта

## Что куда кладётся

| Путь | Что там | Адрес на сайте |
|---|---|---|
| `<lang>/docs/1_game/` | игрокам: установка, игра, настройки, механики | `/<lang>/docs/game` |
| `<lang>/docs/2_editor/` | авторам уровней: руководство и справочники редактора | `/<lang>/docs/editor` |
| `<lang>/docs/3_sdk/` | разработчикам: открытый SDK и формат уровня | `/<lang>/docs/sdk` |
| `<lang>/docs/4_server/` | владельцам серверов: официальный и общественные серверы | `/<lang>/docs/server` |
| `<lang>/docs/5_contribute/` | этот раздел | `/<lang>/docs/contribute` |
| `<lang>/notes/` | статьи, публичные документы и политики, по дате | `/<lang>/notes/<name>` |
| `<lang>/download.md` | страница загрузки | `/<lang>/download` |
| `assets/` | изображения для всех языков | встраиваются в страницы |

`<lang>` - папка языка: `en` или `ru`. Файл вне `docs/`, `notes/` и `download.md` страницей не становится. В `notes/` нет подпапок

**Документация описывает, как всё работает сейчас.** История изменений, мнение или эссе - это заметка в `notes/`

## Как проходит pull request

1. Сделайте форк репозитория и создайте ветку
2. Отредактируйте или добавьте страницы в формате со страницы [[1_writing-pages]]. Измените версию на каждом языке или напишите в pull request, каким языкам правка ещё нужна (как языки отражают друг друга, описано на странице [[2_translating]])
3. Следуйте правилам со страницы [[3_style-guide]]
4. Откройте pull request с коротким описанием, что изменилось и зачем

**Факты берутся из игры, SDK или их документации.** Числа, названия полей, имена файлов, сочетания клавиш и адреса никогда не угадываются. Если не уверены, что что-то верно, скажите об этом в pull request, а не на странице

> [!tip] Подсказка
> Собрать сайт сами вы не сможете, его код закрыт. Ближайший предпросмотр - Obsidian: ссылка, которую не находит Obsidian, не найдётся и на сайте
