# Willkommen

| Produkt | Beschreibung |
|---|---|
| [[1_game/index]] | Der Spielclient, der Hauptteil des Projekts |
| [[2_editor/index]] | Ein großer Leveleditor, Teil des Spielclients |
| [[3_sdk/index]] | Ein offenes SDK für die Inhalte des Spiels |
| [[4_server/index]] | Ein Server für das Spiel (noch in Entwicklung) |
| [[5_changelog/index]] | Was sich in jeder Version des Spiels geändert hat |
| [[community]] | Die Community und alles drumherum |

## Versionen

Jedes Produkt hat seine eigene Version mit einem Buchstabenpräfix, jeweils in der Form `major.minor.revision`:

| Präfix | Steht für | Produkt |
|---|---|---|
| `gv` | `game version` | das Spiel (der Client) |
| `sv` | `sdk version` | das SDK |
| `bv` | `backend version` | das Backend, der Server |
| `fv` | `frontend version` | die Website |
| `mg` | `model generation` | die Daten |

Geschrieben als `gv 1.0.0`, `sv 1.0.0`, `bv 1.0.0`, `fv 1.0.0`, `mg 1`

Mehr dazu unter [[5_versioning]]
