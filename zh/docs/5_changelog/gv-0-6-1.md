# gv 0.6.1

音量滑块旁的静音按钮、记住窗口大小、错误窗口的开关，以及修复改变窗口大小后画面出现边框的问题

- 音频设置中的三个音量滑块都有静音按钮。游戏运行期间再按一次即可恢复之前的音量。静音就是音量为0，所以静音时关闭的游戏再次打开时也是静音
- 你手动调整过大小的窗口会保持这个大小。以前，下一次改变任何设置都会恢复旧的大小
- 界面设置`错误`分区中的`异常时提醒`。开启时，未捕获的错误会在屏幕上所有内容之上打开报告窗口。关闭时，错误只写入日志，报告无论如何都会收集
- 点击时间轴上的关键帧会立即在检视器中打开它的标签页
- 修复：改变窗口大小后，没有要求两侧黑边的关卡可能在窗口中央显示带边框的画面
