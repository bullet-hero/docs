# gv 0.16.1

アバターの歩く速度が毎秒10ユニットから15ユニットになり、最短のダッシュがアバターの体1つ分になりました

- 歩く速度は毎秒10ユニットから15ユニットになりました。アバターが画面を上から下まで横切る時間は、1秒から3分の2秒になります。カーソルで操作するとき、アバターは歩く速度でポインターに追いつくので、素早く動かしたあとの遅れが3分の1短くなりました。10では、精密な場面で遅く感じられました
- ダッシュとノックバックは毎秒50ユニットのままなので、どちらも歩く速度の5倍ではなく3.3倍になりました
- 最短のダッシュはアバターの体1つ分、0.5ユニットです。それより近い目標ではダッシュしません。このしきい値がないと、アバターのすぐ隣にカーソルを置いたままにするだけで1フレームおきにダッシュが発生し、そのたびに軌跡、サウンド、統計の記録が残っていました

アバターのすべての数値は1つのページにまとまっています：[[6_avatar]]
