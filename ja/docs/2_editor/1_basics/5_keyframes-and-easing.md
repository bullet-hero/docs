# キーフレームとイージング

キーフレームは、1つのトラックの1つのフレームでの値と、その値に到達するまでのイージングです。レベル内で動くもの、色が変わるもの、オンとオフが切り替わるものは、すべてキーフレームのリストです

基本的な考え方：[[3_how-the-editor-thinks]]。キーフレームのインスペクターの全フィールド：[[5_object-properties]]

## アニメーションできるもの

トラックはそれぞれ独自のキーフレームを持ち、ほかのトラックからは独立しています：

| 持ち主 | トラック |
|---|---|
| すべてのオブジェクト | 位置、回転、スケール、サイズ、アンカー、ピボット |
| シェイプ | 色、UV |
| テキスト | 色、フォントサイズ、`{{ui:editor_dummy_text-11}}`（テキストのどれだけが書かれているか）、`{{ui:editor_dummy_text-12}}`（どれだけがマスクに隠れているか） |
| カメラ | 位置、回転、ズーム、ピボット、揺れ |
| レベル | 背景、テーマ、画面制限、12種類のポストプロセス効果のそれぞれ |
| プレイヤー | サイズ、速度、表示、操作、衝突 |

シェイプの色のキーフレームは、オブジェクトの矩形全体にかかるグラデーションにもできます。`{{ui:editor_keyframe-color_layout}}`フィールドで配置を選びます：`{{ui:enum_color4-x4-key-type_value}}`（1色）、`{{ui:enum_color4-x4-key-type_vertical}}`（下から上）、`{{ui:enum_color4-x4-key-type_horizontal}}`（左から右）、`{{ui:enum_color4-x4-key-type_bari-centrical}}`（四隅それぞれに1色）

フォントサイズのキーフレームは、ワールド単位の固定サイズを表す1つの数値か、`{{ui:field_common_auto-size}}`をオンにした範囲のどちらかです。テキストは範囲の`{{ui:field_common_max}}`で描画され、矩形に収まるまで`{{ui:field_common_min}}`に向かって縮みます

オブジェクトのキーフレームは、そのスパンの開始から数えられます。そのため、オブジェクトを時間方向に動かすと、アニメーション全体も一緒に移動します

位置は親に対する相対値で設定します。キーフレームには、前のキーフレームからの増分ではなく、値そのものが保存されます

プレイヤーの表示、操作、衝突は、オンかオフのどちらかです。これらのキーフレームにはイージングがありません：混ぜ合わせるものがないためです

空のプレイヤートラックに打った最初のキーフレームは、画面上で何も変えません：表示、操作、衝突はオンで始まり、サイズと速度はプレイヤーの通常の値で始まります。操作がオフのとき、またはプレイヤーが非表示のときは、プレイヤーを操作できません：カーソルが消え、入力は受け付けられません。非表示のプレイヤーにも攻撃は当たります：それを決めるのは衝突だけです

## テキスト：書き出しと出現

2つのテキストトラックは、それぞれ異なる方法で文字を隠します。どちらも0から1の割合を取り、テキストの文字数を数えます

`{{ui:editor_dummy_text-11}}`は、テキストのうち書かれている割合です：0は何もなし、1はすべて。書かれていない文字はまったく描画されないので、行が短くなります。空のトラックではテキスト全体が書かれます。方向はキーフレームごとに設定します：
- `{{ui:enum_text-fill-direction_forward}}`（デフォルト）：最初の文字から、タイプライターのように
- `{{ui:enum_text-fill-direction_backward}}`：最後の文字から
- `{{ui:enum_text-fill-direction_from-center}}`：中央から広がる
- `{{ui:enum_text-fill-direction_to-center}}`：両端から伸びて中央で合わさる

`{{ui:editor_dummy_text-12}}`は、マスクに隠れている文字の割合です：0はすべて表示、1はすべてマスク。隠れた文字は位置を保ったまま、マスク文字（デフォルトは`{{v:text.appearing-mask-default}}`）として描画されます。マスクはテキストオブジェクトの`{{ui:editor_inspector-appearing_mask}}`フィールドで、複数の文字を入れると、隠れた文字それぞれがそのうちの1つを使います。空のトラックでは何も隠れません。モードはキーフレームごとに設定します：
- `{{ui:enum_text-appearing-mode_random}}`（デフォルト）：ばらばらに、ただし毎回同じ散らばり方で。0.3で隠れている文字は0.6でも隠れているので、テキストはちらつかずに浮かび上がります
- `{{ui:enum_text-appearing-mode_forward}}`：隠れた文字が末尾にあり、テキストは先頭から現れる
- `{{ui:enum_text-appearing-mode_backward}}`：隠れた文字が先頭にある

1行をタイプするように表示するには、`{{ui:editor_dummy_text-11}}`を0から1へアニメーションさせます。ノイズの中から解読されるように表示するには、`{{ui:editor_dummy_text-12}}`を1から0へアニメーションさせます

## アドバイス

- キーフレームは動くものにだけ打ってください。キーフレームのないトラックはデフォルト値を使います
- ビートちょうどで変化させるには`Constant`を使います。たとえば、ドロップでのテーマの切り替えです
- 回転は一周で折り返されません：0度のキーフレームと720度のキーフレームでは、オブジェクトは2回転します。ファイルやAIアシスタントが書くラジアンでは、0と12.566です

## 2つのキーフレームの間

最初のキーフレームより前と最後のキーフレームより後では、値は止まったままです。2つのキーフレームの間では、ゲームは経過した時間の割合を取り、それをイージングに通して、2つの値を混ぜ合わせます

割合は描画されたフレームではなく時間で数えられます。そのため、30fpsでも144fpsでもカーブは同じです

**イージングはペアの後ろのキーフレームに属します**。キーフレームのイージングは、前のキーフレームからこのキーフレームに到達するまでの区間を決めます。そのため、トラックの最初のキーフレームのイージングは決して表れません。新しいキーフレームには`Linear`が設定されます

`{{ui:hint_editor_inspector_ease_header}}`フィールドで`{{ui:editor_search-title_ease}}`ウィンドウが開き、各イージングがそれぞれのカーブとして描かれています。複数のキーフレームを、別々のトラックにあっても選択し、1回の元に戻す操作の単位でまとめて変更できます

## 29種類のイージング

`Linear`は直線です。`Constant`は前の値を保ち、キーフレームで値が飛びます

残りの27種類は、3種類ずつの9つのファミリーです：`In`、`Out`、`InOut`。たとえば`InSine`、`OutSine`、`InOutSine`です

| ファミリー | 形 |
|---|---|
| `Sine` | 最もなめらかなカーブ |
| `Quad`、`Cubic`、`Quart`、`Quint` | 2乗、3乗、4乗、5乗 |
| `Expo` | 指数関数 |
| `Circ` | 円の4分の1 |
| `Back` | 範囲を越えてから戻る |
| `Elastic` | 値の周りで振動する |

`In`はゆっくり始まって速く終わります。`Out`は速く始まって落ち着きます。`InOut`は両端でゆっくりです。`Sine`から`Expo`まで、ファミリーは後になるほど鋭くなります

> [!caution] 注意
> `Back`と`Elastic`は範囲の外に出ます：`Out`は目標を行き過ぎ、`In`は開始点より後ろに下がります。コライダーはオブジェクトと一緒に動きます。そのため、安全地帯の縁で止まるはずの弾は、数フレームのあいだ安全地帯に入り込みます

## ランダムな値

キーフレームの値は1つの数値である必要はありません：
- 数値：`{{ui:field_common_value}}`、`{{ui:enum_color-type_random-min-max}}`、`{{ui:enum_float-type_random-min-max-step}}`
- ベクトル（位置、スケールなど）：`{{ui:field_common_value}}`、`{{ui:enum_vector-type_random-rect}}`、`{{ui:enum_vector-type_random-rect-step}}`、`{{ui:enum_vector-type_random-circle}}`、`{{ui:enum_color-type_random-lerp}}`、`{{ui:enum_vector-type_random-lerp-step}}`
- 色：`{{ui:field_common_value}}`、`{{ui:editor_events-timeline_track_theme}}`、`{{ui:enum_color-type_random-min-max}}`、`{{ui:enum_color-type_random-lerp}}`

`{{ui:enum_vector-type_random-rect}}`は軸ごとに別々に値を選びます。`{{ui:enum_color-type_random-lerp}}`はすべての軸に1つの数値を選ぶので、点はAとBを結ぶ線上に乗ります。ステップのある形式は、結果をステップの倍数に切り捨てます。ステップが0ならグリッドはオフになり、値はステップのない形式と同じように振る舞います。その後、キーフレームはほかのキーフレームと同じように混ぜ合わされます

同じシードからは同じレベルが得られます。乱数は、シード、キーフレームのフレーム、レイヤー、オブジェクトの開始フレーム、トラック、チャンネルから計算されます。詳細：[[8_determinism]]
