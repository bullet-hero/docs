# Änderungsprotokoll

Jede Version des Spiels ist eine eigene Seite mit ihrer Liste von Änderungen, die neueste steht ganz oben in der Liste

Jede Version seit `gv 0.0.0` hat eine Seite. Die ersten Versionen sind kurz: Sie erzählen mehr davon, wie das Projekt begann, als dass sie Änderungen auflisten
