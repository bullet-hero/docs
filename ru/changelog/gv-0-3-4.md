# Версия 0.3.4

Первый таймлайн, первый инспектор и выбор объектов прямо во вьюпорте

У редактора появились три части, вокруг которых сегодня строится работа над уровнем. Здесь все три - ранние прототипы

- **Таймлайн.** Показывает номера кадров и объекты уровня на оси кадров
- **Инспектор.** Первая версия панели со свойствами объекта
- **Выбор.** Объект можно выбрать во вьюпорте, и выбор общий с иерархией объектов

Изменились и цвета. Объект с текстурой теперь несёт четыре цвета, по одному на угол, и смешивает их градиентом. Для этого шейдер объектов переписали на основе стандартного шейдера *Unlit* из URP
