# gv 0.6.2

展平预制件、打开设置的启动参数，以及全屏模式和窗口大小的修复

- `展平预制件`把一次预制件放置变成普通物体：与模板的关联消失，物体精确地留在原位。它是预制件检视器中的一个按钮，也是一条编辑器命令，`展平预制件`修改器则对范围内的所有放置做同样的事。之后关卡看起来完全一样，因为每次放置的覆盖已经写入了物体
- `--settings`打开菜单，并在其上打开设置，`--settings graphics`（或其他标签页名称）打开指定的标签页
- 修复：全屏模式可能显示带黑边的模糊640x480画面，退出后再进入也无法修复。现在全屏模式始终使用屏幕的原生分辨率，想用更低的渲染分辨率可以使用`渲染缩放`
- 修复：退出一次全屏模式，就会让游戏把窗口大小记成整个屏幕的大小
- 修复：点击时间轴上的关键帧并不总能在检视器中打开它的标签页
