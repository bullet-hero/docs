# Serveurs

Dans Bullet Hero, un serveur est un service web qui stocke des niveaux. Il y aura le serveur officiel OWS et des serveurs communautaires NOWS que n'importe qui pourra faire tourner

> [!warning] Avertissement
> Il n'y a pas encore de serveur, ni officiel ni communautaire. Le protocole entre le jeu et un serveur n'a pas été conçu

Le code du serveur sera ouvert dans [bullet-hero/backend](https://github.com/bullet-hero/backend), il est vide pour l'instant
