# Server

Ein Server ist in Bullet Hero ein Webdienst, der Levels speichert. Es wird den offiziellen Server OWS geben und Community-Server NOWS, die jeder betreiben kann

> [!warning] Warnung
> Es gibt noch keine Server, weder offizielle noch Community-Server. Das Protokoll zwischen dem Spiel und einem Server ist noch nicht entworfen

Der Servercode wird offen in [bullet-hero/backend](https://github.com/bullet-hero/backend) liegen, bisher ist es leer

Du brauchst einen Server für dich und deine Freunde - [[2_hosting]]

Du brauchst einen großen öffentlichen Server - [[3_advanced-hosting]]
