# gv 0.0.1

The first rendering test: many objects through Unity Entities, and it already runs on Android

Three days after the start the project got its technical base. Objects are drawn through *Unity Entities* (ECS), and the game still stands on that approach. The test scene fills the screen with objects and changes their colours, and the draw order is taken from the depth of each object

- The test build already runs on Android
- The level data model moved into a separate plugin, the future SDK
- The first sprites (shapes, interface icons, skins) were carried over from an older project

At the same time a custom render pipeline was considered and dropped: the standard *URP* was enough
