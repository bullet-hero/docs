# gv 1.0.0

정식 출시: `gv 1.0.0`에서 저장한 파일은 이후 모든 버전에서 열리고, 더 새로운 버전의 파일은 게임 업데이트를 요청합니다

## `gv 1.0.0`의 의미

- **파일은 계속 작동합니다.** `gv 1.0.0`에서 저장한 레벨, 설정, 통계는 이후 모든 버전의 게임에서 열립니다. 파일 형식이 바뀌면 새 버전이 오래된 파일을 읽으면서 스스로 변환합니다
- **더 새로운 파일은 반만 읽지 않고 거부합니다.** 더 새로운 버전의 레벨이나 저장 파일은 `업데이트 필요` 창을 열고, `다운로드`는 다운로드 페이지로 이동합니다. 게임은 읽을 수 없는 것을 추측하지 않으므로, 아무것도 잃거나 몰래 바뀌지 않습니다. 자세히 - [[5_troubleshooting]]
- 게임 버전과 SDK 버전은 `gv 1.0.0`, `sv 1.0.0`입니다. SDK 개발은 아직 게임과 함께 진행되므로, 프로그래밍 인터페이스가 그대로 유지된다는 약속은 아직 하지 않습니다

## 바뀐 점

- **오래된 바이너리 레벨이 깨집니다.** `gv 1.0.0` 이전 버전에서 `Blob` 형식으로 저장한 레벨은 `gv 1.0.0`에서 열리지 않습니다. 출시를 위해 바이너리 형식을 처음부터 다시 만들었기 때문입니다. `Json` 형식으로 저장한 레벨은 영향을 받지 않습니다. 오래된 `Blob` 레벨이 있다면, 먼저 그 레벨을 만든 버전에서 열어 `Json` 형식으로 저장하십시오
- 에디터 설정에서 `가이드라인` 섹션이 제거되었습니다. 가이드는 이제 사이트에 있으며, `커뮤니티` 섹션의 `문서` 링크가 현재 언어로 가이드를 엽니다
- 언어를 바꾸면 레벨 목록의 라벨이 다시 쓰입니다. 이전에는 출처 버튼, 정렬 버튼, 레벨 셀이 이전 언어로 남았습니다
- 게임의 모든 텍스트가 두 언어 모두 문서 저장소에 공개되었으므로, 오타나 어색한 번역을 그곳에 신고하거나 직접 고칠 수 있습니다 - [https://github.com/bullet-hero/docs](https://github.com/bullet-hero/docs)
