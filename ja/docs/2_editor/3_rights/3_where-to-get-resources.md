# リソースの入手先

デフォルトで安全なのは、音楽ならccMixter、Freesound、Kenney、画像ならPoly Haven、Pexels、Unsplash、フォントならGoogle Fontsです。YouTube、SoundCloud、Spotifyからは何も取ってはいけません

## 入手してはいけない場所

> [!caution] 注意
> YouTube、SoundCloud、Spotifyはサイト一覧で**不許可**とされています。これらはどんな種類のライセンスでもなく、誰にも何も与えません。作品がそこにしかないなら、正直な記録は「条件不明」です。残る道は[[2_legal-resource-paths|作者の許可]]だけです

## オーディオ

**デフォルトで安全**：
- [ccMixter](https://ccmixter.org/)：CC BY、CC BY-NC
- [Freesound](https://freesound.org/)：CC0、CC BY、CC BY-NC
- [Incompetech](https://incompetech.com/)：CC BY
- [Teknoaxe](https://teknoaxe.com/)：CC BY
- [Kenney](https://kenney.nl/)：CC0

**記録ごとに確認する価値あり**：
- [SoundImage](https://soundimage.org/)
- [Pixabay](https://pixabay.com)
- [GoodKid](https://goodkidofficial.com/creators/)：形式上は何も宣言していませんが、FAQの内容はクレジット表記が必須でないCC BYに相当します
- NCS：レベルが標準の`CC BY-NC`のままである間に限ります

**先に条件を読む**：[OpenGameArt](https://opengameart.org/)、[Free Music Archive](https://freemusicarchive.org/home)、SoundBible

**疑わしい**：
- Zapsplat
- [Play On Loop](https://www.playonloop.com/music-licensing/)：ゲームが商用プロジェクトでない間に限ります。現在は商用ではありません

## 画像とフォント

**画像、デフォルトで安全**：[Poly Haven](https://polyhaven.com/)、[AmbientCG](https://ambientcg.com/)、[Kenney](https://kenney.nl/)、[Pexels](https://www.pexels.com/)、[Unsplash](https://unsplash.com/)

**画像、記録ごとに確認する価値あり**：[Pixabay](https://pixabay.com)

**画像、先に条件を読む**：[OpenGameArt](https://opengameart.org/)、[Rawpixel](https://www.rawpixel.com/)（PersonalとPublic Domainのみ）、itch.io、Wikimedia Commons

**フォント**：[Google Fonts](https://fonts.google.com/)

## 一覧にないサイト

> [!warning] 警告
> 一覧にないサイトは許可ではありません。そのサイトについて何もわかっていないという意味です

一覧自体は出発点にすぎません。サービスの運営者はそれぞれ一覧を差し替えられます

## 評価

既知のサイトにはそれぞれ評価があります：

| 評価 | 意味 |
|---|---|
| **承認済み** | そこからのものはすべて公開でき、リソースごとのチェックは不要 |
| **一部承認** | サイトに複数の種類の条件があり、記録を確認する価値がある |
| **ライセンスの確認が必要** | どんなライセンスも出てくる可能性があり、アップロードごとに記載されている |
| **リソースの確認が必要** | 条件が作品や、アップロードした人が選んだプランによって変わる |
| **不許可** | 記録に何と書かれていても、ここからは何も使えない |

ライセンスのフィールドは、作者が何を主張しているかを示します。サイトは、その主張にどれだけの価値があるかを示します。両方がそろうとモデレーションの手間が小さくなります

## サイトの判定方法

サイトは、入力したリンクのホストで判定されます。サブドメインも含みます。スキーム（`https://`）のないアドレスも判定されます

YouTube、SoundCloud、Spotifyは、単に一覧から外されているのではなく、一覧に名指しで載っています。そのため、こうしたリンクを持つレベルは、リンクを貼り付けた瞬間に拒否されます。一覧にないサイトなら「誰かが確認すべき」という扱いになるだけです。レベルを公開できない最もよくある理由に対して、それでは甘すぎます
