# Registro de cambios

Cada versión del juego es una página aparte con su lista de cambios, la más reciente arriba de la lista

Cada versión desde `gv 0.0.0` tiene su página. Las primeras versiones son cortas: hablan más de cómo empezó el proyecto que de una lista de cambios
