# gv 0.3.0

Die erste Version, die als Spiel funktioniert: ein Menü, ein Avatar, den du steuerst, Levels von Anfang bis Ende und der erste Editorbildschirm

Bis dahin konnte die Engine ein Level nur in einer Testszene abspielen. Hier entstand das ganze Spiel um sie herum, gebaut auf *UI Toolkit*

- **Menü und Einstellungen.** Das Hauptmenü, ein Einstellungsbildschirm, der zwischen den Starts gespeichert wird, Playlists und eine Levelliste
- **Ein Level spielen.** Ein Level wird ausgewählt, geladen und bis zum Ende gespielt
- **Der Avatar.** Die eigene Form des Spielers im Level, von dir gesteuert
- **Zwei Sprachen.** Die Oberfläche auf Englisch und Russisch
- **Levelvalidierung.** Das SDK kann ein Level gegen eine Reihe von Regeln prüfen und kaputte Daten melden

Der eingebaute Editor erschien in seiner ersten Form. Er kann ein neues Level erstellen, es in einem Ordner speichern, es mit einer gewählten Geschwindigkeit abspielen und die aktuelle Zeit anzeigen. Die Objekthierarchie und der Inspector sind bisher nur Entwürfe

Ein `gv 0.2` gibt es nicht: Die Nummern sprangen von `gv 0.1.0` direkt auf `gv 0.3.0`
