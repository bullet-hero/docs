# Jeu

Bullet Hero est un hybride de jeu de rythme et de bullet hell : tu diriges un petit carré, et il doit survivre jusqu'à la fin du morceau. Le jeu est gratuit, et aucun compte n'est nécessaire

Les premières pages te mettent en jeu. Plus loin viennent les mécaniques d'une partie, pour qui veut les chiffres exacts
