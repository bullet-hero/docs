# Version 0.6.1

Mute buttons on the volume sliders, a remembered window size, a switch for the error window, and a fix for a boxed picture after a window resize

- The three volume sliders in the audio settings have a mute button. Unmuting returns the volume you had before, for as long as the game is running. A mute is simply a volume of 0, so a game closed while muted opens muted
- A window you resized by hand keeps its size. Before, the next change of any setting put the old size back
- `Alert on Exception` in the `Errors` section of the interface settings. On, an uncaught error opens the report window over whatever is on screen. Off, it only goes to the log, and the report is built either way
- Clicking a key on a timeline opens its inspector tab straight away
- Fixed: after a window resize a level that asked for no side bars could show its picture boxed in the middle of the window
