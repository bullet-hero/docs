# gv 0.7.0

Sonidos de interfaz, control completo con gamepad y teclado fuera del editor, y opciones nuevas para las imágenes del nivel

- La interfaz ahora suena. El menú responde a una pulsación, mientras que el editor de niveles solo hace sonar el resultado de una edición: guardar, un rechazo, deshacer o rehacer, eliminar. Pasar por encima de un botón no suena en ningún sitio: es el evento más frecuente, y el primero en cansar
- Un control deslizante nuevo, `Interfaz del editor`, en la configuración de audio controla los sonidos del editor por separado de `Interfaz de usuario`. Los dos están al 50% de forma predeterminada
- Todo excepto el editor se puede jugar solo con un gamepad o solo con un teclado. Mientras tienes un gamepad en la mano, el cursor del ratón se oculta, y la esquina inferior izquierda muestra durante un segundo qué dispositivo tomó el control. Por el propio editor no se puede navegar con un gamepad, pero el botón `Start` permite salir de él
- "Atrás" cierra solo la ventana superior. Antes, una pulsación podía cerrar una ventana junto con la pantalla que había debajo
- Las imágenes del nivel tienen dos opciones nuevas: `Muestreo` (`Suave` o `Nítido`) y `Compresión` (`Permitir` o `Rechazar`). `Rechazar` conserva cada píxel pero ocupa hasta 4 veces más memoria
- Lo que hace una imagen más allá de sus bordes ahora se fija por eje: `Fuera de bordes X` y `Fuera de bordes Y`. Un nivel guardado antes de esta versión lee los dos como `Limitar`, así que una repetición fijada antes hay que volver a fijarla
- El tiempo de recarga del dash es de 0,30 s en lugar de 0,35 s. La invulnerabilidad después de un dash sigue siendo de 0,20 s
- Pausar en mitad de un dash ya no arrastra el avatar por el nivel detenido
- Un avatar atascado muy dentro de una forma ahora se empuja hacia fuera desde su centro. Antes no recibía ningún empuje
- La jerarquía conserva las filas que expandiste después de una edición, y dos botones nuevos expanden o contraen todas las filas a la vez
- La superposición de estadísticas puede mostrar tres bloques más: `Mostrar objetos del fotograma`, `Mostrar objetos del nivel` y `Mostrar memoria`
