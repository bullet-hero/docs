# 化身与移动

化身以每秒15单位的速度行走，冲刺在0.15秒内把它送出7.5单位。判定框是半径0.15单位的圆，比绘制出来的0.5单位方块小

本页是化身的事实标准。游戏和两个机器人都按这些数值制作，SDK把它们记录为`AvatarRules`常量。与本页不一致的代码就是代码的错误

距离以世界单位表示。默认相机正好10单位高（`ValueRules.DefaultZoom`），所以一个单位是屏幕高度的十分之一，化身的身体宽半个单位

相机缩放改变的是你能看到多少，而不是下面的数值

## 数值

| 项目 | 数值 | 通俗地说 |
|---|---|---|
| 行走速度 | `15`单位/秒 | 三分之二秒从屏幕顶端走到底端 |
| 冲刺速度 | `50`单位/秒 | 比行走快3.3倍 |
| 冲刺时长 | `0.15`秒 | |
| 冲刺距离 | `7.5`单位 | 速度×时长，屏幕高度的四分之三 |
| 冲刺冷却 | `0.3`秒 | 从冲刺开始时计算 |
| 冲刺无敌时间 | `0.3`秒 | 同样从开始时计算，所以比移动本身多持续0.15秒 |
| 最短冲刺 | `0.01`单位 | 与到达距离相同，再近你就已经站在目标上了 |
| 击退速度 | `50`单位/秒 | 比行走快3.3倍，[[7_damage]] |
| 击退时长 | `0.15`秒 | 期间无法操控 |
| 伤害间隔 | `1.0`秒 | 其间之后的所有命中都会被忽略 |
| 身体尺寸 | `0.5`单位 | 绘制出来的方块 |
| 判定框 | 半径`0.15`单位 | 身体的0.3，故意比看到的小 |
| 出现与消失 | `0.3`秒 | 长大出现，缩成一点消失 |
| 玩家尺寸对速度的影响 | 完全，`1.0` | 更大的化身按比例移动得更快。这是关卡中的玩家尺寸轨道，不是相机缩放 |
| 转向速度 | `30`/秒 | 外观效果：身体朝向哪里 |
| 到达距离 | `0.01`单位 | 离光标比这更近就算站在光标上 |

由它们推导出的数值，真正决定闪避的是这些：

| 项目 | 数值 |
|---|---|
| 最短冲刺：距离 | `0.01`单位 |
| 最短冲刺：时长 | 远短于一帧 |
| 最短冲刺：冷却和无敌时间 | 各自都远短于一帧 |
| 最频繁的冲刺 | 最多每隔一帧一次 |
| 击退距离 | `7.5`单位 |

被命中时会发生什么：[[7_damage]]

## 移动

操控方式有两种，游戏从不把它们混在一起：
- **方向**：WASD、手柄摇杆、陀螺仪。化身朝你推的方向以行走速度移动。摇杆推到一半就是一半速度，没有别的“慢走”
- **光标**：鼠标或手指。化身追赶这个点，而不是瞬移过去。它以自己的行走速度移动，会落后于快速移动的鼠标

两种方式下移动都是即时的：没有加速、滑行和惯性。你停止操作的那一帧就会停下

## 冲刺

无敌时间比移动多持续0.15秒。正是落地后的这段余量让你能冲刺*穿过*障碍物

冲刺期间由你控制方向。冲刺朝你要求的方向前进：沿着按住的方向，或者朝瞄准点，并且可以在冲刺途中改变。没有按住方向的冲刺不会移动

使用光标时，冲刺朝你指向的地方前进并停在那里：

| 与光标的距离 | 会发生什么 |
|---|---|
| 超过7.5单位 | 朝它完整冲刺。你会停在光标之前 |
| 0.01到7.5单位 | 缩短的冲刺，正好结束在光标上 |
| 小于0.01单位 | 不冲刺 |

缩短的冲刺就是缩小比例的同一个冲刺。路程、无敌时间和冷却一起缩小：短一半的冲刺保护时间少一半，冷却也快一倍。它不会更划算。两次半程冲刺的代价正好等于一次完整冲刺，走过的距离也相同

没有发生的冲刺没有任何代价：冷却不会开始，也不消耗任何东西。使用方向操控却什么都没按的玩家得到同样的结果：不冲刺

冲刺时身体变成更深的蓝色，之后在0.15秒内恢复正常颜色。没有别的东西会改变身体颜色，被命中也不会。冲刺是你自己的动作，所以只有它会改变颜色

冲刺拖尾和这种蓝色取决于冲刺长度：完整冲刺完全显示，最短的冲刺显示`0.3`，介于两者之间的按比例显示。短冲刺的粒子飞得更慢，所以拖尾看起来正好和冲刺一样长

### 两种风格，同一份预算

- 在`方向`模式下，冲刺总是走满7.5单位。距离可靠，无需瞄准，但也无法中途停下
- 使用光标时由你选择长度，可以正好停在某一点。短冲刺意味着更短的保护，以及每次冲刺多一个可被命中的帧。指向远处，完整冲刺就会回来

沿直线移动时，两者在相同时间内走过相同距离。哪种风格都不更强：一种提供精确，另一种提供简单

### 连续冲刺

**按住冲刺不等于无敌**。冷却和保护时长相同，所以按住按键会产生连续不断的冲刺链。但两次冲刺之间总有正好一帧可以被命中，任何帧率下都是如此，慢手机和快电脑一样

最密集的冲刺链是最多每隔一帧冲刺一次

## 判定框

化身上的圆点圆环正好沿着判定框绘制。子弹擦过轮廓却什么也没发生？这是有意为之

当你处于无敌状态时（冲刺中或刚被命中之后），完全没有判定框

同一个圆环也显示生命：亮着的点是一条剩余的命

圆环的明显程度由`设置`→`界面`→`判定框圆环不透明度`决定。`0`会隐藏它，但关卡是按能看到圆环的玩家来平衡的

身体是由25个方块组成的5×5网格。失去生命值时，方块从边缘到中心不是消失而是变暗：失去的方块留作淡淡的残影，所以网格总是显示全部25个，生命值通过仍亮着的方块数量来读取

残影方块足够透明，可以透过它们看到身体下方的判定框圆环

生命值为零时正好亮着一个方块，也就是最后一个

任何生命值的减少都在`0.25`秒内显示，任何恢复都在`0.6`秒内显示，不论涉及多少条命

如果关闭`图形`→`碎裂效果`，身体会变成一个会变暗的方块。这是为性能较弱的设备准备的

## 出现与消失

化身在`0.3`秒内在关卡中长大出现，死亡时在`0.3`秒内缩成一点。两种情况下它都不响应输入，出现期间也无法被命中

## 缩放

关卡可以用自己的轨道为化身的尺寸和速度制作动画。它还可以暂时收回操控，或关闭碰撞

- 行走、冲刺和击退的速度乘以同一个数。所以在一半速度下，冲刺也短一半（3.75单位）
- 更大的化身按比例移动得更快，因为它的闪避也变大了。这里的尺寸是化身自己的尺寸，来自玩家尺寸轨道。相机缩放不改变速度、距离和时间窗口：不论相机怎样，化身都每秒移动15单位
- 判定框是绘制身体的一部分，所以随化身一起变大变小
- 冲刺瞄准使用当前的距离，而不是表中的7.5。在一半速度的关卡中，3.75单位外的光标就已经要求完整冲刺，0.01单位的阈值变成0.005，因为高于它的冲刺也短了一半
- 以秒计的时间窗口不缩放：冷却、无敌时间、伤害间隔、出现。只有冲刺本身的长度会缩放它自己的两个时间窗口

机器人遵循同样的规则，[[9_bots]]
