# gv 0.11.1

關卡也可以通過.zip傳遞，時間軸有了框選工具和摺疊，衝刺取決於距離

沒有`gv 0.11.0`：版本號從`gv 0.10.1`直接跳到了`gv 0.11.1`

- 關卡可以匯出和匯入為`.zip`，而不只是`.tar.gz`，也可以帶密碼。`.7z`檔案會按名稱識別並拒絕，而不是被錯誤讀取。關卡的“包”在遊戲中各處都改稱歸檔包（`關卡歸檔包`）
- 衝刺到比完整距離更近的點，是按比例縮短的衝刺：路徑更短，無敵時間更短，冷卻也更短。目標近於衝刺距離的三分之一時完全不會衝刺
- 沒有方向的衝刺不會執行。以前它會飛向一個你沒有選擇的任意方向
- 衝刺在每一幀都可以操控，完整衝刺後的無敵時間為0.30秒，而不是0.20秒。這等於冷卻時間，所以連續不停地衝刺時，你在兩次衝刺之間恰好暴露一幀
- 時間軸工具：`選擇`、`邊緣`、`剪刀`和新的`框選`工具，後者會把拖出的矩形碰到的所有片段加入選中項。`邊緣`和`剪刀`以前叫Trim和Blade
- `剪刀`可以把一次預製件放置切成兩半，兩半都會從切開的位置繼續播放同一個模板
- 子樹可以在時間軸上摺疊：用`選擇`工具雙擊片段、標籤頁行中的按鈕、層級行的選單或`Ctrl+E`。摺疊不會向關卡寫入任何內容，也不會產生撤銷步驟
- 工具提示現在會出現在釋出的遊戲中，而不只是在Unity內執行時出現。在觸屏上，長按即可開啟工具提示。帶快捷鍵的操作的工具提示會顯示該快捷鍵當前的繫結
- 200多條原本只有英文的文本已經翻譯
