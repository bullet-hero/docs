# gv 0.11.2

層級和時間軸中的摺疊變成了三檔模式，編輯器在手機上有了完整的音訊

- 層級和物體時間軸上的摺疊按鈕在三檔之間切換：全部展開、部分、全部摺疊。“部分”會讓你選擇的物體型別保持展開。按住按鈕即可選擇它們，也可以在`編輯器` > `介面` > `部分摺疊`中設定
- 在關卡編輯器中，音訊在所有平臺上（包括手機）都會被完整解碼。壓縮的音軌不繪製波形，定位時會跳到最近的資料塊，而不是你想要的那一幀。在手機上的遊戲中，音訊仍然保持壓縮
- 音訊軌道上的`適配關卡`會同時延長軌道和關卡，直到片段完整放下。關卡只會變長，已經放得下的片段不會改變任何東西
- 新增其他格式的音訊檔案時，遊戲會說明支援哪些格式：`.mp3`、`.wav`和`.ogg`
- 設定中的一個按鈕可以摺疊所有分割槽或全部展開
- 在編輯器中用鍵盤移動預覽化身時，不再每次移動都讓畫面凍結119毫秒
