# 版本0.14.0

特效按制作时的样子播放，可以从物体上移除特效，新增两个编辑器快捷键

## 特效

- 特效沿其自身物体所指的方向发射，在时间轴上后退一步时绘制的内容与播放时一致。以前喷射方向固定在世界空间中，所以同一帧在播放时可能显示一道弯曲的轨迹，后退一步后又显示一道笔直的轨迹
- `点`以外的发射形状（`圆形`、`线段`、`锥形`、`圆环`）会随物体一起旋转。以前它们始终与世界对齐，所以旋转过的特效会沿着与自身无关的轴生成粒子
- 特效在屏幕外也会继续模拟，因此本应飞入画面的粒子在到达之前就已存在。以前相机之外的发射器什么都不生成，这就是为什么特效在编辑器中看起来正常，在游戏中却不见了。代价是屏幕外的特效也要占用GPU时间
- **现有关卡的不兼容变更**。特效的线性力现在是每秒的加速度，与格式一直以来的描述一致。以前在50Hz的特效频率下，它的作用大约强50倍。设置了它（`lfrc`）的关卡需要重新调整：一个受力`(1, 0)`的粒子现在1秒移动0.51个单位，此前为25.5

## 编辑器

- `Ctrl+Shift+A`（`取消全选`）一次清除所有选中项：物体、关键帧、音频和节拍。`Ctrl+Shift+E`（`退出预制件模式`）退出所有打开的预制件模式会话。两者都可以像其他快捷键一样重新绑定
- 特效选择器提供`无`选项，因此可以从物体上移除特效。以前一旦设置了特效，选择器就无法清除它
- 在编辑器内打开另一个关卡会重建物体列表，预制件模式会与打开它的关卡一起关闭
- 在视图边缘附近双击时间轴片段，不再把物体向上拖一行。以前边缘滚动在按下时就开始了，所以视图会在静止的指针下移动，这次移动就变成了图层的改变
- [[12_launch-arguments|启动参数]]`--autosave on|off`在单次启动中开启或关闭编辑器的自动保存，不改动设置
