# gv 0.15.0

Ein Level mit animierten Bildschirmgrenzen braucht auf Android 19 ms pro Frame statt 30-45

- Ein Level, das sein Seitenverhältnis mit dem Ereignis `Bildschirmgrenze` animiert, braucht auf Android 19 ms pro Frame statt 30-45. Die Kamera nimmt jetzt immer den ganzen Bildschirm ein, und die Balken kommen erst hinzu, wenn das Bild auf den Bildschirm gebracht wird. Deshalb erzeugt der Renderer seine Bilder nicht mehr in jedem Frame neu, in dem sich die Balken bewegen
- Maus und Berührungen lesen dieselben Balken, so landet der Zeiger auf einem Level mit Balken weiterhin dort, wohin er zeigt

Commits: Spiel `9f5d9143`, SDK `57b5af5b`
