# 預製件模式

在預製件模式中，你編輯的是模板，儲存會把改動帶到它的每一個放置。用放置檢視器中的“編輯預製件”按鈕進入，用Ctrl+Shift+E回到關卡

## 預製件模式

> [!caution] 注意
> 你正在編輯模板，而不是它的某一個放置。儲存會把改動帶到引用此模板的每一個放置

放置的工作方式：
- 當你讓一個放置指向某個模板時，這個放置會得到模板中物體的真實副本，並帶有永久ID。在編輯器中，預製件的子物體完全是普通物體
- 關卡檔案只儲存放置本身：模板、副本的ID和覆蓋。每次載入關卡時，副本都會根據模板重新構建
- 放置可以通過**例項覆蓋**與模板不同。在預製件模式**之外**編輯這樣的物體時，就會記錄覆蓋
- 在預製件模式中做的編輯不會記錄覆蓋。它們改變的是模板本身

> [!tip] 提示
> 模板會一層層疊加開啟。模板內的放置會開啟它自己的模板，`{{ui:editor_prefab-timeline_close}}`會帶你回來。同一個模板不能同時開啟兩次。巢狀最多8層

## 進入與退出

有兩種進入方式：
- 放置的檢視器中的`{{ui:editor_inspector-prefab_edit}}`
- 關卡設定`預製件`標籤頁中模板所在行的`{{ui:editor_level-prefab-item_edit}}`。它不需要放置，所以也能開啟沒有放置在任何地方、或只放置在另一個模板內部的模板

右鍵選單和命令面板中的`{{ui:editor_context-menu_open-prefab}}`，對選中的放置或放置帶來的物體起同樣的作用。模板中對應的物體會立即被選中

有兩種退出方式：
- 預製件時間軸上的`{{ui:editor_prefab-timeline_close}}`退出一層，回到開啟當前模板的那個模板
- 主工具欄上的狀態（`正在編輯“...”`）和`Ctrl+Shift+E`會一次退出所有開啟的模板，回到關卡

每次進入或退出時，選中項都會被清空。退回一層時，會恢復那個模板中原來的選中項

在模板內部，選擇的方式與在關卡中相同：單擊、按住`Ctrl`單擊、框選、刪除、複製和摺疊。在視口中單擊不會選中任何東西：視口仍然顯示關卡，其中沒有模板的即時預覽

## 模板內部

模板的所有物體都掛在它的**根**下面。根：
- 橫跨整個模板。它的長度是`{{ui:editor_prefab-mode-frame_length}}`，在根的檢視器中和`預製件`標籤頁上是同一個數字
- 不能被刪除，也不能設定父級
- 它的`{{ui:field_common_active}}`和`{{ui:editor_inspector_layer}}`是隻讀的。這兩項屬於每個放置

如果恰好選中了一個物體（包括根），新物體會放到它下面。否則新物體會放到模板的頂層，也就是根下面。新物體橫跨它父級的整個時段，兩端都帶錨點。在頂層，這就是整個模板

需要整個關卡的生成器在這裡不可用。在模板內部，從選中項建立預製件和展平放置也會被拒絕

## 從選中項建立預製件

把選中的物體變成一個新模板，並在它們原來的位置放置這個模板的一個放置。之後關卡的外觀和玩法都不變

在哪裡找到它：
- 層級中一行的選單裡的`{{ui:editor_context-menu_pack-prefab}}`
- 視口的右鍵選單
- 命令面板中的`{{ui:cmd_editor_pack-prefab}}`，`Ctrl+G`
- 關卡設定`預製件`標籤頁中的`{{ui:settings_level-settings_resources-prefabs-pack}}`

它不會請求確認，只佔一步撤銷。新的放置最後處於選中狀態。只有一個物體時，模板使用該物體的名稱。有多個物體時，模板名為`Prefab`。可以在關卡設定的`預製件`標籤頁中重新命名

以下情況會被拒絕：
- 放置，或放置帶來的物體。對於這些，選單會改為提供`{{ui:editor_context-menu_open-prefab}}`
- 會導致巢狀超過15層的選中項。不會寫入任何內容，訊息會說明這一點

## 展平放置

斷開放置與模板的關聯：它的物體變成普通的關卡物體，並保持在原來的位置

在哪裡找到它：放置的檢視器、層級中一行的選單以及命令面板中的`{{ui:editor_inspector-prefab_flatten}}`

它總是先請求確認。展平之後關卡看起來完全一樣，所以如果誤操作展平了，往往要很久以後，當編輯模板不再影響它時才會發現。選中多個放置時，只會有一次確認和一步撤銷

放置帶來的物體不能單獨展平。請展平它所屬的放置

## 同時展平巢狀的預製件

決定你展平的預製件內部的那些預製件會怎樣

**關**：只有你選中的這個放置不再跟隨模板。放置在它內部的預製件仍然是放置，保留自己的關聯。編輯那個內部模板仍會影響關卡。這是預設值：通常說“解包這個預製件”時，要的就是這個。每次開啟確認視窗時，這個開關都是關閉的

**開**：所有巢狀的內容也一併展平。按下一次之後，關卡中不再有任何內容與這些內部模板關聯，無論巢狀多深

無論哪種方式，模板本身都會保留在關卡中。整個展平只佔一步撤銷
