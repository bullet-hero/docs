# Direitos

Um nível que você publica só pode conter arquivos com licença aberta não mais restritiva que CC BY-NC ou com a permissão do autor. Um nível para uso próprio pode ser feito com qualquer coisa

A verificação é ativada quando o nível sai do seu disco para um servidor ou para o site
