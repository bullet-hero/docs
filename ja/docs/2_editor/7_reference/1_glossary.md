# 用語集

プロジェクトの主要な用語の一覧です。ゲームのインターフェース、このドキュメント、Bullet Heroに関するほかのすべての文章がこれらの言葉を使います。新しい用語はまずここに追加します

## レベルの内容

| 用語 | 意味 |
|---|---|
| **レベル** | 1回のプレイを構成するすべて：オブジェクト、オーディオ、イベント、独自のリソース |
| **オブジェクト** | タイムライン上で作者が作る1つのもの。独自の存続期間、トランスフォーム、親を持ちます |
| **空オブジェクト** | 何も描画しないオブジェクト：トランスフォーム、存続期間、子だけを持ちます。ほかのタイプはすべて、この上に独自の要素を加えます |
| **シェイプ** | オブジェクトが描画する実際のジオメトリで、画像ではありません。ゲームが約500種類を自分で生成します |
| **コライダー** | オブジェクトが当たる範囲。オブジェクトが描画するものと一致しなくてもかまいません |
| **プレハブ** | 再利用できるオブジェクトのテンプレート。レベルに何度でも配置できます |
| **プレハブモード** | 周囲のレベルではなく、テンプレート自体の中身を編集すること |
| **エフェクト** | スポナーです。毎フレーム、いくつかのパラメーターから自分のオブジェクトを生成します |
| **フレーム内オブジェクト** | エフェクトが生成したオブジェクト。エンジンが管理するため、選択も編集もできません |
| **テーマ** | レベルがインデックスで参照するパレット。色の変更は100か所ではなく1か所で済みます |

## 時間とアニメーション

| 用語 | 意味 |
|---|---|
| **フレーム** | レベルの時間の単位。フレームはマス目で、時間は2つのマス目の境界です |
| **キーフレーム** | あるフレームで作者が決めた1つの値。2つのキーフレームの間では値が補間されます |
| **トラック** | アニメーションできるプロパティ1つ分のキーフレームの行：位置、回転、音量 |
| **タイムライン** | レベルを編集するフレームの軸。内容の種類ごとにタブが1つあります |
| **スパン** | オブジェクトが存在する期間：開始フレームと長さで表し、終了フレームでは表しません |
| **再生ヘッド** | 今表示しているフレーム |
| **イージング** | 前のキーフレームからこのキーフレームへの値の動き方 |
| **マーカー** | レベルのルーラー上の名前付きの点。目的の位置に戻るためのものです |
| **チェックポイント** | 死亡したプレイヤーが戻される位置 |

## 配置と描画

| 用語 | 意味 |
|---|---|
| **アンカー** | 親の辺に追従する辺。親を縮めると、子も一緒に動きます |
| **レイヤー** | 描画順で、相対値です：子のレイヤーには親のレイヤーが足されます |
| **ピボット** | オブジェクトの回転と拡大縮小の中心になる点。オブジェクト自身のボックスの中にあります |
| **ギズモ** | ビューポートで選択中のオブジェクトの上に描かれるドラッグ用ハンドル |
| **スナップ** | ドラッグを何かに吸い付けること：磁石がオンなら内容に、ビートのトグルがオンなら音楽に吸い付きます |

## 音楽

| 用語 | 意味 |
|---|---|
| **ビート** | 音楽自体のグリッド。作者が設定し、プレイ中は何もこれを読みません |
| **ビートセグメント** | テンポが一定の1つの区間。独自のテンポ、位相、小節の長さを持ちます |
| **BPM** | 1分あたりの拍数。ビートセグメントの速さを表します |
| **タップ** | テンポを打ち込むときの1回の押下。十分な数のタップでビートセグメントが決まります |

## 自動化とデータ

| 用語 | 意味 |
|---|---|
| **ジェネレーター** | 制作の自動化：いくつかのパラメーターからレベルの内容を作ります |
| **モディファイアー** | 追加する代わりに、既存の内容を編集または削除するジェネレーター |
| **シード** | レベル内のすべてのランダム値の元になる数。何度実行してもまったく同じに再現されます |
| **生データ** | 保存モデル全体を1つの編集可能なツリーにしたもの。ここでは何も検証されません。これは意図的です |
| **AIアシスタント** | MCPでエディターに接続したAIクライアント。目の前で開いているレベルを編集し、1回のバッチが元に戻す操作1回分になります |

## リソースと共有

| 用語 | 意味 |
|---|---|
| **ライブラリ** | レベルをまたいで再利用するための、デバイス上のリソース：自分のライブラリ、自分のコレクション、サブスクライブしたコレクション |
| **コレクション** | 最大7種類の再利用可能なリソースを入れるフォルダー。インポートはそこからコピーするので、レベルはコレクションに依存しません |
| **難易度** | レベルの難しさ：作者が設定し、モデレーターが上書きできる1つの数。プレイヤーには`{{ui:enum_difficulty-tier_auto}}`から`{{ui:enum_difficulty-tier_singularity}}`までの段階として見えます |
