# Links und Community

Gespräche und Fragen gehören auf Discord, Videos auf YouTube, Bugs im Spiel in die Issues des Repositorys bullet-hero/releases. Der Quellcode liegt in der Organisation bullet-hero auf GitHub

Alles, was du herunterladen kannst: das Spiel, das SDK, die Stores - [[download]]

## Quellcode

Alle Repositorys liegen in der Organisation [bullet-hero](https://github.com/bullet-hero)

| Repository | Zugang | Was dort liegt |
|---|---|---|
| [bullet-hero/game](https://github.com/bullet-hero/game) | geschlossen | das Spiel und der Editor |
| [bullet-hero/sdk](https://github.com/bullet-hero/sdk) | offen | das SDK, Issues zum SDK und seinem Code |
| [bullet-hero/releases](https://github.com/bullet-hero/releases) | offen | Builds des Spiels, Issues von Spielern |
| [bullet-hero/docs](https://github.com/bullet-hero/docs) | offen | diese Dokumentation |
| [bullet-hero/backend](https://github.com/bullet-hero/backend) | offen | der Server, vorerst leer |
| [bullet-hero/frontend](https://github.com/bullet-hero/frontend) | geschlossen | die Website |
