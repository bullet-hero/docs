# gv 0.15.0

画面制限をアニメーションさせるレベルは、Androidで1フレームあたり30～45msではなく19msで済むようになりました

- `画面制限`イベントでアスペクト比をアニメーションさせるレベルは、Androidで1フレームあたり30～45msではなく19msで済みます。カメラは常に画面全体を使い、帯はフレームを画面に出すときに追加されます。そのため、帯が動くフレームごとにレンダラーが画像を作り直すことはなくなりました
- マウスとタッチも同じ帯を読み取るので、帯のあるレベルでもポインターは指している場所に正しく当たります

コミット：ゲーム`9f5d9143`、SDK `57b5af5b`
