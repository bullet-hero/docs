# gv 0.11.1

レベルは.zipでも移動でき、タイムラインに矩形選択ツールと折りたたみが加わり、ダッシュは距離に応じて変わります

`gv 0.11.0`はありません：番号は`gv 0.10.1`から直接`gv 0.11.1`に進みました

- レベルは`.tar.gz`だけでなく`.zip`としてもエクスポート・インポートでき、パスワード付きにも対応します。`.7z`ファイルは誤って読み込まれるのではなく、名前で判別されて拒否されます。レベルの「パッケージ」は、ゲーム内のどこでもアーカイブと呼ばれるようになりました（`レベルアーカイブ`）
- 最大距離より近い地点へのダッシュは、距離に比例して短いダッシュになります：移動距離、無敵時間、クールダウンがすべて短くなります。最大距離の3分の1より近い場合はダッシュしません
- 方向のないダッシュは行われません。以前は、選んでいない任意の方向に飛んでいました
- ダッシュは毎フレーム操作でき、フルダッシュ後の無敵時間は0.20秒から0.30秒になりました。これはクールダウンと同じなので、間を空けずにダッシュすると、2回のダッシュの間で無防備になるのはちょうど1フレームです
- タイムラインのツール：`選択`、`エッジ`、`ハサミ`、そして新しい`矩形選択`ツールです。矩形選択は、ドラッグした矩形に触れたクリップをすべて選択に追加します。`エッジ`と`ハサミ`は、以前はTrimとBladeという名前でした
- `ハサミ`でプレハブの配置を2つに切れます。両方の半分は、切った位置から同じテンプレートを再生し続けます
- タイムライン上でサブツリーを折りたためます：`選択`ツールでクリップをダブルクリック、タブの行のボタン、ヒエラルキーの行のメニュー、または`Ctrl+E`です。折りたたみはレベルに何も書き込まず、元に戻すステップも作りません
- ツールチップが、Unity内で実行したときだけでなく、リリース版のゲームでも表示されるようになりました。タッチスクリーンでは長押しでツールチップが開きます。キーボードショートカットのある操作のツールチップには、現在割り当てられているショートカットが表示されます
- 英語のみだった200以上のテキストが翻訳されました
