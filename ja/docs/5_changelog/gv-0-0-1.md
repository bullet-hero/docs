# gv 0.0.1

最初の描画テスト：Unity Entitiesで大量のオブジェクトを描画し、すでにAndroidで動作します

開始から3日後、プロジェクトに技術的な土台ができました。オブジェクトは*Unity Entities*（ECS）で描画され、ゲームは今もこの方式の上に成り立っています。テストシーンは画面をオブジェクトで埋めてその色を変え、描画順は各オブジェクトの深度から決まります

- テストビルドはすでにAndroidで動作します
- レベルのデータモデルは別のプラグイン、のちのSDKに切り出されました
- 最初のスプライト（シェイプ、インターフェースのアイコン、スキン）は以前のプロジェクトから移されました

同じころ独自のレンダーパイプラインも検討されましたが、見送られました。標準の*URP*で十分だったためです

コミット：ゲーム`44c04ca4`、SDK `1411a228`
