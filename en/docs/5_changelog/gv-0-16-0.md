# gv 0.16.0

Files from a newer version do not open and the game asks to be updated, an anonymous mode without saves, and a faster editor on large levels

## Versions and saves

- A file from a newer version of the game does not open, and the `Update required` window appears instead: this happens with a level, with an imported archive and with editor content on the clipboard. `Download` opens the download page on the site. In the level list such a level is marked `From a newer version of the game`. Before, the editor offered to open a newer level after a warning
- Settings or statistics saved by a newer version stay untouched. The game runs on default values, saves nothing of its own until it is closed, and asks what to do: `Keep saves suppressed` or `Overwrite data`. A level whose own statistics are newer shows an explanation on its card instead of the best result
- A new setting, `Suppress game saves (anonymous mode)`. While it is on, the game writes neither settings nor statistics, and what you played during that time does not reach the disk. The [[12_launch-arguments|launch argument]] `--suppress-game-saves` turns it on for the whole launch
- When `--autosave` sets the editor's autosave for this launch, the `Autosave` setting says so

## Game

- When you steer with the mouse button held, passing over the pause button no longer interrupts steering. A press that started on the level stays steering wherever you take it, and one that started on a button stays with the button
- A cursor dash to a point closer than one unit is no longer ignored. Any target the avatar is not already standing on gets a dash shortened by the distance
- On Android the game needs Vulkan, so Google Play no longer offers it to devices without Vulkan. Those devices showed a black screen

## Editor

- The editor is faster on large levels. A timeline or panel that is not on screen is no longer rebuilt on every edit and catches up when it is shown. The question "which placement does this copy belong to" is answered from one index per edit, not by a pass over the whole level for every selected object, field and keyframe track
- An edit no longer resets the selection of event and audio keyframes, and no longer clears the keyframe selection on the Local timeline
- An ordinary edit no longer plays the undo and redo sound. Only undo and redo play it
- A click on two clips with the same span selects the one drawn on top. Before, the hidden one was selected, and in Prefab Mode a click on the content of a nested template selected its placement every time
- Leaving a nested prefab no longer throws the error `Collection was modified` when the outer template had a selection to restore
