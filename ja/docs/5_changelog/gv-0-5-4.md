# gv 0.5.4

あらゆる場所のベクターグラフィックス、HUDの体力表示、完全なカラーカーブ、垂直同期、そしてレベル一覧に並ぶSteamワークショップのレベル

- アイコンとインターフェースの画像は、すべてテクスチャではなくベクター（SVG）になりました
- HUDは進行状況バーの上に、ライフを点の列で表示します。失ったライフは点が消えるのではなく暗くなるため、列の長さは変わりません。無敵のときは列が空になります
- カラーカーブはURPエンジンの8本のカーブになりました：`マスター`、`赤`、`緑`、`青`、`色相/色相`、`色相/彩度`、`彩度/彩度`、`輝度/彩度`。2つの値だけの古いカラーカーブを使うレベルは、読み込み時に変換されます
- 修正：デフォルト値のカラーカーブのキーフレームで、画面が灰色になり、色相が半回転していました
- `垂直同期`の設定。値は`オフ`、`オン`、`1/2レート`で、デスクトップのみです。オンの間はフレームレートの上限が効きません
- Steam版：Steamワークショップでサブスクライブしているレベルがレベル一覧に表示されます。`見つかったコンテンツをすべて表示`をオンにすると、ディスク上にはあっても自分のものと確認されていないもの、たとえばサブスクライブしていないアイテムや手でコピーしたフォルダーも表示されます。そうしたレベルはカードに`未サブスクライブ`または`オフライン`の印が付きます
- レベルの作者それぞれに`担当`フィールドがあります：音楽、カバー、テストプレイなど
