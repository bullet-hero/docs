# gv 0.0.1

第一次绘制测试：通过Unity Entities绘制大量物体，并且已经能在Android上运行

开工三天后，项目有了技术基础。物体通过*Unity Entities*（ECS）绘制，游戏至今仍建立在这种方式上。测试场景用物体填满屏幕并改变它们的颜色，绘制顺序取自每个物体的深度

- 测试版本已经能在Android上运行
- 关卡数据模型移到了一个单独的插件中，也就是后来的SDK
- 第一批精灵图（形状、界面图标、皮肤）从一个更早的项目迁移过来

同一时期还考虑过自己的渲染管线，后来放弃了：标准的*URP*已经够用

提交：游戏`44c04ca4`，SDK `1411a228`
