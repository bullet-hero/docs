# 版本0.10.1

新的内置关卡，版本行中注明构建信息，Android发行包更小

- 游戏自带的两个测试关卡被一个演示关卡`New zero demo`取代
- 设置中的版本行除了版本号，还会注明构建：`gv X, sv Y, mg Z, Windows, Steam, Release`，也就是平台、商店和构建类型。每份日志的第一行也写着同样的内容，因此错误报告和它的日志总是指向同一个构建
- 关卡浏览器中的每个来源筛选一开始都是开启的，即使只有一个来源，也会显示来源行。以前，存在但被筛选掉的关卡看起来就像消失了一样
- 发行构建不再包含调试符号。在Android上，124.9MB的发行包因此减少了25.7MB
