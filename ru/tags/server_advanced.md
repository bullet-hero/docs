# Опытный владелец сервера

Крупный владелец, готовый запустить публичный сервер, расширить официальный или написать собственный

Сервера пока нет, поэтому эти страницы собирают то, что решено об официальном сервере OWS и общественных серверах NOWS, и то, что SDK уже делает для них. Они будут переписаны, когда появится бэкенд
