## 版本

每个产品都有自己的版本号，带一个字母前缀，格式都是`major.minor.revision`：

| 前缀 | 全称 | 产品 |
|---|---|---|
| `gv` | `game version` | 游戏（客户端） |
| `sv` | `sdk version` | SDK |
| `bv` | `backend version` | 后端，即服务器 |
| `fv` | `frontend version` | 网站 |
| `mg` | `model generation` | 数据 |

写法：`gv 1.0.0`、`sv 1.0.0`、`bv 1.0.0`、`fv 1.0.0`、`mg 1`

详细说明见[[5_versioning]]
