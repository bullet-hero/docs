# 操作

可以用哪些设备游玩，如何用它们移动和冲刺，以及哪些可以重新绑定

想一步步学习操作，或者不开关卡就试遍所有模式：[[13_sandbox]]

## 设备

所有操作都在`设置`→`操作`中设置，每种设备一组

| 设备 | 默认模式 | 移动 | 冲刺 |
|---|---|---|---|
| `键盘和鼠标` | `绝对` | 按住左键，化身跟随鼠标 | `Space`、`Shift`、鼠标右键或双击（0.3秒内） |
| `触屏` | `相对` | 在屏幕任意位置拖动手指 | 第二根手指 |
| `手柄` | `方向` | 任意一个摇杆 | 除`Start`和`Select`以外的任意按键 |
| `体感` | `方向` | 让设备偏离水平放置的姿态，倾斜20°时达到全速 | 点按屏幕任意位置 |

只用鼠标就够了：左键控制方向，`冲刺按钮`用来冲刺。键盘不是必需的

在手柄上，`Start`用于暂停和继续。手柄的按键不能重新绑定：游戏中除`Start`和`Select`以外的每个按键都会冲刺，包括右侧的正面按键。在暂停菜单中，右侧的正面按键用于返回，和其他菜单一样

## 操作模式

| 模式 | 你的输入代表什么 |
|---|---|
| `绝对` | 一个位置。光标跳到那里，化身追着它移动 |
| `相对` | 一段移动。光标把它累加起来，化身追着光标移动 |
| `方向` | 一个方向。完全没有光标 |

在所有模式下移动都是即时的：没有加速，也没有滑行

在光标模式下，化身以自己的行走速度追赶光标。所以鼠标移动很快时，化身会落在后面。冲刺朝光标方向进行。如果光标离得近，冲刺会更短，并正好停在光标上

松开控制方向的按键或抬起手指之后会发生什么，由一个复选框决定 - 鼠标是`松开时停止`，触摸屏是`抬起手指时停止`：

- 开启 - 化身停在原地，光标回到化身身上。鼠标默认开启
- 关闭 - 光标留在你放开的位置，化身继续走到那里。只有受到伤害才会移动光标。触摸屏默认关闭

在`方向`模式下，摇杆推到一半就是一半速度。冲刺总是冲满全程

在触屏的`绝对`模式下，光标位于手指上方（`手指偏移Y`）。这样手指不会挡住化身

一根手指控制化身时，第二根手指无论落在哪里都会冲刺，落在面板或按钮上也一样。界面会忽略这次触摸，所以冲刺永远不会误按任何东西

## 体感

体感操作不需要校准。手机屏幕朝上平放时，化身保持不动

- 让右边缘向下倾斜，化身向右移动
- 让上边缘向下倾斜，化身向上移动
- `灵敏度`为1时，倾斜20°达到全速。为2时，一半的倾斜角度就够了

它跟随屏幕方向：把手机转到横屏再转回来，右依然是右。体感有两种模式：`绝对`和`方向`

## 重新绑定

- **游戏操作**在`操作`中：模式、`冲刺按键`、`冲刺按钮`、灵敏度、死区、平滑、反转、屏幕摇杆和冲刺按钮。`重置操作设置`会把所有设备恢复为当前平台的默认值
- **键盘快捷键**在`快捷键`中，几乎都是编辑器的快捷键。编辑器之外有`切换全屏`（默认`F11`）和导航按键。`重置快捷键`会撤销所有重新绑定

游戏等待按键时会显示`请按下要绑定到“...”的按键`。此时的规则是`点按或Esc取消，Backspace解除绑定`

对于快捷键，游戏只保存你重新绑定过的部分。如果以后某个默认绑定有所改进，你会得到这项改进，除非你自己改过这个绑定。`操作`标签页会被完整保存，所以以后它的默认值有变化也不会影响你

编辑器的快捷键：[[3_speed-and-shortcuts]]

## 同时使用多个设备

控制化身的只有一个设备：你最后使用的那个。切换会自动发生，在同一帧内完成，不需要任何菜单

游戏每帧都会读取所有已启用的设备。没被碰过的手柄报告的是零，这不算使用

第一帧时还没有使用过任何设备，所以由平台决定：电脑上是鼠标，手机上是触屏

冲刺和暂停在所有已启用的设备上都有效，无论当前由哪个设备控制方向。鼠标控制方向时，手柄按键也能冲刺。单独一次冲刺不会接管方向控制

一个设备只有在以下情况下才能控制方向：

- 它被勾选为启用
- 平台支持它
- 它此刻已连接

顶部的`当前启用`显示当前由哪个设备控制

> [!tip] 提示
> 某种操作方式好像没有反应？通常是在它之后碰了另一个设备。先看`当前启用`
