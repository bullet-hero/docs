# 机器人

机器人替你游玩关卡时做了什么、不承诺什么、代价是什么，以及两种机器人有何不同

**机器人用你的操作方式替你游玩关卡**。它观察即将到来的东西，寻找空位，移动的是和你一样的角色。它会行走、冲刺、受到伤害和死亡

**机器人不保证通关**。它从不疲倦，但可能失败。如果某个弹幕必须提前一秒就正确进入，机器人就会被击中。发生这种情况并不代表有什么坏了

**机器人会增加设备负载**。寻找空位是每一帧都要做的实际计算。在性能较弱的设备上，帧率会降低。在复杂的关卡中，开头几秒最明显

要选择机器人，请使用关卡界面上的`机器人`选项：`无机器人`、`Reflex Bot v1`或`Warm Bot v1`。它和生命、速度一样，每局单独选择

> [!info] 须知
> 机器人无法作弊，这是由它的构造决定的，而不是一句承诺。它拥有和你相同的操作，仅此而已：相同的速度、相同的冲刺、相同的判定框、相同的伤害。你穿不过的东西，它也穿不过

## 关卡打败了机器人？

机器人会在它从未见过的关卡上变得更好。这样的关卡值得提交

在[bullet-hero/releases](https://github.com/bullet-hero/releases/issues)提交issue。说明是哪个机器人在哪里失败了，并附上关卡文件夹

## 两种机器人

机器人每帧产生一个输入，和键盘产生的输入是同一种，除此之外什么都没有。它无法获取化身的位置、生命值或关卡的状态。如果机器人在某一帧没有给出输入，那一帧就由你自己的设备操控

| | `Reflex Bot v1` | `Warm Bot v1` |
|---|---|---|
| 它知道什么 | 接下来的1.5秒，每帧重新计算 | 整个关卡，一次性算好 |
| 何时占用设备 | 每一帧，只要它在运行 | 一次，在开始之前 |
| 它能做什么 | 避开能预见到的东西 | 执行任何前瞻都找不到的计划 |
| 什么会让它失败 | 必须提前一秒进入的弹幕 | 关卡在它脚下发生变化 |
| 如何操控 | 方向 | 目标点 |

`Warm Bot v1`的目标是零伤害。为此它要多一个加载阶段：`计算路线`，可能需要几十秒

计算之前游戏会提醒你。`取消`会停止计算，把这一局交还给你。`Warm Bot v1`的路线取决于种子，[[8_determinism]]

## 机器人还会在哪里游玩

- **编辑器的预览玩家**：`设置`→`编辑器`→`由机器人操控玩家`。那里只有`Reflex Bot v1`：它不需要任何准备，拖动播放头也不会出问题。更多：[[5_bot-playtest]]
- **主菜单背景**：按钮后面的竞技场就是`Reflex Bot v1`在实时游玩，完全没有前瞻

机器人是纪录条件的一部分。所以由机器人完成的一局永远不会取代你自己的最佳成绩，[[10_statistics]]
