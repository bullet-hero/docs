# gv 0.5.1

プレイヤー向けにチェックポイント、統計、新しい操作、翻訳されたインターフェース、作者向けに履歴ツリーとビートグリッド、そしてスマートフォンでは4倍速い描画

## ゲーム

- チェックポイントが機能します。死亡すると、プレイは最後に到達したチェックポイントまで巻き戻されます：レベルのクロックが0.5秒かけて滑らかに止まり、巻き戻り、また滑らかに加速します。`失敗時にメニューを開く`をオンにすると、代わりに結果ウィンドウが表示されます
- 統計がディスクに保存されます。レベル画面には選んだ起動オプションごとの`ベスト`と`挑戦回数`が表示され、設定の`プロファイル`タブには起動回数と、ゲーム、メニュー、エディターで過ごした時間が表示されます
- 操作を4つのデバイス向けに書き直しました：`キーボードとマウス`、`タッチスクリーン`、`ゲームパッド`、`モーションセンサー`。タッチスクリーンには画面上の操作ボタンが付きました
- どのキーボードショートカットも`キー割り当て`タブで割り当て直せ、変更はゲーム全体に適用されます
- `メニューの背景`では`なし`、`シェイプ`、`ボット`を選べます。新しいデフォルトは`ボット`です：ボットがアバターを操作し、リアルタイムで危険を回避する生きたアリーナです
- `画面の向き`の設定と、画面の縦向きレイアウト。レベルは自分の向きを宣言します
- 内蔵レベルがゲームに同梱されます。ほかのレベルと同じように遊べますが編集はできず、自分のフォルダーにコピーすればそのコピーを編集できます
- インターフェースが完全に英語とロシア語に対応し、エディターやほかの画面にヒントが付きました
- アンチエイリアス：`MSAA`と`FXAA`

## エディター

- `履歴`タブ：元に戻す履歴はブランチを持つツリーで、その任意の地点にジャンプできます
- タイムラインのツールTrimとBlade、マーカー、ビートグリッドへのスナップ
- ビートグリッド：ビートセグメント、`T`で音楽に合わせてタップする機能、タップをセグメントに変える`タップから作成`
- 複数のオブジェクトを選択し、1つのフィールドをすべてのオブジェクトでまとめて編集できます。コピー、貼り付け、複製
- 生データエディターは、インスペクターでは扱えない場合のために、レベル全体をデータとして編集します
- すべての選択画面が、フィルターとタグ付きの1つの検索ウィンドウになりました
- 1つのトグルでレベル全体のコライダーを表示できます
- フィールドやパネルの横の`?`でヒントが開き、エディター設定にはレベル作者向けの手引きが書かれています
- `自動保存`が機能し、ゲームの`backups`フォルダーにバックアップを書き出します
- エディターの環境設定は設定画面に移り、エディタータブの9つのセクションに分かれました

## レベルとフォーマット

- デフォルトのテクスチャに代わってシェイプが入りました：ゲーム自身が生成する約500種類のシェイプです。同じシェイプがコライダーとしても使われます
- バイナリの`.blob`フォーマット。テストレベルvolcano（19,341個のオブジェクト）は、JSONでは15.7MBのところ5.1MBで済み、読み込みは9,946ミリ秒ではなく203ミリ秒です。JSON自体の読み込みも6倍速くなりました：11,249ミリ秒から1,837ミリ秒に

## パフォーマンス

- スマートフォンでのレベルの描画が約4倍速くなりました。Snapdragon 732G（Adreno 618）では、ストレスシーンの1フレームが52.19ミリ秒から12.94ミリ秒（毎秒77フレーム）になりました
- 画面の切り替え時に、以前表示されていた緑の画面に代わってロード画面が出ます
