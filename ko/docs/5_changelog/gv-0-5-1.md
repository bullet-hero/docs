# gv 0.5.1

플레이어에게는 체크포인트, 통계, 새로운 조작, 번역된 인터페이스, 제작자에게는 기록 트리와 비트 그리드, 그리고 스마트폰에서 4배 빨라진 화면

## 게임

- 체크포인트가 작동합니다. 사망하면 플레이가 마지막으로 도달한 체크포인트로 되감깁니다: 레벨 클록이 0.5초에 걸쳐 부드럽게 멈추고, 되감긴 뒤, 다시 부드럽게 빨라집니다. `실패 시 메뉴 열기` 설정은 대신 결과 창을 다시 띄웁니다
- 통계가 디스크에 저장됩니다. 레벨 화면은 선택한 실행 옵션별로 `최고`, `시도 횟수` 값을 보여 주고, 설정의 `프로필` 탭은 실행 횟수와 게임, 메뉴, 에디터에서 보낸 시간을 보여 줍니다
- 조작을 네 가지 기기용으로 다시 작성했습니다: `키보드/마우스`, `터치스크린`, `게임패드`, `모션 센서`. 터치스크린에는 화면 조작 버튼이 생겼습니다
- 모든 키보드 단축키를 `키 할당` 탭에서 다시 지정할 수 있으며, 변경은 게임 전체에 적용됩니다
- `메뉴 배경`에서 `없음`, `도형`, `봇` 중 하나를 고를 수 있습니다. 새 기본값은 `봇` 옵션입니다: 봇이 아바타를 조종하며 실시간으로 위험을 피하는 살아 있는 아레나입니다
- `화면 방향` 설정과 화면의 세로 레이아웃. 레벨은 자신의 방향을 선언합니다
- 내장 레벨이 게임과 함께 제공됩니다. 다른 레벨처럼 플레이되고 편집은 할 수 없으며, 개인 폴더로 복사하면 그 사본을 편집할 수 있습니다
- 인터페이스가 영어와 러시아어로 완전히 번역되었으며, 에디터와 다른 화면에 힌트가 있습니다
- 안티앨리어싱: `MSAA`, `FXAA`

## 에디터

- `기록` 탭: 실행 취소 기록이 브랜치가 있는 트리이며, 그 어느 지점으로든 이동할 수 있습니다
- Trim, Blade 타임라인 도구, 마커, 비트 그리드 스냅
- 비트 그리드: 비트 세그먼트, `T` 키로 음악에 맞춰 탭하기, 탭을 세그먼트로 바꾸는 `탭으로 생성`
- 여러 오브젝트를 선택하고 한 필드를 모두에 대해 한꺼번에 편집할 수 있습니다. 복사, 붙여넣기, 복제
- 원시 데이터 에디터는 인스펙터가 다루지 못하는 경우를 위해 레벨 전체를 데이터로 편집합니다
- 모든 선택 창이 필터와 태그가 있는 하나의 검색 창이 되었습니다
- 토글 하나로 레벨 전체의 콜라이더를 표시합니다
- 필드와 패널 옆의 `?` 버튼이 힌트를 열고, 에디터 설정에는 레벨 제작자를 위한 안내서가 있습니다
- `자동 저장` 기능이 작동하며 게임의 `backups` 폴더에 백업을 씁니다
- 에디터 환경 설정이 설정 화면의 에디터 탭으로 옮겨져 9개 섹션으로 나뉘었습니다

## 레벨과 형식

- 기본 텍스처 대신 도형이 들어왔습니다: 게임이 직접 생성하는 약 500종의 도형입니다. 같은 도형이 콜라이더로도 쓰입니다
- 바이너리 `.blob` 형식. volcano 테스트 레벨(19 341개 오브젝트)의 크기는 JSON에서 15.7 MB이지만 이 형식에서는 5.1 MB이고, 읽기에는 9 946밀리초 대신 203밀리초가 걸립니다. JSON 자체도 6배 빠르게 읽힙니다: 11 249밀리초 대신 1 837밀리초

## 성능

- 스마트폰이 레벨을 약 4배 빠르게 그립니다. Snapdragon 732G(Adreno 618)에서 스트레스 씬의 한 프레임이 52.19밀리초에서 12.94밀리초(초당 77프레임)로 줄었습니다
- 화면 사이에 로딩 화면이 생겨, 이전에 보이던 초록색 화면을 대체했습니다
