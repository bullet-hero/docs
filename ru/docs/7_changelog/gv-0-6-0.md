# Версия 0.6.0

Аргументы запуска, F11 для полноэкранного режима, версия в настройках и более понятный отчёт об импорте из Afterbeat

- Аргументы запуска на компьютере: `--menu`, `--editor` или `--game` выбирают первый экран, `--level` указывает уровень по его id или папке, а `--speed`, `--lives`, `--seed`, `--bot` и `--checkpoints` / `--no-checkpoints` настраивают забег. Неверный аргумент никогда не мешает игре запуститься, он только оставляет строку в логе. Подробнее - [[12_launch-arguments]]
- F11 переключает полноэкранный режим на любом экране игры, а второе нажатие возвращает окно как было. Клавиша меняет ту же настройку, что и выпадающий список в настройках. На телефонах её нет
- Настройки показывают версию игры, версию SDK и поколение формата уровня одной строкой. Клик копирует её в буфер обмена
- Отчёт об импорте из Afterbeat показывает самые серьёзные находки первыми и не тормозит на длинном отчёте
- Описание уровня с переносами строк больше не растягивает свою строку в списке уровней: оно остаётся в одну строку и заканчивается многоточием
