# gv 0.4.1

關卡編輯器從時間軸和層級成長為完整的編輯器，關卡有了後期處理、音訊效果和可重複的隨機性

## 編輯器

- 用於物體、關鍵幀和關卡事件的檢視器。在這個版本之前，編輯器只有時間軸、層級，幾乎沒有別的
- 五個時間軸：關卡、一個選中物體的關鍵幀、關卡事件、音訊和預製件
- 視口中的控制柄，用於位置、旋轉、縮放、尺寸、錨點和軸心。每種模式都有自己的快捷鍵
- 預製件經過重做：模板在單獨的預製件模式中編輯，每次放置都可以覆蓋模板的值
- 關卡資源在編輯器中管理：音訊、紋理、字型、碰撞體、特效、主題和預製件。特效、主題、碰撞體和預製件也可以從現成的庫中選取。檔案選擇目前只在電腦上可用
- 自定義碰撞體編輯器、曲線編輯器、漸變編輯器，以及帶預覽的緩動預設
- 物體可以更換型別和父級，無需重新建立
- 選中項以流動的虛線輪廓繪製
- 可以直接從編輯器啟動關卡。化身在編輯器中可見，後期處理可以在編輯器中關閉
- 關卡設定中新增了作者、許可證、生成器和規則檢查，規則檢查會找出關卡中的問題並提出修復

## 遊戲

- 後期處理作為關卡事件，共12種：模擬故障、數字故障、泛光、色差、顏色曲線、膠片顆粒、鏡頭畸變、提升/伽馬/增益、運動模糊、陰影/中間調/高光、暗角和白平衡
- 音訊軌道上的音訊效果，共11種：合唱、壓縮器、失真、回聲、鑲邊、高通濾波、低通濾波、標準化、引數均衡、變調和混響
- 音樂同步經過重寫。遊戲跟隨音訊時鐘，用輕微改變音高來糾正小的不同步，而不是跳躍，因此每隔幾幀出現的音訊卡頓消失了
- 修復：在編輯器中，時間軸游標會讓關卡時鐘變慢約15%
- 隨機性可重複：同一關卡使用同一種子，在任何裝置上的遊玩都相同。關卡介面有種子欄位，並帶有設定隨機種子和重置的按鈕
- 關卡介面顯示關卡及其資源的作者和許可證

## 關卡與格式

- 物體的存在時間由起點和長度組成。每條邊都可以用錨點固定到父級的一條邊上，之後便跟隨那條邊
- 圖層相對於父級計算，而不是一個絕對數字
