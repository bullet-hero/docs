# gv 0.5.3

전체 화면 비트 창, 밀어서 열고 늘릴 수 있는 패널, 인스펙터 모든 필드의 초기화 버튼, 오래된 백업과 통계 정리

- `비트 창 열기` 버튼을 누르면 비트 창이 전체 화면으로 열립니다. 탭 입력기 하나와 두 결과가 나란히 있습니다: `탭으로 생성` 버튼은 새 비트 세그먼트를 만들고, `선택 항목에 적용` 버튼은 선택한 세그먼트의 템포를 다시 계산합니다. 녹음은 적용하기 전에 들어 볼 수 있으며, 창이 열려 있는 동안에도 레벨은 계속 재생됩니다
- 에디터 설정의 `시간 형식`에서 타임라인 눈금자의 단위를 고릅니다: 프레임, 타임코드, 프레임이 포함된 타임코드, `마디와 비트`. 레벨 자체는 바뀌지 않습니다
- 에디터 패널은 핸들을 밀어서 열고 닫으며, 열린 패널은 더 넓게 늘릴 수 있습니다. 스마트폰에서는 버튼이 커졌습니다
- 인스펙터의 모든 필드에 힌트를 여는 `?` 버튼과 초기화 버튼이 있고, 모든 그룹의 머리글에도 같은 한 쌍이 있습니다. 그룹 초기화는 실행 취소 한 단계입니다
- `콜라이더를 도형에 연결`: 켜져 있는 동안 도형을 고르면 맞는 콜라이더도 함께 설정되어 히트박스가 실루엣을 따릅니다
- 레벨을 열지 않고 레벨 목록에서 삭제할 수 있습니다. `레벨 삭제` 창은 어디서나 같습니다
- 설정의 `저장소` 항목은 더 이상 존재하지 않는 레벨의 백업과 통계, 또는 그 전부를 삭제합니다
- 뷰포트 그리드는 확대/축소할 때 칸 크기가 정확히 10배씩 바뀝니다. Unity 자체의 씬 그리드와 같습니다
- 타임라인은 클립마다 별도의 인터페이스 요소를 쓰는 대신 대부분의 클립을 메시 하나로 그리며, 긴 레벨에서 더 가볍습니다
- 이펙트와 오디오 효과의 필드에 설명이 붙었습니다
