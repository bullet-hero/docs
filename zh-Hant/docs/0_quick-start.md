# 快速開始

下載遊戲，開啟關卡列表，通關任意一個關卡。想做自己的關卡，就在編輯器中建立一個關卡，並把一首1到2分鐘的曲目放進它的資料夾

每一步都是最短的路徑，細節請看連結。常見問題的簡短回答：[[6_faq]]

## 1. 獲取遊戲

所有版本和商店：[[download]]

## 2. 啟動

主選單裡你需要三個按鈕：`{{ui:menu_main_levels-btn}}`、`{{ui:menu_main_editor-btn}}`和`{{ui:settings_common_title}}`。`{{ui:menu_main_story-btn}}`和`{{ui:menu_main_multiplayer-btn}}`暫時還不能用

## 3. 通關第一個關卡

按`{{ui:menu_main_levels-btn}}`，選擇一個關卡，然後按`開始`。你操控一個小方塊，目標是一直活到曲目結束

> [!tip] 提示
> 第一次玩時，把`{{ui:menu_levelview_options-lifes_title}}`設為`{{ui:menu_levelview_options-lifes_option-zen}}`。這樣這一局不會結束，你可以慢慢熟悉操作。`{{ui:menu_levelview_options-no-collision_title}}`更進一步：開啟後，任何東西都碰不到你

有人發給你一個關卡？它是一個資料夾。把它複製到`levels`資料夾，然後按`{{ui:root_level-browser_refresh}}`。更多：[[2_playing-levels]]

## 4. 操作

| 裝置 | 移動 | 衝刺 |
|---|---|---|
| 滑鼠 | 按住左鍵 | `Space`、`Shift`或右鍵 |
| 觸屏 | 用手指拖動 | 第二根手指 |
| 手柄 | 任意一個搖桿 | 除`Start`和`Select`以外的任意按鍵 |

除手柄按鍵以外，所有操作都可以在`{{ui:settings_common_title}}`→`{{ui:settings_controls_title}}`中重新繫結。更多：[[3_controls]]

## 5. 如果出了問題

常見問題及解決方法：[[5_troubleshooting]]

去哪裡報告問題：[[11_help]]

## 6. 做出第一個關卡

按`{{ui:menu_main_editor-btn}}`，建立一個關卡，把一首曲目（`ogg`、`mp3`或`wav`）放進它的資料夾。入門用1到2分鐘的曲目就夠了

編輯器會在修改一分鐘後自動儲存關卡。`Ctrl+S`立即儲存

完整的分步流程：[[2_first-level]]
