# 링크와 커뮤니티

대화와 질문은 Discord에서, 영상은 YouTube에서, 게임 버그는 bullet-hero/releases 저장소의 issues에서 다룹니다. 소스 코드는 GitHub의 bullet-hero 조직에 있습니다

다운로드할 수 있는 모든 것: 게임, SDK, 스토어 - [[download]]

## 소셜 미디어

| 출처 | 설명 |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | 대화, 질문, 피드백, 버그, 직접 만든 레벨 |
| [YouTube](https://www.youtube.com/@bulletherogame) | 게임 트레일러와 영상 |

## 피드백

| 출처 | 설명 |
|---|---|
| [Game Issues](https://github.com/bullet-hero/releases/issues) | 게임의 오류와 버그 (기술적인 것만) |
| [SDK Issues](https://github.com/bullet-hero/sdk/issues) | SDK의 오류 |
| [Docs Issues](https://github.com/bullet-hero/docs/issues) | 텍스트와 번역의 오류 |
| [Discord](https://discord.gg/gkHQrp9NgS) | 질문과 토론, 게임에 대한 피드백 |

## 소스 코드

| 저장소 | 접근 | 내용 |
|---|---|---|
| [bullet-hero/game](https://github.com/bullet-hero/game) | 비공개 | 게임과 에디터 |
| [bullet-hero/sdk](https://github.com/bullet-hero/sdk) | 공개 | SDK, SDK 및 그 코드에 관한 issues |
| [bullet-hero/releases](https://github.com/bullet-hero/releases) | 공개 | 게임 빌드, 플레이어가 올린 issues |
| [bullet-hero/docs](https://github.com/bullet-hero/docs) | 공개 | 이 문서 |

| [bullet-hero/frontend](https://github.com/bullet-hero/frontend) | 비공개 | 사이트 |
