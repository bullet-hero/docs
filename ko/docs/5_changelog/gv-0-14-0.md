# gv 0.14.0

이펙트가 제작자의 의도대로 재생되고, 오브젝트에서 이펙트를 제거할 수 있으며, 에디터에 새 단축키 두 개가 생겼습니다

## 이펙트

- 이펙트는 오브젝트가 향하는 방향으로 파티클을 방출하며, 타임라인에서 뒤로 이동해도 재생 때와 같은 것이 그려집니다. 이전에는 흐름이 월드에 붙어 있어서, 같은 프레임에서도 재생 중에는 휜 궤적이, 뒤로 이동한 뒤에는 곧은 궤적이 보일 수 있었습니다
- `점` 이외의 이미터 모양(`원`, `선`, `원뿔`, `토러스`)이 오브젝트와 함께 회전합니다. 이전에는 월드 기준으로 정렬된 채 남아 있어서, 회전한 이펙트가 자신과 무관한 축을 따라 파티클을 생성했습니다
- 이펙트는 화면 밖에서도 시뮬레이션을 계속하므로, 프레임 안으로 날아 들어올 파티클이 도착하기 전부터 존재합니다. 이전에는 카메라 밖의 이미터가 아무것도 생성하지 않아서, 에디터에서는 맞아 보이던 이펙트가 게임에서 사라질 수 있었습니다. 대가는 화면 밖 이펙트에 드는 GPU 시간입니다
- **기존 레벨이 깨집니다.** 이펙트의 선형 힘은 이제 형식이 늘 설명해 온 대로 초당 가속도입니다. 이전에는 50 Hz 이펙트 주기에서 약 50배 강하게 작용했습니다. 이 값이 설정된 레벨(`lfrc`)은 다시 조정해야 합니다: 힘이 `(1, 0)`인 파티클 하나는 이제 1초에 0.51 유닛 이동하며, 이전에는 25.5 유닛이었습니다

## 에디터

- `Ctrl+Shift+A`(`선택 해제`)는 오브젝트, 키프레임, 오디오, 비트까지 선택 전체를 한 번에 지웁니다. `Ctrl+Shift+E`(`프리팹 모드 종료`)는 열린 모든 프리팹 모드 세션을 종료합니다. 둘 다 다른 단축키처럼 다시 할당할 수 있습니다
- 이펙트 선택기에 `없음` 옵션이 생겨 오브젝트에서 이펙트를 제거할 수 있습니다. 이전에는 이펙트를 한 번 고르면 선택기로 지울 수 없었습니다
- 에디터 안에서 다른 레벨을 열면 오브젝트 목록이 다시 만들어지고, 프리팹 모드는 그것이 열린 레벨과 함께 닫힙니다
- 영역 가장자리 근처에서 타임라인 클립을 더블 클릭해도 더 이상 오브젝트가 위 트랙으로 끌려가지 않습니다. 이전에는 누르는 순간 가장자리 스크롤이 시작되어 포인터가 멈춰 있는데도 화면이 밀렸고, 이동이 레이어 변경으로 바뀌었습니다
- [[12_launch-arguments|실행 인수]] `--autosave on|off` 하나로 설정을 바꾸지 않고 한 번의 실행 동안 에디터 자동 저장을 켜거나 끕니다
