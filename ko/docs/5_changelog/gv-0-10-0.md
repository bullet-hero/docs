# gv 0.10.0

프리팹이 실제 루트 오브젝트를 중심으로 다시 만들어졌고, 크기 키프레임이 없는 오브젝트는 더 이상 자체 크기를 갖지 않습니다

- 프리팹 템플릿에 이제 실제 루트 오브젝트가 있고, 안의 모든 것이 그 아래에 매달립니다. 이전에는 그룹을 프리팹으로 만들면 그룹용 오브젝트 두 개가 연달아 남았고, 이를 합칠 방법이 없었습니다. 이제는 선택 항목이 한 번만 감싸집니다
- 크기 키프레임이 없는 오브젝트는 이제 1×1 대신 0×0 크기입니다. 빈 오브젝트, 이펙트, 프리팹 배치는 아무것도 그리지 않는 그룹이므로 크기가 없습니다. 새 도형이나 텍스트는 생성될 때 크기 키프레임을 받으며, 그 값은 `에디터` > `생성`(`새 도형 너비`, `새 텍스트 너비`와 두 높이)에서 설정합니다
- 그 결과는 두 가지입니다: 그룹은 뷰포트에서 클릭으로 선택할 수 없고, 이펙트는 파티클이 차지하는 영역으로 선택됩니다
- 계층 구조의 행을 다른 행 위로 드래그하면 부모가 바뀌고, 빈 공간으로 드래그하면 부모가 제거됩니다. 선택한 여러 행은 실행 취소 한 단계로 함께 이동합니다. 마우스와 펜으로 작동합니다. 휴대폰에서는 인스펙터에서 부모를 바꿉니다
- 백쿼트 키(`` ` ``)를 누르고 있으면 에디터 인터페이스 전체가 숨겨지고 레벨만 보입니다. 키를 놓으면 모두 돌아옵니다. 키는 다시 할당할 수 있습니다
- 레벨 브라우저가 `최근` 순으로 정렬된 채 열리므로, 마지막으로 저장한 레벨이 맨 위에 있습니다
- 결과 화면에 "승리"나 "패배" 대신 `클리어` 또는 `실패`가 표시됩니다
- 프리팹 배치를 평탄화하면 먼저 확인을 요청합니다. 배치가 더 이상 템플릿을 따르지 않게 되기 때문입니다
- 명령 팔레트와 추가 메뉴가 번역되었습니다. 이전에는 언어와 관계없이 영어 텍스트가 표시되었습니다
