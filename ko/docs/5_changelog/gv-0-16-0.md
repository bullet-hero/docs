# gv 0.16.0

더 새로운 버전의 파일은 열리지 않고 게임이 업데이트를 요청하며, 저장 없는 익명 모드가 생겼고, 큰 레벨에서 에디터가 빨라졌습니다

## 버전과 저장

- 더 새로운 버전 게임의 파일은 열리지 않고, 대신 `업데이트 필요` 창이 나타납니다: 레벨, 가져온 아카이브, 클립보드의 에디터 내용에서 그렇습니다. `다운로드`는 사이트의 다운로드 페이지를 엽니다. 레벨 목록에서는 이런 레벨에 `더 새로운 버전의 게임에서 만들어졌습니다` 표시가 붙습니다. 이전에는 에디터가 경고 후 더 새로운 레벨을 열겠다고 제안했습니다
- 더 새로운 버전이 저장한 설정이나 통계는 건드리지 않습니다. 게임은 기본값으로 실행되고, 종료할 때까지 자체적으로 아무것도 저장하지 않으며, 어떻게 할지 묻습니다: `계속 저장 안 함` 또는 `데이터 덮어쓰기`. 레벨 자체의 통계가 더 새로우면 그 카드에 최고 기록 대신 설명이 표시됩니다
- 새 설정 `게임 저장 안 함 (익명 모드)`. 켜져 있는 동안 게임은 설정도 통계도 기록하지 않으며, 그동안 플레이한 내용은 디스크에 닿지 않습니다. [[12_launch-arguments|실행 인수]] `--suppress-game-saves` 하나로 실행 전체 동안 이 설정을 켭니다
- `--autosave` 인수로 이번 실행의 에디터 자동 저장을 정하면, `자동 저장` 설정이 그 사실을 알려 줍니다

## 게임

- 마우스 버튼을 누른 채 조종할 때 일시 정지 버튼 위를 지나가도 더 이상 조종이 끊기지 않습니다. 레벨에서 시작한 누름은 어디로 가져가도 조종으로 남고, 버튼에서 시작한 누름은 버튼에 남습니다
- 1 유닛보다 가까운 지점으로의 커서 대시가 더 이상 무시되지 않습니다. 아바타가 이미 서 있는 곳이 아니라면 어떤 목표든 거리만큼 줄어든 대시가 일어납니다
- Android에서 게임에 Vulkan 지원이 필요하므로, Google Play 스토어는 더 이상 Vulkan 미지원 기기에 게임을 제공하지 않습니다. 그런 기기에서는 검은 화면이 나왔습니다

## 에디터

- 큰 레벨에서 에디터가 빨라졌습니다. 화면에 없는 타임라인이나 패널은 더 이상 편집할 때마다 다시 만들어지지 않고, 표시될 때 따라잡습니다. "이 복사본은 어느 배치에 속하는가"라는 질문은 선택한 오브젝트, 필드, 키프레임 트랙마다 레벨 전체를 훑는 대신 편집마다 인덱스 하나로 답합니다
- 편집해도 더 이상 이벤트와 오디오 키프레임의 선택이 초기화되지 않으며, 로컬 타임라인의 키프레임 선택도 지워지지 않습니다
- 일반 편집에서 더 이상 실행 취소, 다시 실행 소리가 나지 않습니다. 실행 취소와 다시 실행에서만 납니다
- 같은 구간을 가진 두 클립을 클릭하면 위에 그려진 클립이 선택됩니다. 이전에는 가려진 클립이 선택되었고, 프리팹 모드에서 중첩된 템플릿의 내용을 클릭하면 매번 그 배치가 선택되었습니다
- 바깥 템플릿에 복원할 선택이 있을 때 중첩 프리팹에서 나가도 더 이상 `Collection was modified` 오류가 발생하지 않습니다
