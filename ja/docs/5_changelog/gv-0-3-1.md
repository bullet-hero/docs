# gv 0.3.1

エディターがオブジェクトの作成と、その取り消し、ヒエラルキーへの表示に対応しました

`gv 0.3.0`の5日後、エディターは保存ボタン付きのレベルプレイヤー以上のものになりました

- オブジェクトを作成でき、その操作に元に戻すとやり直しが使えます
- オブジェクトのヒエラルキーにレベルのオブジェクトが表示され、そこからオブジェクトを非表示にできます
- 確認のうえでレベルを削除できます
- 通知とコンソールパネルが、エディターが直前に何をしたかを知らせます
- エディター内でのレベルの再生は、ゲーム内と同じように動作します

Androidビルドも、GPUが弱いスマートフォン向けに調整されました

コミット：ゲーム`393c49d2`、SDK `e2d57751`
