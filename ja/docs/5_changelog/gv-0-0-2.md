# gv 0.0.2

テクスチャ、親、パーティクル、テキスト、ポストプロセス効果を、テストシーンで1つずつ試しました

このバージョンは実験の集まりです。レベルに必要になる機能それぞれに専用のテストが作られ、その大半が残りました

- オブジェクトにテクスチャが付きました
- オブジェクトは親を持てるようになり、親と一緒に動きます
- パーティクルエフェクトとテキストが加わりました（当時は*TextMeshPro*を使用）
- 画面のポストプロセス効果

すべてAndroidのスマートフォンで計測されました。当時のメモによると、30fpsで約1,500個のオブジェクトを維持できました。2Dの影も試されましたが、見送られました
