# gv 0.10.1

새 기본 레벨, 버전 줄의 빌드 이름, 더 가벼워진 Android 릴리스

- 게임에 함께 제공되던 테스트 레벨 두 개가 데모 레벨 `New zero demo` 하나로 바뀌었습니다
- 설정의 버전 줄에 버전과 함께 빌드도 표시됩니다: `gv X, sv Y, mg Z, Windows, Steam, Release`, 즉 플랫폼, 스토어, 빌드 유형입니다. 모든 로그의 첫 줄도 같은 내용이므로, 버그 리포트와 거기에 첨부된 로그는 항상 같은 빌드를 가리킵니다
- 레벨 브라우저를 열면 모든 출처 필터가 켜져 있고, 출처가 하나뿐이어도 출처 행이 표시됩니다. 있지만 필터에 걸러진 레벨은 없는 레벨처럼 보였습니다
- 릴리스 빌드에 더 이상 디버깅 심볼이 들어가지 않습니다. Android에서는 124.9 MB였던 릴리스가 25.7 MB 줄었습니다

커밋: 게임 `d7eabd71`, SDK `b77e9337`
