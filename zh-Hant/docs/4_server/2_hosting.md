# 給朋友的伺服器

你需要開源的伺服器工具、每位玩家都使用遊戲完整版，以及一個PublishProfile檔案。稽核和遵守關卡許可證由伺服器所有者負責

> [!warning] 警告
> 伺服器工具尚未釋出，協議尚未設計。這裡只有已經確定的內容

## 需要什麼

- **伺服器工具**。它們將以MIT許可證開源。這與官方伺服器執行的是同一份程式碼。你可以用這些工具或基於它們的任何東西搭建自己的伺服器
- **每個連線的人都使用遊戲完整版**。來自Google Play和App Store的版本無法連線社群伺服器。完整版位於[GitHub](https://github.com/bullet-hero/releases)和專案網站
- **釋出配置**。`PublishProfile`檔案決定你的伺服器接受哪些關卡。更多：[[7_publish-profiles]]
- **執行伺服器的機器**。系統要求、執行環境、埠和啟動方式目前都還不知道

## 釋出配置

配置規定接受哪些許可證、關卡可以從哪裡獲取檔案，以及它的大小限制。這些都不需要修改程式碼

官方伺服器使用`standard`預設，它在伺服器配置中設定。以它為起點，按自己的需要放寬或收緊

## 你要承擔什麼

- **稽核**。Bullet Hero不稽核社群伺服器。完整版的EULA會把這一點告知每位玩家
- **不得用於商業**。關卡預設以*CC BY-NC*釋出，作者可以選擇其他許可證。請遵守每個關卡的許可證。*CC BY-NC*下的關卡可以免費託管和分享，但不能為它收費，也不能以其他方式靠它賺錢
- **資源的權利**。關卡中可能有他人的音樂和影像。檢查得多嚴格由你的配置決定。但針對他人作品的投訴會找到你。官方伺服器的規則：[[ugc-licensing-policy]]

非商業分發的許可由每個關卡的作者授予，而不是由遊戲授予。所以只有作者才能給出例外

## 尚不清楚的事

- 遊戲如何找到伺服器並連線
- 社群伺服器是否會有賬號
- 關卡如何上傳並進入列表
- 幾個人用的伺服器與公共伺服器的配置方式是否不同

大型伺服器已經具備的內容：[[3_advanced-hosting]]
