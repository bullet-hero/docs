# Серверы

Сервер в Bullet Hero - веб-сервис, который хранит уровни. Будут официальный сервер OWS и общественные серверы NOWS, которые может запустить кто угодно

> [!warning] Предупреждение
> Серверов пока нет, ни официального, ни общественного. Протокол между игрой и сервером не спроектирован

Код сервера будет открыт в [bullet-hero/backend](https://github.com/bullet-hero/backend), пока там пусто
