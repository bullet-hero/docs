# 版本0.13.0

预制件的根可以选中，自动保存让编辑器卡顿的时间减半，关卡卡片注明音乐作者

- 预制件模板的根可以选中了。在预制件时间轴中单击它所在的行，就可以像编辑其他物体一样编辑它的关键帧。打开一次放置时会落在根上，选中根时会按模板自身的长度循环播放
- 自动保存让编辑器卡住的时间减半：在12.3MB的关卡上为133毫秒，此前为265毫秒。以前它会把整个关卡复制两次，一次用于备份，一次用于保存
- 保存后的清理不再在主线程上运行。删除另一种格式的过时文件和轮换备份，以前是在一帧的中途进行的，每次自动保存要进行四次
- 关卡卡片在关卡作者下方单独一行注明音乐作者。注明哪个资源，由该资源上的`在关卡卡片上显示`复选框决定。只有一个音频资源的关卡无需勾选就会显示这一行
- 时间轴不再绘制被同一行上另一个片段完全挡住的片段。较宽的片段位于较窄片段的下方，选中或正在拖动的片段位于该行的最上层。未绘制的片段仍然可以点击
- 时间轴一旦隐藏就会释放它的元素。以前，折叠的关卡和未选中的标签页每帧的开销与打开时一样
