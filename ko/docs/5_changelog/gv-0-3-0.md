# gv 0.3.0

게임으로 작동하는 첫 버전: 메뉴, 직접 조작하는 아바타, 처음부터 끝까지 플레이하는 레벨, 첫 에디터 화면

그전까지 엔진은 테스트 씬에서만 레벨을 재생할 수 있었습니다. 이 버전에서 그 주위에 *UI Toolkit* 기반의 게임 전체가 생겼습니다

- **메뉴와 설정.** 메인 메뉴, 실행 사이에 저장되는 설정 화면, 플레이리스트, 레벨 목록
- **레벨 플레이.** 레벨을 고르고, 불러오고, 끝까지 플레이합니다
- **아바타.** 레벨 안에 있는 플레이어 자신의 도형으로, 직접 조작합니다
- **두 가지 언어.** 영어와 러시아어 인터페이스
- **레벨 검증.** SDK에서 규칙 세트로 레벨을 검사하고 망가진 데이터를 보고할 수 있습니다

내장 에디터가 첫 형태로 등장했습니다. 새 레벨을 만들고, 폴더에 저장하고, 정한 속도로 재생하고, 현재 시간을 표시할 수 있습니다. 오브젝트 계층 구조와 인스펙터는 아직 초안일 뿐입니다

`gv 0.2` 버전은 없습니다: 번호는 `gv 0.1.0`에서 `gv 0.3.0`(으)로 바로 넘어갔습니다
