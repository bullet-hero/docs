## Versiones

Cada producto tiene su propia versión con un prefijo de letras, cada una con la forma `major.minor.revision`:

| Prefijo | Significado | Producto |
|---|---|---|
| `gv` | `game version` | el juego (el cliente) |
| `sv` | `sdk version` | el SDK |
| `bv` | `backend version` | el backend, el servidor |
| `fv` | `frontend version` | el sitio web |
| `mg` | `model generation` | los datos |

Se escriben así: `gv 1.0.0`, `sv 1.0.0`, `bv 1.0.0`, `fv 1.0.0`, `mg 1`

Más sobre esto en [[5_versioning]]
