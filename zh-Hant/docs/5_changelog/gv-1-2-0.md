# gv 1.2.0

從編輯器匯出影片、用一個檔案轉移檔案、關卡列表的篩選，以及在Discord中顯示你的動態

## 匯出影片

- 關卡設定側欄中的`匯出影片`會把關卡渲染成影片。命令面板中也有同樣的命令
- 電腦上需要安裝`7.0`或更新版本的ffmpeg，視窗會自己找到它。支援Windows、macOS和Linux，手機上不可用
- 畫面逐幀渲染，所以無論電腦多慢，影片都是精確的
- 支援MP4、MKV、MOV、WebM、GIF、WebP、APNG、圖片序列或只匯出聲音。解析度從720p到2160p，或最大7680的任意尺寸，每秒1到240幀
- 由機器人遊玩關卡（`由誰遊玩`），網格、控制柄和選中框永遠不會出現在畫面中

更多：[[18_video-export]]

## 轉移檔案

- `設定` → `其他` → `轉移檔案`會把你的檔案打包成一個zip檔案：關卡、統計資料、設定和庫。自動儲存、錯誤報告和錄影在勾選後也會打包進去
- `匯入`可以替換現有內容（`替換`），也可以新增到現有內容中（`合併`）。合併時保留關卡較新的副本和統計資料中較大的數值
- 匯入替換掉的內容會保留為一份備份，`恢復`可以把它找回來
- 支援Windows、macOS、Linux和Android。iOS上不可用

更多：[[14_profile-transfer]]

## 關卡列表

- `篩選`會開啟一個包含更多篩選條件的視窗：AI內容、長度、進度、最近遊玩、年齡分級、帶密碼或來自更新版本的關卡，以及必須包含或排除的標籤
- `反向排序`會把排序反過來
- 搜尋先看關卡名稱，然後是作者，最後是標籤

更多：[[2_playing-levels]]

## Discord

- Steam版會在你的Discord個人資料中顯示你正在遊戲中做什麼：選單、編輯器、沙盒或某個關卡
- 只有公開的關卡才會顯示名稱：Steam創意工坊物品或遊戲自帶的關卡。你自己的關卡和正在編輯的關卡永遠不會顯示名稱
- 只有當Discord應用在同一臺電腦上執行時才有效。可以在Discord中隱藏你的動態

更多：[[game-privacy-policy#Discord Rich Presence]]

## 修復

- 在設定中關閉聲音後，關卡現在真的會靜音。以前它只會讓其他聲音設定變灰
- 關閉遊戲前剛改的設定不會再丟失。每次寫入設定時都會出現儲存圖示
- 設定開啟時，`Ctrl+S`會儲存設定（`儲存設定`）。在編輯器中它仍然儲存關卡
- 手機上的設定行不會再自己跳回第一個選項
- 某些特效可能會從畫面上消失，現在不會了
