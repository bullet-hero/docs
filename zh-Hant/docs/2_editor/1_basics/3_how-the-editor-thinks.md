# 編輯器的工作方式

物體、幀、時段、圖層、父級、關鍵幀，整個編輯器建立在這六個概念之上

理解了這六個概念，編輯器的其餘部分自然就能看懂：

| 概念 | 簡述 |
|---|---|
| 物體 | 形狀（你看到的）和碰撞體（造成傷害的），兩個獨立的欄位 |
| 幀 | 時間的一個格子，而不是一個瞬間 |
| 時段 | 物體的存在時間：起點和時長，不包括終點 |
| 圖層 | 繪製順序，與所有父級的圖層相加 |
| 父級 | 把變換、活動狀態和存在時間傳給子物體 |
| 關鍵幀 | 欄位在某一幀上的數值，關鍵幀之間的數值由遊戲自動過渡 |

遇到不認識的詞：[[1_glossary]]

## 物體

物體既是被繪製的東西，也是造成傷害的東西。這是兩個不同的欄位：形狀（你看到的）和碰撞體（造成傷害的）。一道發光但碰不到你的光束，就是有形狀、沒有碰撞體的物體。隱形牆則正好相反

## 幀與時段

幀是時間的一個格子，而不是一個瞬間。第30幀佔據一段時間，而不是一個點。時間軸從1開始計數。長度為900幀的關卡包含第1幀到第900幀。數字901是結束邊界，不是一幀

時段是物體的存在時間：起點和時長。終點不屬於時段。所以首尾相接的兩個物體，不會在共同的一幀上重疊

更多：[[4_frames-and-time]]

## 圖層與父級

圖層是繪製順序。它是相對的：物體的圖層會與它所有父級的圖層相加

> [!caution] 注意
> 把物體拖到另一個父級下，即使你沒有改過數字，它的繪製順序也會改變

父級把變換、活動狀態和存在時間傳給子物體。子物體的時段必須位於父級的時段之內

編輯器不會裁剪你寫下的值。它保留你的數值，另外計算實際生效的數值。所以縮短父級是可逆的：把它拉長回去，子物體就會回來

## 關鍵幀

關鍵幀是欄位在某一幀上的數值。兩個關鍵幀之間的數值由遊戲自動過渡。每個欄位都有自己的一組關鍵幀：位置、旋轉、縮放、尺寸、錨點和軸心

> [!info] 須知
> 沒有關鍵幀的欄位並沒有壞，它取預設值。不需要為了整齊給所有欄位都打上關鍵幀
