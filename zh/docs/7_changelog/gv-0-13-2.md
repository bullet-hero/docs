# 版本0.13.2

修复物体自身起始帧之前的帧、关卡文本预热、时间轴上的非活动物体，以及编辑器窗口中的Escape键

- 起始帧被锚定的物体会在它设定的起始帧之前就开始播放，在这些帧上它现在保持第一个关键帧的数值。以前帧计算会在这里抛出错误，可能导致整帧无法构建，在发行版中还可能让游戏关闭
- 关卡文本会在关卡开始播放之前再次完成准备。文本库更新后，预热悄无声息地失效了，于是每个字母都要在它第一次出现的那一帧才放入字体图集
- 关卡时间轴和预制件时间轴把关卡不绘制的物体显示为褪色的灰色片段。这包括自身的活动复选框被关闭的物体，以及父级的活动复选框被关闭的物体。预制件片段会保留一点紫色，因此两种状态都能分辨
- `Escape`关闭22个编辑器窗口的方式与单击背景相同，其中包括未保存的更改、搜索面板、备份、生成器、关卡密码和各资源编辑器
- 校验不再报告位于关卡结尾之后的关键帧或物体，它的修复也不再把它们钳制到最后一帧。结尾之后的内容是合法的：关卡一变长它就会播放。位于第一帧之前的帧仍然会被报告
