# gv 0.0.1

La primera prueba de renderizado: muchos objetos con Unity Entities, y ya funciona en Android

Tres días después del inicio el proyecto tuvo su base técnica. Los objetos se dibujan con *Unity Entities* (ECS), y el juego sigue apoyándose en ese enfoque. La escena de prueba llena la pantalla de objetos y cambia sus colores, y el orden de dibujo sale de la profundidad de cada objeto

- La compilación de prueba ya funciona en Android
- El modelo de datos del nivel pasó a un plugin aparte, el futuro SDK
- Los primeros sprites (formas, iconos de la interfaz, skins) se trajeron de un proyecto anterior

Al mismo tiempo se estudió una canalización de renderizado propia y se descartó: el *URP* estándar bastaba
