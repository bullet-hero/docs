# gv 0.10.0

预制件围绕真正的根物体重建，没有尺寸关键帧的物体不再有自己的尺寸

- 预制件模板现在有一个真正的根物体，里面的一切都挂在它下面。以前，把一个分组变成预制件会留下连续两个分组物体，而且没有办法把它们合并。现在选中项只被包裹一次
- 没有尺寸关键帧的物体现在是0乘0，而不是1乘1。空物体、特效和预制件放置都是不绘制任何内容的分组，所以它们没有尺寸。新的形状或文本在创建时会得到一个尺寸关键帧，它在`编辑器` > `创建`中设置（`新形状宽度`、`新文本宽度`和两个高度）
- 两个后果：分组无法在视口中点击选中，特效则按其粒子占据的区域来选中
- 把层级中的一行拖到另一行上即可更换它的父级，拖到空白处则移除父级。多个选中的行作为一个撤销步骤一起移动。这适用于鼠标和手写笔。在手机上，父级在检视器中更换
- 按住反引号键（`` ` ``）即可隐藏整个编辑器界面，只看关卡。松开后一切恢复。这个按键可以重新绑定
- 关卡浏览器打开时按`最近`排序，所以最后保存的关卡排在最上面
- 结果画面显示`通过`或`失败`，而不是“胜利”或“战败”
- 展平预制件放置之前会先请求确认，因为放置将不再跟随模板
- 命令面板和添加菜单已翻译。以前无论选择什么语言，它们都显示英文
