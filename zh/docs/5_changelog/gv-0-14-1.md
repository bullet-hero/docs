# gv 0.14.1

手机上的修复（关卡进行中屏幕不会熄灭，内存清理不会打断游玩），以及许可证记录和演示关卡的回归

- 关卡播放时屏幕不会熄灭，一旦你暂停，屏幕又会遵循系统的超时设置。以前，你按住摇杆操控的一局会被当作无操作，手机会在关卡中途锁屏
- 在关卡进行中收到的内存不足警告，会在关卡停止后处理。在Android上，清理耗时163毫秒和715毫秒，在33秒的游玩中造成了两帧，分别为735毫秒和523毫秒，每一帧都足以让这一局失败。代价是：真正内存不足时，系统现在可能在关卡进行中关闭游戏
- 游戏相机只在输出区域移动一整个像素时才更新它。以前每帧都会更新，渲染器每秒重建60次中间图像，即使关卡的宽高比没有变化
- `许可证`窗口可以折叠：两级标题现在都可以展开和收起。关卡自己的资源默认展开，随游戏提供的一切都折叠
- 删除资源也会删除它的许可证记录。以前`许可证`窗口还在为关卡中已经不存在的资源感谢作者。撤销会恢复这条记录
- 关卡封面按图像的真实类型保存为`logo.png`或`logo.jpg`，不管源文件叫什么名字。既不是PNG也不是JPEG的图像不被接受
- 内置关卡`New zero demo`回来了，带有封面，并注明了音乐作者Dunderpatrullen
