# gv 0.10.1

Un nouveau niveau intégré, le nom de la compilation dans la ligne de version et une version Android plus légère

- Les deux niveaux de test livrés avec le jeu sont remplacés par un seul niveau de démonstration, `New zero demo`
- La ligne de version des paramètres nomme la compilation en plus de la version : `gv X, sv Y, mg Z, Windows, Steam, Release`, c'est-à-dire la plateforme, le store et le type de compilation. La première ligne de chaque journal dit la même chose, donc un rapport de bug et son journal joint nomment toujours une seule et même compilation
- Dans le navigateur de niveaux, chaque filtre de source est activé à l'ouverture, et la rangée des sources s'affiche même avec une seule source. Un niveau présent mais filtré ressemblait à un niveau manquant
- Les versions Release n'embarquent plus les symboles de débogage. Sur Android, cela fait 25,7 Mo de moins sur une version de 124,9 Mo

Commits : jeu `d7eabd71`, SDK `b77e9337`
