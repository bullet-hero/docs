# インストール

ゲームはレベル、設定、統計を1つのデータフォルダーに保存します。更新は安全です：新しいバージョンは古いデータをすべて読み込みます。Androidでは、ゲームをアンインストールするとレベルも消えます

ダウンロードはこちら：[[download]]

## ファイルの場所

| システム | フォルダー |
|---|---|
| Windows | `C:\Users\<ユーザー名>\AppData\LocalLow\vertoker\Bullet Hero` |
| Android | `/storage/emulated/0/Android/data/com.vertoker.BulletHero/files` |

いちばん早い開き方はゲーム内から：`{{ui:settings_common_title}}`→`{{ui:settings_general_title}}`→`{{ui:settings_general-open_folder}}`

中身：

| フォルダー | 内容 |
|---|---|
| `levels` | レベル。それぞれ専用のフォルダーに入っています |
| `backups` | エディターの自動保存 |
| `stats` | 統計 |
| `settings.json` | 設定 |
| `reports` | エラーレポート |

## アンインストール

Windows、Linux、Macでは、無料版のゲームの隣にアンインストーラーがあります：Windowsでは`unins000.exe`、Linuxでは`unins000`、Macでは`Bullet Hero.app`の隣の`unins000`です。実行すると、何も確認せずに自動でゲームを削除します。レベル、設定、統計はデータフォルダーに残ります

削除されるのはゲーム自身のファイルだけです。ゲームのフォルダーに自分で入れたものは残り、フォルダーは空になったときにだけ削除されます。ゲームが起動中なら、アンインストーラーはまず閉じるボタンと同じようにゲームを閉じ、AIのMCPサーバーも一緒に終了させます。未保存の変更があるレベルはその変更を失うので、アンインストールの前に保存してください

Windowsインストーラーでインストールしたゲームは、他のプログラムと同じように、Windowsの設定の「アプリ」から削除します

ストア版は、そのストアから削除します

## 更新

新しいバージョンのゲームは、どんな更新で何が変わっても、古いデータをすべて問題なく読み込みます

古いバージョンは、新しいバージョンのレベルを開きません。ゲームに更新を求められたら、更新してください

> [!caution] 注意
> Androidでは、ゲームをアンインストールするとすべてのレベルも削除されます。アンインストールの前にプロファイルをエクスポートしてください：[[14_profile-transfer]]
