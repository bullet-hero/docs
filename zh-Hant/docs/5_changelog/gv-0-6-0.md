# gv 0.6.0

啟動引數、用F11切換全屏，以及設定中的版本號

- 電腦上的啟動引數：`--menu`、`--editor`或`--game`選擇第一個畫面，`--level`按id或資料夾指定關卡，`--speed`、`--lives`、`--seed`、`--bot`和`--checkpoints` / `--no-checkpoints`設定本次遊玩。錯誤的引數永遠不會阻止遊戲啟動，只會在日誌中留下一行。更多：[[12_launch-arguments]]
- F11在遊戲的任何畫面上切換全屏，再按一次則把視窗恢復原樣。這個按鍵改變的是與設定中的下拉式清單相同的設定。手機上沒有這個按鍵
- 設定在一行中顯示遊戲版本、SDK版本和關卡格式代數。點選即可複製到剪貼簿
- 帶換行的關卡描述不再撐高它在關卡列表中的那一行：它保持一行，並以省略號結尾
