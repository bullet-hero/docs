# gv 0.5.5

Folder access on Android, a reset button on every settings tab and a fix for the resolution setting

- Android: the game opens folders through the system folder picker and sees only the folder you picked, so it needs no storage permission. `Folder access` in the settings shows every granted folder, and `Revoke` removes the access without deleting anything inside
- Every settings tab has its own reset button, which returns only that tab to its default values
- Fixed: the resolution setting did nothing if the window had been resized before, by hand or with Alt+Enter
- The level list got a `Scan again` button
- The level settings have a `Publication` tab. For now it says `In development`
