# Jogo

Bullet Hero é um híbrido de jogo de ritmo e bullet hell: você guia um pequeno quadrado, e ele precisa sobreviver até o fim da música. O jogo é gratuito e não precisa de conta

As primeiras páginas servem para começar a jogar. Mais adiante está a mecânica de uma partida, para quem quer os números exatos
