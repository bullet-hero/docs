# 版本0.13.1

预制件放置随所在分组移动，历史标签页显示每一步改了什么，时间轴工具集中到一组按键上

- 拖动包含预制件放置的分组时，这些放置所放出的内容现在会一起移动。以前这些副本留在原来的帧上，只要向左移动一帧，就会在本次会话余下的每一帧都打印错误`Frame must be at least 1`
- 修剪过的放置在你编辑它的时段后，会让自己的动画保持原位。以前这种编辑会让放置的关键帧相对于它放出的内容发生错位
- `历史`标签页的每一行，以及控制台中的每条撤销或重做记录，现在都带有这一步背后的数字：物体的ID和名称、轨道，以及它在哪两帧之间移动（例如`f150 -> f160`）
- 时间轴工具移到一组按键上，顺序与工具栏相同：`Z`折叠、`X`吸附、`C`选择、`V`框选、`B`剪刀、`N`边缘。以前`V`是选择，`C`是剪刀，请检查一下自己的习惯。工具较少的标签页从右侧去掉多余的工具（局部标签页只有`Z` `X` `C` `V`），因此同一个字母在另一个标签页上绝不会代表另一个工具。六个按键都可以在设置中重新绑定，名称为`工具：吸附`、`工具：循环切换折叠`等
- 校验不再对使用预制件的关卡报出大量虚假问题。在一个有700个物体的关卡上，它曾报告38,736个损坏的重映射和19,993个悬空的根覆盖，而其中没有一个是真的
- 内置关卡`New zero demo`从这个版本中移除
