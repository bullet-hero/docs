# gv 0.8.0

時間軸從1開始計幀，選中項一步即可變成預製件

- 幀從1開始計數。關卡的第一幀是第1幀，它從0秒開始，播放頭、檢視器和關卡檔案顯示同一個數字。物體內部關鍵幀的幀號也從1開始
- 已有關卡沒有轉換，所以有三樣東西發生了偏移。所有隨機值都重新隨機了一次，因為隨機值取決於幀號。在這個版本之前儲存的檢查點死亡記錄和最佳成績，讀取時會偏移一幀。改動之前寫入的撤銷歷史和自動儲存無法重放
- 播放頭讀數以毫秒顯示秒的小數部分（第60幀顯示`0:00.983`）。旁邊就是幀號，以前的寫法看起來像是與它矛盾
- `從選中項建立預製件`（`Ctrl+G`）把選中的物體變成預製件。層級行的選單中也有同樣的操作：`由此建立預製件`
- 化身現在出現時會逐漸長大，消失時會縮成一個點，而不是瞬間出現和消失
- 關閉的視窗每幀要花掉編輯器畫面4.6毫秒：介面仍然會遍歷它們。現在其中十個視窗在關閉時會完全從介面中移除
- 統計疊加層新增`顯示效能分析`區塊：模擬的每個階段花了多長時間
