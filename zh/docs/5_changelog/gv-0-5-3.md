# gv 0.5.3

全屏节拍窗口、可以滑动和拉伸的面板、每个检视器字段上的重置按钮，以及清理旧备份和统计数据

- 节拍窗口通过`打开节拍窗口`按钮全屏打开。其中有一个敲击器和并排的两个结果：`由敲击创建`生成一个新的节拍段，`应用到选中项`重新计算选中节拍段的速度。录制的敲击可以在应用前试听，窗口打开时关卡继续播放
- 编辑器设置中的`时间格式`决定时间轴标尺以什么计数：帧、时间码、带帧的时间码或`小节和节拍`。关卡本身不会改变
- 编辑器面板通过滑动把手打开和关闭，打开的面板可以拉得更宽。手机上的按钮变大了
- 每个检视器字段都有一个带提示的`?`和一个重置按钮，每个分组的标题中也有同样的一对。重置分组是一个撤销步骤
- `碰撞体跟随形状`：开启时，选择形状也会设置相同的碰撞体，判定框跟随轮廓
- 可以在关卡列表中删除关卡，无需打开它。`删除关卡`窗口在各处都相同
- 设置中的`存储`会删除已不存在的关卡的备份和统计数据，或者全部删除
- 视口网格在缩放时把格子大小精确地改变10倍，和Unity本身的场景网格一样
- 时间轴用一个网格绘制大部分片段，而不是为每个片段使用单独的界面元素，这在长关卡上开销更小
- 特效和音频效果的字段有了说明
