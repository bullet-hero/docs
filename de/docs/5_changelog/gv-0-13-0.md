# gv 0.13.0

Die Wurzel eines Prefabs wurde auswählbar, das Autospeichern friert den Editor halb so lange ein, und die Levelkarte nennt den Künstler der Musik

- Die Wurzel einer Prefab-Vorlage lässt sich auswählen. Klick auf ihre Zeile in der Prefab-Zeitleiste, und ihre Keyframes werden wie die jedes anderen Objekts bearbeitet. Das Öffnen einer Platzierung landet auf der Wurzel, und solange sie ausgewählt ist, läuft die Wiedergabe in Schleife über die eigene Länge der Vorlage
- Das Autospeichern friert den Editor halb so lange ein: 133 ms statt 265 ms bei einem Level von 12,3 MB. Vorher kopierte es das ganze Level zweimal, einmal für die Sicherung und einmal für das Speichern
- Das Aufräumen nach dem Speichern läuft nicht mehr im Hauptthread. Das Löschen einer veralteten Datei im anderen Format und das Rotieren der Sicherungen liefen früher mitten in einem Frame, viermal pro automatischer Speicherung
- Die Levelkarte nennt den Künstler der Musik in einer eigenen Zeile unter den Autoren des Levels. Welche Ressource genannt wird, legt das Kontrollkästchen `Auf der Levelkarte zeigen` an der Ressource selbst fest. Ein Level mit genau einer Audioressource bekommt diese Zeile ohne Kontrollkästchen
- Die Zeitleiste zeichnet keinen Clip mehr, der von einem anderen Clip auf derselben Bahn ganz verdeckt ist. Ein breiterer Clip liegt unter einem schmaleren, und ein ausgewählter oder gezogener Clip liegt über der ganzen Bahn. Ein nicht gezeichneter Clip lässt sich trotzdem per Klick auswählen
- Eine Zeitleiste gibt ihre Elemente frei, sobald sie ausgeblendet ist. Ein eingeklapptes Level und ein nicht gewählter Tab kosteten früher in jedem Frame so viel wie im geöffneten Zustand
