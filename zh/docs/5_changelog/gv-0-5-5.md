# gv 0.5.5

Android上的文件夹访问、每个设置标签页上的重置按钮，以及分辨率设置的修复

- Android：游戏通过系统的文件夹选择器打开文件夹，只能看到你选择的那个文件夹，所以不需要存储权限。设置中的`文件夹访问权限`显示所有已授权的文件夹，`撤销`会移除访问权限，不删除其中任何内容
- 每个设置标签页都有自己的重置按钮，只把这个标签页恢复为默认值
- 修复：如果之前手动或通过Alt+Enter改变过窗口大小，分辨率设置不起作用
- 关卡列表中新增了`重新扫描`按钮
- 关卡设置中有`发布`标签页。目前上面写着`开发中`

提交：游戏`7d40c382`，SDK `284ff03a`
