# Version 0.0.1

The first rendering test: many objects drawn through Unity Entities, running on Android

Three days after the start the project got its technical base. Objects are drawn through *Unity Entities* (ECS), the approach the game still uses. A test scene fills the screen with objects and changes their colours, and the draw order is taken from each object's depth

- The test build already runs on Android
- The level data model moved into its own plugin, the future SDK
- The first sprites (shapes, interface icons, skins) were carried over from an older project

A custom render pipeline was considered at this point and dropped: the standard *URP* was enough
