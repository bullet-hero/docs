# gv 0.5.5

Acceso a carpetas en Android, un botón de restablecer en cada pestaña de configuración y una corrección para la opción de resolución

- Android: el juego abre carpetas con el selector de carpetas del sistema y solo ve la carpeta que elegiste, así que no necesita permiso de almacenamiento. `Acceso a carpetas` en la configuración muestra cada carpeta concedida, y `Revocar` quita el acceso sin borrar nada de dentro
- Cada pestaña de configuración tiene su propio botón de restablecer, que devuelve a sus valores predeterminados solo esa pestaña
- Corregido: la opción de resolución no hacía nada si la ventana se había redimensionado antes, a mano o con Alt+Enter
- La lista de niveles recibió un botón `Volver a buscar`
- La configuración del nivel tiene una pestaña `Publicación`. Por ahora dice `En desarrollo`
