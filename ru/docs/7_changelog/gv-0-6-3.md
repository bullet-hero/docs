# Версия 0.6.3

Вне уровня телефон по умолчанию свободно поворачивается, а у большего числа экранов появилась вертикальная раскладка

- `Ориентация экрана` теперь по умолчанию `Автоповорот`: меню и настройки поворачиваются вслед за телефоном. Запущенный уровень по-прежнему держит ось, которую он указывает (по умолчанию горизонтальную), а редактор не подчиняется ни одной из этих настроек
- Управление, клавиши, статистика, профиль, подсказки и окно ввода значения получили вертикальную раскладку и остаются читаемыми на телефоне, который держат вертикально

Коммиты: игра `d3def6be`, SDK `56d2f0a2`
