# 第一个关卡：路线

从空文件夹到第一次试玩的六个步骤

## 六个步骤

这里只讲操作顺序。每个字段的作用，由对应面板旁边的提示说明

**1. 创建关卡**。`编辑器设置` → `创建关卡`。选择一个预设，设置名称和时长。时长之后可以修改

**2. 添加曲目**。把音频文件复制到关卡文件夹，并在关卡中接入它。`ogg`效果最好，`flac`无法加载。更多：[[2_preparing-the-track]]

**3. 标出节奏**。`节拍`标签页：BPM、偏移、每小节拍数。网格不是给游戏用的，而是给你用的：内容会吸附到网格上

不知道BPM？在`节拍网格`窗口（`Shift+T`）中跟着曲目敲出速度。敲击本身没有默认按键

**4. 放置第一批物体**。创建一个物体，给它一个形状，并在它的位置上放两个关键帧。关键帧之间的数值由游戏自动过渡

**5. 试玩**。直接从编辑器开始试玩。很可能所有东西不是移动得太快，就是太慢。这很正常：速度只能靠耳朵来调

**6. 保存**。`Ctrl+S`

自动保存默认开启。出现未保存的修改60秒后，它会保存关卡，并把一份副本放进`backups/<level id>/`。更多：[[4_not-losing-work#自动保存]]

## 第一个关卡要小

> [!tip] 建议
> 选一首短曲目，1到2分钟。4分钟的关卡工作量是四倍，半途放弃的理由是十倍

从能用的最简单的弹幕模式开始，而不是从你想到的最难的开始。在给别人看之前，自己先从头到尾玩一遍

生成器、预制件和修改器以后再用。它们在大型关卡上能节省时间，在第一个关卡上只会碍事
