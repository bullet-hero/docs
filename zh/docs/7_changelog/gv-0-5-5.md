# 版本0.5.5

Android上的文件夹访问，每个设置标签页都有重置按钮，并修复了分辨率设置

- Android：游戏通过系统的文件夹选择器打开文件夹，只能看到你选择的文件夹，因此不需要存储权限。设置中的`文件夹访问权限`列出你授权过的每个文件夹，`撤销`会移除访问权限，但不删除其中任何内容
- 每个设置标签页都有自己的重置按钮，只把该标签页恢复为默认值
- 修复：手动或用Alt+Enter调整过窗口大小后，分辨率设置不起作用
- 关卡浏览器有了`重新扫描`按钮
- 关卡设置新增`发布`标签页。目前显示`开发中`
