# gv 0.10.0

預製件圍繞真正的根物體重建，沒有尺寸關鍵幀的物體不再有自己的尺寸

- 預製件模板現在有一個真正的根物體，裡面的一切都掛在它下面。以前，把一個分組變成預製件會留下連續兩個分組物體，而且沒有辦法把它們合併。現在選中項只被包裹一次
- 沒有尺寸關鍵幀的物體現在是0乘0，而不是1乘1。空物體、特效和預製件放置都是不繪製任何內容的分組，所以它們沒有尺寸。新的形狀或文本在建立時會得到一個尺寸關鍵幀，它在`編輯器` > `建立`中設定（`新形狀寬度`、`新文本寬度`和兩個高度）
- 兩個後果：分組無法在視口中點選選中，特效則按其粒子佔據的區域來選中
- 把層級中的一行拖到另一行上即可更換它的父級，拖到空白處則移除父級。多個選中的行作為一個撤銷步驟一起移動。這適用於滑鼠和手寫筆。在手機上，父級在檢視器中更換
- 按住反引號鍵（`` ` ``）即可隱藏整個編輯器介面，只看關卡。鬆開後一切恢復。這個按鍵可以重新繫結
- 關卡瀏覽器開啟時按`最近`排序，所以最後儲存的關卡排在最上面
- 結果畫面顯示`通過`或`失敗`，而不是“勝利”或“戰敗”
- 展平預製件放置之前會先請求確認，因為放置將不再跟隨模板
- 命令面板和新增選單已翻譯。以前無論選擇什麼語言，它們都顯示英文
