# gv 1.0.0

The release: a file saved by `gv 1.0.0` opens in every later version, and a file from a newer version asks you to update the game

## What `gv 1.0.0` means for you

- **Your files keep working.** A level, your settings and your statistics saved by `gv 1.0.0` open in every later version of the game. When the file format changes, the new version converts the old file by itself as it reads it
- **A newer file is refused, not half-read.** A level or a save from a newer version opens the `Update required` window, and `Download` leads to the download page. The game does not guess at what it cannot read, so nothing is lost or silently changed. More - [[5_troubleshooting]]
- The game and SDK versions are `gv 1.0.0` and `sv 1.0.0`. The SDK still develops together with the game, so its programming interface is not promised to stay the same yet

## What changed

- **Breaks old binary levels.** A level saved as `Blob` by a version before `gv 1.0.0` does not open in `gv 1.0.0`, because the binary format was started over for the release. A level saved as `Json` is not affected. If you have an old `Blob` level, first open it in the version that made it and save it as `Json`
- The `Guidelines` section is removed from the editor settings. The guide now lives on the site, and the `Community` section has a `Documentation` link that opens it in your language
- The level list rewrites its labels when the language changes. Before, the source buttons, the sort button and the level cells stayed in the old language
- Every text of the game in both languages is now public in the docs repository, so a typo or a poor translation can be reported there or fixed yourself - [https://github.com/bullet-hero/docs](https://github.com/bullet-hero/docs)
