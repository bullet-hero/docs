# gv 0.3.0

ゲームとして動く最初のバージョン：メニュー、自分で操作するアバター、最初から最後まで遊べるレベル、最初のエディター画面

それまでエンジンはテストシーンでしかレベルを再生できませんでした。このバージョンで、その周りに*UI Toolkit*で作られたゲーム全体が現れました

- **メニューと設定**。メインメニュー、起動をまたいで保存される設定画面、プレイリスト、レベル一覧
- **レベルのプレイ**。レベルを選び、読み込み、最後までプレイできます
- **アバター**。レベル内のプレイヤー自身のシェイプで、プレイヤーが自分で操作します
- **2つの言語**。英語とロシア語のインターフェース
- **レベルの検証**。SDKはルールのセットに照らしてレベルを検証し、壊れたデータを報告できます

内蔵エディターが最初の形で登場しました。新しいレベルを作成し、フォルダーに保存し、指定した速度で再生し、現在の時間を表示できます。オブジェクトのヒエラルキーとインスペクターはまだ下書きにすぎません

`gv 0.2`はありません。番号は`gv 0.1.0`から`gv 0.3.0`に直接進みました
