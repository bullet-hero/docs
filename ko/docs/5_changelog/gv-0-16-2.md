# gv 0.16.2

휴대폰이 레벨과 설정에서 안정적으로 60프레임을 유지하고, 화면 키보드로 텍스트를 입력할 수 있습니다

## 게임

- 휴대폰은 안티앨리어싱을 끈 상태로 시작하고, 데스크톱은 계속 MSAA 방식입니다. MSAA에서 Xiaomi 2209116AG 기기는 GPU 부하가 98%였고 레벨에서 초당 47-56프레임이 나왔습니다. 대신 FXAA 방식을 쓰면 GPU 사용률은 51%였고, 레벨은 안정적으로 60프레임을 유지했습니다. FXAA도 기본값이 되지 않았는데, 포스트 프로세싱이 없는 레벨에서도 포스트 프로세싱 패스를 켜 두기 때문입니다. 그래픽 설정에서 여전히 안티앨리어싱을 켤 수 있으며, MSAA에서 다른 방식으로 바꾸면 이제 정말로 꺼집니다
- 화면 전체를 덮는 화면은 그 뒤의 레벨을 그리지 않습니다: 설정, 에디터 설정, 생성기, 비트 창. 같은 휴대폰에서 설정이 45프레임 대신 60프레임으로 실행됩니다. 레벨은 그 아래에서 계속 재생되며, 그려지지만 않을 뿐입니다
- 그래픽 설정에 게임이 실제로 유지하는 프레임 레이트 상한이 표시됩니다(예: `60 fps` 또는 `무제한`)
- 휴대폰의 텍스트 입력이 화면 키보드로 작동합니다. 필드를 열 때마다 키보드가 열리고, 완료 키는 텍스트를 저장하며 취소는 이전 텍스트를 되돌립니다. 다음 필드는 자기 키보드를 받으므로, 글자가 더 이상 숫자 필드에 들어가지 않습니다. 회색 비활성 필드는 더 이상 입력 창으로 바꿀 수 없습니다

## 에디터

- 타임라인에서 선택한 클립에 밝은 4픽셀 테두리가 생기고, 선택한 키프레임 점에는 외곽선이 생깁니다. 이전에는 선택이 클립 자체 테두리와 비슷한 색의 얇은 테두리여서 휴대폰에서는 잘 보이지 않았습니다
- 휴대폰의 에디터에서 봇이 아바타를 조종하는 동안에도 뷰포트가 터치를 받으므로, 이동하고 선택할 수 있습니다. 이전에는 뷰포트가 어떤 터치에도 반응하지 않았습니다
- `상대` 조작 모드에서는 카메라가 움직이는 동안 커서가 화면의 제자리에 머뭅니다. 이전에는 화면을 가로질러 흘러갔습니다

커밋: 게임 `d2f02b9f`, SDK `1ad7009c`
