# gv 0.3.2

Ein kleines Release für Handys: doppelt so viele Objekte gleichzeitig auf dem Bildschirm

Die Grenze für Objekte, die in einem Frame gezeichnet werden, stieg von 512 auf 1024. Etwa 1000 Objekte gleichzeitig auf einem Handy sind vorerst die Obergrenze: Mehr lassen sich weder im Speicher anlegen noch auf einer schwachen GPU schnell genug zeichnen

Außerdem wurden die Formen in einen Texturatlas gepackt, und eine Stresstest-Szene kam hinzu, um die Grenze zu messen
