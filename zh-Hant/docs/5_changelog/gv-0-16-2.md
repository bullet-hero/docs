# gv 0.16.2

手機在關卡和設定中保持穩定的60幀，文本輸入支援螢幕鍵盤

## 遊戲

- 手機啟動時關閉抗鋸齒，電腦仍使用MSAA。使用MSAA時，Xiaomi 2209116AG的GPU負載達到98%，在關卡中只有每秒47到56幀。改用FXAA時，GPU佔用51%，關卡保持穩定的60幀。FXAA也沒有成為預設選項，因為即使在沒有後期處理的關卡中，它也會讓後期處理通道保持開啟。抗鋸齒仍然可以在圖形設定中開啟，現在從MSAA切換到其他型別確實會把它關閉
- 覆蓋整個畫面的介面會停止繪製它後面的關卡：設定、編輯器設定、生成器和節拍視窗。在同一部手機上，設定以60幀執行，而不是45幀。關卡在它們下面繼續播放，只是不被繪製
- 圖形設定顯示遊戲實際保持的幀率上限，例如`60 FPS`或`無限制`
- 手機上的文本輸入支援螢幕鍵盤。每次開啟欄位時鍵盤都會開啟，它的完成鍵儲存文本，取消鍵恢復原來的文本，下一個欄位會得到自己的鍵盤，所以字母不會再輸入到數字欄位中。灰色的未啟用欄位不能再通過輸入視窗修改

## 編輯器

- 時間軸上選中的片段有一個4畫素的醒目邊框，選中的關鍵幀點有描邊。以前選中項是一個細邊框，顏色與片段自身的邊框相近，在手機上會看不出來
- 在手機上的編輯器中，機器人操控化身時，視口會把觸控留給你，所以仍然可以移動視口並在其中選擇。以前視口對任何觸控都沒有反應
- 在`相對`操作模式下，相機移動時游標停留在螢幕上的原位。以前它會在螢幕上漂移
