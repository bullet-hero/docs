# gv 0.7.0

인터페이스 사운드, 에디터 밖에서의 완전한 게임패드와 키보드 조작, 레벨 이미지의 새 설정

- 이제 인터페이스에서 소리가 납니다. 메뉴는 누를 때마다 반응하고, 레벨 에디터는 편집의 결과만 소리로 알립니다: 저장, 거부, 실행 취소 또는 다시 실행, 삭제. 버튼 위에 마우스를 올려도 어디서나 소리가 나지 않습니다: 가장 자주 일어나는 이벤트이며, 가장 먼저 귀에 거슬리기 때문입니다
- 오디오 설정의 새 슬라이더 `에디터 인터페이스`에서 에디터의 소리를 `인터페이스` 슬라이더와 따로 조절합니다. 둘 다 기본값은 50%입니다
- 에디터를 제외한 모든 것을 게임패드만으로 또는 키보드만으로 플레이할 수 있습니다. 게임패드를 쥐고 있는 동안 마우스 커서가 숨겨지고, 왼쪽 아래 모서리에 어떤 기기로 전환되었는지 잠깐 표시됩니다. 에디터 자체는 게임패드로 조작할 수 없지만, `Start` 버튼으로 에디터에서 나갈 수 있습니다
- "뒤로" 동작은 맨 위의 창만 닫습니다. 이전에는 한 번 누르면 창과 그 아래 화면까지 함께 닫힐 수 있었습니다
- 레벨 이미지에 두 가지 새 설정이 생겼습니다: `샘플링`(`부드러움` 또는 `선명함`), `압축`(`허용` 또는 `거부`). `거부` 값은 모든 픽셀을 유지하지만 메모리를 최대 4배 더 씁니다
- 이미지가 가장자리 바깥에서 어떻게 되는지를 이제 축마다 설정합니다: `래핑 X`, `래핑 Y`. 이 버전 이전에 저장된 레벨은 둘 다 `클램프` 값으로 읽으므로, 예전에 설정한 반복은 다시 설정해야 합니다
- 대시 쿨다운이 0.35초에서 0.30초가 되었습니다. 대시 후 무적 시간은 0.20초 그대로입니다
- 대시 도중에 일시 정지해도 더 이상 멈춘 레벨 위로 아바타가 끌려가지 않습니다
- 도형 깊숙이 박힌 아바타는 이제 도형의 중심에서 바깥으로 밀려납니다. 이전에는 전혀 밀려나지 않았습니다
- 계층 구조는 편집 후에도 펼친 행을 유지하며, 새 버튼 두 개로 모든 행을 한꺼번에 펼치거나 접을 수 있습니다
- 통계 오버레이에 블록 세 개를 더 표시할 수 있습니다: `프레임 오브젝트 표시`, `레벨 오브젝트 표시`, `메모리 표시`
