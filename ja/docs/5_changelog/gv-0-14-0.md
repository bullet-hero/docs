# gv 0.14.0

エフェクトが作者の意図どおりに再生され、オブジェクトからエフェクトを外せるようになり、エディターに2つの新しいショートカットが加わりました

## エフェクト

- エフェクトは、オブジェクトの向いている方向にパーティクルを放出し、タイムラインで後ろに戻っても再生時と同じものが描画されます。以前は流れがワールドに固定されていて、同じフレームでも、再生中は曲がった軌跡、後ろに戻ったあとはまっすぐな軌跡が見えることがありました
- `点`以外のエミッター形状（`円`、`線`、`円錐`、`トーラス`）は、オブジェクトと一緒に回転します。以前はワールドの向きのままで、回転したエフェクトが自分とは関係のない軸に沿ってパーティクルを生成していました
- エフェクトは画面外でもシミュレーションを続けるので、フレームに飛び込んでくるはずのパーティクルは到着前から存在します。以前はカメラの外にあるエミッターは何も生成しなかったため、エディターでは正しく見えるエフェクトがゲームでは消えることがありました。その代わり、画面外のエフェクトにもGPU時間を使います
- **既存のレベルが壊れます**。エフェクトの線形の力は、フォーマットが元々説明していたとおり、1秒あたりの加速度になりました。以前は50Hzのエフェクトレートで約50倍強く作用していました。この力が設定されているレベル（`lfrc`）は調整し直す必要があります：力`(1, 0)`のパーティクル1つは、1秒で0.51ユニット進みます。以前は25.5ユニットでした

## エディター

- `Ctrl+Shift+A`（`すべて選択解除`）は、オブジェクト、キーフレーム、オーディオ、ビートの選択を一度にすべて解除します。`Ctrl+Shift+E`（`プレハブモードを終了`）は、開いているすべてのプレハブモードのセッションを終了します。どちらも他のショートカットと同じように割り当て直せます
- エフェクトの選択欄に`なし`の項目ができたので、オブジェクトからエフェクトを外せます。以前は一度エフェクトを選ぶと、選択欄から消すことができませんでした
- エディター内から別のレベルを開くとオブジェクトの一覧が作り直され、プレハブモードは開いていたレベルと一緒に閉じます
- 領域の端の近くでタイムラインのクリップをダブルクリックしても、オブジェクトが上のトラックに引きずられなくなりました。以前は押した時点で端のスクロールが始まり、止まっているポインターの下で表示が動き、移動がレイヤーの変更になっていました
- [[12_launch-arguments|起動引数]]`--autosave on|off`は、設定を変えずに、1回の起動の間だけエディターの自動保存をオンまたはオフにします
