# Version 0.16.0

Files from a newer version are refused with a request to update, an anonymous mode that saves nothing, and a faster editor on large levels

## Versions and saves

- A file from a newer version of the game is refused with the `Update required` window instead of being opened: a level, an archive you import, or editor content on the clipboard. `Download` opens the download page on the site. In the level list such a level is marked `From a newer version of the game`. Before, the editor offered to open a newer level after a warning
- Settings or statistics saved by a newer version are left untouched. The game runs on defaults, saves nothing of its own until it is closed, and asks what to do: `Keep saves suppressed` or `Overwrite data`. A level whose own statistics are newer shows a note on its card instead of the record
- A new setting, `Suppress game saves (anonymous mode)`. While it is on, the game writes neither settings nor statistics, and what you play in that time never reaches the disk. The [[12_launch-arguments|launch argument]] `--suppress-game-saves` turns it on for the whole launch
- When `--autosave` decides the editor's autosave for a launch, the `Autosave` setting says so

## Game

- When you steer with the mouse by holding a button, a drag across the pause button no longer stops steering. A press that starts on the level stays a steer wherever it goes, and one that starts on a button stays with the button
- A cursor dash aimed at a point nearer than one unit is no longer ignored. Any target the avatar is not already standing on gets a dash scaled to the distance
- On Android the game requires Vulkan, so Google Play no longer offers it to devices without Vulkan. Those devices got a black screen

## Editor

- The editor is faster on large levels. A timeline or a panel that is not on screen no longer rebuilds on every edit and catches up when it is shown. The question "which placement owns this copy" is answered from one index per edit instead of a pass over the whole level for every selected object, field and key lane
- An edit no longer drops the selection of event and audio keyframes, and no longer clears the keyframe selection on the Local timeline
- An ordinary edit no longer plays the undo and redo sound. Only undo and redo play it
- A click on two clips with exactly the same span selects the one drawn on top. Before, it selected the hidden one, so in Prefab Mode a click on the content of a nested template selected its placement every time
- Leaving a nested prefab no longer throws the error `Collection was modified` when the outer template had a selection to restore
