# Версия 0.8.0

Таймлайн считает кадры с 1, а выделение превращается в префаб одним действием

- Кадры считаются с 1. Первый кадр уровня - кадр 1, он начинается в 0 секунд, и плейхед, инспектор и файл уровня показывают одно и то же число. Кадр ключа внутри объекта тоже начинается с 1
- Существующие уровни не конвертировались, поэтому сдвинулись три вещи. Все случайные значения выпали заново, т.к. случайное значение зависит от номеров кадров. Смерти по чекпоинтам и лучший результат, сохранённые до этой версии, читаются со сдвигом на один кадр. История отмен и автосохранения, записанные до изменения, не воспроизводятся
- Показания плейхеда выводят доли секунды в миллисекундах (`0:00.983` на кадре 60). Рядом стоит номер кадра, и прежняя запись выглядела так, будто противоречит ему
- `Создать префаб из выделения` (`Ctrl+G`) превращает выделенные объекты в префаб. То же действие есть в меню строки иерархии: `Создать префаб из этого`
- Аватар теперь вырастает, когда появляется, и сжимается в точку, когда исчезает, а не возникает и пропадает мгновенно
- Закрытые окна стоили экрану редактора 4.6 мс каждый кадр: интерфейс всё равно обходил их. Десять из них теперь полностью убираются из интерфейса, пока закрыты
- В оверлее статистики появился блок `Показывать профилирование`: сколько заняла каждая стадия симуляции
