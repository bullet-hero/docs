# gv 0.7.0

Sons de interface, controle completo por gamepad e teclado fora do editor, e configurações novas para as imagens do nível

- A interface agora faz sons. O menu responde a um toque, enquanto o editor de níveis só dá som ao resultado de uma edição: salvar, uma recusa, desfazer ou refazer, uma exclusão. Passar o cursor sobre um botão é silencioso em todo lugar: é o evento mais frequente, e o primeiro a cansar
- Um controle deslizante novo, `Interface do editor`, nas configurações de áudio controla os sons do editor separadamente de `Interface`. Os dois começam em 50%
- Tudo, menos o editor, pode ser jogado só com um gamepad ou só com um teclado. Enquanto um gamepad está na mão, o cursor do mouse fica oculto, e o canto inferior esquerdo mostra por um segundo qual dispositivo assumiu. O próprio editor não pode ser navegado com um gamepad, mas o botão `Start` leva para fora dele
- "Voltar" fecha só a janela de cima. Antes, um único toque podia fechar uma janela junto com a tela que estava embaixo
- As imagens do nível têm duas configurações novas: `Amostragem` (`Suave` ou `Nítida`) e `Compressão` (`Permitir` ou `Recusar`). `Recusar` mantém cada pixel, mas ocupa até 4 vezes mais memória
- O que uma imagem faz além das próprias bordas agora é definido por eixo: `Fora das bordas X` e `Fora das bordas Y`. Um nível salvo antes desta versão lê os dois como `Limitar`, então uma repetição definida antes precisa ser definida de novo
- O tempo de recarga do dash é 0,30 s em vez de 0,35 s. A invulnerabilidade depois de um dash continua 0,20 s
- Pausar no meio de um dash não arrasta mais o avatar pelo nível parado
- Um avatar preso bem dentro de uma forma agora é empurrado para fora a partir do centro dela. Antes, ele não recebia empurrão nenhum
- A hierarquia mantém as linhas que você expandiu depois de uma edição, e dois botões novos expandem ou recolhem todas as linhas de uma vez
- A sobreposição de estatísticas pode mostrar mais três blocos: `Mostrar objetos do quadro`, `Mostrar objetos do nível` e `Mostrar memória`
