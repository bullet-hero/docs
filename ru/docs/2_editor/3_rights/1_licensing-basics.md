# Лицензии: главное за три минуты

Можно ли взять этот трек в уровень и что для этого нужно

> [!warning] Предупреждение
> Официального сервера и сайта для уровней пока нет, они в разработке. Правила ниже уже написаны, но кнопки публикации в игре ещё нет

## Коротко

Трек можно взять, если выполнено одно из двух:
- у него открытая лицензия не строже `CC BY-NC`, например `CC0`, `CC BY`, `MIT` или `SIL OFL 1.1`
- автор прямо разрешил использовать его в уровне

Трек с YouTube, SoundCloud или Spotify без разрешения автора взять нельзя. Эти сервисы никому не выдают лицензию

То же правило работает для картинок, шрифтов и любых других файлов в уровне.
Подробнее - [[2_legal-resource-paths]]

## Дома не проверяется ничего

Уровень на вашем диске не проверяется. Ни при создании, ни при сохранении, ни при загрузке.
Уровень для себя можно собрать из каких угодно файлов, редактор не ставит условий

Проверка включается в один момент: **когда уровень отдают сервису**

## Порядок работы

1. Выберите источник до того, как строить уровень - [[3_where-to-get-resources]]
2. Нет подходящей лицензии? Спросите автора, тоже до того, как строить - [[6_asking-permission]]
3. Заполните карточку ресурса сразу, когда добавляете файл - [[4_resource-record]]
4. Перед публикацией проверьте уровень - [[5_publish-readiness]]

## Лицензия уровня

Уровни распространяются под `CC BY-NC`:
- **CC** - Creative Commons
- **BY** - нужно указывать автора
- **NC** - только некоммерческое использование

Эта лицензия покрывает **вашу работу**: расстановку, тайминги, ключи, композицию.
Чужие файлы внутри уровня она не перелицензирует. У каждого внешнего ресурса остаются свои условия, и записываются они отдельно, по ресурсу

## Годиться должен каждый ресурс

Уровень годится, только если годится каждый ресурс в нём.
Если хотя бы один не подходит ни под один из [[2_legal-resource-paths|двух вариантов]], уровень не попадёт на официальный сервер

## Чего лицензия не покрывает

Это описывают правила сервиса:
- ваше заявление, что у вас есть права, которые вы заявляете
- право оператора модерировать и удалять уровни
- право показывать название уровня в списках
- отказ от ответственности

## Почему некоммерческая

Разработчики не мешают свободно распространять уровни.
Против они только коммерческого использования

> [!info] Интересно
> Игра бесплатна: ни покупок, ни рекламы, ни платного содержимого, ни донатов, привязанных к размещённому. Поэтому условие "некоммерческое" для самой платформы выполнено. CC 4.0 лицензирует каждого получателя напрямую от автора, и цепочке автор - сервер - игрок дополнительное разрешение не нужно
