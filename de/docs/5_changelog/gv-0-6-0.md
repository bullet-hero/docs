# gv 0.6.0

Startargumente, F11 für den Vollbildmodus und die Version in den Einstellungen

- Startargumente auf dem Desktop: `--menu`, `--editor` oder `--game` wählen den ersten Bildschirm, `--level` nennt ein Level über seine ID oder seinen Ordner, und `--speed`, `--lives`, `--seed`, `--bot` und `--checkpoints` / `--no-checkpoints` richten den Lauf ein. Ein falsches Argument hält das Spiel nie vom Start ab, es hinterlässt nur eine Zeile im Log. Mehr - [[12_launch-arguments]]
- F11 schaltet auf jedem Bildschirm des Spiels den Vollbildmodus um, und ein zweiter Druck bringt das Fenster so zurück, wie es war. Die Taste ändert dieselbe Einstellung wie das Dropdown in den Einstellungen. Auf Handys gibt es sie nicht
- Die Einstellungen zeigen die Spielversion, die SDK-Version und die Generation des Levelformats in einer Zeile. Ein Klick kopiert sie in die Zwischenablage
- Eine Levelbeschreibung mit Zeilenumbrüchen dehnt ihre Zeile in der Levelliste nicht mehr: Sie bleibt einzeilig und endet mit einer Ellipse
