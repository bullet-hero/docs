# gv 0.3.3

Ein schneller Shader und eine Editorkamera, die sich mit der Maus oder zwei Fingern bewegen lässt

- **Ein neuer Shader für Levelobjekte.** Er hat einen Pass und nur das, was zum Zeichnen nötig ist, und läuft etwa doppelt so schnell wie der alte
- **Die Editorkamera.** Am PC wird sie mit der Maus bewegt, auf einem Handy mit zwei Fingern. Eine eigene Schaltfläche bringt sie zurück zum Fokus
- **Texturen.** Jede Textur des Spiels oder des Levels lässt sich jetzt mit eigenen UV-Koordinaten auf ein Objekt legen
- **Der Log-Viewer.** Die erste Version eines Bereichs, der die Meldungen des Editors zeigt

Commits: Spiel `b9d32ac7`, SDK `88c3224d`
