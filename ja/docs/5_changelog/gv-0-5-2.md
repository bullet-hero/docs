# gv 0.5.2

ルール検証が約2倍速くなり、レベルの保存時にはバックグラウンドで検証されるようになりました

- ルール検証が1.9〜2.4倍速くなりました。テストレベルvolcano（19,341個のオブジェクト）では1,614ミリ秒から850ミリ秒に、weathergirl（4,151個のオブジェクト）では264ミリ秒から112ミリ秒になりました。エディターはレベルを開くときにルール検証を実行するため、大きなレベルが速く開きます
- レベルを保存すると、ファイルがディスクに書き込まれたあとでバックグラウンドでルールに照らして検証され、見つかった問題の数が報告されます。自動では何も修正されません
- `ルール`タブでは、各行が重大度で色分けされます：エラー、警告、アドバイス
