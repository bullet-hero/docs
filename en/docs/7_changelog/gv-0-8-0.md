# Version 0.8.0

The timeline counts frames from 1, and a selection becomes a prefab in one step

- Frames count from 1. The first frame of a level is frame 1 and starts at 0 seconds, and the playhead, the inspector and the level file show the same number. A keyframe's frame inside its object starts at 1 too
- Existing levels were not converted, so three things shifted. Every random value rolled again, because a random value depends on frame numbers. Deaths per checkpoint and the best result saved before this version read back one frame off. Undo history and autosaves recorded before the change do not replay
- The playhead readout shows the part after the seconds in milliseconds (`0:00.983` on frame 60). A frame number stands right next to it, and the old form looked like that number contradicting itself
- `Create Prefab From Selection` (`Ctrl+G`) turns the selected objects into a prefab. The same action is `Create Prefab From This` in a hierarchy row's menu
- The avatar grows in when it appears and shrinks to a point when it leaves, instead of popping in and out
- Closed windows cost the editor screen 4.6 ms every frame, because the interface still walked through them. Ten of them now leave the interface completely while closed
- The statistics overlay has a `Show Profiling` block: how long each simulation stage took
