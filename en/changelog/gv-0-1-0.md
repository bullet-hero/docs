# Version 0.1.0

The first level format and the first engine that plays it: objects, themes, effects, text, audio and collisions

Six weeks of work turned the experiments into two real parts of the game. There is still no menu and no editor on screen, but a level can already be described in a file and played back

**The level format.** A level is a `JSON` file described by the SDK. It already holds objects, parents, themes (colour palettes, as in *Project Arrhythmia*), effects, audio and prefabs

**The engine that plays it.** Every frame is built by parallel jobs and then drawn:

- position, rotation, scale and parents
- colours taken from the level's theme, and textures
- the level's camera
- particle effects through one shared *VFX Graph* effect
- the level's music
- text through *UniText*, which replaced *TextMeshPro*
- collision checks, the base for hitting the player later
- prefabs placed into a level

The project also moved to Unity 6.4 in this version
