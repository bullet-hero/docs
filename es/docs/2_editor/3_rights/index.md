# Derechos

Un nivel que publicas solo puede contener archivos con una licencia abierta no más estricta que CC BY-NC o con el permiso de su autor. Un nivel para ti puede montarse con cualquier cosa

La comprobación se activa cuando el nivel sale de tu disco hacia un servidor o el sitio web
