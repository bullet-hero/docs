# gv 1.0.0

正式釋出：`gv 1.0.0`儲存的檔案可以在之後的每個版本中開啟，來自更新版本的檔案會提示你更新遊戲

## `gv 1.0.0`對你意味著什麼

- **你的檔案會一直可用**。由`gv 1.0.0`儲存的關卡、你的設定和統計資料，可以在之後每個版本的遊戲中開啟。檔案格式發生變化時，新版本會在讀取時自動轉換舊檔案
- **更新的檔案會被拒絕開啟，而不是隻讀一半**。來自更新版本的關卡或存檔會開啟`需要更新`視窗，`下載`會轉到下載頁面。遊戲不會猜測它讀不懂的內容，所以不會有任何東西丟失或被悄悄改變。更多：[[5_troubleshooting]]
- 遊戲和SDK的版本是`gv 1.0.0`和`sv 1.0.0`。SDK仍在與遊戲一起發展，所以它的程式設計介面暫時不保證保持不變

## 改動內容

- **舊的二進位制關卡無法使用**。`gv 1.0.0`之前的版本以`Blob`儲存的關卡無法在`gv 1.0.0`中開啟，因為二進位制格式在正式釋出時重新開始了。以`Json`儲存的關卡不受影響。如果你有舊的`Blob`關卡，請先在製作它的那個版本中開啟，並儲存為`Json`
- `指南`分割槽已從編輯器設定中移除。指南現在放在網站上，`社群`分割槽中有一個`文件`連結，會以你的語言開啟它
- 切換語言時，關卡列表會重寫自己的標籤。以前來源按鈕、排序按鈕和關卡單元格會停留在舊的語言
- 遊戲的所有文本（兩種語言）現在都公開在文件倉庫中，所以可以在那裡報告錯別字或不好的翻譯，也可以自己修正：[https://github.com/bullet-hero/docs](https://github.com/bullet-hero/docs)
