# gv 0.1.0

Первый формат уровня и первый движок, который его проигрывает: объекты, темы, эффекты, текст, звук и столкновения

За шесть недель эксперименты превратились в две настоящие части игры. Меню и редактора на экране ещё нет, но уровень уже можно описать в файле и проиграть

**Формат уровня.** Уровень - это файл `JSON`, который описывает SDK. В нём уже есть объекты, родители, темы (палитры цветов), эффекты, звук и префабы

**Движок, который его проигрывает.** Каждый кадр собирается параллельными задачами, а затем рисуется:

- позиция, поворот, масштаб и родители
- цвета из темы уровня и текстуры
- камера уровня
- эффекты частиц через один общий эффект *VFX Graph*
- музыка уровня
- текст через *UniText*, который заменил *TextMeshPro*
- проверка столкновений - основа, на которой позже объекты начнут задевать игрока
- префабы, размещённые в уровне

В этой же версии проект перешёл на Unity 6.4

Коммиты: игра `8c7c8844`, SDK `a5c42199`
