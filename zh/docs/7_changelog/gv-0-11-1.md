# 版本0.11.1

关卡也可以用.zip传递，时间轴新增框选工具和折叠功能，冲刺按距离缩放

没有0.11.0版本：版本号从0.10.1直接跳到了0.11.1

- 关卡除了`.tar.gz`，还可以导出和导入为`.zip`，也支持密码。`.7z`文件会按名称识别并拒绝，而不是被错误读取。游戏中所有地方关卡的“包”现在都统一叫作归档包（`关卡归档包`）
- 冲刺瞄准的点如果比完整冲刺距离更近，冲刺会按比例缩短：移动距离、无敌时间和冷却时间都更短。不到冲刺距离的三分之一时，完全不会冲刺
- 没有方向的冲刺不会发动。以前它会朝一个你并未选择的任意方向飞出去
- 冲刺在每一帧都可以转向，完整冲刺后的无敌时间为0.30秒，此前为0.20秒。这与冷却时间相等，所以不间断地冲刺，只会在两次冲刺之间留下恰好一帧的破绽
- 时间轴工具为`选择`、`边缘`、`剪刀`和新的`框选`，框选会把拖出的方框碰到的所有片段加入选中项。`边缘`和`剪刀`以前叫Trim和Blade
- `剪刀`可以把一次预制件放置切成两半，两半都从切开的位置继续播放同一个模板
- 可以把一棵子树从时间轴中折叠起来：用`选择`工具双击片段、使用标签页所在行中的按钮、层级行的菜单或`Ctrl+E`。折叠不会向关卡写入任何内容，也不占用撤销步骤
- 工具提示现在也会出现在发行版游戏中，而不只是在Unity中运行时出现。在触屏上长按即可打开工具提示。带快捷键的操作，其工具提示会显示当前绑定的快捷键
- 超过200条原本只有英文的文本已翻译
