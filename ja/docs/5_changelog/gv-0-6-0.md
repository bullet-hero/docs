# gv 0.6.0

起動引数、F11での全画面表示、設定に表示されるバージョン

- デスクトップでの起動引数：`--menu`、`--editor`、`--game`は最初の画面を選び、`--level`はIDかフォルダーでレベルを指定し、`--speed`、`--lives`、`--seed`、`--bot`、`--checkpoints` / `--no-checkpoints`はプレイの条件を設定します。間違った引数でゲームの起動が止まることはなく、ログに1行残るだけです。詳細：[[12_launch-arguments]]
- F11はゲームのどの画面でも全画面表示を切り替え、もう一度押すとウィンドウが元の状態に戻ります。このキーは、設定のドロップダウンと同じ設定を変更します。スマートフォンにはありません
- 設定に、ゲームのバージョン、SDKのバージョン、レベルフォーマットの世代が1行で表示されます。クリックするとクリップボードにコピーされます
- 改行を含むレベルの説明が、レベル一覧の行を縦に広げなくなりました：1行に収まり、末尾は省略記号になります

コミット：ゲーム`b079b86d`、SDK `29e6f26e`
