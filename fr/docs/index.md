## Versions

Chaque produit a sa propre version avec un préfixe en lettres, toujours de la forme `major.minor.revision` :

| Préfixe | Signification | Produit |
|---|---|---|
| `gv` | `game version` | le jeu (le client) |
| `sv` | `sdk version` | le SDK |
| `bv` | `backend version` | le backend, le serveur |
| `fv` | `frontend version` | le site |
| `mg` | `model generation` | les données |

S'écrit `gv 1.0.0`, `sv 1.0.0`, `bv 1.0.0`, `fv 1.0.0`, `mg 1`

Pour en savoir plus, voir [[5_versioning]]
