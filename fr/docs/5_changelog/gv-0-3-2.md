# gv 0.3.2

Une petite version pour les téléphones : deux fois plus d'objets à l'écran en même temps

La limite d'objets dessinés en une image est passée de 512 à 1024. Environ 1000 objets à la fois sur un téléphone, c'est le plafond pour l'instant : au-delà, on ne peut ni les allouer en mémoire ni les dessiner assez vite sur un GPU faible

Les formes ont aussi été regroupées dans un seul atlas de textures, et une scène de test de charge a été ajoutée pour mesurer la limite

Commits : jeu `223d907c`, SDK `d3af9547`
