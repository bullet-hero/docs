# gv 0.8.0

타임라인이 프레임을 1부터 세고, 선택 항목을 한 번의 동작으로 프리팹으로 바꿉니다

- 프레임은 1부터 셉니다. 레벨의 첫 프레임은 프레임 1이고, 0초에 시작하며, 재생 헤드, 인스펙터, 레벨 파일이 같은 숫자를 보여 줍니다. 오브젝트 안에서 키프레임의 프레임도 1부터 시작합니다
- 기존 레벨은 변환되지 않아 세 가지가 어긋났습니다. 무작위 값은 프레임 번호에 따라 달라지므로 모든 무작위 값이 다시 뽑혔습니다. 이 버전 이전에 저장된 체크포인트 사망 기록과 최고 기록은 한 프레임 어긋나게 읽힙니다. 변경 전에 기록된 실행 취소 기록과 자동 저장은 재생되지 않습니다
- 재생 헤드 표시는 초의 소수 부분을 밀리초로 보여 줍니다(프레임 60에서 `0:00.983`). 바로 옆에 프레임 번호가 있는데, 예전 표기는 그것과 모순되는 것처럼 보였습니다
- `선택 항목으로 프리팹 생성`(`Ctrl+G`) 명령은 선택한 오브젝트를 프리팹으로 바꿉니다. 같은 동작이 계층 구조 행의 메뉴에도 있습니다: `이 항목으로 프리팹 생성`
- 아바타가 이제 즉시 나타나고 사라지는 대신, 나타날 때 커지고 사라질 때 점으로 줄어듭니다
- 닫힌 창들이 에디터 화면에 매 프레임 4.6밀리초의 비용을 들게 했습니다: 인터페이스가 그래도 그 창들을 순회했기 때문입니다. 이제 그중 10개는 닫혀 있는 동안 인터페이스에서 완전히 제거됩니다
- 통계 오버레이에 `프로파일링 표시` 블록이 생겼습니다: 시뮬레이션의 각 단계에 걸린 시간
