# アバターと移動

アバターは毎秒{{v:avatar.move-speed}}ユニットで歩き、ダッシュは{{v:avatar.dash-time}}秒で{{v:avatar.dash-distance}}ユニット進みます。当たり判定は半径{{v:avatar.hitbox-radius}}ユニットの円で、描画される{{v:avatar.body-size}}ユニットの正方形より小さくなっています

このページはアバターに関する正式な基準です。ゲームと2つのボットはこの数値に合わせて作られており、SDKはこれらを`AvatarRules`定数として記録しています。このページと食い違うコードは、コード側のバグです

距離はワールド単位（ユニット）です。デフォルトのカメラの高さはちょうど{{v:camera.default-height}}ユニット（`ValueRules.DefaultZoom`）なので、1ユニットは画面の高さの10分の1で、アバターの体の幅は0.5ユニットです。カメラのズームで変わるのは見える範囲だけで、以下の数値は変わりません

## 数値

| 項目 | 値 | わかりやすく言うと |
|---|---|---|
| 歩行速度 | `{{v:avatar.move-speed}}`ユニット/秒 | 画面を上から下まで3分の2秒で横切ります |
| ダッシュ速度 | `{{v:avatar.dash-speed}}`ユニット/秒 | 歩行の{{v:avatar.dash-to-walk-ratio}}倍の速さ |
| ダッシュ時間 | `{{v:avatar.dash-time}}`秒 | |
| ダッシュ距離 | `{{v:avatar.dash-distance}}`ユニット | 速度×時間。画面の高さの4分の3 |
| ダッシュのクールダウン | `{{v:avatar.dash-cooldown}}`秒 | ダッシュの開始から数えます |
| ダッシュの無敵時間 | `{{v:avatar.dash-invulnerability}}`秒 | これも開始から数えるので、移動そのものより{{v:avatar.dash-invulnerability-margin}}秒長く続きます |
| 最短のダッシュ | `{{v:avatar.arrival-distance}}`ユニット | 到着距離と同じ。これより近ければ、すでに目標の上に立っています |
| ノックバック速度 | `{{v:avatar.knockback-speed}}`ユニット/秒 | 歩行の{{v:avatar.knockback-to-walk-ratio}}倍の速さ、[[7_damage]] |
| ノックバック時間 | `{{v:avatar.knockback-time}}`秒 | その間は操作できません |
| ダメージタイムアウト | `{{v:avatar.damage-timeout}}`秒 | その間の追加の被弾はすべて無視されます |
| 体のサイズ | `{{v:avatar.body-size}}`ユニット | 描画される正方形 |
| 当たり判定 | 半径`{{v:avatar.hitbox-radius}}`ユニット | 体の{{v:avatar.hitbox-scale}}。見た目より意図的に小さくしています |
| 出現と消滅 | `{{v:avatar.spawn-time}}`秒 | 点から大きくなり、点に縮みます |
| プレイヤーサイズが速度に与える影響 | 完全、`{{v:avatar.size-speed-influence}}` | 大きいアバターほど比例して速く動きます。これはレベルのプレイヤーサイズのトラックで、カメラのズームではありません |
| 旋回速度 | `{{v:avatar.turn-speed}}`/秒 | 見た目だけ：体がどちらを向くか |
| 到着距離 | `{{v:avatar.arrival-distance}}`ユニット | カーソルからこれより近ければ、カーソルの上に立っているとみなされます |

ここから導かれる値で、回避を左右するのはこちらです：

| 項目 | 値 |
|---|---|
| 最短のダッシュ：距離 | `{{v:avatar.arrival-distance}}`ユニット |
| 最短のダッシュ：時間 | 1フレームよりかなり短い |
| 最短のダッシュ：クールダウンと無敵時間 | どちらも1フレームよりかなり短い |
| 最も頻繁なダッシュ | 最短でも1フレームおき |
| ノックバック距離 | `{{v:avatar.knockback-distance}}`ユニット |

被弾したときに何が起きるか：[[7_damage]]

## 移動

アバターの操作方法は2つあり、ゲームが両者を混ぜることはありません：
- **方向**：WASD、ゲームパッドのスティック、ジャイロスコープ。アバターは入力した方向へ歩行速度で動きます。スティックを半分倒すと速度も半分になり、それ以外の「ゆっくり歩き」はありません
- **カーソル**：マウスまたは指。アバターはその点へテレポートするのではなく、追いかけます。自分の歩行速度で動くので、速いマウスの動きには遅れます

どちらの場合も移動は即座に反応します：加速も、滑りも、慣性もありません。入力をやめたその同じフレームで止まります

## ダッシュ

無敵時間は移動より{{v:avatar.dash-invulnerability-margin}}秒長く続きます。着地後のこの余裕があるからこそ、障害物を*すり抜けて*ダッシュできます

ダッシュ中も方向を操作できます。ダッシュは指示した方へ進みます：押している方向へ、または狙った点へ。途中で変えることもできます。方向を押していないダッシュはどこにも動きません

カーソルの場合、ダッシュは指した場所へ進み、そこで止まります：

| カーソルまでの距離 | 何が起きるか |
|---|---|
| {{v:avatar.dash-distance}}ユニットより遠い | カーソルへ向かって最大距離のダッシュ。カーソルの手前で止まります |
| {{v:avatar.arrival-distance}}ユニットから{{v:avatar.dash-distance}}ユニットまで | 短縮されたダッシュで、ちょうどカーソルの上で終わります |
| {{v:avatar.arrival-distance}}ユニットより近い | ダッシュしません |

短縮されたダッシュは、同じダッシュを縮小したものです。距離、無敵時間、クールダウンが一緒に縮みます：半分の長さのダッシュは守ってくれる時間も半分で、2倍速くチャージされます。安くなることはありません。半分のダッシュ2回は、最大距離のダッシュ1回とちょうど同じコストで、同じ距離を進みます

起きなかったダッシュにコストはかかりません：クールダウンは始まらず、何も消費されません。方向で操作していて何も押していない場合も同じで、ダッシュは起きません

ダッシュ中、体はより濃い青になり、その後{{v:avatar.dash-tint-fade}}秒かけて通常の色に戻ります。体の色を変えるものはほかにありません。被弾でも変わりません。ダッシュは自分自身の動きなので、色を変えるのはダッシュだけです

ダッシュの軌跡とこの青は、ダッシュの長さによって変わります：最大距離のダッシュでは完全に、最短のダッシュではその`{{v:avatar.dash-effect-min}}`で表示され、その間は比例します。短いダッシュはパーティクルをゆっくり放つので、軌跡の長さはダッシュの長さとちょうど同じに見えます

### 2つのスタイル、1つの予算

- `{{ui:field_common_direction}}`モードでは、ダッシュは常に{{v:avatar.dash-distance}}ユニット全部を進みます。狙わなくても距離が確実ですが、途中で止まることもできません
- カーソルなら長さを選べて、ちょうど狙った点で止まれます。短いダッシュは守られる時間も短く、ダッシュ1回ごとに無防備なフレームが1つ増えます。遠くを指せば最大距離のダッシュに戻ります

直線なら、どちらも同じ距離を同じ時間で進みます。どちらのスタイルが強いということはありません：一方は精度を、もう一方は手軽さを与えます

### 連続ダッシュ

**押しっぱなしのダッシュは無敵ではありません**。クールダウンと無敵時間は同じ長さなので、ボタンを押し続けるとダッシュが途切れずにつながります。ただし、2回のダッシュの間には必ずちょうど1フレーム、被弾しうるフレームがあります。フレームレートに関係なく、遅いスマートフォンでも速いPCでも同じです。最も詰めたつなぎ方でも、ダッシュは1フレームおきが限界です

## 当たり判定

アバターの点の輪は、ちょうど当たり判定に沿って描かれています。弾が輪郭をかすめても何も起きなかった？それは意図どおりです

無敵の間（ダッシュ中や被弾直後）は、当たり判定がまったくありません

同じ輪がライフも表しています：点灯している点は残りのライフです

輪の見えやすさは`{{ui:settings_common_title}}` → `{{ui:settings_interface_label}}` → `{{ui:settings_interface_hitbox-ring-opacity}}`で設定します。`0`にすると隠れますが、レベルは輪が見えている前提で調整されています

体は{{v:avatar.grid-cells}}個の正方形が{{v:avatar.grid-side}}×5に並んだグリッドです。体力が減ると、端から中心に向かって正方形が消えるのではなく薄くなります：失った正方形は淡い残像として残るので、グリッドには常に{{v:avatar.grid-cells}}個すべてが表示され、体力はまだ点灯している数で読み取れます。残像の正方形は十分に透明なので、体の下にある当たり判定の輪が透けて見えます。体力がゼロのときは、ちょうど1つ、最後の正方形だけが点灯しています。体力の減少は何ライフ分であっても`{{v:avatar.health-loss-time}}`秒、回復は`{{v:avatar.health-gain-time}}`秒かけて表示されます。`{{ui:settings_graphics_title}}` → `{{ui:settings_graphics_avatar-render}}`をオフにすると、体は薄くなっていく1つの正方形になります。これは性能の低いデバイス向けです

これはクラシックスキンの見た目です。スキンはグリッド、各マスの形、色を変えられます - [[16_skins]]

## 出現と消滅

アバターはレベルに`{{v:avatar.spawn-time}}`秒かけて現れ、死亡時には`{{v:avatar.spawn-time}}`秒かけて点に縮みます。どちらの間も入力に反応せず、出現中は被弾しません

## スケーリング

レベルは独自のトラックで、アバターのサイズと速度をアニメーションできます。一時的に操作を取り上げたり、衝突をオフにしたりすることもできます

- 歩行、ダッシュ、ノックバックの速度には1つの数値が掛けられます。そのため、速度が半分ならダッシュの長さも半分（{{v:avatar.half-speed-dash-distance}}ユニット）になります
- 大きいアバターほど比例して速く動きます。回避に必要な動きも大きくなるからです。ここでのサイズは、プレイヤーサイズのトラックによるアバター自身のサイズです。カメラのズームは速度も距離も時間枠も変えません：カメラがどう動いても、アバターは毎秒{{v:avatar.move-speed}}ユニット進みます
- 当たり判定は描画される体に対する割合なので、アバターと一緒に大きくも小さくもなります
- ダッシュの狙いには、表の7.5ではなく現在の距離が使われます。速度が半分のレベルでは、{{v:avatar.half-speed-dash-distance}}ユニット先のカーソルでもう最大距離のダッシュになり、{{v:avatar.arrival-distance}}ユニットのしきい値は{{v:avatar.half-speed-arrival-distance}}になります。そのしきい値より上のダッシュも半分の長さになるからです
- 秒単位の時間枠はスケーリングされません：クールダウン、無敵時間、ダメージタイムアウト、出現。ダッシュ自体の長さだけが、ダッシュ自身の2つの時間枠をスケーリングします

ボットも同じルールに従います、[[9_bots]]
