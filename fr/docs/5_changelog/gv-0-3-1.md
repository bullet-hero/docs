# gv 0.3.1

L'éditeur a appris à créer des objets, à annuler cette action et à les afficher dans la hiérarchie

Cinq jours après `gv 0.3.0`, l'éditeur est devenu plus qu'un lecteur de niveaux avec un bouton d'enregistrement

- Les objets peuvent être créés, et l'annulation et le rétablissement fonctionnent pour cela
- La hiérarchie des objets affiche les objets du niveau, et un objet peut y être masqué
- Un niveau peut être supprimé après confirmation
- Des notifications et un panneau console indiquent ce que l'éditeur vient de faire
- Lire un niveau dans l'éditeur se comporte comme dans le jeu

La version Android a aussi été ajustée pour les téléphones avec un GPU faible

Commits : jeu `393c49d2`, SDK `e2d57751`
