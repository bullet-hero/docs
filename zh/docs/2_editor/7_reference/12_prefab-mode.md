# 预制件模式

在预制件模式中，你编辑的是模板，保存会把改动带到它的每一个放置。用放置检视器中的“编辑预制件”按钮进入，用Ctrl+Shift+E回到关卡

## 预制件模式

> [!caution] 注意
> 你正在编辑模板，而不是它的某一个放置。保存会把改动带到引用此模板的每一个放置

放置的工作方式：
- 当你让一个放置指向某个模板时，这个放置会得到模板中物体的真实副本，并带有永久ID。在编辑器中，预制件的子物体完全是普通物体
- 关卡文件只保存放置本身：模板、副本的ID和覆盖。每次加载关卡时，副本都会根据模板重新构建
- 放置可以通过**实例覆盖**与模板不同。在预制件模式**之外**编辑这样的物体时，就会记录覆盖
- 在预制件模式中做的编辑不会记录覆盖。它们改变的是模板本身

> [!tip] 提示
> 模板会一层层叠加打开。模板内的放置会打开它自己的模板，`保存并关闭`会带你回来。同一个模板不能同时打开两次。嵌套最多8层

## 进入与退出

有两种进入方式：
- 放置的检视器中的`编辑预制件`
- 关卡设置`预制件`标签页中模板所在行的`编辑`。它不需要放置，所以也能打开没有放置在任何地方、或只放置在另一个模板内部的模板

右键菜单和命令面板中的`在预制件中打开`，对选中的放置或放置带来的物体起同样的作用。模板中对应的物体会立即被选中

有两种退出方式：
- 预制件时间轴上的`保存并关闭`退出一层，回到打开当前模板的那个模板
- 主工具栏上的状态（`正在编辑“...”`）和`Ctrl+Shift+E`会一次退出所有打开的模板，回到关卡

每次进入或退出时，选中项都会被清空。退回一层时，会恢复那个模板中原来的选中项

在模板内部，选择的方式与在关卡中相同：单击、按住`Ctrl`单击、框选、删除、复制和折叠。在视口中单击不会选中任何东西：视口仍然显示关卡，其中没有模板的实时预览

## 模板内部

模板的所有物体都挂在它的**根**下面。根：
- 横跨整个模板。它的长度是`帧长度`，在根的检视器中和`预制件`标签页上是同一个数字
- 不能被删除，也不能设置父级
- 它的`活动`和`图层`是只读的。这两项属于每个放置

如果恰好选中了一个物体（包括根），新物体会放到它下面。否则新物体会放到模板的顶层，也就是根下面。新物体横跨它父级的整个时段，两端都带锚点。在顶层，这就是整个模板

需要整个关卡的生成器在这里不可用。在模板内部，从选中项创建预制件和展平放置也会被拒绝

## 从选中项创建预制件

把选中的物体变成一个新模板，并在它们原来的位置放置这个模板的一个放置。之后关卡的外观和玩法都不变

在哪里找到它：
- 层级中一行的菜单里的`由此创建预制件`
- 视口的右键菜单
- 命令面板中的`从选中项创建预制件`，`Ctrl+G`
- 关卡设置`预制件`标签页中的`从选中项`

它不会请求确认，只占一步撤销。新的放置最后处于选中状态。只有一个物体时，模板使用该物体的名称。有多个物体时，模板名为`Prefab`。可以在关卡设置的`预制件`标签页中重命名

以下情况会被拒绝：
- 放置，或放置带来的物体。对于这些，菜单会改为提供`在预制件中打开`
- 会导致嵌套超过15层的选中项。不会写入任何内容，消息会说明这一点

## 展平放置

断开放置与模板的关联：它的物体变成普通的关卡物体，并保持在原来的位置

在哪里找到它：放置的检视器、层级中一行的菜单以及命令面板中的`展平预制件`

它总是先请求确认。展平之后关卡看起来完全一样，所以如果误操作展平了，往往要很久以后，当编辑模板不再影响它时才会发现。选中多个放置时，只会有一次确认和一步撤销

放置带来的物体不能单独展平。请展平它所属的放置

## 同时展平嵌套的预制件

决定你展平的预制件内部的那些预制件会怎样

**关**：只有你选中的这个放置不再跟随模板。放置在它内部的预制件仍然是放置，保留自己的关联。编辑那个内部模板仍会影响关卡。这是默认值：通常说“解包这个预制件”时，要的就是这个。每次打开确认窗口时，这个开关都是关闭的

**开**：所有嵌套的内容也一并展平。按下一次之后，关卡中不再有任何内容与这些内部模板关联，无论嵌套多深

无论哪种方式，模板本身都会保留在关卡中。整个展平只占一步撤销
