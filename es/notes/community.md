# Comunidad

Las preguntas, los comentarios y tus niveles van a Discord. Cualquiera puede ayudar al juego: corregir un error en la documentación, añadir una traducción, informar de un bug o hacer un nivel

## Dónde hablar

| Dónde | Para qué |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | preguntas, comentarios, bugs, tus niveles |
| [YouTube](https://www.youtube.com/@bulletherogame) | tráileres y videos sobre el juego |
| [GitHub](https://github.com/bullet-hero) | las partes abiertas: el SDK, esta documentación, las versiones publicadas |

Todos los enlaces del proyecto - [[links]]

## Cómo ayudar

Primero elige dónde escribir

| Qué | Dónde |
|---|---|
| Builds del juego, bugs y peticiones sobre el juego | [bullet-hero/releases](https://github.com/bullet-hero/releases) |
| El SDK, su código y los bugs que tenga | [bullet-hero/sdk](https://github.com/bullet-hero/sdk) |
| El texto de estas páginas y las traducciones | [bullet-hero/docs](https://github.com/bullet-hero/docs) |
| Preguntas y debate | [Discord](https://discord.gg/gkHQrp9NgS) |
