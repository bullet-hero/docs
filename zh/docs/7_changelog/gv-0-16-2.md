# 版本0.16.2

手机在关卡和设置中稳定60 FPS，文本输入支持屏幕键盘，Afterbeat导入保留原有结构

## 游戏

- 手机首次启动时关闭抗锯齿，桌面端保留MSAA。开启MSAA时，Xiaomi 2209116AG在关卡中的GPU占用为98%，帧率47到56 FPS。换成FXAA后GPU占用51%，关卡稳定在60 FPS。FXAA也不是默认值，因为即使关卡不使用任何后期处理，它也会让后期处理通道保持运行。你仍然可以在图形设置中开启抗锯齿，而且从MSAA切换到其他选项时，现在会真正关闭它
- 覆盖整个视图的界面会停止绘制其后方的关卡：设置、编辑器设置、生成器和节拍窗口。在同一部手机上，设置界面从45 FPS提高到60 FPS。关卡仍在下面继续播放，只是不绘制
- 图形设置显示游戏实际保持的帧率上限，例如`60 FPS`或`无限制`
- 在手机上可以用屏幕键盘输入。每次打开字段时键盘都会弹出，完成键保留输入的文本，取消键恢复原来的文本，下一个字段会有自己的键盘，因此字母不会再输入到数字字段中。灰显的字段不再能通过输入窗口编辑

## 编辑器

- 时间轴上选中的片段会有4px的亮色边框，选中的关键帧点会有一个框。以前选中状态只是一条细边框，颜色与片段自身的边框相近，在手机上根本看不出来
- 在手机上的编辑器中，机器人操控化身时视口仍会响应你的触摸，因此你仍然可以平移和选择。以前视口会忽略所有触摸
- 在`相对`操控模式下，相机移动时光标会保持在屏幕上的位置不变。以前它会在屏幕上滑动

## Afterbeat导入与导出

- 导入时会重新排布图层：深度仍然决定谁绘制在前面，但行由时间决定。子物体从1开始使用自己的图层，一次预制件放置占用一行。在关卡weathergirl上，最拥挤的一行同时存在的片段从128个降到2个，687个负值的子物体图层降到0个
- 导入会恢复预制件：展开的实例重新变回放置，嵌套的预制件则被内联
- 导出时，未改动、静态且未修剪的放置会写成真正的Afterbeat预制件物体，并省略它的副本。其他放置仍像以前一样被展平
