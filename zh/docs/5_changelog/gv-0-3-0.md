# gv 0.3.0

第一个能作为游戏运行的版本：菜单、由你操控的化身、从头玩到尾的关卡，以及第一个编辑器画面

在此之前，引擎只能在测试场景中播放关卡。这个版本围绕它搭起了整个游戏，基于*UI Toolkit*构建

- **菜单与设置**。主菜单、在多次启动之间保存的设置界面、播放列表和关卡列表
- **游玩关卡**。选择关卡、加载并玩到结束
- **化身**。玩家在关卡中自己的形状，由你操控
- **两种语言**。界面提供英文和俄文
- **关卡校验**。SDK可以按一组规则检查关卡，并报告损坏的数据

内置编辑器以最初的形态出现。它可以创建新关卡、保存到文件夹、以选定的速度播放并显示当前时间。物体层级和检视器目前只是草稿

没有`gv 0.2`：版本号从`gv 0.1.0`直接跳到了`gv 0.3.0`

提交：游戏`8d37ed8f`，SDK `4a66fd94`
