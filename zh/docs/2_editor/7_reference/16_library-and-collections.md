# 库与合集

“库”标签页、可复用资源的合集、它们从哪里来，以及它们如何进入关卡、又如何从关卡中取出

## 什么是合集

**合集**是一个存放可复用资源的文件夹。它可以包含以下七类资源：

| 类别 | 存储方式 |
|---|---|
| 预制件、主题、形状、特效 | 数据，每个条目一个文件 |
| 纹理、字体、音频 | 媒体文件 |

合集不属于任何关卡。它保存在你的设备上，你打开的每个关卡都能用

关卡从不引用合集。导入总是把内容复制到关卡中，所以关卡始终是一个自包含的文件夹，在哪里都能游玩

## 来源

库列出来自三个来源的资源。每个来源是列表上方的一个筛选标签：

| 标签 | 是什么 | 可修改 |
|---|---|---|
| `我的库` | 本设备的共享库：`resources/prefabs`、`themes`、`shapes`、`effects` | 是 |
| `我的合集` | 你自己的合集，`resources/collections` | 是 |
| `创意工坊` | 你在Steam创意工坊订阅的合集，直接在原位置读取。仅限Steam版本 | 否 |

只读合集的修改方式是：把它的条目复制到你自己的合集中

## “库”标签页

`库`是编辑器主页上的最后一个标签页，位于`社区`之后

一列窄按钮用来选择类别：
- `合集`
- `预制件`、`主题`、`形状`、`特效`
- `纹理`、`字体`、`音频`

它的右侧，页面标题在左、页面按钮在右，排成一行。列表在它们下方。空列表会在中间说明

在七个类别的页面上，从`预制件`到`音频`，`目标合集`在标题下方独占一整行。来源筛选标签位于它下面一行

库的窗口（合集信息卡、纹理图片、分享窗口）用右上角的叉号关闭，没有`关闭`按钮

每一行都是一个按钮。按下它会执行该类别的主要操作：

| 类别 | 按下一行 |
|---|---|
| 合集 | 打开它的页面 |
| 主题、形状、特效 | 打开编辑器 |
| 纹理 | 显示图片及其尺寸 |
| 预制件、字体、音频 | 无操作。音频行有自己的播放按钮 |

行右侧的小按钮是其他操作，垃圾桶图标用于删除或移除

`打开文件夹`在系统文件管理器中显示当前页面的文件夹。仅在Windows、macOS和Linux上提供

### 合集

`打开文件夹`和`刷新`位于页面标题右侧。`新建合集`和`导入压缩包`在标题下方单独一行，靠右对齐

- `新建合集`创建一个空的合集并打开它的信息卡
- `导入压缩包`从`.zip`、`.tar.gz`或`.tar`文件添加合集，也可以从带密码的压缩包添加：自带密码的`.zip`、`.zip.gpg`或`.tar.gz.gpg`。如果设备上已有这个合集，游戏会询问是否替换

带密码的压缩包会打开`需要密码`窗口：`此压缩包已加密。输入密码以打开它`。输入密码后按`打开`。
密码错误时显示`此密码无法打开该压缩包，请重试`
- `打开文件夹`打开`resources/collections`
- `刷新`重新读取文件夹

你自己的合集有`编辑`和垃圾桶图标。垃圾桶会先询问，然后删除合集及其中的所有文件

### 合集信息卡

`编辑`打开合集信息卡窗口：
- `名称`、`描述`
- `作者`，用逗号分隔
- `许可证`：`未说明`或某个常见许可证
- `封面`选择一张png图片。旁边的一行显示合集是否有封面

`保存`写入信息卡。`取消`、叉号或点击窗口外会丢弃改动

### 合集页面

| 控件 | 作用 |
|---|---|
| `返回` | 回到列表 |
| `编辑` | 打开信息卡。仅限你自己的合集 |
| `分享` | 打开分享窗口：`压缩包`，格式为`.zip`或`.tar.gz`，可带密码也可不带，在Steam版本中，你自己的合集还有`Steam创意工坊` |
| `打开文件夹` | 打开合集自己的文件夹 |
| `删除` | 询问后删除合集 |

下面是合集内容。按下一行会像在该类别页面一样打开条目，垃圾桶图标把它从合集中移除

只读合集会显示`只读。要修改条目，请把它们复制到你自己的合集`

关于`分享`的更多内容：[[17_publishing]]

### 预制件、主题、形状、特效

这些页面各自列出所有来源中的全部条目。筛选标签可以缩小列表

`目标合集`从你自己的合集中选择一个，默认为`未选择`。选好目标后，来自其他位置的每一行都会出现`复制`

主题、形状或特效会在与关卡设置相同的编辑器中打开。`保存`把改动写回条目所在的位置：`我的库`或你自己的合集。
来自创意工坊的条目以只读方式打开，`保存`不可用。要修改它，请先复制到你自己的合集

`新建`在编辑器中创建新的主题、形状或特效。它会保存到目标合集；未选择目标时保存到`我的库`。预制件在关卡中制作，没有`新建`

可以修改的条目有垃圾桶图标，它会先询问

每一行都有`分享`。它会把条目连同它需要的一切（例如预制件的形状、纹理和嵌套预制件）打包成`.zip`或`.tar.gz`（可带密码也可不带），作为只有一个条目的合集。接收者用`导入压缩包`导入该文件，和导入任何合集一样

`打开文件夹`打开该类别的设备库文件夹，例如`resources/themes`

### 纹理、字体、音频

这些页面列出所有合集中的文件。文件没有个人库，所以这几类只存在于合集中

- 纹理行会显示图片
- 音频行有播放按钮。同一时间只播放一首，离开页面时停止
- 字体行没有预览

`添加文件`把设备上的文件放入目标合集，所以需要先选择目标。纹理为png或jpg，字体为ttf或otf，音频为mp3、wav或ogg。
如果合集中已有字节完全相同的文件，则不会添加，游戏会给出提示

行上有`复制`和垃圾桶图标

### 复制会带上什么

复制会带上条目需要的一切：预制件的形状、纹理、字体和嵌套预制件，特效的粒子形状。这些资源的署名也会一并带上

## “合集”标签页

`合集`是关卡设置中的一个标签页，紧跟在`预制件`之后。顶部有两种模式：`导入`和`生成合集`

### 导入

1. 标签页列出合集。按下需要的合集
2. 勾选需要的条目。`全选`和`全不选`勾选全部或全部取消
3. `已选：N，将添加依赖：M`这一行显示将导入的内容。依赖会自动添加
4. 按`导入`

整个导入是一次撤销步骤

纹理、字体和音频会在关卡中得到新的id，它们的文件以唯一的名称复制到关卡文件夹中。
关卡中已有字节完全相同的文件时不会再次复制：导入会使用关卡自己的纹理、字体或音轨

### 生成合集

1. `目标`选择`新合集`或你自己的某个合集。新合集的名称取自`名称`
2. 勾选关卡的资源，七类中任意一类都可以
3. 按`生成`

新合集会沿用关卡的作者

受保护的关卡不能生成合集。更多：[[13_export-and-protection]]

## 选择器与搜索

搜索和资源选择器中有一个`库`层级，用于预制件、主题、形状和特效。它列出所有来源。选择器指形状、碰撞体、特效和主题字段，以及`放置预制件……`

选择库中的条目会把它连同依赖一起导入关卡，并完成指定。遇到冲突时，会提出与“合集”标签页相同的问题

关卡各资源标签页里的库浏览器也按同样的方式工作，并显示来源标签。更多：[[11_level-resources]]

## 冲突

要导入的条目可能已经以相同的id存在于关卡中：
- 内容相同：无需任何操作
- 内容不同：打开`关卡中已存在`窗口

窗口列出每一个冲突，每个冲突都有一个`作为副本导入`开关：

| 选择 | 结果 |
|---|---|
| 保留（开关关闭） | 关卡的版本保留并被使用 |
| `作为副本导入` | 合集的版本以新的id加入。与它一起导入的内容都指向这个副本 |

`全部保留`和`全部作为副本`一次设置所有开关。`导入`应用选择，`取消`什么都不导入

没有哪个版本会被悄悄选中。每一个内容不同的冲突都在这个窗口里由你决定

## 署名

关卡的资源记录除了纹理、字体和音频，也涵盖主题、特效、形状和预制件。导入会把对应的记录复制到关卡中，所以署名会随资源一起到达

更多：[[4_resource-record]]

## 磁盘上的位置

合集存放在游戏数据文件夹的`resources/collections/<collection-guid>/`中。这就是`levels`旁边存放本设备共享库的那个`resources`文件夹。更多：[[4_level-folder-and-backups]]

| 路径 | 内容 |
|---|---|
| `collection.json`或`collection.blob` | 清单：名称、描述、作者、许可证、纹理、字体和音频条目，以及其中所有内容的署名 |
| `cover.png` | 封面，可选 |
| `prefabs/`、`themes/`、`shapes/`、`effects/` | 每个条目一个`<guid>.json`或`<guid>.blob`，与本设备共享库中的文件相同 |
| `media/` | 纹理、字体和音频文件 |

合集以压缩包的形式传递：在合集页面上用`分享`，在列表中用`导入压缩包`。不是合集的压缩包会被拒绝
