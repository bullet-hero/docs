# Ссылки и сообщество

Общение и вопросы - в Discord, видео - на YouTube, ошибки в игре - в issues репозитория bullet-hero/releases. Исходный код - в организации bullet-hero на GitHub

Всё, что можно скачать: игра, SDK, магазины - [[download]]

## Социальные сети

| Источник | Описание |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | общение, вопросы, обратная связь, баги, ваши уровни |
| [YouTube](https://www.youtube.com/@bulletherogame) | трейлеры и видео об игре |

## Обратная связь

| Источник | Описание |
|---|---|
| [Game Issues](https://github.com/bullet-hero/releases/issues) | Ошибки и баги по игре (только технические) |
| [SDK Issues](https://github.com/bullet-hero/sdk/issues) | Ошибки в SDK |
| [Docs Issues](https://github.com/bullet-hero/docs/issues) | Ошибки в тексте и переводах |
| [Discord](https://discord.gg/gkHQrp9NgS) | Вопросы и обсуждение, обратная связь по игре |

## Исходный код

Все репозитории - в организации [bullet-hero](https://github.com/bullet-hero)

| Репозиторий | Доступ | Что там |
|---|---|---|
| [bullet-hero/game](https://github.com/bullet-hero/game) | закрыт | игра и редактор |
| [bullet-hero/sdk](https://github.com/bullet-hero/sdk) | открыт | SDK, issues по SDK и его коду |
| [bullet-hero/releases](https://github.com/bullet-hero/releases) | открыт | сборки игры, issues от игроков |
| [bullet-hero/docs](https://github.com/bullet-hero/docs) | открыт | эта документация |
| [bullet-hero/backend](https://github.com/bullet-hero/backend) | открыт | сервер, пока пусто |
| [bullet-hero/frontend](https://github.com/bullet-hero/frontend) | закрыт | сайт |
