# gv 0.5.5

Ordnerzugriff auf Android, eine Zurücksetzen-Schaltfläche in jedem Tab der Einstellungen und eine Korrektur der Auflösungseinstellung

- Android: Das Spiel öffnet Ordner über die Ordnerauswahl des Systems und sieht nur den Ordner, den du gewählt hast, deshalb braucht es keine Speicherberechtigung. `Ordnerzugriff` in den Einstellungen zeigt jeden freigegebenen Ordner, und `Widerrufen` entzieht den Zugriff, ohne darin etwas zu löschen
- Jeder Tab der Einstellungen hat seine eigene Zurücksetzen-Schaltfläche, die nur diesen Tab auf seine Standardwerte zurücksetzt
- Behoben: Die Auflösungseinstellung bewirkte nichts, wenn die Fenstergröße vorher geändert worden war, von Hand oder mit Alt+Enter
- Die Levelliste bekam eine Schaltfläche `Neu suchen`
- Die Leveleinstellungen haben einen Tab `Veröffentlichung`. Vorerst steht dort `In Entwicklung`
