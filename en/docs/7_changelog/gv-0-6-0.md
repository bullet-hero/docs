# Version 0.6.0

Launch arguments, F11 for full screen, the version shown in the settings, and a clearer Afterbeat import report

- Launch arguments on desktop: `--menu`, `--editor` or `--game` pick the first screen, `--level` names a level by its id or its folder, and `--speed`, `--lives`, `--seed`, `--bot` and `--checkpoints` / `--no-checkpoints` set up the run. A wrong argument never stops the game from starting, it only leaves a line in the log. More - [[12_launch-arguments]]
- F11 switches full screen on every screen of the game, and pressing it twice puts the window back where it was. It changes the same setting as the dropdown in the settings. Phones do not have it
- The settings show the game version, the SDK version and the level format generation on one line. A click copies it to the clipboard
- The Afterbeat import report lists the worst findings first and handles a long report without slowing down
- A level description with line breaks no longer stretches its row in the level list, it stays on one line and ends with an ellipsis
