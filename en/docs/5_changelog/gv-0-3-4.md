# gv 0.3.4

The first timeline, the first inspector and selecting objects right in the viewport

The editor got the three parts that work on a level is built around today. Here all three are early prototypes

- **The timeline.** Shows frame numbers and the level's objects on a frame axis
- **The inspector.** The first version of a panel with an object's properties
- **Selection.** An object can be selected in the viewport, and the selection is shared with the object hierarchy

The colours changed too. An object with a texture now carries four colours, one per corner, and blends them in a gradient. For that the object shader was rewritten on top of URP's standard *Unlit* shader
