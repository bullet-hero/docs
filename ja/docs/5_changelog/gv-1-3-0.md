# gv 1.3.0

実績、自分で描けるアバターのスキン、7つの新しい言語、Steamクラウド、そしてすべてのレベルに難易度と動作の評価が付きました

## 実績

- メインメニューの`実績`に39個の実績があり、そのうち4個はシークレットです
- 実績は統計から計算されるので、これまでにプレイした分も最初の起動から数えられます。解除された実績が再びロックされることはありません
- 数えられるのは他の人のレベルだけで、公平なクリアだけです：ボットなし、衝突オン、速度1.00以上、ライフオン
- Steam版では、Steamでも同時に解除されます。Google Play版では、Google Play Gamesにログインしていれば、そこでも解除されます

詳細：[[15_achievements]]

## アバターのスキン

- メインメニューの`アバター`でアバターハブが開きます。用意された形を選び、色を変え、目、手、影、トレイルなどのパーツをオンオフできます
- `エディター`では、1辺3〜8マスのグリッドに自分のアバターを描けます
- スキンは1つのファイルです。`マイスキン`の`エクスポート`と`インポート`で移動でき、プロファイル転送ではすべてのスキンが運ばれます（`アバターのスキン`）
- スキンが変えるのは見た目だけです。当たり判定と速度はどのスキンでも同じです

詳細：[[16_skins]]

## 言語

- 日本語、韓国語、スペイン語、フランス語、ドイツ語、ブラジルポルトガル語、繁体字中国語に対応し、全部で10言語になりました
- `設定`の言語が`システム`なら、デバイスの言語が使われます

## Steamクラウド

- Steam版では、設定、統計、実績、レベル、ライブラリ、スキンがSteamアカウントについてきます。ボタンはありません：起動時、プレイ中、終了時に同期されます
- グラフィックと操作の設定はコンピューターごとに別です
- `設定` → `その他` → `クラウドセーブ`で、同期がオンかどうかと最後に同期した時刻を確認できます

詳細：[[14_profile-transfer]]

## 難易度と動作

- レベルには`オート`から`特異点`までの難易度があります。作者が`レベル設定`（`難易度`）で決め、レベル一覧とレベルページに表示されます
- すべてのレベルに表示される5本のバーで、お使いのデバイスでどれだけ重いかがわかります。レベル一覧の`このデバイスでの動作`で絞り込めます
- このバージョンより前に保存されたレベルは、作者がもう一度保存するまで`未測定`と表示されます
- `設定` → `グラフィック` → `デバイス性能` → `このデバイスを測定`で、最長60秒のストレステストを実行します。測定するまでは、標準的なデバイスで評価されます

詳細：[[2_playing-levels]]、[[17_performance-rating]]

## Androidでのアップデート

- Google Play版とRuStore版では、アップデートがバックグラウンドでダウンロードされます。準備ができるとメインメニューに`アップデートの準備ができました`と表示され、`再起動`でインストールされます
- レベルをクリアした後、ゲームの評価を求められることがあります。3回目のクリアより前には求められず、60日に1回までです

詳細：[[1_installation]]

## エディターのAIアシスタント

- コンピューターでは、MCPに対応したAIアシスタントが、見ている前で開いているレベルを編集できます。`設定` → `エディター` → `AIエージェント（MCP）`の`AIの接続を許可`をオンにするまではオフのままです
- 接続できるのはこのコンピューターだけです。AIの編集のまとまりはそれぞれ履歴の1ステップになり、AIは何も公開、削除、上書きできません
- AIはメモをレベルの`ai`フォルダーに保存します。`このレベルにAIコンテキストを含める`を外さない限り、エクスポートとワークショップへのアップロードに含まれますが、パスワード付きのエクスポートには決して含まれません

詳細：[[7_ai-assistant]]

## 修正とその他

- Windows、macOS、Linuxの無料版には`unins000`が付いています。ゲーム自身のファイルを削除し、レベル、設定、統計は残します
- インストール後、メニューまでの起動が速くなり、テスト用のスマートフォンでは約2秒短くなりました
- 公開時に、レベルのライセンスが音楽のライセンスと合っているかを確認します
- エディターで拒否された編集が履歴に壊れたステップを残さなくなり、インスペクターのキーフレームの`フレーム`欄でキーが動くようになりました
