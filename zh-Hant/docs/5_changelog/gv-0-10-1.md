# gv 0.10.1

新的內建關卡、版本行中的構建名稱，以及更小的Android正式版

- 隨遊戲提供的兩個測試關卡被一個演示關卡`New zero demo`取代
- 設定中的版本行除了版本，還寫出構建：`gv X, sv Y, mg Z, Windows, Steam, Release`，也就是平臺、商店和構建型別。每份日誌的第一行寫的也是同樣的內容，所以錯誤報告和附帶的日誌總是指向同一個構建
- 關卡瀏覽器開啟時，所有來源篩選器都處於開啟狀態，即使只有一個來源，也會顯示來源行。存在但被篩掉的關卡，看起來就像丟失了一樣
- 正式版構建不再帶除錯符號。在Android上，124.9 MB的正式版因此減少了25.7 MB
