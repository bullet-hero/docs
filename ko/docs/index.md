## 버전

제품마다 문자 접두사가 붙은 자체 버전이 있으며, 모두 `major.minor.revision` 형식입니다:

| 접두사 | 의미 | 제품 |
|---|---|---|
| `gv` | `game version` | 게임 (클라이언트) |
| `sv` | `sdk version` | SDK |
| `bv` | `backend version` | 백엔드, 서버 |
| `fv` | `frontend version` | 웹사이트 |
| `mg` | `model generation` | 데이터 |

표기 형식은 `gv 1.0.0`, `sv 1.0.0`, `bv 1.0.0`, `fv 1.0.0`, `mg 1`입니다

자세한 내용은 [[5_versioning]]에서 읽을 수 있습니다
