# 版本1.1.0

发布到Steam创意工坊、资源合集、带教程的沙盒、快速设置、“仅碰撞体”模式和中文

> [!warning] 警告
> 1.1.0保存的文件无法在1.0.0中打开：你的设置、你的统计数据和你保存的关卡。在1.0.0中它会打开`需要更新`窗口。1.0.0的文件在1.1.0中照常打开。更多：[[5_troubleshooting]]

## 分享与创意工坊

- `分享`按钮汇集了发送关卡的所有方式。`分享方式`窗口提供`压缩包`、`Afterbeat`和`Steam创意工坊`，每种方式在发送前都会自行检查关卡
- 压缩包可以是文件夹、tar.gz或zip，zip可以用密码保护
- 在Steam版本中，关卡或合集可以直接从编辑器发布到创意工坊。再次发布同一关卡会更新你已有的物品
- 关卡、它的每个资源以及它的`封面`都可以声明是否由AI制作（`AI 生成`）。只要其中有AI制作的内容，菜单中的关卡卡片就会标明

## 合集

- 合集是一组可以在任何关卡中重复使用的资源：预制件、主题、形状、特效、纹理、字体和音频
- 编辑器设置中有`库`标签页：你自己的资源、你的合集，以及你在创意工坊订阅的合集
- `关卡设置`中有`合集`标签页。它可以连同所有依赖一起导入整个合集，也可以用关卡自己的资源组成一个合集
- 如果关卡中已经有同一资源的另一个副本，游戏会询问保留哪一个

## 游玩

- **`沙盒`**是主菜单中的新按钮。里面有六步教程（移动、冲刺、躲避、冲刺穿过圆环、选择操作模式），以及一个可以手动向自己发动攻击的面板。游戏只在首次启动时提供一次教程
- **`快速设置`**在一个画面上设置性能、画面特效、语言和音量。首次启动时它会自动打开，之后一直留在菜单中。设置中的高级分区默认折叠
- **`“仅碰撞体”模式`**位于设置的`图形`标签页。关卡只绘制可能击中你的东西，以平面填充显示在纯色背景上。音乐、碰撞和统计都保留，这里的游玩与其他游玩同样计入
- 受击后的击退距离是7.5个单位而不是10，正好是一次完整冲刺的长度。紧贴光标的极短冲刺现在总会触发
- `禅`模式重新会受击：有击退、护盾和受击效果，但不消耗生命。想让子弹穿过你，可以使用单独的`无碰撞`选项，它的游玩单独统计
- 暂停和结果窗口中的`返回参数设置`会回到开始这局游戏的画面，并保留相同的参数
- 游戏支持简体中文

## 操作

- 每个设备只有一个`启用`开关。你最后使用的设备主导操作，冲刺和暂停可以在任何启用的设备上进行
- 倾斜操作以屏幕朝上平放的手机为静止状态。不需要校准，屏幕旋转后依然正确
- 手柄上除Start和Select外，任意按键都会冲刺。Start暂停
- 松开鼠标按键时化身停下（`松开时停止`），触摸则不会（`抬起手指时停止`）。两者都可以切换
- 操作时第二根手指总是冲刺，不再按下它下面的按钮

## Android

- 没有Vulkan的手机又可以安装并游玩了。游戏会退回到OpenGL ES 3
