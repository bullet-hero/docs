# gv 0.6.0

Les arguments de lancement, F11 pour le plein écran et la version dans les paramètres

- Les arguments de lancement sur ordinateur : `--menu`, `--editor` ou `--game` choisissent le premier écran, `--level` désigne un niveau par son id ou son dossier, et `--speed`, `--lives`, `--seed`, `--bot` et `--checkpoints` / `--no-checkpoints` configurent la partie. Un argument erroné n'empêche jamais le jeu de démarrer, il laisse seulement une ligne dans le journal. Plus - [[12_launch-arguments]]
- F11 bascule le plein écran sur n'importe quel écran du jeu, et un second appui rend à la fenêtre son état précédent. La touche modifie le même paramètre que la liste déroulante des paramètres. Les téléphones ne l'ont pas
- Les paramètres affichent la version du jeu, la version du SDK et la génération du format de niveau sur une seule ligne. Un clic la copie dans le presse-papiers
- Une description de niveau avec des retours à la ligne n'étire plus sa ligne dans la liste des niveaux : elle reste sur une ligne et se termine par des points de suspension
