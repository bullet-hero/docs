# gv 0.6.0

실행 인수, 전체 화면용 F11 키, 설정에 표시되는 버전

- 데스크톱의 실행 인수: `--menu`, `--editor`, `--game` 인수는 첫 화면을 고르고, `--level` 인수는 ID나 폴더로 레벨을 지정하며, `--speed`, `--lives`, `--seed`, `--bot`, `--checkpoints` / `--no-checkpoints` 인수는 플레이를 설정합니다. 잘못된 인수가 게임 실행을 막는 일은 없으며, 로그에 한 줄이 남을 뿐입니다. 자세히 - [[12_launch-arguments]]
- F11 키는 게임의 어느 화면에서든 전체 화면을 전환하며, 다시 누르면 창이 원래대로 돌아옵니다. 이 키는 설정의 드롭다운과 같은 설정을 바꿉니다. 스마트폰에는 없습니다
- 설정에 게임 버전, SDK 버전, 레벨 형식 세대가 한 줄로 표시됩니다. 클릭하면 클립보드에 복사됩니다
- 줄 바꿈이 있는 레벨 설명이 더 이상 레벨 목록의 행을 늘리지 않습니다: 한 줄에 머물고 말줄임표로 끝납니다

커밋: 게임 `b079b86d`, SDK `29e6f26e`
