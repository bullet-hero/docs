# 编辑器的工作方式

物体、帧、时段、图层、父级、关键帧，整个编辑器建立在这六个概念之上

理解了这六个概念，编辑器的其余部分自然就能看懂：

| 概念 | 简述 |
|---|---|
| 物体 | 形状（你看到的）和碰撞体（造成伤害的），两个独立的字段 |
| 帧 | 时间的一个格子，而不是一个瞬间 |
| 时段 | 物体的存在时间：起点和时长，不包括终点 |
| 图层 | 绘制顺序，与所有父级的图层相加 |
| 父级 | 把变换、活动状态和存在时间传给子物体 |
| 关键帧 | 字段在某一帧上的数值，关键帧之间的数值由游戏自动过渡 |

遇到不认识的词：[[1_glossary]]

## 物体

物体既是被绘制的东西，也是造成伤害的东西。这是两个不同的字段：形状（你看到的）和碰撞体（造成伤害的）。一道发光但碰不到你的光束，就是有形状、没有碰撞体的物体。隐形墙则正好相反

## 帧与时段

帧是时间的一个格子，而不是一个瞬间。第30帧占据一段时间，而不是一个点。时间轴从1开始计数。长度为900帧的关卡包含第1帧到第900帧。数字901是结束边界，不是一帧

时段是物体的存在时间：起点和时长。终点不属于时段。所以首尾相接的两个物体，不会在共同的一帧上重叠

更多：[[4_frames-and-time]]

## 图层与父级

图层是绘制顺序。它是相对的：物体的图层会与它所有父级的图层相加

> [!caution] 注意
> 把物体拖到另一个父级下，即使你没有改过数字，它的绘制顺序也会改变

父级把变换、活动状态和存在时间传给子物体。子物体的时段必须位于父级的时段之内

编辑器不会裁剪你写下的值。它保留你的数值，另外计算实际生效的数值。所以缩短父级是可逆的：把它拉长回去，子物体就会回来

## 关键帧

关键帧是字段在某一帧上的数值。两个关键帧之间的数值由游戏自动过渡。每个字段都有自己的一组关键帧：位置、旋转、缩放、尺寸、锚点和轴心

> [!info] 须知
> 没有关键帧的字段并没有坏，它取默认值。不需要为了整齐给所有字段都打上关键帧

关键帧存储什么，数值如何在关键帧之间变化：[[5_keyframes-and-easing]]

## 坐标

位置、尺寸和距离都以世界单位表示。只要相机没有自己的关键帧，点(0, 0)就是屏幕中心。x向右增大，y向上增大

相机的缩放就是可见区域的高度，以单位计，默认为{{v:camera.default-height}}。所以16:9的屏幕显示的x大约从-{{v:camera.default-half-width}}到{{v:camera.default-half-width}}，y从-{{v:camera.default-half-height}}到{{v:camera.default-half-height}}。更宽或更窄的屏幕只改变宽度

位置关键帧相对于父级。它是物体轴心相对于父级锚点的偏移，并随父级一起旋转和缩放。没有父级的物体放在世界坐标中。相机的子物体随相机移动

- **轴心**：物体自身框内的一个点，位置放置的就是这个点，旋转和缩放也围绕它进行。默认为`(0.5, 0.5)`，即中心
- **锚点**：父级框内的一个点，位置从这里算起，从`(0, 0)`（左下）到`(1, 1)`（右上）。默认为中心。两个不同的锚点会让子物体随父级一起拉伸

旋转方向为逆时针。文件以弧度存储旋转，AI助手写入的也是弧度。检查器默认显示角度，编辑器设置`{{ui:settings_game-editor_interface-rotation-unit}}`可以切换为弧度
