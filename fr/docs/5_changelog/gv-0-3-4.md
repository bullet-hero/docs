# gv 0.3.4

La première timeline, le premier inspecteur et la sélection des objets directement dans la vue

L'éditeur a reçu les trois parties autour desquelles s'organise aujourd'hui le travail sur un niveau. Ici, toutes les trois sont des prototypes précoces

- **La timeline.** Affiche les numéros d'image et les objets du niveau sur un axe d'images
- **L'inspecteur.** La première version d'un panneau avec les propriétés d'un objet
- **La sélection.** Un objet peut être sélectionné dans la vue, et la sélection est partagée avec la hiérarchie des objets

Les couleurs ont changé aussi. Un objet avec une texture porte maintenant quatre couleurs, une par coin, et les mélange en dégradé. Pour cela, le shader des objets a été réécrit sur la base du shader *Unlit* standard d'URP
