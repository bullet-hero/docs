# はじめてのレベル：手順

最初のテストプレイまでは6ステップです：レベルを作成する、音楽トラックを追加する、リズムを設定する、オブジェクトを置く、テストプレイする、保存する

## 6つのステップ

ここで扱うのは作業の順番だけです。各フィールドの役割は、そのパネルの横にあるヒントが説明しています

**1. レベルを作成する**。`{{ui:settings_editor-settings_editor-settings}}` → `{{ui:settings_editor-settings_create-level}}`。プリセットを選び、名前と長さを設定します。長さは後から変更できます

**2. 音楽トラックを追加する**。オーディオファイルをレベルフォルダーにコピーし、レベルに接続します。いちばん適しているのは`ogg`で、`flac`は読み込めません。詳細：[[2_preparing-the-track]]

**3. リズムを設定する**。`{{ui:editor_inspector-beat_tab}}`タブ：BPM、オフセット、1小節の拍数。グリッドはゲームのためではなく、作者のためのものです：コンテンツがグリッドにスナップします

テンポがわからない場合は、`{{ui:editor_beat-window_title}}`ウィンドウ（`Shift+T`）で、トラックに合わせてタップして求めてください。タップ自体にはデフォルトのキーがありません

**4. 最初のオブジェクトを置く**。オブジェクトを作成し、シェイプを設定し、位置に2つのキーフレームを打ちます。キーフレームの間の値は、ゲームが自動で動かします

**5. 確認する**。エディターから直接テストプレイを始めます。おそらく、すべてが速すぎるか遅すぎるはずです。それで普通です：速度は耳で合わせるしかありません

**6. 保存する**。`Ctrl+S`

自動保存はデフォルトでオンです。未保存の編集から{{v:editor.autosave-delay}}秒後にレベルを保存し、そのコピーを`backups/<level id>/`に置きます。詳細：[[4_not-losing-work#自動保存]]

## 最初のレベルは小さく

> [!tip] 推奨
> 1分から2分の短いトラックを選ぶことをおすすめします。4分のレベルは作業量が4倍になり、未完成のまま投げ出す理由は10倍になります

思いついた中で最も難しいパターンではなく、成立する最も簡単なパターンから始めてください。誰かに見せる前に、まず自分で最初から最後までプレイしてください

ジェネレーター、プレハブ、モディファイアーは後回しにしてください。大きなレベルでは時間の節約になりますが、最初のレベルでは邪魔になります

## トラックと権利

自分のために使うトラックには、誰の許可もいりません。権利が確認されるのは公開するときだけです。詳細：[[1_licensing-basics]]

公式サーバーで公開するための規則の全文：[[ugc-licensing-policy]]
