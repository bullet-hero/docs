# gv 0.10.0

Prefabs rebuilt around a real root object, and an object without size keyframes no longer has a size of its own

- A prefab template now has a real root object, and everything inside hangs off it. Before, turning a group into a prefab left two grouping objects in a row with no way to merge them. Now the selection is wrapped once
- An object without size keyframes is now 0 by 0 instead of 1 by 1. A Rect, an effect and a prefab placement are groups that draw nothing, so they have no size. A new shape or text gets a size keyframe when it is created, set in `Game Editor` > `Creation` (`New Shape Width`, `New Text Width` and the two heights)
- Two consequences: a group cannot be selected with a click in the viewport, and an effect is selected by the area its particles take up
- Drag a hierarchy row onto another row to change its parent, and onto empty space to remove the parent. Several selected rows move as one undo step. This works with a mouse and a pen. On a phone the parent is changed in the inspector
- Hold the backquote key (`` ` ``) to hide the whole editor interface and see only the level. Release it and everything comes back. The key can be rebound
- The level browser opens sorted by `Recent`, so the level saved last is at the top
- The result screen says `Passed` or `Failed` instead of "Win" or "Lose"
- Flattening a prefab placement asks for confirmation first, because the placement stops following the template
- The command palette and the add menu are translated. Before, they showed English text whatever the language
