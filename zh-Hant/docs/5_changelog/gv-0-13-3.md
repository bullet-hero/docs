# gv 0.13.3

手機上的記憶體處理（撤銷歷史的上限、對記憶體不足警告的響應、堵住的洩漏），以及兩項預製件模式修復

- 新的編輯器設定`歷史物體數`限制撤銷歷史在步數之外最多儲存多少個物體。一次批次刪除就是一步，其中可能有50,000個物體，這個上限針對的正是這種情況。手機預設最多儲存200,000個，電腦沒有上限。`0`取消上限
- 當Android或iOS發出記憶體不足警告時，遊戲現在會響應。編輯器丟棄已經無法到達的歷史分支，遊戲則釋放不再被任何東西使用的內容。以前沒有人理會這個警告，唯一的結果就是系統關閉遊戲
- 以前每次開啟關卡，每張紋理都有兩個材質一直留在記憶體中，直到會話結束。現在它們會在關卡關閉時釋放
- 在編輯器中關閉關卡會釋放關卡資料。以前這些資料會一直留在記憶體中，直到開啟下一個關卡
- 玩完一個大型關卡後，如果為它預留的記憶體超過普通關卡的四倍，且下一個關卡用不到，遊戲會把這部分記憶體歸還
- Prefab時間軸不再在預製件模式中每次編輯後跳到最上面一行。它只在進入預製件模式時重置
- 預製件模板中沒有指定父級的頂層物體，現在會適配模板的時間軸並跟隨其錨點，與它在關卡中的副本一樣。以前貼上可能把它留在模板範圍之外，編輯器顯示的樣子與實際播放不同
