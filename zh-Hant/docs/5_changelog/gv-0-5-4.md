# gv 0.5.4

處處使用向量圖形、HUD顯示生命值、完整的顏色曲線、垂直同步，以及關卡列表中的Steam創意工坊關卡

- 所有圖示和介面影像現在都是向量圖（SVG），而不是紋理
- HUD在進度條上方用一排圓點顯示生命。失去的生命會讓對應的圓點變暗，而不是移除它，所以這一排的長度不變。無敵時這一排為空
- 顏色曲線變成了URP引擎的八條曲線：`主控`、`紅`、`綠`、`藍`、`色相/色相`、`色相/飽和`、`飽和/飽和`和`亮度/飽和`。使用舊版兩值顏色曲線的關卡會在載入時轉換
- 修復：使用預設值的顏色曲線關鍵幀會讓畫面變灰，並把色相旋轉半圈
- `垂直同步`設定，值為`關`、`開`和`半速率`，僅限電腦。開啟時，幀率上限不起作用
- Steam版本：你在Steam創意工坊訂閱的關卡會出現在關卡列表中。`顯示所有找到的內容`還會顯示磁碟上有、但未確認屬於你的內容，例如沒有訂閱的物品或手動複製的資料夾。這類關卡在卡片上標為`未訂閱`或`離線`
- 關卡的每位作者都有`分工`欄位：音樂、封面、試玩等
