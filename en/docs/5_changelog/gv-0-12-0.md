# gv 0.12.0

Curves with tangents, random values along a line, theme slot names and a long list of fixes for the timelines and Prefab Mode

## Game

- The avatar is drawn in front of layer 0 instead of behind it. Content on the layer where a new object is created is now behind the player, and to cover the player, content is put on layer 1

## Editor

- A curve is edited with tangents, not only by the position of its points. The selected keyframe gets a handle on each side, `Broken tangents` turns it into a corner, and with `Weighted tangents` the length of a handle is its weight. The preview line takes weights into account too and shows the curve that will actually play
- `Q W E R T` switch the five timelines of the bottom panel from left to right: level, local, audio, events, prefab. Because of that, `Tap Tempo` lost its `T` key. The tempo is tapped in the `Beat Grid` window (`Shift+T`), and a key for `Tap Tempo` can be assigned in `Keybindings`
- Prefab Mode selects the same way as the rest of the editor: ctrl-click adds a clip, the prefab tab has the `Marquee` tool, and many objects are edited in one inspector and deleted or copied in one undo step. Before, it selected one object at a time
- Dragging an object along a timeline drags its children with it, so the hierarchy keeps its timing. One undo brings back the whole subtree
- Each timeline tab remembers its own tool. `Reset Tool On Tab Change` in `Game Editor` > `Timeline` decides whether a tab returns to `Selection`, and it is on by default
- `Editor Playback` in the audio settings is a separate volume for playback in the editor, so the volume of the game itself stays as it was
- Autosave saves the level itself, not only a copy in `backups/`. Before, it made only the copy, and an evening of edits ended up in `backups/` and not in the level the browser shows
- After a test run the editor returns to its previous state: the camera frame, the selection and the gizmo handles work, the preview player is in place if it was there, and the playhead and speed show the same as before Play
- A click on the last cell of the local timeline puts a keyframe on frame 60 of a 60-frame object, not on 59

## Levels and format

- A theme slot can have a name. A colour field that refers to slot 12 shows `12 - background` instead of `12`
- A random vector or colour can lie on a line instead of in a rectangle: `Rnd A to B` rolls one number, and the value moves along a straight line from `From` to `To`. A random tint then reads as one tint, and a random drift as one direction. Give an axis the same number at both ends to keep it still
- An image resource has its own tiling and offset (`Tiling X`, `Tiling Y`, `Offset X` and `Offset Y` in the `Import` block). Every object with this image that has no UV keyframes of its own takes them, so a sprite sheet is described once
