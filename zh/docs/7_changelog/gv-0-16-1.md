# 版本0.16.1

化身的行走速度从每秒10个单位提高到15个单位，最短冲刺为一个化身身体的长度

- 行走速度为每秒15个单位，此前为10。化身从屏幕顶部走到底部只需三分之二秒，此前为一秒。用光标操控时，化身以行走速度追赶指针，所以快速甩动后的滞后缩短了三分之一。速度为10时，在需要精确操作的段落中会感觉太慢
- 冲刺和击退仍为每秒50个单位，所以两者现在都是行走速度的3.3倍，此前为5倍
- 最短冲刺为一个化身身体的长度，即0.5个单位。比这更近的目标完全不会触发冲刺。没有这个下限时，停在化身旁边的光标每隔一帧就会触发一次冲刺，每次都有自己的拖尾、音效和统计

化身的所有数值都集中在一个页面上：[[6_avatar]]
