# 術語表

專案的主要術語列表。遊戲介面、這份文件以及其他所有關於Bullet Hero的文字都使用這些詞，新術語要先新增到這裡

## 關卡內容

| 術語 | 含義 |
|---|---|
| **關卡** | 一次遊玩的全部內容：物體、音訊、事件和它自己的資源 |
| **物體** | 時間軸上由作者建立的一個東西，有自己的生命週期、變換和父級 |
| **空物體** | 不繪製任何內容的物體：只有變換、生命週期和子物體。其他型別都在它的基礎上新增自己的內容 |
| **形狀** | 物體繪製的真實幾何體，不是圖片。遊戲自己生成約500種 |
| **碰撞體** | 物體用來碰撞的部分。它可能與物體繪製的內容不一致 |
| **預製件** | 可複用的物體模板，可以在關卡中放置任意多次 |
| **預製件模式** | 編輯模板自身的內容，而不是它周圍的關卡 |
| **特效** | 一種生成源：每幀根據幾個引數建立自己的物體 |
| **幀內物體** | 特效生成的物體。它由引擎管理：不能選中或編輯 |
| **主題** | 關卡按索引引用的調色盤：重新配色只需改一處，而不是一百處 |

## 時間與動畫

| 術語 | 含義 |
|---|---|
| **幀** | 關卡時間的單位。幀是一個格子，時間是兩個格子之間的邊界 |
| **關鍵幀** | 某一幀上由作者設定的一個值。兩個關鍵幀之間的值會被插值 |
| **軌道** | 一個可動畫屬性的一行關鍵幀：位置、旋轉、音量 |
| **時間軸** | 編輯關卡所用的幀軸：每類內容一個標籤頁 |
| **時段** | 物體存在的時間：起始幀和長度，而不是結束幀 |
| **播放頭** | 當前正在顯示的幀 |
| **緩動** | 數值從上一個關鍵幀移動到這一個的方式 |
| **標記** | 關卡標尺上的命名點，用於回到需要的位置 |
| **檢查點** | 死亡後玩家被送回的位置 |

## 擺放與繪製

| 術語 | 含義 |
|---|---|
| **錨點** | 跟隨父級邊緣的邊：縮小父級，子物體會隨之移動 |
| **圖層** | 繪製順序，並且是相對的：子物體的圖層會加上父級的圖層 |
| **軸心** | 物體旋轉和縮放所圍繞的點，位於它自己的框內 |
| **控制柄** | 視口中繪製在選中物體上的拖拽手柄 |
| **吸附** | 把拖拽拉到某個東西上：開啟磁鐵時吸附到內容，開啟節拍開關時吸附到音樂 |

## 音樂

| 術語 | 含義 |
|---|---|
| **節拍** | 音樂自己的網格：由作者設定，遊玩時沒有任何東西讀取它 |
| **節拍段** | 一段恆定速度，有自己的速度、相位和小節長度 |
| **BPM** | 每分鐘節拍數，即一個節拍段走得多快 |
| **敲擊** | 你敲出速度時的一次按下。足夠多次敲擊就能描述一個節拍段 |

## 自動化與資料

| 術語 | 含義 |
|---|---|
| **生成器** | 創作自動化：根據幾個引數生成關卡內容 |
| **修改器** | 編輯或刪除已有內容而不是新增內容的生成器 |
| **種子** | 關卡中所有隨機值的來源數字：每次執行都完全相同地重放 |
| **原始資料** | 整個儲存模型作為一棵可編輯的樹。這裡不做任何校驗，這是有意的 |
| **AI助手** | 通過MCP連線到編輯器的AI客戶端。它在你眼前編輯開啟的關卡，每個批次操作是一個撤銷步驟 |

## 資源與分享

| 術語 | 含義 |
|---|---|
| **庫** | 裝置上供各關卡複用的資源：你的庫、你的合集和你訂閱的合集 |
| **合集** | 存放最多七類可複用資源的資料夾。匯入會從中複製內容，所以關卡不依賴它 |
