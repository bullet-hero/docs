# gv 0.10.1

新しい内蔵レベル、バージョン行のビルド名、軽くなったAndroidリリース

- ゲームに付属していた2つのテストレベルは、1つのデモレベル`New zero demo`に置き換えられました
- 設定のバージョン行は、バージョンだけでなくビルドも示します：`gv X, sv Y, mg Z, Windows, Steam, Release`、つまりプラットフォーム、ストア、ビルドの種類です。すべてのログの1行目も同じ内容なので、バグ報告と添付したログは常に同じビルドを指します
- レベルブラウザーを開くとすべてのソースフィルターがオンになっていて、ソースが1つだけでもソースの行が表示されます。存在するのにフィルターで除外されているレベルが、消えたレベルのように見えていました
- リリースビルドにデバッグシンボルが含まれなくなりました。Androidでは124.9MBのリリースのうち25.7MBの削減です

コミット：ゲーム`d7eabd71`、SDK `b77e9337`
