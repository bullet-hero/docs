# 서버

Bullet Hero의 서버는 레벨을 저장하는 웹 서비스입니다. 공식 서버 OWS, 그리고 누구나 운영할 수 있는 커뮤니티 서버 NOWS의 두 종류가 생길 예정입니다

> [!warning] 경고
> 아직 서버는 공식 서버도, 커뮤니티 서버도 없습니다. 게임과 서버 사이의 프로토콜도 설계되지 않았습니다

서버 코드는 [bullet-hero/backend](https://github.com/bullet-hero/backend)에서 공개될 예정이며, 지금은 비어 있습니다

자신과 친구들을 위한 서버가 필요하다면 - [[2_hosting]]

대규모 공개 서버가 필요하다면 - [[3_advanced-hosting]]
