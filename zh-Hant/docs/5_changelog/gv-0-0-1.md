# gv 0.0.1

第一次繪製測試：通過Unity Entities繪製大量物體，並且已經能在Android上執行

開工三天後，專案有了技術基礎。物體通過*Unity Entities*（ECS）繪製，遊戲至今仍建立在這種方式上。測試場景用物體填滿螢幕並改變它們的顏色，繪製順序取自每個物體的深度

- 測試版本已經能在Android上執行
- 關卡資料模型移到了一個單獨的外掛中，也就是後來的SDK
- 第一批精靈圖（形狀、介面圖示、皮膚）從一個更早的專案遷移過來

同一時期還考慮過自己的渲染管線，後來放棄了：標準的*URP*已經夠用

提交：遊戲`44c04ca4`，SDK `1411a228`
