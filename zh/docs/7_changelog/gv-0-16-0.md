# 版本0.16.0

来自更新版本的文件会被拒绝并提示更新，新增不保存任何数据的匿名模式，大型关卡上的编辑器更快

## 版本与存档

- 来自更新版本游戏的文件不再被打开，而是弹出`需要更新`窗口：包括关卡、你导入的归档包，以及剪贴板上的编辑器内容。`下载`会打开网站上的下载页面。在关卡列表中，这样的关卡会标记为`来自更新版本的游戏`。以前编辑器会在警告后提供打开更新版本关卡的选项
- 由更新版本保存的设置或统计数据不会被改动。游戏使用默认值运行，在关闭之前不保存任何自己的数据，并询问你如何处理：`继续停用存档`或`覆盖数据`。如果某个关卡自己的统计数据来自更新版本，它的卡片上会显示一条说明，而不是记录
- 新设置`不保存游戏数据（匿名模式）`。开启时，游戏既不写入设置也不写入统计数据，这段时间里你玩的内容都不会写入磁盘。[[12_launch-arguments|启动参数]]`--suppress-game-saves`会在整次启动中开启它
- 当`--autosave`为本次启动决定了编辑器的自动保存时，`自动保存`设置会注明这一点

## 游戏

- 按住按键用鼠标操控时，拖过暂停按钮不再中断操控。在关卡上开始的按下，无论移到哪里都保持为操控，在按钮上开始的按下则始终属于按钮
- 光标冲刺瞄准的点距离不到一个单位时，不再被忽略。只要目标不是化身已经站着的位置，就会得到一次按距离缩放的冲刺
- 在Android上，游戏需要Vulkan，因此Google Play不再向不支持Vulkan的设备提供游戏。这些设备以前会黑屏

## 编辑器

- 编辑器在大型关卡上更快了。不在屏幕上的时间轴或面板不再在每次编辑时重建，而是在显示时再更新。“这个副本属于哪次放置”这个问题，现在每次编辑只需查询一个索引，而不是为每个选中的物体、字段和关键帧行都遍历整个关卡
- 编辑不再丢失事件和音频关键帧的选中状态，也不再清除局部时间轴上的关键帧选中项
- 普通编辑不再播放撤销和重做的音效。只有撤销和重做会播放它
- 单击时段完全相同的两个片段时，会选中绘制在上层的那个。以前会选中被遮住的那个，所以在预制件模式中单击嵌套模板的内容，每次选中的都是它的放置
- 当外层模板有需要恢复的选中项时，退出嵌套预制件不再抛出错误`Collection was modified`
