# Enlaces y comunidad

Las conversaciones y preguntas van a Discord, los videos a YouTube y los bugs del juego a los issues del repositorio bullet-hero/releases. El código fuente está en la organización bullet-hero de GitHub

Todo lo que puedes descargar: el juego, el SDK, las tiendas - [[download]]

## Redes sociales

| Fuente | Descripción |
|---|---|
| [Discord](https://discord.gg/gkHQrp9NgS) | conversación, preguntas, comentarios, bugs, tus niveles |
| [YouTube](https://www.youtube.com/@bulletherogame) | tráileres y videos sobre el juego |

## Código fuente

Todos los repositorios están en la organización [bullet-hero](https://github.com/bullet-hero)

| Repositorio | Acceso | Qué contiene |
|---|---|---|
| [bullet-hero/game](https://github.com/bullet-hero/game) | cerrado | el juego y el editor |
| [bullet-hero/sdk](https://github.com/bullet-hero/sdk) | abierto | el SDK, issues sobre el SDK y su código |
| [bullet-hero/releases](https://github.com/bullet-hero/releases) | abierto | builds del juego, issues de los jugadores |
| [bullet-hero/docs](https://github.com/bullet-hero/docs) | abierto | esta documentación |
| [bullet-hero/backend](https://github.com/bullet-hero/backend) | abierto | el servidor, vacío por ahora |
| [bullet-hero/frontend](https://github.com/bullet-hero/frontend) | cerrado | el sitio |
