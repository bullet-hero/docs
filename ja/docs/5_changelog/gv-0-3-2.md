# gv 0.3.2

スマートフォン向けの小さなリリース：同時に画面に出せるオブジェクトが2倍になりました

1フレームで描画されるオブジェクトの上限が512から1024に上がりました。スマートフォンでは同時に約1,000個のオブジェクトが今のところの上限です。それ以上はメモリに確保できないか、弱いGPUで十分な速さで描画できません

シェイプも1つのテクスチャアトラスにまとめられ、上限を測るためのストレステストシーンが追加されました

コミット：ゲーム`223d907c`、SDK `d3af9547`
