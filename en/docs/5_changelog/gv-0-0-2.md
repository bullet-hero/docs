# gv 0.0.2

Textures, parents, particles, text and post-processing effects, tried one at a time in test scenes

This version is a set of experiments. Every feature a level would need got its own test, and most of them stayed

- Objects got textures
- An object can have a parent, and the object moves along with it
- Particle effects and text arrived (back then through *TextMeshPro*)
- Screen post-processing effects: the ones *Project Arrhythmia* has, and a few of its own

Everything was measured on an Android phone. According to the notes of the time, it held about 1500 objects at 30 fps. 2D shadows were tried and dropped
