# Version 0.15.0

A level that animates its screen limits runs at 19 ms a frame on Android, down from 30-45

- A level that animates its aspect with the `Screen Limit` event costs 19 ms a frame on Android, down from 30-45. The camera now always covers the whole screen, and the bars are added when the frame is put on screen. So the renderer no longer rebuilds its images on every frame the bars move
- Mouse and touch input read the same bars, so a pointer still lands where it points on a letterboxed level
