# gv 0.1.0

最初のレベルフォーマットと、それを再生する最初のエンジン：オブジェクト、テーマ、エフェクト、テキスト、サウンド、衝突

6週間で、実験はゲームの本物の2つの部分になりました。画面にはまだメニューもエディターもありませんが、レベルはすでにファイルに記述して再生できます

**レベルフォーマット**。レベルはSDKが定義する`JSON`ファイルです。オブジェクト、親、テーマ（カラーパレット）、エフェクト、サウンド、プレハブがすでに入っています

**それを再生するエンジン**。各フレームは並列ジョブで組み立てられ、そのあと描画されます：

- 位置、回転、スケール、親
- レベルのテーマの色とテクスチャ
- レベルのカメラ
- 共有の*VFX Graph*エフェクト1つによるパーティクルエフェクト
- レベルの音楽
- *TextMeshPro*に代わった*UniText*によるテキスト
- 衝突判定：のちにオブジェクトがプレイヤーに当たるようになるための土台
- レベルに配置されたプレハブ

同じバージョンで、プロジェクトはUnity 6.4に移行しました
