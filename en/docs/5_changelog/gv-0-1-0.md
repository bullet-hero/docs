# gv 0.1.0

The first level format and the first engine that plays it: objects, themes, effects, text, sound and collisions

Over six weeks the experiments turned into two real parts of the game. There is no menu or editor on screen yet, but a level can already be described in a file and played

**The level format.** A level is a `JSON` file described by the SDK. It already holds objects, parents, themes (colour palettes), effects, sound and prefabs

**The engine that plays it.** Every frame is built by parallel jobs and then drawn:

- position, rotation, scale and parents
- colours from the level's theme, and textures
- the level's camera
- particle effects through one shared *VFX Graph* effect
- the level's music
- text through *UniText*, which replaced *TextMeshPro*
- collision checks, the base on which objects will later start hitting the player
- prefabs placed in the level

In the same version the project moved to Unity 6.4
