# gv 1.0.0

Das Release: Eine Datei, die `gv 1.0.0` gespeichert hat, öffnet sich in jeder späteren Version, und eine Datei aus einer neueren Version bittet dich, das Spiel zu aktualisieren

## Was `gv 1.0.0` für dich bedeutet

- **Deine Dateien funktionieren weiter.** Ein Level, deine Einstellungen und deine Statistik, die `gv 1.0.0` gespeichert hat, öffnen sich in jeder späteren Version des Spiels. Wenn sich das Dateiformat ändert, wandelt die neue Version die alte Datei beim Lesen selbst um
- **Eine neuere Datei wird abgelehnt, nicht halb gelesen.** Ein Level oder ein Speicherstand aus einer neueren Version öffnet das Fenster `Update erforderlich`, und `Herunterladen` führt zur Download-Seite. Das Spiel rät nicht, was es nicht lesen kann, so geht nichts verloren und nichts wird still verändert. Mehr - [[5_troubleshooting]]
- Die Versionen von Spiel und SDK sind `gv 1.0.0` und `sv 1.0.0`. Das SDK entwickelt sich weiter zusammen mit dem Spiel, deshalb ist noch nicht versprochen, dass seine Programmierschnittstelle gleich bleibt

## Was sich geändert hat

- **Macht alte Binärlevels kaputt.** Ein Level, das eine Version vor `gv 1.0.0` als `Blob` gespeichert hat, öffnet sich in `gv 1.0.0` nicht, weil das Binärformat für das Release neu begonnen wurde. Ein als `Json` gespeichertes Level ist nicht betroffen. Wenn du ein altes `Blob`-Level hast, öffne es zuerst in der Version, die es erstellt hat, und speichere es als `Json`
- Der Abschnitt `Leitfaden` ist aus den Editoreinstellungen entfernt. Der Leitfaden lebt jetzt auf der Website, und der Abschnitt `Community` hat einen Link `Dokumentation`, der ihn in deiner Sprache öffnet
- Die Levelliste schreibt ihre Beschriftungen neu, wenn sich die Sprache ändert. Vorher blieben die Quellen-Schaltflächen, die Sortier-Schaltfläche und die Levelzellen in der alten Sprache
- Jeder Text des Spiels in beiden Sprachen ist jetzt öffentlich im Repository der Dokumentation, so lässt sich ein Tippfehler oder eine schwache Übersetzung dort melden oder selbst korrigieren - [https://github.com/bullet-hero/docs](https://github.com/bullet-hero/docs)
