# Servidores

Um servidor no Bullet Hero é um serviço web que guarda níveis. Haverá o servidor oficial OWS e os servidores da comunidade NOWS, que qualquer pessoa pode rodar

> [!warning] Aviso
> Ainda não há servidores, nem oficial nem da comunidade. O protocolo entre o jogo e um servidor não foi projetado

O código do servidor será aberto em [bullet-hero/backend](https://github.com/bullet-hero/backend), por enquanto o repositório está vazio
