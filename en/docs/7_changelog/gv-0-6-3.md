# Version 0.6.3

The phone turns freely outside a level by default, and more screens have a vertical layout

- `Screen Orientation` now defaults to `Auto-Rotate`: the menus and settings follow the phone when you turn it over. A running level still keeps the axis it declares (horizontal by default), and the editor answers to neither setting
- Controls, keybindings, statistics, the profile, hints and the field input window got vertical layouts, so they stay readable on an upright phone
