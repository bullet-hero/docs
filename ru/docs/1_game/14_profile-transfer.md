# Перенос профиля

Весь профиль помещается в один zip-файл: уровни, статистика, настройки и библиотека. Экспортируйте его перед переустановкой или переездом на другое устройство, а там импортируйте

Кнопки находятся в `{{ui:settings_common_title}}` → `{{ui:settings_other_title}}` → `{{ui:settings_profile-transfer_title}}`. Работает на Windows, Mac, Linux и Android. На iOS недоступно

## Что попадает в файл

| Часть | В папке данных | Отмечено по умолчанию |
|---|---|---|
| `{{ui:settings_profile-transfer_category-levels}}` | `levels` | да |
| `{{ui:settings_profile-transfer_category-statistics}}` | `stats` | да |
| `{{ui:settings_profile-transfer_category-settings}}` | `settings.json` | да |
| `{{ui:settings_profile-transfer_category-library}}` | `resources` | да |
| `{{ui:settings_profile-transfer_category-backups}}` | `backups` | нет |
| `{{ui:settings_profile-transfer_category-reports}}` | `reports` | нет |
| `{{ui:settings_profile-transfer_category-recordings}}` | `recordings` | нет |

Файл - обычный zip и открывается любым архиватором. Внутри те же папки, что и в папке данных ([[1_installation]]), плюс `profile.json`, который описывает файл

## Экспорт

1. Нажмите `{{ui:settings_profile-transfer_export}}`
2. Отметьте нужные части
3. Выберите, куда сохранить файл

Экспорт работает везде, где открываются настройки: в главном меню, на паузе забега и в редакторе. Статистика сначала записывается на диск, поэтому файл актуален

## Импорт

1. Откройте настройки из главного меню и нажмите `{{ui:settings_profile-transfer_import}}`
2. Выберите zip-файл
3. Отметьте части и выберите режим
4. Подтвердите

Импорт работает только из главного меню. Запущенный уровень или открытый редактор держат свои файлы, и заменить их на ходу нельзя

| Режим | Что происходит |
|---|---|
| `{{ui:settings_profile-transfer_mode-replace}}` | каждая отмеченная часть очищается и заполняется из файла |
| `{{ui:settings_profile-transfer_mode-merge}}` | уровни добавляются. Уровень, который есть и там и тут, целиком заменяется более новой копией. Статистика сохраняет большее значение каждого счётчика и лучший рекорд. Файлы библиотеки, автосохранения и отчёты только добавляются, ваши остаются |

Перед записью любой импорт спрашивает ещё раз. Замена называет части, которые очистит, объединение - сколько уровней добавит, заменит и оставит

**Настройки с устройства другого типа.** Профиль с телефона, импортированный на компьютер (или наоборот), сохраняет ваши собственные управление и графику. Всё остальное берётся из файла

Игра отказывается принимать файл из более новой версии игры - сначала обновите игру. Также она отказывается от файла, который не zip, от zip, который не профиль, от zip с паролем и от повреждённого файла. Ни в одном из этих случаев ничего не меняется

## Резервная копия

Перед любым импортом игра сохраняет части, которые собирается заменить, в одну резервную копию. Она лежит в папке `profile-backups` внутри папки данных. Копия одна: следующий импорт её перезаписывает

- `{{ui:settings_profile-transfer_backup-restore}}` возвращает копию. То, что она заменяет, становится новой резервной копией, поэтому восстановление тоже можно отменить
- `{{ui:settings_profile-transfer_backup-save-as}}` сохраняет копию туда, куда вы выберете
- `{{ui:settings_profile-transfer_backup-delete}}` удаляет её
- `{{ui:settings_profile-transfer_clear-cache}}` удаляет всю папку `profile-backups`: резервную копию и то, что оставил прерванный перенос

`{{ui:settings_profile-transfer_backup-to-folder}}` при импорте отмечено по умолчанию: игра сразу спросит, куда сохранить копию вне игры

> [!caution] Внимание
> На Android резервная копия лежит в папке данных игры и удаляется вместе с игрой. Перед удалением игры экспортируйте профиль или сохраните копию в другое место

Если игра закроется посреди импорта, при следующем запуске профиль вернётся в прежнее состояние

## Переход между сборками на Android

Игру, установленную из файла (itch.io и т.п.), нельзя обновить из Google Play, и наоборот. Сборки подписаны по-разному, поэтому Android отказывает в обновлении. Чтобы перейти:

1. Экспортируйте профиль и сохраните файл вне игры
2. Удалите игру
3. Установите другую сборку
4. Импортируйте профиль
