# Version 0.7.0

Interface sounds, full gamepad and keyboard control outside the editor, and new settings for level images

- The interface makes sounds now. Menus answer a press, while the level editor only sounds the result of an edit: a save, a refusal, an undo or redo, a deletion. Hovering over a button is silent everywhere, because it is the most frequent event and the first to get tiring
- A new `Editor Interface` slider in the audio settings controls the editor's sounds separately from `User Interface`. Both start at 50%
- Everything outside the editor can be played with a gamepad or a keyboard alone. The mouse cursor hides while a gamepad is in use, and a short notice in the bottom left corner shows which device took over. The editor itself is not navigated with a gamepad, but its `Start` button leads out of it
- Back closes only the topmost window. Before, one press could close a window and the screen underneath it
- Level images have two new settings: `Sampling` (`Smooth` or `Sharp`) and `Compression` (`Allow` or `Refuse`). `Refuse` keeps every pixel and costs up to 4 times the memory
- Wrapping of a level image is set per axis now, in `Wrapping X` and `Wrapping Y`. A level saved before this version reads both as `Clamp`, so a repeat set earlier has to be set again
- The dash cooldown is 0.30 s instead of 0.35 s. Invulnerability after a dash stays 0.20 s
- Pausing in the middle of a dash no longer slides the avatar across the stopped level
- An avatar caught deep inside a shape is now pushed away from its centre. Before, it got no push at all
- The hierarchy keeps the rows you unfolded after an edit, and two new buttons unfold or fold every row at once
- The statistics overlay can show three more blocks: `Show Frame Objects`, `Show Level Objects` and `Show Memory`
