# 版本0.5.1

为玩家带来检查点、统计、新的操作方式和翻译后的界面，为作者带来历史树和节拍网格，支持Afterbeat导入导出，手机画面快4倍

## 游戏

- 检查点生效。死亡会把本次游玩倒回到最后到达的检查点：关卡时钟在0.5秒内缓动停下，跳回，再缓动恢复。`失败时打开菜单`则改为弹出结果窗口
- 统计数据保存在磁盘上。关卡界面显示你所选启动选项下的`最佳`和`尝试次数`，设置中的`档案`标签页显示启动次数以及在游戏、菜单和编辑器中的时长
- 操作方式为四种设备重写：`键盘和鼠标`、`触屏`、`手柄`和`体感`。触屏有屏幕上的操控按钮
- 每个快捷键都可以在`快捷键`标签页中重新绑定，改动对整个游戏生效
- `菜单背景`提供`无`、`形状`和`机器人`三种。`机器人`是新的默认值：一个实时竞技场，由机器人操控化身并实时躲避危险
- 新增`屏幕方向`设置和各界面的竖屏布局。关卡会声明自己的方向
- 游戏自带内置关卡。它们的玩法与其他关卡相同，不能编辑，但可以复制到你自己的文件夹中编辑副本
- 界面完整提供英文和俄文，编辑器和其他界面中有提示
- 抗锯齿：`MSAA`和`FXAA`

## 编辑器

- `历史`标签页：撤销历史是一棵带分支的树，你可以跳到其中任意一点
- 时间轴工具Trim和Blade、标记，以及吸附到节拍网格
- 节拍网格：节拍段、按`T`跟着音乐敲击，以及用`由敲击创建`把敲击变成一个节拍段
- 可以选中多个物体并同时编辑它们的某个字段。复制、粘贴和创建副本
- 原始数据编辑器把整个关卡当作数据来编辑，用于检视器覆盖不到的情况
- 所有选择器都是同一个带筛选和标签的搜索窗口
- 一个开关即可显示整个关卡的碰撞体
- 字段和面板旁的`?`会打开提示，编辑器设置中还有一份写给关卡作者的指南
- `自动保存`生效，备份写入游戏的`backups`文件夹
- 编辑器偏好设置移入设置，位于编辑器标签页的9个分区中

## 关卡与格式

- 形状取代了默认纹理：约500种形状，由游戏生成。同样的形状也用作碰撞体
- 可以导入和导出Afterbeat（原名*Project Arrhythmia*）关卡
- 二进制`.blob`格式。火山测试关卡（19,341个物体）占用5.1MB，而JSON需要15.7MB，读取耗时203毫秒，而不是9,946毫秒。JSON本身的读取也快了6倍：1,837毫秒，此前为11,249毫秒

## 性能

- 手机绘制关卡的速度约快了4倍。在Snapdragon 732G（Adreno 618）上，压力测试场景的一帧从52.19毫秒降到12.94毫秒（77 FPS）
- 界面之间的加载画面取代了以前显示的绿屏
