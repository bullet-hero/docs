# 版本0.6.2

展平预制件，打开设置的启动参数，以及全屏和窗口大小的修复

- `展平预制件`把一次预制件放置变成普通物体：与模板的关联被移除，物体保持原位不动。它是预制件检视器中的一个按钮，也是一条编辑器命令，`展平预制件`修改器则对某个范围内的每次放置做同样的事。展平后关卡看起来完全相同，因为每次放置的覆盖已经写入物体
- `--settings`打开菜单并在最上层显示设置，`--settings graphics`（或其他标签页名称）打开指定的标签页
- 修复：全屏可能显示模糊的、带黑边的640x480画面，退出再进入全屏也无法恢复。现在全屏始终使用显示器自身的分辨率，想要更低的渲染分辨率请使用`渲染缩放`
- 修复：退出一次全屏后，游戏会把窗口大小记成整个显示器的大小
- 修复：单击时间轴上的关键帧并不总能打开它的检视器标签页
