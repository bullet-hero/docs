# Registro de alterações

Cada versão do jogo é uma página separada com sua lista de mudanças, e a mais recente fica no topo da lista

Toda versão desde `gv 0.0.0` tem uma página. As primeiras versões são curtas: falam mais de como o projeto começou do que de uma lista de mudanças
