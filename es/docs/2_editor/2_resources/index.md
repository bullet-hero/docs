# Recursos

El nivel mínimo es una canción. Las imágenes y las fuentes las traes tú, y todo vive en la carpeta del nivel

La canción se carga en `ogg`, `mp3` y `wav`, las imágenes en `png` y `jpg`, las fuentes en `ttf`, `otf` y `ttc`
