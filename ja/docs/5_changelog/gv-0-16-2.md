# gv 0.16.2

スマートフォンがレベルでも設定でも安定した60フレームを保ち、画面キーボードでテキストを入力できるようになりました

## ゲーム

- スマートフォンはアンチエイリアスがオフの状態で始まり、デスクトップはMSAAのままです。MSAAではXiaomi 2209116AGがGPUを98%まで使い、レベルで毎秒47～56フレームでした。代わりにFXAAにするとGPUの使用率は51%で、レベルは安定して60フレームを保ちました。FXAAもデフォルトにはなっていません。ポストプロセスのないレベルでも、ポストプロセスのパスをオンのままにするためです。アンチエイリアスは引き続きグラフィック設定でオンにでき、MSAAから別の種類に切り替えると本当にオフになるようになりました
- 画面全体を覆う画面は、その後ろのレベルの描画を止めます：設定、エディターの設定、ジェネレーター、ビートウィンドウです。同じスマートフォンで、設定は45フレームではなく60フレームで動きます。レベルはその下で再生を続けていて、描画されないだけです
- グラフィック設定には、ゲームが実際に保っているフレームレートの上限が表示されます。例：`60 fps`や`無制限`
- スマートフォンでのテキスト入力は、画面キーボードで動作します。フィールドを開くたびにキーボードが開き、完了キーでテキストを保存し、キャンセルで元のテキストに戻します。次のフィールドには専用のキーボードが開くので、数値のフィールドに文字が入ることはなくなりました。灰色の非アクティブなフィールドは、入力ウィンドウから変更できなくなりました

## エディター

- タイムラインで選択したクリップには明るい4ピクセルの枠が付き、選択したキーフレームの点には輪郭線が付きます。以前の選択はクリップ自身の枠に近い色の細い枠で、スマートフォンでは見失われていました
- スマートフォンのエディターでは、ボットがアバターを操作している間もビューポートがタッチを受け付けるので、ビューポートを動かしたり、その中で選択したりできます。以前はビューポートがどのタッチにも反応しませんでした
- `相対`操作モードでは、カメラが動いている間もカーソルは画面上の同じ位置に留まります。以前は画面上を流れていました
