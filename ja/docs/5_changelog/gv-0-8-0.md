# gv 0.8.0

タイムラインがフレームを1から数えるようになり、選択を1回の操作でプレハブに変えられるようになりました

- フレームは1から数えます。レベルの最初のフレームはフレーム1で、0秒に始まり、再生ヘッド、インスペクター、レベルファイルが同じ数字を示します。オブジェクト内のキーフレームのフレームも1から始まります
- 既存のレベルは変換されなかったため、3つのことがずれました。ランダム値はフレーム番号に依存するため、すべてのランダム値が振り直されました。このバージョンより前に保存されたチェックポイントでの死亡とベスト記録は、1フレームずれて読み込まれます。変更前に書かれた元に戻す履歴と自動保存は再生されません
- 再生ヘッドの表示は、秒の端数をミリ秒で示します（フレーム60で`0:00.983`）。すぐ隣にフレーム番号があり、以前の表記はそれと矛盾しているように見えていました
- `選択項目からプレハブを作成`（`Ctrl+G`）は、選択したオブジェクトをプレハブに変えます。同じ操作はヒエラルキーの行のメニューにもあります：`これからプレハブを作成`
- アバターは、一瞬で現れたり消えたりする代わりに、現れるときに大きくなり、消えるときに点まで縮むようになりました
- 閉じたウィンドウが、エディター画面に毎フレーム4.6ミリ秒のコストをかけていました：インターフェースが閉じたウィンドウもたどっていたためです。そのうち10個は、閉じている間はインターフェースから完全に取り除かれるようになりました
- 統計オーバーレイに`プロファイリングを表示`ブロックが加わりました：シミュレーションの各段階にかかった時間を示します

コミット：ゲーム`c5f26d08`、SDK `88af9895`
