# gv 0.14.1

手機上的修復（關卡進行中螢幕不會熄滅，記憶體清理不會打斷遊玩），以及許可證記錄和演示關卡的迴歸

- 關卡播放時螢幕不會熄滅，一旦你暫停，螢幕又會遵循系統的超時設定。以前，你按住搖桿操控的一局會被當作無操作，手機會在關卡中途鎖屏
- 在關卡進行中收到的記憶體不足警告，會在關卡停止後處理。在Android上，清理耗時163毫秒和715毫秒，在33秒的遊玩中造成了兩幀，分別為735毫秒和523毫秒，每一幀都足以讓這一局失敗。代價是：真正記憶體不足時，系統現在可能在關卡進行中關閉遊戲
- 遊戲相機只在輸出區域移動一整個畫素時才更新它。以前每幀都會更新，渲染器每秒重建60次中間影像，即使關卡的寬高比沒有變化
- `許可證`視窗可以摺疊：兩級標題現在都可以展開和收起。關卡自己的資源預設展開，隨遊戲提供的一切都摺疊
- 刪除資源也會刪除它的許可證記錄。以前`許可證`視窗還在為關卡中已經不存在的資源感謝作者。撤銷會恢復這條記錄
- 關卡封面按影像的真實型別儲存為`logo.png`或`logo.jpg`，不管原始檔叫什麼名字。既不是PNG也不是JPEG的影像不被接受
- 內建關卡`New zero demo`回來了，帶有封面，並註明了音樂作者Dunderpatrullen
