# 版本0.0.2

在测试场景中逐一试验纹理、父子关系、粒子、文本和后期效果

这个版本是一组实验。关卡需要的每项功能都有自己的测试，其中大部分保留了下来

- 物体可以带纹理
- 物体可以有父级，并随父级一起移动
- 出现了粒子特效和文本（当时文本用的是*TextMeshPro*）
- 屏幕后期效果：*Project Arrhythmia*中的那些，外加几个开发者自己做的

所有测量都在一部Android手机上进行。当时的记录显示，这部手机上约1500个物体可以跑到30 FPS。2D阴影试过，没有保留
