# gv 0.6.3

Außerhalb eines Levels dreht sich das Handy standardmäßig frei, und weitere Bildschirme bekamen ein vertikales Layout

- `Bildschirmausrichtung` steht jetzt standardmäßig auf `Automatisch drehen`: Das Menü und die Einstellungen drehen sich mit dem Handy. Ein laufendes Level hält weiterhin die Achse, die es festlegt (standardmäßig horizontal), und der Editor folgt keiner dieser Einstellungen
- Steuerung, Tastenbelegung, Statistik, das Profil, Hilfen und das Fenster zur Werteingabe bekamen ein vertikales Layout und bleiben auf einem aufrecht gehaltenen Handy lesbar
