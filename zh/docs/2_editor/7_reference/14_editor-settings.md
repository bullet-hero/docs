# 编辑器设置

编辑器的设置标签页、创建关卡、库，以及使用他人的作品

## 编辑器

自动保存、相机、选择和文件格式都在这里设置

| 设置 | 作用 | 默认值 |
|---|---|---|
| `自动保存` | 开启自动保存 | 开 |
| `自动保存频率` | 从出现未保存的编辑到自动保存之间的秒数 | 60 |
| `自动保存文件上限` | 保留多少份副本。达到上限时丢弃最旧的一份 | 25 |

只有存在未保存的编辑时，计时器才会计时

一次自动保存做两件事：
1. 把关卡的副本写入`<game folder>/backups/<level id>/`
2. 保存关卡本身，和按`Ctrl+S`一样

副本只包含关卡文件。有两种方式恢复它：
- 在关卡设置中：`危险区域` → `从备份恢复`
- 手动：把它复制到关卡文件夹中，命名为`level.json`（或`level.blob`）

更多：[[4_not-losing-work#自动保存]]

`相机最小尺寸`和`相机最大尺寸`限制编辑器视口最多能放大和缩小到什么程度

`多选需按住`和`按AABB选取不可见部分`会改变在视口中单击的含义。如果选择的行为突然和你记得的不一样，先检查这两项

`关卡格式`和`资源格式`设置写入磁盘时的默认格式

更多：[[3_speed-and-shortcuts]]

## 网格

视口网格绘制在关卡后面，帮助你摆放物体

| 设置 | 作用 | 默认值 |
|---|---|---|
| `默认显示网格` | 打开编辑器时是否显示网格。它只是初始状态 | 关 |
| `网格大小` | 一个格子的边长，以世界单位计 | 1 |
| `网格不透明度` | 线条的明显程度，从0到1 | 0.25 |

工具栏上的网格按钮用于开关网格。这个状态不会在会话之间保存

网格的外观：
- 它没有边界。缩放时格子以10倍为一级变化，更细的网格会逐渐显现
- 当某一级网格需要的线条太多时，这一级会被关闭，而不是被稀疏化
- 线条颜色始终与当前帧相机背景的颜色相反，所以背景变化时网格依然可见。只有不透明度由你决定

开启吸附时，拖动位置会吸附到半个格子：吸附到交叉点和格子中心。它使用的是你能看到的那一级网格。关闭网格时，拖动位置会吸附到固定的步长

## 选择

| 设置 | 作用 | 默认值 |
|---|---|---|
| `多选需按住` | 开：在多选模式中，只有按住`Ctrl`时单击才会添加，普通单击会替换选中项。关：多选模式开启后，每次单击都会添加 | 开 |
| `选中时预览碰撞体` | 用半透明填充绘制每个选中物体的判定框 | 关 |
| `按AABB选取不可见部分` | 单击时按物体的整个矩形来选取，而不是按它绘制的内容 | 关 |
| `长按延迟` | 长按多久才会打开菜单，以秒计 | 0.5 |
| `长按位移容差` | 长按期间指针可以偏移多远，超过就算作拖动 | 8 |
| `选中判定框不透明度` | 选中物体的判定框绘制得有多实 | 0.5 |
| `判定框视图不透明度` | 显示所有判定框的视图中的同一设置，更淡一些，因为那里有数百个判定框相互重叠 | 0.25 |

在多选模式中松开`Ctrl`不会清除任何内容，也不会退出该模式。只有下一次普通单击才会替换选中项。关于这个模式的更多内容：[[4_hierarchy-and-clipboard]]

工具栏上的碰撞体按钮会显示帧中所有内容的判定框，包括玩家的圆形判定框。这个状态不会在会话之间保存。如果屏幕上的判定框太多，这个视图会自行关闭并给出提示，而不是只绘制其中一部分

没有碰撞体的物体在两种视图中都不绘制判定框，未激活的物体也一样

## 控制柄

| 设置 | 作用 | 默认值 |
|---|---|---|
| `控制柄大小` | 视口中拖拽手柄的大小，从0.1到10。为鼠标设计大小的手柄，用拇指很难点中 | 1 |

无论如何缩放，手柄在屏幕上的大小都保持不变

## 创建关卡

`关卡预设`决定新关卡的初始内容：空的，或者一小套基础框架。没有预设的话，你每次都得手工搭建这套框架

> [!caution] 注意
> `参数`设置的是事后不便修改的内容：帧长度和帧率

> [!tip] 提示
> `“level”文件格式`和`“metadata”文件格式`下拉菜单决定关卡及其元数据以何种格式写入磁盘。两者之后都可以在关卡的`危险区域`中修改

更多：[[2_first-level]]

## 库

`库`是最后一个标签页，位于`社区`之后。这里存放你在关卡之间复用的资源：本设备的共享库、你自己的合集，以及在Steam版本中你在Steam创意工坊订阅的合集

左侧一列选择类别：先是`合集`，然后是预制件、主题、形状和特效，最后是纹理、字体和音频。你可以在这里新建、编辑合集，在合集之间复制条目，导入和导出合集，并在Steam版本中发布你自己的合集

更多：[[16_library-and-collections]]

## 使用他人的作品

关卡中的每个外部资源（音乐、图片、字体、文本）都必须满足以下两者之一：
- 许可证至少与`CC BY-NC`同等自由
- 版权所有者本人给出的许可，涵盖公开的非商业再分发

> [!caution] 注意
> 私下一句“没问题，用吧”是不够的。采用`CC BY-NC`的关卡会被公开再分发。许可必须涵盖这一点，而不只是你的个人使用

只保存在你设备上的关卡不会接受任何检查。规则只在一个时刻生效：关卡被提交给某个服务的时候
