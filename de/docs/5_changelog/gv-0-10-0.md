# gv 0.10.0

Prefabs um ein echtes Wurzelobjekt neu aufgebaut, und ein Objekt ohne Größen-Keyframes hat keine eigene Größe mehr

- Eine Prefab-Vorlage hat jetzt ein echtes Wurzelobjekt, und alles darin hängt an ihm. Vorher hinterließ das Umwandeln einer Gruppe in ein Prefab zwei gruppierende Objekte hintereinander, ohne Möglichkeit, sie zusammenzuführen. Jetzt wird die Auswahl einmal umschlossen
- Ein Objekt ohne Größen-Keyframes ist jetzt 0 mal 0 statt 1 mal 1. Ein leeres Objekt (Rect), ein Effekt und eine Prefab-Platzierung sind Gruppen, die nichts zeichnen, also haben sie keine Größe. Eine neue Form oder ein neuer Text bekommt beim Erstellen einen Größen-Keyframe, festgelegt unter `Editor` > `Erstellen` (`Breite neuer Formen`, `Breite neuer Texte` und die beiden Höhen)
- Zwei Folgen: Eine Gruppe lässt sich nicht per Klick im Viewport auswählen, und ein Effekt wird über die Fläche ausgewählt, die seine Partikel einnehmen
- Zieh eine Hierarchiezeile auf eine andere Zeile, um ihr Elternobjekt zu ändern, und auf eine leere Stelle, um das Elternobjekt zu entfernen. Mehrere ausgewählte Zeilen wandern als ein Rückgängig-Schritt. Das funktioniert mit Maus und Stift. Auf einem Handy wird das Elternobjekt im Inspector geändert
- Halte die Backtick-Taste (`` ` ``) gedrückt, um die ganze Oberfläche des Editors auszublenden und nur das Level zu sehen. Lass sie los, und alles kommt zurück. Die Taste lässt sich neu belegen
- Der Levelbrowser öffnet sich nach `Zuletzt` sortiert, so steht das zuletzt gespeicherte Level oben
- Der Ergebnisbildschirm sagt `Bestanden` oder `Verloren` statt "Win" oder "Lose"
- Das Auflösen einer Prefab-Platzierung fragt zuerst nach einer Bestätigung, weil die Platzierung danach der Vorlage nicht mehr folgt
- Die Befehlspalette und das Hinzufügen-Menü sind übersetzt. Vorher zeigten sie unabhängig von der Sprache englischen Text
