# 連線伺服器

遊戲將有面向所有版本的官方伺服器OWS，以及僅面向完整版的社群伺服器NOWS。Bullet Hero不稽核社群伺服器，請只連線你認識其所有者的伺服器

> [!warning] 警告
> 目前還沒有伺服器，遊戲也無法連線伺服器。沒有地址格式，沒有連線介面，也沒有賬號

## 將會有哪些伺服器

| | OWS | NOWS |
|---|---|---|
| 全稱 | Official Web Services | Non-official web services |
| 由誰執行 | Bullet Hero | 任何人 |
| 由誰稽核 | Bullet Hero | 伺服器所有者 |
| 可連線的版本 | 全部 | 僅完整版 |

**OWS是預設伺服器**。每個平臺上的每個遊戲版本都認識它，無需任何設定

**NOWS是社群伺服器**。Bullet Hero既不控制也不稽核它們

**Steam創意工坊是PC上的第三個關卡渠道**。Steam版可以列出並啟動你訂閱的物品，也可以在編輯器中把關卡和合集釋出到那裡：[[17_publishing]]

## 哪些版本可以連線

| 版本 | 來源 | OWS | NOWS |
|---|---|---|---|
| 商店版 | Google Play、App Store | 是 | 否 |
| 完整版 | [GitHub](https://github.com/bullet-hero/releases)和專案網站 | 是 | 是 |

商店版無論如何都無法連線社群伺服器。對NOWS的支援在編譯時就從中移除了，而不是藏在某個設定後面

原因在於商店規則。商店評判的是程式能做什麼，而不是它顯示了哪些按鈕。而按照商店規則，其他人能看到的內容必須經過稽核

計劃為完整版分配獨立的應用ID，這樣在Android上它可以與商店版並存安裝。目前所有Android版本共用一個ID：`com.vertoker.BulletHero`

## OWS將提供什麼

- 賬號和使用條款
- 每個關卡釋出前都要檢查：有錯誤的關卡會被拒絕，有警告的關卡交給稽核員
- 舉報關卡和使用者，以及封禁它們

賬號中儲存什麼還沒有決定。伺服器將有自己的隱私政策，與伺服器同時出現。它會說明賬號的內容，並解釋如何刪除賬號。遊戲和網站的隱私政策不涵蓋伺服器：[[game-privacy-policy]]、[[privacy-policy]]

## 什麼時候

釋出到Steam創意工坊已經可以在Steam版中使用。其餘部分沒有日期。順序是：先是OWS，然後是Google Play版，最後是App Store版

在伺服器上一起遊玩目前還沒有，也沒有設計

## 他人伺服器的風險

社群伺服器的執行者很可能是你不認識的人。Bullet Hero既不控制也不稽核這類伺服器。完整版的EULA明確說明了這一點

| 風險 | 原因 |
|---|---|
| 關卡的權利未經檢查 | 檢查什麼由所有者決定，也可能什麼都不檢查。關卡中可能帶有作者無權分享的音樂 |
| 沒有人稽核內容 | 無法保證有人檢視上傳的內容 |
| 來自其他網站的檔案 | 標準策略允許關卡通過直接連結獲取檔案。開啟這樣的關卡時，遊戲會從關卡作者選定的網站下載檔案。因此商店版禁止這樣做 |
| 所有者能看到你的流量 | 目前還沒有協議，所以不知道伺服器具體會收到什麼。請認為所有者能看到你傳送的一切 |
| 伺服器可能消失 | 只存在於該伺服器上的關卡會隨之消失 |

關卡預設以*CC BY-NC*釋出，作者可以在關卡後設資料中選擇其他許可證。伺服器必須遵守每個關卡的許可證。在*CC BY-NC*下，任何人都不得以商業方式託管關卡，社群伺服器也不例外，對這類關卡收費的伺服器違反了其中每位作者的許可證

> [!tip] 建議
> 只連線你認識其所有者的伺服器。為每個你在意的關卡保留一份自己的副本：關卡就是一個裝有檔案的資料夾，你磁碟上的副本不依賴任何伺服器

## EULA

完整版附帶一份EULA。其中寫明：社群伺服器是第三方服務，Bullet Hero既不控制也不稽核它們

商店版會在釋出關卡前要求你接受EULA

這些文本都還沒有寫
