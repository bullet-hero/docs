# パフォーマンス評価

プレイする前に、レベルがあなたのデバイスでどれだけ重いかを、ゲームが5本のバーのゲージで表示します：点灯しているバーが多いほど、レベルは軽くなります。緑のバーは快適に動作、黄はぎりぎり、赤はフレームレートが落ちることを表します

スコアは数値で、`{{v:performance.score-limit}}` がちょうど目標フレームレートで1フレームにかけられる時間に当たります。区分はスコアで決まります：

| バー | 区分 | スコア |
|---|---|---|
| 5 | `{{ui:level_performance_holds}}` | `{{v:performance.score-warning}}` 未満 |
| 4 | `{{ui:level_performance_tight}}` | `{{v:performance.score-warning}}` から `{{v:performance.score-limit}}` まで |
| 3 | `{{ui:level_performance_drops}}` | `{{v:performance.score-limit}}` を超え、`{{v:performance.score-heavy}}` まで |
| 2 | `{{ui:level_performance_severe-drops}}` | `{{v:performance.score-heavy}}` を超え、`{{v:performance.score-severe}}` まで |
| 1 | `{{ui:level_performance_does-not-hold}}` | `{{v:performance.score-severe}}` を超える |
| なし | `{{ui:level_performance_unknown}}` | レベルかデバイスがまだ測定されていない |

スコアはレベルの平均ではなく、最も重い場面の予測です。3分間は軽く、1秒だけ止まるレベルは、その1秒のスコアになります

## どこで見られるか

- レベルブラウザー：各レベルカードのゲージと、フィルターの `{{ui:root_level-filters_performance}}` グループ
- メニューのレベルページ：ゲージ、区分、スコア
- レベルエディターのレベルのメタデータ：あなたのデバイスと基準デバイスでのスコア、そしてレベルの最も重い場面のタイムスタンプ

## スコアの2つの半分

**レベルの半分**は保存のたびにその後の数秒間、作業を続けている間にエディターで測定され、そのメタデータに保存されます。終わる前にエディターを離れると、ファイルには前回の測定が残ります。レベルが何を要求するかを表します：生きているオブジェクトの数、それが画面のどれだけを覆うか、エフェクトとポストプロセスのパスがいくつ動くか。この機能より前に保存されたレベルにはこの記録がなく、もう一度保存されるまで `{{ui:level_performance_unknown}}` と表示されます。エディターはレベルを開いたときにそれを測定し、エディターを離れるまで結果を保持しますが、ファイルには書き込みません

**デバイスの半分**は、あなたのデバイスがそれぞれをどれだけ速く処理するかを表します。デバイスを測定するまでは、ゲームはあなたのプラットフォームの基準デバイスを使います。設定も反映されます：レンダースケール、アンチエイリアス、エフェクト、ポストプロセスは、測定し直さなくてもスコアを変えます

## デバイスを測定する

1. メインメニューから `{{ui:settings_common_title}}` → `{{ui:settings_graphics_title}}` → `{{ui:settings_graphics-performance_title}}` を開きます
2. `{{ui:settings_graphics-performance_measure}}` を押します。測定に役立つことがウィンドウに表示されます：他のアプリやゲームを閉じる、スマホやノートPCを充電器につなぐ、デバイスに触れない
3. `{{ui:settings_graphics-performance_start}}` を押して、最大{{v:performance.benchmark-max-seconds}}秒待ちます。設定画面が隠れ、ゲームがテスト用のレベルを再生し、測定中の内容を画面上部の両隅に表示します。他のアプリに切り替えないでください

`{{ui:settings_graphics-performance_stop}}`で測定を途中で止められます。止めた測定や時間切れになった測定は何も保存せず、前の結果がそのまま残ります

終わると、ウィンドウに結果が表示されます：あなたのデバイスでのデモレベルのゲージ、デバイスを制限しているもの（プロセッサーかグラフィックチップ）、おすすめの `{{ui:settings_quick-setup_performance}}` プリセット、そしてあなたのレベルが各区分にいくつ入るか。`{{ui:settings_graphics-performance_again}}` でもう一度測定します

測定が不安定だった場合（デバイスが熱くなりすぎた、他のアプリが動いていた）でも、どの基準デバイスよりもあなたのデバイスに近いため、ゲームはそれを使い、ウィンドウがそのことを知らせます。より正確なスコアにするには、他のアプリを閉じて、もう一度測定してください

## 別のデバイスに移る

測定結果は、測定したデバイスのものです。プロファイルの移行（[[14_profile-transfer]]）とクラウドセーブはそれを運ばないので、新しいデバイスは測定し直すまで基準デバイスから始まります
