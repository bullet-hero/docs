# gv 0.0.1

Первый тест отрисовки: много объектов через Unity Entities, и это уже запускается на Android

Через три дня после старта у проекта появилась техническая основа. Объекты рисуются через *Unity Entities* (ECS) - на этом подходе игра стоит до сих пор. Тестовая сцена заполняет экран объектами и меняет им цвета, а порядок отрисовки берётся из глубины каждого объекта

- Тестовая сборка уже запускается на Android
- Модель данных уровня вынесена в отдельный плагин - будущий SDK
- Первые спрайты (фигуры, иконки интерфейса, скины) перенесены из более старого проекта

Тогда же рассматривали собственный конвейер рендеринга и отказались от него: стандартного *URP* хватило

Коммиты: игра `44c04ca4`, SDK `1411a228`
