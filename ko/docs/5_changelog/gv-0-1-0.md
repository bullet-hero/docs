# gv 0.1.0

첫 레벨 형식과 그것을 재생하는 첫 엔진: 오브젝트, 테마, 이펙트, 텍스트, 사운드, 충돌

6주 동안 실험은 게임의 실제 두 부분이 되었습니다. 화면에는 아직 메뉴도 에디터도 없지만, 레벨은 이미 파일로 기술하고 플레이할 수 있습니다

**레벨 형식.** 레벨은 SDK에서 정의하는 `JSON` 파일입니다. 이미 오브젝트, 부모, 테마(색상 팔레트), 이펙트, 사운드, 프리팹을 담고 있습니다

**그것을 재생하는 엔진.** 각 프레임은 병렬 잡으로 구성된 뒤 그려집니다:

- 위치, 회전, 스케일, 부모
- 레벨 테마의 색상, 그리고 텍스처
- 레벨의 카메라
- 공용 *VFX Graph* 이펙트 하나를 통한 파티클 이펙트
- 레벨의 음악
- 텍스트: *TextMeshPro* 대신 *UniText* 사용
- 충돌 검사: 나중에 오브젝트가 플레이어를 맞히게 될 기반
- 레벨에 배치된 프리팹

같은 버전에서 프로젝트는 Unity 6.4 버전으로 옮겨 갔습니다

커밋: 게임 `8c7c8844`, SDK `a5c42199`
