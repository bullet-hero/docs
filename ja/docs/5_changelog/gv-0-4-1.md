# gv 0.4.1

レベルエディターがタイムラインとヒエラルキーだけの状態から本格的なエディターに育ち、レベルにはポストプロセス効果、オーディオエフェクト、再現できるランダム性が加わりました

## エディター

- オブジェクト、キーフレーム、レベルイベント用のインスペクター。このバージョンより前のエディターには、タイムラインとヒエラルキー以外にほとんど何もありませんでした
- 5つのタイムライン：レベル、選択した1つのオブジェクトのキーフレーム、レベルイベント、オーディオ、プレハブ
- ビューポートの位置、回転、スケール、サイズ、アンカー、ピボット用のギズモ。モードごとに専用のキーボードショートカットがあります
- プレハブを作り直しました。テンプレートは別のプレハブモードで編集し、配置ごとにテンプレートの値をオーバーライドできます
- レベルのリソースをエディターから管理できます：オーディオ、テクスチャ、フォント、コライダー、エフェクト、テーマ、プレハブ。エフェクト、テーマ、コライダー、プレハブは既製のライブラリからも取り込めます。ファイルの選択は今のところデスクトップでのみ動作します
- カスタムコライダーエディター、カーブエディター、グラデーションエディター、プレビュー付きのイージングプリセット
- オブジェクトは作り直さずにタイプと親を変更できます
- 選択は動く破線の輪郭で描かれます
- エディターから直接レベルを起動できます。エディターでもアバターが表示され、そこではポストプロセス効果をオフにできます
- レベル設定に作者、ライセンス、ジェネレーター、ルール検証が加わりました。ルール検証はレベルの問題を見つけ、修正を提案します

## ゲーム

- レベルイベントとしてのポストプロセス効果、全12種類：アナロググリッチ、デジタルグリッチ、ブルーム、色収差、カラーカーブ、フィルムグレイン、レンズ歪み、リフト/ガンマ/ゲイン、モーションブラー、シャドウ/中間調/ハイライト、ビネット、ホワイトバランス
- オーディオトラックのオーディオエフェクト、全11種類：コーラス、コンプレッサー、ディストーション、エコー、フランジャー、ハイパスフィルター、ローパスフィルター、ノーマライズ、パラメトリックEQ、ピッチシフター、リバーブ
- 音楽の同期を書き直しました。ゲームはオーディオのクロックに従い、小さなずれをジャンプではなくわずかなピッチの変化で補正するため、数フレームごとに起きていた音の途切れがなくなりました
- 修正：エディターでタイムラインのカーソルがレベルのクロックを約15%遅くしていました
- ランダム性が再現できるようになりました。同じレベルを同じシードで遊べば、どのデバイスでも同じように進みます。レベル画面にはシードの欄があり、ランダムなシードを設定するボタンとリセットするボタンが付いています
- レベル画面に、レベルとそのリソースの作者とライセンスが表示されます

## レベルとフォーマット

- オブジェクトの存続期間は開始と長さで表されます。それぞれの端は親の端にアンカーで固定でき、その場合は親の端に追従します
- レイヤーは絶対値ではなく、親からの相対値で数えます
