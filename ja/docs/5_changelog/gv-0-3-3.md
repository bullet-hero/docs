# gv 0.3.3

高速なシェーダーと、マウスや2本指で動かせるエディターのカメラ

- **レベルオブジェクト用の新しいシェーダー**。パスは1つで、描画に必要なものだけを持ち、古いものの約2倍の速さで動きます
- **エディターのカメラ**。PCではマウスで、スマートフォンでは2本指で動かします。専用のボタンでフォーカスに戻せます
- **テクスチャ**。ゲームやレベルのどのテクスチャも、そのテクスチャ自身のUV座標でオブジェクトに貼れるようになりました
- **ログビューアー**。エディターのメッセージを表示するパネルの最初のバージョン

コミット：ゲーム`b9d32ac7`、SDK `88c3224d`
