# gv 0.6.1

Mute buttons on the volume sliders, a remembered window size, a toggle for the error window and a fix for a framed picture after the window is resized

- The three volume sliders in the audio settings have a mute button. Pressing it again brings back the previous volume while the game is running. Muted is simply volume 0, so a game closed while muted opens muted
- A window you resized by hand keeps that size. Before, the next change of any setting brought back the old size
- `Alert on Exception` in the `Errors` section of the interface settings. On, an uncaught error opens a report window on top of whatever is on screen. Off, it only goes to the log, and the report is collected either way
- A click on a keyframe in the timeline opens its tab in the inspector right away
- Fixed: after the window was resized, a level that did not ask for side bars could show a framed picture in the middle of the window
