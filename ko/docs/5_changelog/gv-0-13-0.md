# gv 0.13.0

프리팹 루트를 선택할 수 있게 되었고, 자동 저장으로 에디터가 멈추는 시간이 절반으로 줄었으며, 레벨 카드에 음악 아티스트가 표시됩니다

- 프리팹 템플릿의 루트를 선택할 수 있습니다. 프리팹 타임라인에서 루트의 행을 클릭하면 다른 오브젝트처럼 키프레임을 편집할 수 있습니다. 배치를 열면 루트가 선택되고, 루트가 선택된 동안 재생은 템플릿 자체의 길이로 반복됩니다
- 자동 저장으로 에디터가 멈추는 시간이 절반이 되었습니다: 12.3 MB 레벨에서 265 ms 대신 133 ms. 이전에는 레벨 전체를 두 번 복사했습니다. 한 번은 백업용, 한 번은 저장용이었습니다
- 저장 후 정리 작업이 더 이상 메인 스레드에서 실행되지 않습니다. 다른 형식의 오래된 파일 삭제와 백업 교체가 프레임 도중에, 자동 저장마다 네 번씩 실행되었습니다
- 레벨 카드에서 레벨 제작자 아래 별도 줄에 음악 아티스트가 표시됩니다. 어떤 리소스를 표시할지는 리소스 자체의 `레벨 카드에 표시` 체크박스로 정합니다. 오디오 리소스가 정확히 하나인 레벨은 체크박스 없이도 이 줄이 생깁니다
- 타임라인은 같은 레인에서 다른 클립에 완전히 가려진 클립을 더 이상 그리지 않습니다. 넓은 클립은 좁은 클립 아래에 놓이고, 선택했거나 드래그 중인 클립은 레인 전체의 맨 위에 있습니다. 그려지지 않은 클립도 클릭으로 선택할 수 있습니다
- 타임라인은 숨겨지는 즉시 요소를 해제합니다. 접힌 레벨과 선택되지 않은 탭이 열려 있을 때와 똑같은 비용을 매 프레임 치렀습니다
