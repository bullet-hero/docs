# gv 0.13.0

プレハブのルートが選択可能になり、自動保存によるエディターの停止時間が半分になり、レベルカードに音楽のアーティストが表示されます

- プレハブテンプレートのルートを選択できます。プレハブタイムラインでその行をクリックすると、他のオブジェクトと同じようにキーフレームを編集できます。配置を開くとルートが選択された状態になり、ルートを選択している間、再生はテンプレート自体の長さでループします
- 自動保存によるエディターの停止時間が半分になりました：12.3MBのレベルで265msから133msです。以前は、バックアップ用と保存用に1回ずつ、レベル全体を2回コピーしていました
- 保存後の後処理は、メインスレッドで実行されなくなりました。もう一方のフォーマットの古いファイルの削除とバックアップのローテーションは、以前はフレームの途中で、自動保存1回につき4回実行されていました
- レベルカードには、レベルの作者の下に別の行で音楽のアーティストが表示されます。どのリソースを表示するかは、そのリソース自体の`レベルカードに表示`チェックボックスで設定します。オーディオリソースがちょうど1つのレベルでは、チェックボックスなしでこの行が表示されます
- タイムラインは、同じレーン上で別のクリップに完全に覆われたクリップを描画しなくなりました。幅の広いクリップは狭いクリップの下になり、選択中またはドラッグ中のクリップはレーン全体の一番上になります。描画されていないクリップも、クリックで選択できます
- タイムラインは、非表示になるとすぐに要素を解放します。折りたたんだレベルや選択していないタブは、以前は開いているときと同じだけ毎フレーム負荷がかかっていました
