# gv 0.5.2

Die Regelvalidierung läuft etwa doppelt so schnell, und beim Speichern wird ein Level jetzt im Hintergrund geprüft

- Die Regelvalidierung ist 1,9-2,4 Mal schneller. Auf dem Testlevel volcano (19 341 Objekte) braucht sie 850 ms statt 1 614 ms, auf weathergirl (4 151 Objekte) 112 ms statt 264 ms. Der Editor führt sie beim Öffnen eines Levels aus, deshalb öffnen sich große Levels schneller
- Beim Speichern wird ein Level im Hintergrund gegen die Regeln geprüft, sobald die Datei schon auf der Festplatte liegt, und die Zahl der gefundenen Probleme wird gemeldet. Automatisch behoben wird nichts
- Im Tab `Regeln` ist jede Zeile nach Schweregrad eingefärbt: Fehler, Warnung oder Hinweis

Commit: Spiel `c025ac8c`
