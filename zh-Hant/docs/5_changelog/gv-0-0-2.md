# gv 0.0.2

紋理、父級、粒子、文本和後期效果，在測試場景中逐一試驗

這個版本是一組實驗。關卡將來需要的每項功能都有了自己的測試，其中大部分保留了下來

- 物體有了紋理
- 物體可以有父級，並隨父級一起移動
- 出現了粒子特效和文本（當時還通過*TextMeshPro*實現）
- 屏幕後期效果

一切都在一部Android手機上測量。根據當時的記錄，它能在30 FPS下承載約1500個物體。2D陰影試過之後放棄了
