# Version 1.0.0

The release: a file saved by 1.0.0 opens in every later version, and a file from a newer version asks you to update

## What 1.0.0 means for you

- **Your files keep working.** A level, your settings and your statistics saved by 1.0.0 open in every later version of the game. When the file format changes, the new version converts the old file as it reads it
- **A newer file is refused, never half-read.** A level or a save from a newer version opens the `Update required` window, and `Download` takes you to the download page. The game does not guess at what it cannot read, so nothing is lost or silently changed. More - [[5_troubleshooting]]
- The game and the SDK are both at 1.0.0. The SDK still moves with the game, so its code interface is not promised to stay the same yet

## What changed

- **A break for old binary levels.** A level saved as `Blob` by a version before 1.0.0 does not open in 1.0.0, because the binary format was started over for the release. A level saved as `Json` is not affected. If you have an old `Blob` level, open it in the version that made it and save it as `Json` first
- The `Guidelines` section is gone from the editor's settings. The guide lives on the site now, and `Community` has a `Documentation` link that opens it in your language
- The level list rewrites its own labels when you switch the language. Before, the source buttons, the sort button and the level cells stayed in the old language
- Every text of the game, in both languages, is now public in the docs repository, so a typo or a bad translation can be reported or fixed there - [https://github.com/bullet-hero/docs](https://github.com/bullet-hero/docs)
