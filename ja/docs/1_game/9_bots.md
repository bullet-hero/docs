# ボット

ボットはプレイヤーと同じ操作でレベルを代わりにプレイします。迫ってくるものを見て空いている場所を探し、プレイヤーと同じキャラクターを動かします：歩き、ダッシュし、ダメージを受け、死亡します

**ボットはクリアを保証しません**。疲れはしませんが、負けることはあります。パターンが届く1秒前に正しく入っておく必要がある場合、ボットは被弾します。そうなっても、何も壊れてはいません

**ボットはデバイスに負荷をかけます**。空いている場所の探索は、毎フレーム行われる実際の処理です。性能の低いデバイスではフレーム落ちを覚悟してください。重いレベルでは最初の数秒が最もひどくなります

ボットを選ぶには、レベル画面の`{{ui:menu_levelview_options-bot}}`の条件を使います：`{{ui:enum_bot-kind_none}}`、`{{ui:enum_bot-kind_reflex}}`、`{{ui:enum_bot-kind_warm}}`のいずれかです。ライフや速度と同じく、プレイごとに選びます

> [!info] 補足
> ボットはずるができません。これは約束ではなく、そういう作りになっているということです。ボットが持っているのはプレイヤーと同じ操作だけで、それ以上は何もありません：同じ速度、同じダッシュ、同じ当たり判定、同じダメージ。プレイヤーがすり抜けられないものは、ボットもすり抜けられません

## レベルがボットに勝った？

ボットは、まだ見たことのないレベルで強くなります。そういうレベルはぜひ送ってください

[bullet-hero/releases](https://github.com/bullet-hero/releases/issues)でissueを作成してください。どのボットがどこで負けたかを書き、レベルフォルダーを添付してください

## 2つのボット

ボットは毎フレーム、キーボードと同じように1つの入力を出すだけで、それ以外は何もしません。アバターの位置、体力、レベルの状態にはアクセスできません。あるフレームでボットが応答しなければ、そのフレームはデバイスからの入力で操作されます

| | `{{ui:enum_bot-kind_reflex}}` | `{{ui:enum_bot-kind_warm}}` |
|---|---|---|
| 知っていること | 次の1.5秒。毎フレーム計算し直す | レベル全体。1回だけ計算する |
| デバイスに負荷をかけるとき | 動作中は毎フレーム | プレイの前に1回 |
| できること | 前方に見えるものを避ける | どれだけ先読みしても見つからない計画に従う |
| 弱点 | 1秒前に入っておく必要があったパターン | 計画後に変更されたレベル |
| 操作方法 | 方向 | 目標地点 |

Warmボットはノーダメージを目指します。その代わりに読み込みの段階が1つ増えます：`{{ui:root_loading_baking}}`。これには数十秒かかることがあります

`{{ui:menu_levelview_options-bot}}`の横の`?`が、ボットごとに1段落ずつ、このことを事前に知らせます。`{{ui:root_loading_cancel}}`で計算を中止し、プレイを自分で操作できます。Warmボットのルートはシードによって変わります、[[8_determinism]]

## ボットがプレイするほかの場所

- **エディターのテストプレイヤー**：`{{ui:settings_common_title}}` → `{{ui:settings_game-editor_title}}` → `{{ui:settings_game-editor-player_bot}}`。そこでプレイするのはReflexボットだけです：事前の準備が何もいらず、巻き戻しにも耐えられるからです。詳細：[[5_bot-playtest]]
- **メインメニューの背景**：ボタンの後ろのアリーナでは、Reflexボットが先読みをまったくせずにライブでプレイしています

ボットはプレイ記録の条件の一部です。そのため、ボットのプレイが自己ベストを置き換えることはありません、[[10_statistics]]
