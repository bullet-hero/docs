# gv 0.10.0

プレハブは本物のルートオブジェクトを中心に作り直され、サイズのキーフレームがないオブジェクトは独自のサイズを持たなくなりました

- プレハブのテンプレートに本物のルートオブジェクトができ、中身はすべてその下にぶら下がります。以前は、グループをプレハブにするとグループ化用のオブジェクトが2つ連続で残り、それらをまとめる方法がありませんでした。現在は選択範囲が1回だけ包まれます
- サイズのキーフレームがないオブジェクトは、1×1ではなく0×0になりました。空オブジェクト、エフェクト、プレハブの配置は何も描画しないグループなので、サイズを持ちません。新しいシェイプやテキストには作成時にサイズのキーフレームが付き、その値は`エディター` > `作成`（`新規シェイプの幅`、`新規テキストの幅`と2つの高さ）で設定します
- 結果として2つのことが起きます：グループはビューポートのクリックでは選択できず、エフェクトはパーティクルが占める範囲で選択されます
- ヒエラルキーの行を別の行にドラッグすると親が変わり、空いている場所にドラッグすると親が外れます。選択した複数の行は、元に戻す1ステップ分としてまとめて移動します。マウスとペンで使えます。スマートフォンでは親はインスペクターで変更します
- バッククォートキー（`` ` ``）を押し続けると、エディターのインターフェース全体が隠れ、レベルだけが見えます。離すとすべて戻ります。キーは割り当て直せます
- レベルブラウザーは`最近`の並び順で開くので、最後に保存したレベルが一番上に来ます
- 結果画面には「勝利」や「敗北」ではなく`クリア`または`失敗`と表示されます
- プレハブの配置をフラット化するときは、先に確認を求めます。配置がテンプレートに追従しなくなるためです
- コマンドパレットと追加メニューが翻訳されました。以前は言語に関係なく英語のテキストが表示されていました
