# gv 0.11.2

계층 구조와 타임라인의 접기가 3단계 모드가 되었고, 휴대폰의 에디터에서도 오디오가 온전히 지원됩니다

- 계층 구조와 오브젝트 타임라인의 접기 버튼은 세 단계를 순환합니다: 모두 펼침, 부분, 모두 접음. "부분"은 고른 종류의 오브젝트를 펼친 채로 둡니다. 버튼을 길게 눌러 종류를 고르거나, `에디터` > `인터페이스` > `부분 접기`에서 설정합니다
- 레벨 에디터에서는 휴대폰을 포함한 모든 플랫폼에서 오디오를 통째로 디코딩합니다. 압축된 트랙은 파형을 그리지 못했고, 원하는 프레임 대신 가장 가까운 블록으로 이동했습니다. 휴대폰의 게임에서는 오디오가 여전히 압축된 상태로 남습니다
- 오디오 트랙의 `레벨 맞춤`은 클립 전체가 들어갈 때까지 트랙과 레벨을 함께 늘립니다. 레벨은 길어지기만 하며, 이미 들어가는 클립에서는 아무것도 바뀌지 않습니다
- 다른 형식의 오디오 파일을 추가하면 게임이 지원 형식을 알려 줍니다: `.mp3`, `.wav`, `.ogg`
- 설정의 버튼 하나로 모든 섹션을 접거나 모두 펼칩니다
- 에디터에서 키보드로 미리 보기 아바타를 움직일 때 더 이상 이동할 때마다 화면이 119 ms씩 멈추지 않습니다
