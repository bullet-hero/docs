# 版本0.12.0

带切线的曲线，沿直线取值的随机值，可命名的主题槽位，以及一长串时间轴和预制件模式的修复

## 游戏

- 化身绘制在图层0的前面，而不是后面。在新物体默认创建的图层上的内容，现在位于玩家后面，要遮住玩家，请把内容放到图层1。从*Afterbeat*导入的关卡会相应地上移一个图层

## 编辑器

- 曲线不仅可以通过点编辑，还可以通过切线编辑。选中的关键帧两侧各有一个控制柄，`断开切线`把它变成尖角，开启`加权切线`时，控制柄的长度就是它的权重。预览线也会绘制权重，因此显示的就是实际播放的曲线
- `Q W E R T`从左到右切换底部面板的五条时间轴：关卡、局部、音频、事件、预制件。`敲击测速`因此失去了`T`键。敲击改在`节拍网格`窗口（`Shift+T`）中进行，也可以在`快捷键`中为`敲击测速`设置按键
- 预制件模式的选择方式与编辑器其他部分一致：按住Ctrl单击可添加片段，预制件标签页有`框选`工具，多个物体可以在一个检视器中编辑，并在一步撤销中删除或复制。以前一次只能选择一个物体
- 沿时间轴拖动物体时，它的子物体会一起移动，层级结构保持自己的时间安排。一次撤销就能恢复整棵子树
- 每个时间轴标签页都会记住自己的工具。`编辑器` > `时间轴`中的`切换标签页时重置工具`决定标签页切回来时是否回到`选择`，默认开启
- 音频设置中的`编辑器播放`是编辑器内播放的单独音量，游戏本身的音量保持不变
- 自动保存除了在`backups/`中保存副本，还会保存关卡本身。以前它只保存副本，所以一晚上的编辑都在`backups/`里，而不在浏览器列出的关卡中
- 测试游玩结束返回后，编辑器保持原样：相机取景、选中项和控制柄都能正常使用，如果之前有预览玩家，它会回来，播放头和速度也恢复到播放前的数值
- 单击局部时间轴的最后一格，会在60帧长的物体的第60帧上放置关键帧，而不是第59帧

## 关卡与格式

- 主题槽位可以命名。指向槽位12的颜色字段显示为`12 - background`，而不是`12`
- 随机的向量或颜色可以位于一条直线上，而不是一个方框内：`A到B随机`只取一个随机数，数值沿着从`起点`到`终点`的直线移动。这样随机色调就是一种色调，随机漂移就是一个方向。某个轴两端设为同一个数，即可让它保持不动
- 图片资源有自己的平铺和偏移（位于其`导入`区块中的`平铺X`、`平铺Y`、`偏移X`和`偏移Y`）。所有使用该图片但没有自己UV关键帧的物体都会采用这些值，因此精灵表只需描述一次
