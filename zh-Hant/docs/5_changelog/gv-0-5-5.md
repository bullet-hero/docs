# gv 0.5.5

Android上的資料夾訪問、每個設定標籤頁上的重置按鈕，以及解析度設定的修復

- Android：遊戲通過系統的資料夾選擇器開啟資料夾，只能看到你選擇的那個資料夾，所以不需要儲存許可權。設定中的`資料夾訪問許可權`顯示所有已授權的資料夾，`撤銷`會移除訪問許可權，不刪除其中任何內容
- 每個設定標籤頁都有自己的重置按鈕，只把這個標籤頁恢復為預設值
- 修復：如果之前手動或通過Alt+Enter改變過視窗大小，解析度設定不起作用
- 關卡列表中新增了`重新掃描`按鈕
- 關卡設定中有`釋出`標籤頁。目前上面寫著`開發中`

提交：遊戲`7d40c382`，SDK `284ff03a`
