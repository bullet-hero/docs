# gv 0.0.1

첫 렌더링 테스트: 많은 오브젝트를 Unity Entities 방식으로 그리며, 벌써 Android에서도 실행됩니다

시작 3일 뒤 프로젝트에 기술적 기반이 생겼습니다. 오브젝트는 *Unity Entities*(ECS) 방식으로 그려지며, 게임은 지금도 이 방식 위에 서 있습니다. 테스트 씬은 화면을 오브젝트로 채우고 그 색을 바꾸며, 그리기 순서는 각 오브젝트의 깊이에서 정해집니다

- 테스트 빌드가 이미 Android에서 실행됩니다
- 레벨 데이터 모델이 별도의 플러그인으로 옮겨졌습니다. 훗날의 SDK입니다
- 첫 스프라이트(도형, 인터페이스 아이콘, 스킨)는 이전 프로젝트에서 가져왔습니다

같은 시기에 자체 렌더 파이프라인도 검토되었지만 채택되지 않았습니다: 표준 *URP* 파이프라인으로 충분했기 때문입니다

커밋: 게임 `44c04ca4`, SDK `1411a228`
