# gv 0.6.1

音量滑塊旁的靜音按鈕、記住視窗大小、錯誤視窗的開關，以及修復改變視窗大小後畫面出現邊框的問題

- 音訊設定中的三個音量滑塊都有靜音按鈕。遊戲執行期間再按一次即可恢復之前的音量。靜音就是音量為0，所以靜音時關閉的遊戲再次開啟時也是靜音
- 你手動調整過大小的視窗會保持這個大小。以前，下一次改變任何設定都會恢復舊的大小
- 介面設定`錯誤`分割槽中的`異常時提醒`。開啟時，未捕獲的錯誤會在螢幕上所有內容之上開啟報告視窗。關閉時，錯誤只寫入日誌，報告無論如何都會收集
- 點選時間軸上的關鍵幀會立即在檢視器中開啟它的標籤頁
- 修復：改變視窗大小後，沒有要求兩側黑邊的關卡可能在視窗中央顯示帶邊框的畫面
