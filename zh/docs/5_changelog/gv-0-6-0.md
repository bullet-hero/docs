# gv 0.6.0

启动参数、用F11切换全屏，以及设置中的版本号

- 电脑上的启动参数：`--menu`、`--editor`或`--game`选择第一个画面，`--level`按id或文件夹指定关卡，`--speed`、`--lives`、`--seed`、`--bot`和`--checkpoints` / `--no-checkpoints`设置本次游玩。错误的参数永远不会阻止游戏启动，只会在日志中留下一行。更多：[[12_launch-arguments]]
- F11在游戏的任何画面上切换全屏，再按一次则把窗口恢复原样。这个按键改变的是与设置中的下拉列表相同的设置。手机上没有这个按键
- 设置在一行中显示游戏版本、SDK版本和关卡格式代数。点击即可复制到剪贴板
- 带换行的关卡描述不再撑高它在关卡列表中的那一行：它保持一行，并以省略号结尾
