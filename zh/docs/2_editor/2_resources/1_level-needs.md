# 关卡需要什么

最少只需要一首曲目。其余都是可选的，而且几乎都要你自己准备

## 关卡可以使用什么

| 内容 | 说明 | 存放位置 |
|---|---|---|
| 音频 | 至少一条音频轨道，可以有多条 | 关卡的`resources`文件夹 |
| 图片 | 形状不够用时 | 关卡的`resources`文件夹 |
| 字体 | `ttf`、`otf`、`ttc` | 关卡的`resources`文件夹 |
| 形状 | 497个内置形状，以及在`形状编辑器`中画出的任意形状 | 内置在游戏或关卡中 |
| 主题、特效、预制件 | 是数据而不是文件 | 在`level.json`内部 |

音频、图片和字体是真正的文件。只有它们会增加文件夹的体积，发布前需要记录来源，并且可能在转移时丢失

没有自带字体时，文本会用系统中现有的字体绘制

**游戏不附带任何纹理**。内置形状是几何体，而不是图片。它们没有像素，不占体积，也无处可加载

> [!tip] 建议
> 始终优先用形状，其次才是图片。一张图片意味着一个可能在转移时丢失的文件、加载时占用的内存，以及许可记录中的一行。形状没有这些代价

## 文件夹的体积

没有硬性限制。但关卡是靠复制传递的，接收的人会看到文件夹的体积

一首4分钟的`ogg`曲目为4到6MB。同一首曲目用`wav`约为40MB

## 同一资源的多个来源

资源可以带一个获取位置的列表：关卡旁边的文件、绝对路径、直接链接。游戏按顺序尝试这个列表，直到有一个能加载

> [!tip] 建议
> 把链接作为文件的补充，而不是替代。网站可能宕机、迁移，或开始提供别的内容。文件夹里的文件和关卡在同一个地方

## 文件的版权

如果关卡离开你的磁盘，其中的每个文件都需要允许这样做的许可证。这取决于你在最开始选择的资源
