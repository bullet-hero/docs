# gv 0.5.2

规则检查的速度约提高一倍，保存关卡时会在后台检查它

- 规则检查快了1.9到2.4倍。在volcano测试关卡（19,341个物体）上耗时850毫秒，而不是1,614毫秒，在weathergirl（4,151个物体）上耗时112毫秒，而不是264毫秒。编辑器在打开关卡时运行规则检查，所以大关卡打开得更快
- 保存关卡时，文件写入磁盘之后会在后台按规则检查关卡，并报告发现的问题数量。不会自动修复任何内容
- 在`规则`标签页中，每一行按严重程度着色：错误、警告或建议
