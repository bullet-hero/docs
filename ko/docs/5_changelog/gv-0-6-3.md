# gv 0.6.3

레벨 밖에서는 기본적으로 스마트폰이 자유롭게 회전하고, 더 많은 화면에 세로 레이아웃이 생겼습니다

- `화면 방향`의 기본값이 이제 `자동 회전` 옵션입니다: 메뉴와 설정이 스마트폰을 따라 돌아갑니다. 실행 중인 레벨은 여전히 자신이 선언한 축(기본은 가로)을 유지하며, 에디터는 이 설정 중 어느 쪽도 따르지 않습니다
- 조작, 키 할당, 통계, 프로필, 힌트, 값 입력 창에 세로 레이아웃이 생겨, 스마트폰을 세워 들어도 읽기 쉽습니다
