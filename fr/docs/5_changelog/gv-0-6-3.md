# gv 0.6.3

Hors d'un niveau, le téléphone pivote librement par défaut, et davantage d'écrans ont reçu une disposition verticale

- `Orientation de l'écran` vaut désormais `Rotation automatique` par défaut : le menu et les paramètres tournent avec le téléphone. Un niveau en cours garde toujours l'axe qu'il déclare (horizontal par défaut), et l'éditeur n'obéit à aucun de ces paramètres
- Les contrôles, l'attribution des touches, les statistiques, le profil, les aides et la fenêtre de saisie de valeur ont reçu une disposition verticale et restent lisibles sur un téléphone tenu droit

Commits : jeu `9731731f`, SDK `d44635e6`
