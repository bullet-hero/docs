# Version 0.3.3

A faster shader and an editor camera you can move with a mouse or two fingers

- **A new shader for level objects.** It has a single pass and only what drawing needs, and it runs about twice as fast as the old one
- **The editor camera.** You drag it with the mouse on PC and with two fingers on a phone. A button brings it back into focus
- **Textures.** Any texture of the game or the level can now be mapped onto an object by its own UV coordinates
- **A log view.** A first version of the panel that shows the editor's messages
