# Imagens a partir de formas

Use primeiro formas integradas, desenhe as suas só onde nenhuma servir. Ponha luz e sombra sobre uma forma base, faça de cada repetição um prefab e compare com a imagem original sobre o nível

## Primeiro as formas integradas

Uma forma integrada é geometria real com bordas limpas, e reutilizá-la não custa nada. Um círculo e um quadrado se esticam para qualquer tamanho: um quadrado esticado e girado é qualquer barra, linha ou vara, um círculo esticado é uma elipse

Desenhe uma forma própria no editor de formas só onde nenhuma integrada servir: um casaco, uma mão, uma vela. Dê a ela só os cantos reais, com arestas retas entre eles. Uma dúzia de cantos se lê melhor que cem traçados seguindo cada pixel

> [!tip] Recomendação
> O detalhe é o preço das bordas limpas. Um contorno irregular ou uma emenda visível estragam uma imagem mais que um entalhe perdido

## Uma base, detalhes por cima

Luz e sombra são formas separadas por cima de uma forma base, cortadas ao longo da borda dela. Duas formas que só se tocam aresta com aresta deixam entre elas uma emenda fina do fundo, e ela aparece

A parte que outra cobre continua por baixo dela. Um pescoço entra um pouco sob o casaco e a cabeça, uma perna sob a barra da roupa. Assim as partes continuam se encontrando quando uma delas se move

## Repetições são prefabs

Tudo o que aparece mais de uma vez é um prefab: um olho, uma janela, uma pétala. Monte um, transforme-o em prefab, posicione o resto e mude em cada cópia só o que difere: posição, tamanho, cores. Cada mudança dessas é uma substituição daquela cópia

Uma edição no modelo chega então a todas as cópias, e o nível continua pequeno

## Camadas

Dê a cada objeto a própria camada. Dois objetos na mesma camada ao mesmo tempo são desenhados em uma ordem que você não escolheu. Mantenha a base abaixo dos detalhes dela e os detalhes abaixo do que fica sobre eles

## Comparação com o original

Importe a imagem original como textura e coloque-a em um retângulo exatamente do tamanho dela, por cima de tudo. Para comparar, ative o retângulo. Desative-o pelo resto do trabalho em vez de deixá-lo transparente: um objeto desativado não desenha nada

Confira a imagem como um todo e depois com zoom, parte por parte: as bordas, onde as partes se encontram, as sombras
