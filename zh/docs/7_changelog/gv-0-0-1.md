# 版本0.0.1

第一次渲染测试：通过Unity Entities绘制大量物体，运行在Android上

开工三天后，项目有了技术基础。物体通过*Unity Entities*（ECS）绘制，游戏至今仍沿用这种方式。一个测试场景用物体铺满屏幕并改变它们的颜色，绘制顺序取自每个物体的深度

- 测试构建已经能在Android上运行
- 关卡数据模型移入独立的插件，也就是后来的SDK
- 第一批精灵图（形状、界面图标、皮肤）从一个更早的项目中搬了过来

当时考虑过自定义渲染管线，后来放弃了：标准的*URP*已经够用
