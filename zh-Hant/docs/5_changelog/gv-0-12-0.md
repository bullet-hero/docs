# gv 0.12.0

帶切線的曲線、沿線段的隨機值、主題槽位名稱，以及一長串時間軸和預製件模式的修復

## 遊戲

- 化身繪製在圖層0之前，而不是之後。新物體所在圖層上的內容現在位於玩家後面，要遮住玩家，需要把內容放到圖層1

## 編輯器

- 曲線可以用切線編輯，而不只是移動點的位置。選中的關鍵幀兩側各有一個手柄，`斷開切線`把它變成尖角，開啟`加權切線`後，手柄的長度就是它的權重。預覽線也會考慮權重，顯示真正會播放的曲線
- `Q W E R T`從左到右切換底部面板的五個時間軸：關卡、區域性、音訊、事件、預製件。因此`敲擊測速`失去了`T`鍵。速度在`節拍網格`視窗（`Shift+T`）中敲擊，`敲擊測速`的按鍵可以在`快捷鍵`中指定
- 預製件模式的選擇方式與編輯器其他部分相同：Ctrl+單擊新增片段，預製件標籤頁有`框選`工具，多個物體在一個檢視器中編輯，並以一個撤銷步驟刪除或複製。以前它一次只能選中一個物體
- 在時間軸上拖動物體時會帶著它的子物體一起移動，所以層級保持自己的時間安排。一次撤銷即可恢復整棵子樹
- 每個時間軸標籤頁都記住自己的工具。`編輯器` > `時間軸`中的`切換標籤頁時重置工具`決定標籤頁是否回到`選擇`，預設開啟
- 音訊設定中的`編輯器播放`是編輯器內播放的單獨音量，遊戲本身的音量保持不變
- 自動儲存會儲存關卡本身，而不只是`backups/`中的副本。以前它只做副本，於是一晚上的編輯都在`backups/`裡，而不在瀏覽器顯示的那個關卡中
- 測試執行結束後，編輯器回到之前的狀態：相機框、選中項和控制柄都能正常工作，如果原來有預覽玩家，它也會回到原位，播放頭和速度顯示的與按下播放之前相同
- 點選區域性時間軸的最後一格，會在長度為60幀的物體的第60幀放置關鍵幀，而不是第59幀

## 關卡與格式

- 主題槽位可以有名稱。引用槽位12的顏色欄位顯示`12 - background`，而不是`12`
- 隨機向量或顏色可以落在一條線段上，而不是一個矩形內：`A到B隨機`只隨機一個數，數值沿直線從`起點`移動到`終點`。這樣隨機色調讀起來是一種色調，隨機漂移是一個方向。給某個軸的兩端設定同一個數，它就會保持不動
- 影像資源有自己的平鋪和偏移（`匯入`區塊中的`平鋪X`、`平鋪Y`、`偏移X`和`偏移Y`）。所有使用這張影像、且沒有自己UV關鍵幀的物體都會採用它們，所以精靈表只需描述一次
