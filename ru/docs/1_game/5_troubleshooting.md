# Решение проблем

Скопированный вручную уровень появится в списке после повторного поиска. Уровень из новой версии требует обновить игру, а архив .7z - перепаковать в zip. Забытый пароль не восстановить

Не нашли свою проблему? Куда о ней написать - [[11_help]]

## Уровня нет в списке

- **Скопирован вручную.** Папка уровня должна лежать прямо в `levels`, [[1_installation]]. После копирования нажмите `{{ui:root_level-browser_refresh}}`
- **Предмет мастерской.** Сборка для Steam показывает только ваши подписки. Папки, найденные на диске, добавляет `{{ui:settings_common_title}}` → `{{ui:settings_general_title}}` → `{{ui:settings_general_show-all-found-content}}`. Они помечены `{{ui:root_level-entry_not-listed}}`
- **Не видно вообще ничего.** Возможно, папка с уровнями недоступна. Очистка хранилища в `{{ui:settings_other_title}}` в таком состоянии не запускается и пишет `Сканирование не нашло ни одного уровня, поэтому очистка отменена`

## Уровень не загружается

Экран загрузки показывает стадию: `{{ui:root_loading_reading}}`, `{{ui:root_loading_validating}}`, `{{ui:root_loading_resources}}`, `{{ui:root_loading_building}}`

- **Файл по веб-адресу.** Уровень может брать файл по ссылке, а не хранить его в папке. `{{ui:settings_general_title}}` → `{{ui:settings_general_resource-web-timeout}}` - сколько секунд игра ждёт такой файл
- **Повреждённый уровень.** Уровень в `Json` - это текст, его можно прочитать глазами. Повреждённый `Blob` отклоняется целиком. Подробнее - [[4_level-folder-and-backups]]
- **Окно ошибки.** В нём есть `{{ui:root_error_copy}}`, `{{ui:root_error_save}}` и `{{ui:root_error_open-reports-folder}}`. Отчёт ложится в папку `reports`. Приложите его к сообщению об ошибке в [bullet-hero/releases](https://github.com/bullet-hero/releases/issues), [[11_help]]
- **`Уровню нужно больше объектов на кадр, чем позволяет это устройство`.** Это не ошибка загрузки. Уровень играется, но часть его не рисуется. Подробнее - [[1_level-budget]]

## "Нужно обновить игру"

Старая версия игры не открывает файлы из новой. Обновите игру

| Сообщение | Что делать |
|---|---|
| `Этот уровень сделан в более новой версии игры...` | обновить игру |
| `В этом архиве уровень из более новой версии игры...` | обновить игру |
| `В буфере обмена лежит содержимое редактора, скопированное в более новой версии игры...` | обновить игру |
| `Ваши настройки или статистика сохранены более новой версией игры...` | `{{ui:root_update-required_download}}`, `{{ui:root_update-required_keep}}` или `{{ui:root_update-required_overwrite}}` |

Карточка с пометкой `{{ui:root_level-entry_newer-version}}` или `{{ui:root_level-entry_newer-file}}` - тот же отказ. Он виден ещё до открытия уровня

### Настройки или статистика из новой версии

В этом случае игра работает на значениях по умолчанию. До закрытия она ничего своего не сохраняет, и новые файлы остаются нетронутыми. Это анонимный режим, [[4_settings]].
С `--suppress-game-saves` кнопки `{{ui:root_update-required_overwrite}}` нет

Статистика уровня от более новой версии не показывается. Прохождение уровня её перезапишет, если сохранения не отключены

### Почему игра отказывается

Каждое изменение формата файлов получает новый номер поколения. Сборка не читает файл более нового поколения, чтобы не прочитать его неправильно

## Защищённый уровень

Перед открытием игра спрашивает `{{ui:level_passphrase_password}}`.
Пароль спрашивают один раз за сессию и держат только в памяти

Шифруется только содержимое: объекты, ключи, темы. Название, обложка и медиа остаются читаемыми, поэтому карточка видна и без пароля

Для удаления защищённого уровня пароль не нужен

> [!caution] Внимание
> Забытый пароль не восстановить. Ключ нигде не хранится - ни в игре, ни в файле, ни у кого

## Архив отклонён

| Сообщение | Причина |
|---|---|
| `{{ui:editor_create-level_archive-unsupported}}` | это `.7z`. Перепакуйте его в `.zip` |
| `{{ui:editor_create-level_archive-wrong-password}}` | пароль не подходит |
| `{{ui:editor_create-level_archive-damaged}}` | архив сломан, попросите его ещё раз |
| `{{ui:editor_create-level_archive-not-archive}}` | файл вообще не архив уровня |

Переименованный архив - не проблема: игра узнаёт формат по байтам файла.
Какие архивы принимаются - [[2_playing-levels]]
