# 版本0.11.2

层级和时间轴中的折叠变为三档模式，编辑器在手机上也有完整的音频

- 层级和物体时间轴的折叠按钮在三档之间循环：全部展开、部分折叠、全部折叠。部分折叠会让你选择的物体类型保持展开。按住按钮即可选择这些类型，也可以在`编辑器` > `界面` > `部分折叠`中设置
- 在关卡编辑器中，音频在所有平台上都会完整解码，包括手机。压缩的音轨不绘制波形，并且会跳到最近的数据块，而不是你要求的那一帧。在手机上玩游戏时，音频仍保持压缩
- 音频轨道上的`适配关卡`会同时加长轨道和关卡，直到整个音频片段都能放下。关卡只会变长，已经能放下的片段不会有任何变化
- 添加其他格式的音频文件时，会提示支持哪些格式：`.mp3`、`.wav`和`.ogg`
- 设置中的一个按钮可以折叠所有分区或全部展开
- 在编辑器中用键盘移动预览化身时，不再每次移动都让画面卡住119毫秒
