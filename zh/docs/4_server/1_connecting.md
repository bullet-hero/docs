# 连接服务器

游戏将有哪些服务器，哪些版本能连接它们，以及玩家在别人的服务器上要承担什么风险

> [!warning] 警告
> 目前还没有任何服务器，游戏也无法连接服务器。没有地址格式，没有连接界面，也没有账号

## 将会有哪些服务器

| | OWS | NOWS |
|---|---|---|
| 全称 | Official Web Services | Non-official web services |
| 由谁运行 | 开发者 | 任何人 |
| 由谁审核 | 开发者 | 运营者 |
| 可连接的版本 | 全部 | 仅完整版 |

**OWS是默认服务器**。每个平台上的每个游戏版本都认识它，无需任何设置

**NOWS是社区服务器**。开发者既不控制也不审核它们

**Steam创意工坊是PC上的第三个关卡渠道**。Steam版已经可以列出并游玩你订阅的物品。目前还不能从游戏中把关卡发布到那里

## 哪些版本可以连接

| 版本 | 来源 | OWS | NOWS |
|---|---|---|---|
| 商店版 | Google Play、App Store | 是 | 否 |
| 完整版 | [GitHub](https://github.com/bullet-hero/releases)和项目网站 | 是 | 是 |

商店版无论如何都无法连接社区服务器。对NOWS的支持在编译时就被移除了，而不是藏在某个设置后面

原因在于商店规则。商店评判的是程序能做什么，而不是它显示了哪些按钮。而按照商店规则，展示给其他人的内容必须经过审核

计划为完整版分配独立的应用ID，这样在Android上它可以与商店版并存安装。目前所有Android版本共用一个ID：`com.vertoker.BulletHero`

## OWS将提供什么

- 账号和服务条款
- 每个关卡发布前都要检查：有错误的关卡会被拒绝，有警告的关卡交给审核员
- 举报和封禁关卡与用户

账号中保存什么还没有确定。服务器将有自己的隐私政策，在服务器出现时编写。它会说明账号的内容，并解释如何删除账号。游戏和网站的隐私政策不涵盖服务器：[[game-privacy-policy]]、[[privacy-policy]]

## 什么时候

没有日期。顺序是：先发布到Steam创意工坊，然后是OWS，然后是Google Play版，最后是App Store版

向任何服务发布关卡的功能，最早也要在`gv 1.0.0`之后的更新中才会推出

在服务器上一起游玩目前还不存在，也没有设计

## 第三方服务器的风险

社区服务器的运营者很可能是你不认识的人。开发者既不控制也不审核这类服务器。完整版的EULA明确说明了这一点

| 风险 | 原因 |
|---|---|
| 关卡的权利未经检查 | 检查什么由运营者决定，也可能什么都不检查。关卡中可能带有作者无权分享的音乐 |
| 没有人审核内容 | 无法保证有人查看上传的内容 |
| 来自其他网站的文件 | 标准策略允许关卡通过直接URL获取文件。打开这样的关卡时，游戏会从关卡作者选定的网站下载文件。因此商店版禁止这样做 |
| 运营者能看到你的流量 | 目前还没有协议，所以不知道服务器具体会收到什么。请把你发送的一切都视为运营者可见 |
| 服务器可能消失 | 只存在于该服务器上的关卡会随之消失 |

关卡默认以*CC BY-NC*授权，作者可以在关卡元数据中选择其他许可证。服务器必须遵守每个关卡自己的许可证。在*CC BY-NC*下，任何人都不得以商业方式托管关卡，社区服务器也不例外，对这类关卡收费的服务器违反了其中每位作者的许可证

> [!tip] 建议
> 只连接你认识其运营者的服务器。为每个你在意的关卡保留一份自己的副本：关卡就是一个装有文件的文件夹，你磁盘上的副本不依赖任何服务器

## EULA

完整版附带一份EULA。其中写明：社区服务器是第三方服务，开发者既不控制也不审核它们

商店版会在你发布关卡前要求你接受一份EULA

这两份文本都还没有写
