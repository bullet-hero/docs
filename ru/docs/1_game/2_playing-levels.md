# Как играть в уровни

Как найти уровень, добавить чужой, запустить забег и прочитать окно результата

## Главное меню

| Кнопка | Что делает |
|---|---|
| `Уровни` | список уровней, описан ниже |
| `Редактор` | редактор уровней, [[2_editor/1_basics/index]] |
| `Настройки` | все настройки, [[4_settings]] |
| `История` | пока не работает |
| `Мультиплеер` | пока не работает |

## Список уровней

`Уровни` в главном меню открывают список уровней. Уровни берутся из трёх мест:

- `Мои уровни` - папка `levels`, [[1_installation]]
- `Встроенные` - уровни, которые идут с игрой
- `Мастерская` - только в сборке для Steam. Здесь видны предметы, на которые вы подписаны

Сверху есть поиск, `Сортировка` и `Вид` (сетка или список).
Сортировать можно `По совпадению`, `По названию`, `По длительности`, `По прогрессу` и `По дате`

Скопировали уровень в папку? Нажмите `Искать заново`, и список обновится

Замок на карточке значит, что уровень защищён паролем

Удержание или правый клик по карточке открывает меню: `Открыть` и `Удалить`

## Как добавить чужой уровень

Уровень - это обычная папка с файлами. Её можно заархивировать и отправить другу

**Папка.** Скопируйте папку уровня в `levels` и нажмите `Искать заново`.
Копировать нужно саму папку уровня: ту, где лежат `level.json` (или `level.blob`) и `metadata.json`

**Архив.** Откройте редактор и создайте новый уровень генератором `Архив уровня`.
Затем выберите файл кнопкой `Выбрать архив уровня...`

| Файл | Результат |
|---|---|
| `.zip`, `.tar.gz` | открывается |
| `.zip` с собственным паролем, `.zip.gpg`, `.tar.gz.gpg` | открывается после `защищён, введите пароль и нажмите ещё раз` |
| `.7z` | пока отклоняется. Перепакуйте его в zip |
| что-то другое | отклоняется, [[5_troubleshooting]] |

Переименованный архив тоже откроется: игра узнаёт формат по байтам файла.
Архив из старой версии игры обновится при импорте

Импортированный уровень по умолчанию получает свой id. Поэтому он не перезапишет уровень, который уже есть на устройстве

Подробнее - [[6_sharing-by-hand]]. Уровни *Afterbeat* - [[3_afterbeat-import]]

## Экран уровня

На экране уровня видны обложка, авторы, описание и автор музыки. Там же кнопки `Авторы` и `Лицензии`

Возрастной рейтинг указывает автор уровня. Разработчики его не проверяют

Перед забегом можно выбрать условия:

| Условие | Варианты |
|---|---|
| `Жизни` | `Дзен` (забег не заканчивается), `Одна жизнь`, `Три жизни`, `Своё` (ползунок до 16) |
| `Скорость` | `0.5`, `1.0`, `2.0`, `Своё` (ползунок до 2). Уровень и музыка меняются вместе |
| `Контрольные точки` | вкл. или выкл., [[7_damage]] |
| `Бот` | `Без бота`, `Reflex Bot v1`, `Warm Bot v1`, [[9_bots]] |
| `Сид игрока` | число, `Случайно`, `Очистить`. `0` - новый сид на каждый забег, [[8_determinism]] |

`Начать` запускает забег

В паузе есть `Продолжить`, `Рестарт`, `Настройки`, `Назад в меню` и `Выйти из игры`

## Окно результата

Окно показывает `Пройдено` или `Не пройдено` и три секции: `Прогресс`, `Урон` и `Условия забега`

- строки: `Пройдено`, `Достигнут чекпоинт`, `Время`, `Длина уровня`, `Получено урона`, `Осталось жизней`, `Дольше всего без урона`
- условия забега: `Скорость`, `Жизни`, `Бот`, `Сид`, `Чекпоинты`
- кнопки: `Рестарт`, `Рестарт с контрольной точки`, `Настройки`, `Назад в меню`

При поражении окно по умолчанию не открывается. Вместо этого забег отматывается к последней контрольной точке.
Изменить это - `Настройки` → `Интерфейс` → `Открывать меню при поражении`

## Рекорды

На экране уровня есть блок рекорда: `Рекорд`, `Попыток` и `Пройден` (или `Ещё не играли`)

Рекорд свой для каждого набора условий: жизни, скорость, контрольные точки и бот. Блок показывает рекорд для условий, выбранных сейчас.
Попытки и прохождения считаются для любого забега

Как выбирается рекорд - [[10_statistics]]

## Пометки на карточках

| Пометка | Что значит |
|---|---|
| `Не в подписках` | папка мастерской есть на диске, но вы на неё не подписаны. Видна, только если включено `Настройки` → `Общее` → `Отображать весь найденный контент` |
| `Офлайн` | источник уровней не ответил |
| `Новее сборки`, `Из более новой версии игры` | эта версия игры уровень не откроет, [[5_troubleshooting]] |

## Удаление уровня

Удержание или правый клик по карточке → `Удалить`. Игра сначала спросит подтверждение

Вместе с уровнем можно удалить его статистику (`Также удалить статистику`) и бэкапы (`Также удалить бэкапы`)

Для удаления защищённого уровня пароль не нужен
