## バージョン

製品ごとに、文字のプレフィックスが付いた独自のバージョンがあります。形式はどれも`major.minor.revision`です：

| プレフィックス | 意味 | 製品 |
|---|---|---|
| `gv` | `game version` | ゲーム（クライアント） |
| `sv` | `sdk version` | SDK |
| `bv` | `backend version` | バックエンド、サーバー |
| `fv` | `frontend version` | Webサイト |
| `mg` | `model generation` | データ |

表記は`gv 1.0.0`、`sv 1.0.0`、`bv 1.0.0`、`fv 1.0.0`、`mg 1`のようになります

詳しくは[[5_versioning]]を参照してください
