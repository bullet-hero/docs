# gv 1.2.0

에디터의 동영상 내보내기, 파일 하나로 하는 프로필 이전, 레벨 목록 필터, Discord에 표시되는 활동

## 동영상 내보내기

- `레벨 설정` 옆 열의 `동영상 내보내기`는 레벨을 동영상으로 렌더링합니다. 같은 명령이 명령 팔레트에도 있습니다
- 컴퓨터에 ffmpeg `7.0` 이상이 설치되어 있어야 하며, 창이 스스로 찾습니다. Windows, macOS, Linux에서 작동하며, 휴대폰에서는 사용할 수 없습니다
- 프레임을 하나씩 렌더링하므로, 컴퓨터가 아무리 느려도 동영상은 정확합니다
- MP4, MKV, MOV, WebM, GIF, WebP, APNG, 이미지 시퀀스 또는 소리만. 720p부터 2160p까지 또는 7680까지의 임의 크기, 초당 1-240프레임
- 레벨은 봇이 플레이하며(`플레이 주체`), 그리드, 기즈모, 선택은 절대 프레임에 들어가지 않습니다

자세히 - [[18_video-export]]

## 프로필 이전

- `설정` → `기타` → `프로필 이전`은 프로필을 zip 파일 하나에 담습니다: 레벨, 통계, 설정, 라이브러리. 자동 저장, 오류 보고, 녹화는 체크하면 포함됩니다
- `가져오기`는 지금 있는 것을 교체하거나(`교체`) 거기에 추가합니다(`병합`). 병합은 레벨의 더 새로운 사본과 통계의 더 높은 수치를 남깁니다
- 가져오기로 교체된 것은 백업으로 남으며, `복원`으로 되돌릴 수 있습니다
- Windows, macOS, Linux, Android. iOS에서는 사용할 수 없습니다

자세히 - [[14_profile-transfer]]

## 레벨 목록

- `필터`는 더 많은 필터가 있는 창을 엽니다: AI 콘텐츠, 길이, 진행도, 최근 플레이, 연령 등급, 비밀번호가 있거나 더 새로운 버전에서 만든 레벨, 그리고 포함하거나 제외할 태그
- `역순`은 정렬을 뒤집습니다
- 검색은 레벨 이름을 먼저, 그다음 제작자, 그다음 태그를 봅니다

자세히 - [[2_playing-levels]]

## Discord

- Steam 빌드는 게임에서 하고 있는 일을 Discord 프로필에 표시합니다: 메뉴, 에디터, 샌드박스 또는 레벨
- 레벨 이름은 공개된 레벨일 때만 표시됩니다: Steam 창작마당 아이템이나 게임과 함께 제공되는 레벨. 직접 만든 레벨과 편집 중인 레벨의 이름은 절대 표시되지 않습니다
- 같은 컴퓨터에서 Discord 앱이 실행 중일 때만 작동합니다. Discord 자체에서 숨길 수 있습니다

자세히 - [[game-privacy-policy#Discord Rich Presence]]

## 수정

- 설정에서 소리를 끄면 이제 정말로 레벨이 조용해집니다. 이전에는 다른 소리 설정만 회색으로 바뀌었습니다
- 게임을 닫기 직전에 바꾼 설정이 더 이상 사라지지 않습니다. 설정이 기록될 때마다 저장 아이콘이 나타납니다
- 설정이 열려 있는 동안 `Ctrl+S` 키는 설정을 저장합니다(`설정 저장`). 에디터에서는 여전히 레벨을 저장합니다
- 휴대폰에서 설정 행이 더 이상 저절로 첫 번째 옵션으로 튀지 않습니다
- 일부 이펙트가 화면에서 사라질 수 있었습니다. 이제는 그렇지 않습니다
