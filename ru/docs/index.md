## Версии

У каждого продукта своя версия с буквенным префиксом, каждая в виде `major.minor.revision`:

| Префикс | Расшифровка | Продукт |
|---|---|---|
| `gv` | `game version` | игра (клиент) |
| `sv` | `sdk version` | SDK |
| `bv` | `backend version` | бэкенд, сервер |
| `fv` | `frontend version` | сайт |
| `mg` | `model generation` | данные |

Пишется в формате - `gv 1.0.0`, `sv 1.0.0`, `bv 1.0.0`, `fv 1.0.0`, `mg 1`

Подробнее об этом читайте в [[5_versioning]]
