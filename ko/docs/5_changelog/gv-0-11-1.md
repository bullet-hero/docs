# gv 0.11.1

레벨을 .zip 형식으로도 옮길 수 있고, 타임라인에 사각형 선택 도구와 접기가 생겼으며, 대시는 거리에 따라 달라집니다

`gv 0.11.0` 버전은 없었습니다: `gv 0.10.1` 다음 번호는 바로 `gv 0.11.1` 버전이었습니다

- 레벨을 `.tar.gz`뿐 아니라 `.zip` 형식으로도 내보내고 가져올 수 있으며, 비밀번호도 쓸 수 있습니다. `.7z` 파일은 잘못 읽히는 대신 이름으로 인식되어 거부됩니다. 레벨 "패키지"는 이제 게임 어디에서나 아카이브라고 부릅니다(`레벨 아카이브`)
- 전체 거리보다 가까운 지점으로 대시하면 그만큼 짧은 대시가 됩니다: 이동 경로, 무적 시간, 쿨다운이 모두 짧아집니다. 전체 거리의 3분의 1보다 가까우면 대시가 아예 일어나지 않습니다
- 방향이 없는 대시는 일어나지 않습니다. 이전에는 고르지 않은 임의의 방향으로 날아갔습니다
- 대시는 매 프레임 조종되며, 완전한 대시 후의 무적 시간은 0.20초 대신 0.30초입니다. 이는 쿨다운과 같으므로, 쉬지 않고 대시하면 두 대시 사이에 정확히 한 프레임만 노출됩니다
- 타임라인 도구는 `선택`, `가장자리`, `가위`, 그리고 새로운 `사각형 선택`입니다. `사각형 선택`은 드래그한 사각형에 닿는 모든 클립을 선택에 추가합니다. `가장자리`와 `가위`의 이전 이름은 각각 Trim, Blade 도구였습니다
- `가위`로 프리팹 배치를 둘로 자를 수 있으며, 두 조각 모두 자른 지점부터 같은 템플릿을 계속 재생합니다
- 타임라인에서 하위 트리를 접을 수 있습니다: `선택` 도구로 클립을 더블 클릭하거나, 탭 행의 버튼, 계층 구조 행의 메뉴, `Ctrl+E` 키를 사용합니다. 접기는 레벨에 아무것도 기록하지 않으며 실행 취소 단계도 만들지 않습니다
- 이제 툴팁이 Unity 안에서 실행할 때뿐 아니라 출시된 게임에서도 나타납니다. 터치스크린에서는 길게 누르면 툴팁이 열립니다. 단축키가 있는 동작의 툴팁에는 현재 할당된 단축키가 표시됩니다
- 영어로만 되어 있던 텍스트 200개 이상이 번역되었습니다
