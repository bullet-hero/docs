# Contributor

Someone who fixes a text, updates an outdated fact or adds a translation in the open documentation repository

These pages cover how a page is laid out, how links and tags work, how translations are kept in step and the house style every page follows. Changes arrive as pull requests to [github.com/vertoker/bullet-hero-docs](https://github.com/vertoker/bullet-hero-docs)
