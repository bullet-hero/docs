# gv 0.13.3

手机上的内存处理（撤销历史的上限、对内存不足警告的响应、堵住的泄漏），以及两项预制件模式修复

- 新的编辑器设置`历史物体数`限制撤销历史在步数之外最多保存多少个物体。一次批量删除就是一步，其中可能有50,000个物体，这个上限针对的正是这种情况。手机默认最多保存200,000个，电脑没有上限。`0`取消上限
- 当Android或iOS发出内存不足警告时，游戏现在会响应。编辑器丢弃已经无法到达的历史分支，游戏则释放不再被任何东西使用的内容。以前没有人理会这个警告，唯一的结果就是系统关闭游戏
- 以前每次打开关卡，每张纹理都有两个材质一直留在内存中，直到会话结束。现在它们会在关卡关闭时释放
- 在编辑器中关闭关卡会释放关卡数据。以前这些数据会一直留在内存中，直到打开下一个关卡
- 玩完一个大型关卡后，如果为它预留的内存超过普通关卡的四倍，且下一个关卡用不到，游戏会把这部分内存归还
- Prefab时间轴不再在预制件模式中每次编辑后跳到最上面一行。它只在进入预制件模式时重置
- 预制件模板中没有指定父级的顶层物体，现在会适配模板的时间轴并跟随其锚点，与它在关卡中的副本一样。以前粘贴可能把它留在模板范围之外，编辑器显示的样子与实际播放不同
