# 版本0.5.3

全屏节拍窗口，可滑动和调整大小的面板，每个检视器字段都有重置按钮，并能清理旧的备份和统计数据

- 用`打开节拍窗口`以全屏方式打开节拍窗口。窗口中只有一个敲击区，两种结果并排：`由敲击创建`生成新的节拍段，`应用到选中项`为选中的节拍段重设速度。提交前可以预览这次敲击的结果，窗口打开期间关卡继续播放
- 编辑器设置中的`时间格式`决定时间轴标尺的计数方式：帧、时间码、带帧的时间码或`小节和节拍`。关卡本身不变
- 编辑器面板通过拖动手柄滑动打开和关闭，打开的面板可以拖宽。手机上的按钮更大
- 每个检视器字段都有一个带提示的`?`和一个重置按钮，每个分组的标题中也有同样的一对。重置分组是一步撤销
- `碰撞体跟随形状`：开启时，选择形状会同时设置相同的碰撞体，让判定框贴合轮廓
- 无需打开关卡，就能在关卡浏览器中删除它。`删除关卡`窗口在各处都一样
- 设置中的`存储`会删除已不存在的关卡的备份和统计数据，或者全部删除
- 视口网格在缩放时以10为整倍数改变格子大小，与Unity自己的场景网格一样
- 时间轴把大多数片段绘制为一个网格，而不是每个片段一个界面元素，在长关卡中开销更小
- 特效和音频效果的字段有了说明
