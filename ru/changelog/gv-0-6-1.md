# Версия 0.6.1

Кнопки выключения звука у ползунков громкости, запоминание размера окна, переключатель окна ошибок и исправление картинки в рамке после изменения размера окна

- У трёх ползунков громкости в настройках звука есть кнопка выключения звука. Повторное нажатие возвращает прежнюю громкость, пока игра запущена. Выключенный звук - это просто громкость 0, поэтому игра, закрытая без звука, и откроется без звука
- Окно, размер которого вы изменили вручную, сохраняет этот размер. Раньше следующее изменение любой настройки возвращало старый размер
- `Сообщать об ошибках` в разделе `Ошибки` настроек интерфейса. Включено - непойманная ошибка открывает окно отчёта поверх всего, что на экране. Выключено - она только пишется в лог, а отчёт собирается в любом случае
- Клик по ключу на таймлайне сразу открывает его вкладку в инспекторе
- Исправлено: после изменения размера окна уровень, который не просил боковых полос, мог показывать картинку в рамке посреди окна
