# gv 0.5.5

Acesso a pastas no Android, um botão de redefinir em cada aba das configurações e uma correção na configuração de resolução

- Android: o jogo abre pastas pelo seletor de pastas do sistema e só enxerga a pasta que você escolheu, então não precisa de permissão de armazenamento. `Acesso a pastas` nas configurações mostra cada pasta liberada, e `Revogar` remove o acesso sem excluir nada do que está dentro
- Cada aba das configurações tem o próprio botão de redefinir, que volta só aquela aba aos valores padrão
- Corrigido: a configuração de resolução não fazia nada se a janela tivesse sido redimensionada antes, à mão ou com Alt+Enter
- A lista de níveis ganhou um botão `Buscar de novo`
- As configurações do nível têm uma aba `Publicação`. Por enquanto ela diz `Em desenvolvimento`
