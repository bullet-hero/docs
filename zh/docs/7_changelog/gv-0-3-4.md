# 版本0.3.4

第一个时间轴、第一个检视器，以及直接在视口中选择物体

编辑器有了如今关卡制作所围绕的三个部件。在这个版本中它们都还是早期原型

- **时间轴**。显示帧编号，以及帧轴上关卡中的物体
- **检视器**。用于编辑物体属性的面板的第一个版本
- **选中项**。可以在视口中点选物体，选中项与物体层级共享

颜色也变了。带纹理的物体现在有四种颜色，每个角一种，并在它们之间以渐变过渡。为此，物体着色器改为基于标准URP *Unlit*着色器重写
