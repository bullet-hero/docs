# gv 0.9.0

체력과 실제 히트박스가 아바타 위에 바로 보이고, 더 새로운 버전의 레벨은 경고 후에 열립니다

- 아바타의 몸은 사각형 그리드이며, 체력을 잃으면 가장자리에서 중심 쪽으로 사각형이 떨어져 나갑니다. 좋지 않은 플레이는 막대가 아니라 플레이어 자신에게 드러납니다. 그래픽 설정의 `파편 효과` 항목으로 이 기능을 끌 수 있습니다: 그러면 몸은 사각형 하나가 되고 대신 어두워집니다
- 아바타의 점 링은 정확히 히트박스 위에 놓입니다: 너비 1유닛의 몸에 반지름 0.4. 실루엣은 히트박스였던 적이 없으며, 이제 히트박스의 실제 위치가 보입니다. 같은 링이 생명도 셉니다: 밝은 점은 남은 생명, 어두운 점은 소모한 생명입니다
- 인터페이스 설정의 `히트박스 링 불투명도` 항목은 링이 얼마나 잘 보이는지 정하며, 기본값은 0.6입니다. 0 값은 링을 끄지만, 레벨은 링이 보이는 플레이어를 기준으로 설계됩니다
- 체크포인트에 `체력 회복` 설정이 생겼습니다: 레벨이 체크포인트를 지나는 순간 생명이 다시 채워집니다
- 더 새로운 버전에서 만든 레벨은 레벨 브라우저에서 `새 버전` 표시가 붙고 경고 후에 열립니다. 읽는 동안 무언가를 바꿔야 했다면, 게임은 먼저 백업을 쓰고 몇 개를 바꿨는지 알려 줍니다
- `반복` 설정이 꺼진 이펙트는 켜졌을 때보다 훨씬 적은 파티클을 방출해서, 색상 그레이디언트가 작동하지 않는 것처럼 보였습니다. 이제 한 번만 재생되는 이펙트도 반복 이펙트가 유지하는 만큼의 파티클을 방출합니다
