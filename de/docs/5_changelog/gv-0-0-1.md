# gv 0.0.1

Der erste Rendering-Test: viele Objekte über Unity Entities, und es läuft schon auf Android

Drei Tage nach dem Start bekam das Projekt seine technische Grundlage. Objekte werden über *Unity Entities* (ECS) gezeichnet, und das Spiel steht bis heute auf diesem Ansatz. Die Testszene füllt den Bildschirm mit Objekten und ändert ihre Farben, und die Zeichenreihenfolge ergibt sich aus der Tiefe jedes Objekts

- Der Test-Build läuft schon auf Android
- Das Datenmodell des Levels wanderte in ein eigenes Plugin, das künftige SDK
- Die ersten Sprites (Formen, Icons der Oberfläche, Skins) wurden aus einem älteren Projekt übernommen

Gleichzeitig wurde eine eigene Render-Pipeline erwogen und verworfen: Das Standard-*URP* reichte aus
