# gv 0.16.1

化身的行走速度从每秒10个单位提高到15个单位，最短的冲刺等于一个化身身体的长度

- 行走速度为每秒15个单位，而不是10个。化身从屏幕顶部走到底部只需三分之二秒，而不是一秒。用光标操控时，化身以行走速度追赶指针，所以急速移动后的滞后缩短了三分之一。速度为10时，在需要精确的地方会感觉很慢
- 冲刺和击退仍为每秒50个单位，所以两者现在是行走速度的3.3倍，而不是5倍
- 最短的冲刺是一个化身身体，0.5个单位。比这更近的目标完全不会触发冲刺。没有这个门槛时，紧贴化身的光标每隔一帧就会触发一次冲刺，每次都有自己的轨迹、音效和统计记录

化身的所有数值都集中在一个页面上：[[6_avatar]]
