# 问题排查

关卡不在列表中、无法加载、要求更新游戏或输入密码，或者归档包被游戏拒绝时该怎么办

你的问题不在这里？去哪里报告：[[11_help]]

## 关卡不在列表中

- **手动复制的关卡**。关卡文件夹必须直接放在`levels`中，[[1_installation]]。复制后按`重新扫描`
- **创意工坊物品**。Steam版本只列出你的订阅。`设置`→`常规`→`显示所有找到的内容`会加入在硬盘上找到的文件夹，它们会标有`未订阅`
- **列表完全为空**。关卡文件夹可能无法访问。此时`其他`中的存储清理不会运行，并提示`关卡扫描没有找到任何内容，因此已拒绝此次清理`

## 关卡无法加载

加载界面会显示当前阶段：`读取关卡`、`检查关卡`、`加载资源`、`构建关卡`

- **网址上的文件**。关卡可以通过链接获取文件，而不是把文件放在自己的文件夹里。`常规`→`资源网络超时`是游戏等待这类文件的秒数
- **损坏的关卡**。`Json`格式的关卡是文本，可以直接阅读。损坏的`Blob`会被整个拒绝。更多：[[4_level-folder-and-backups]]
- **错误窗口**。窗口中有`复制`、`保存报告`和`打开报告文件夹`。报告会保存到`reports`文件夹。把它附在[bullet-hero/releases](https://github.com/bullet-hero/releases/issues)的bug报告中，[[11_help]]
- **`关卡每帧需要的物体数超过此设备的上限`**。这不是加载失败。关卡可以游玩，但有一部分不会被绘制。更多：[[1_level-budget]]

## “需要更新”

旧版本的游戏不会打开新版本的文件。请更新游戏

| 提示 | 怎么做 |
|---|---|
| `这个关卡由更新版本的游戏制作...` | 更新游戏 |
| `这个归档包中的关卡来自更新版本的游戏...` | 更新游戏 |
| `剪贴板中的编辑器内容是在更新版本的游戏中复制的...` | 更新游戏 |
| `你的设置或统计由更新版本的游戏保存...` | `下载`、`继续停用存档`或`覆盖数据` |

标有`版本较新`或`来自更新版本的游戏`的卡片也是同样的拒绝，只是在你打开关卡之前就显示出来

### 来自更新版本的设置或统计

这种情况下游戏使用默认值运行。在关闭之前，它不保存任何自己的数据，更新版本的文件也不会被改动。这就是匿名模式，[[4_settings]]。使用`--suppress-game-saves`时没有`覆盖数据`按钮

来自更新版本的关卡统计不会显示。游玩这个关卡会覆盖它们，除非存档被停用

### 游戏为什么拒绝

文件格式的每次改动都会得到一个新的代数编号。构建版本不会读取更新一代的文件，这样就不会读错

## 受保护的关卡

打开之前，游戏会要求输入`密码`。每次会话只询问一次密码，而且只保存在内存中

只有内容是加密的：物体、关键帧、主题。名称、封面和媒体文件仍然可读，所以不输入密码也能显示卡片

删除受保护的关卡不需要密码

> [!caution] 注意
> 忘记的密码无法找回。密钥不保存在任何地方：游戏里没有，文件里没有，也不会发送到任何地方

## 归档包被拒绝

| 提示 | 原因 |
|---|---|
| `此版本暂时无法读取该归档包格式` | 是`.7z`文件。请重新打包为`.zip` |
| `密码错误` | 密码不匹配 |
| `文件已损坏` | 归档包已损坏，请让对方重新发送 |
| `不是关卡归档包` | 这个文件根本不是关卡归档包 |

改过扩展名的归档包没有问题：游戏根据文件的字节判断格式。哪些归档包可以接受：[[2_playing-levels]]
