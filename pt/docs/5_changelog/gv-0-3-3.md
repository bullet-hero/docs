# gv 0.3.3

Um shader rápido e uma câmera do editor que se move com o mouse ou com dois dedos

- **Um shader novo para os objetos do nível.** Ele tem uma só passada e apenas o que o desenho precisa, e roda cerca de duas vezes mais rápido que o antigo
- **A câmera do editor.** No PC ela se move com o mouse, no celular com dois dedos. Um botão separado a traz de volta para o foco
- **Texturas.** Agora qualquer textura do jogo ou do nível pode ser aplicada a um objeto pelas próprias coordenadas UV
- **O visualizador de logs.** A primeira versão de um painel que mostra as mensagens do editor
